# 지그재그 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 2023년 11월께 iOS 앱 주문·결제 흐름 화면 8장(서로 다른 화면 7종) + 2025년 여름 할인 행사 기간 홈 1장(어두운 화면)·검색 시작 1장, 375pt 폭 1배율 이미지(검색 1장은 393pt 기기를 430px로 담은 이미지)에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

## 1. 개요
- 서비스 성격: 카카오스타일이 운영하는 여성 패션 쇼핑 앱. 여러 쇼핑몰·브랜드 상품을 한 앱에서 모아 사고, 한 번에 결제한다. 화면 하단 법적 고지에서 운영사 이름을 확인했다.
- 디자인 인상 한 줄: 흰 바탕과 진한 회검정 글자 위에 분홍(#e976dd) 하나로 혜택과 행동을 칠한다. 상단 바만 검정에 가까운 어두운 띠다.
- 공식 시스템 이름: 확인 필요 (공개 문서·공개 코드를 찾지 못했다)
- 특징
  - 강조색은 분홍 하나다. 결제·쿠폰 받기 버튼, 쿠폰 금액, 할인율, 총 결제 금액, 선택된 라디오·체크, 진행 막대에 쓴다.
  - 주요 버튼은 화면 폭을 꽉 채운 알약 모양(높이 50pt, 완전히 둥근 모서리)이다. 분홍 버튼과 검정 버튼 두 가지가 있다.
  - 상단 바는 어두운 회검정(#1a1a1a) 바탕에 흰 제목과 왼쪽 닫기(X) 아이콘이다. 주문·결제 흐름이 모달처럼 열린다.
  - 구획 사이는 8pt 높이의 연회색 띠(#f5f6f8)로 나누고, 같은 구획 안 줄은 1pt 선으로 나눈다.
  - 글자는 순검정이 아니라 푸른 기가 도는 회검정(#242628)이다. 회색 글자도 푸른 회색 계열(#6a7174)이다.
  - 카드·입력창은 8pt 모서리, 버튼·칩은 완전히 둥글게. 각진 요소는 작은 기한 배지(D-5) 정도뿐이다.
  - 홈 캡처는 바탕까지 어두운(#181818) 화면이다. 다크 모드인지 할인 행사 기간 테마인지는 확인 필요. 어두운 화면에서 분홍은 조금 밝은 #f55dd6으로 보인다.
  - 검색 시작 화면은 흰 바탕에 연회색 알약 검색창, 옅은 파랑(#f4f7ff) 알약 검색어 칩, 2열 순위 목록으로 구성된다.

## 4. 간격·레이아웃
- 기준 화면: 375pt 폭 아이폰(상태 표시줄 44pt + 상단 바 50pt = 어두운 띠 94pt).
- 화면 좌우 여백: 16pt. 카드, 입력창, 버튼 모두 16pt 안쪽에서 시작해 343pt 폭이다.
- 간격 단계(관찰, pt): 4, 8, 12, 16, 24
- 구획 사이: 8pt 회색 띠(#f5f6f8).
- 목록 줄 높이: 약 49pt, 줄 사이는 1pt 선.
- 쿠폰 카드 사이: 8pt. 카드 안쪽 여백 16pt.
- 하단 고정 버튼: 위에 1pt 구분선, 버튼은 화면 아래 홈 인디케이터 위에 16pt 여백으로 붙는다.
- 상품 가로 목록: 이미지 폭 104pt, 높이 124pt(약 5:6), 사이 8pt. 네 번째 카드가 오른쪽에 살짝 보인다.
- 두 버튼 나란히: 각 약 166pt, 사이 10pt.
- 홈 위쪽 구조: 상태 표시줄 → 로고 줄(오른쪽 날씨·검색·장바구니 아이콘) → 가로 탭(선택 탭 위에 작은 점) → 큰 배너(좌우 16pt 여백, 둥근 카드) → 원형 바로가기 줄(지름 약 52pt, 중심 사이 약 66pt).
- 홈 하단: 탭 바 바로 위에 혜택 진행 막대 판(막대 높이 약 6pt)이 붙는다. 하단 탭 바는 홈 인디케이터 포함 약 86pt, 5칸.
- 검색 시작 화면: 뒤로 + 알약 검색창(높이 약 32pt) + 이미지 검색 아이콘. 좌우 여백 16pt.
- 추천 검색어 칩: 높이 약 35pt, 칩 사이 약 8pt, 줄 사이 약 10pt.
- 순위 목록: 2열, 한 줄 간격 약 35pt.
- 그리드: 확인 필요

## 6. 주요 컴포넌트
### 버튼
- 분홍 주요 버튼: 폭 343pt, 높이 50pt, 완전히 둥근 모서리, 흰 15pt 굵은 글자. 결제, 쿠폰 모두 받기처럼 화면의 마지막 행동에 쓴다.
- 검정 주요 버튼: 같은 크기·모양에 #121313 바탕. 적용·계속 같은 확정 행동에 쓴다.
- 외곽선 버튼: 흰 바탕 + 1pt #d2d5d6 테두리 + 진한 글자, 높이 약 44pt 알약. 검정 버튼 왼쪽에 짝으로 둔다.
- 분홍 외곽선 칩: 높이 약 24pt 알약, 1pt 분홍 테두리 + 분홍 12pt 글자. 쿠폰 카드 오른쪽 위.
- 회색 칩 버튼: #f5f6f8 바탕 알약, 높이 약 32pt, 13pt 진한 글자. 입력창 오른쪽 "전액 사용" 같은 보조 행동.
- 텍스트 링크: 분홍 글자 + `>`.

### 칩
- 추천 검색어 칩: #f4f7ff 바탕 알약, 높이 약 35pt, 12pt 진한 글자. 첫 칩만 파랑 글자(#2358c2).
- 홈 필터 칩(어두운 화면): 선택은 #d9dcde 바탕 + 어두운 글자, 나머지는 어두운 바탕 + 1pt 테두리. 아래쪽이 캡처에서 잘려 높이는 확인 필요.

### 입력창
- 흰 바탕, 1pt #e8e9eb 테두리, 8pt 모서리, 높이 40~42pt, 안쪽 여백 약 12pt.
- 검색창: 테두리 없는 #f5f6f6 알약, 높이 약 32pt, 안에 회색 안내 글자와 오른쪽 검정 돋보기. 왼쪽에 뒤로 꺾쇠, 오른쪽 바깥에 이미지 검색 아이콘.
- 숫자 입력은 오른쪽 정렬이고, 오른쪽 끝에 회색 원형 지우기 버튼과 단위 글자를 붙인다.
- 선택 상자(드롭다운): 같은 모양에 오른쪽 검정 삼각형.
- 라디오: 지름 약 22pt. 선택 안 됨은 회색 1pt 테두리, 선택은 분홍 채움 + 가운데 흰 점.
- 체크: 분홍 원 안의 흰 체크(전체 동의), 하위 항목은 테두리 없는 분홍 체크 표시만.

### 카드·리스트
- 쿠폰 카드: 흰 바탕, 1pt 회색 테두리, 8pt 모서리. 위에서부터 분홍 큰 금액 → 굵은 쿠폰 이름 → 회색 조건 → 회색 기한. 오른쪽 위에 분홍 외곽선 칩.
- 선택된 쿠폰 카드: 테두리가 분홍으로 바뀌고 금액 앞에 분홍 원형 체크가 붙는다. 아래에 연분홍 기한 배지.
- 목록 줄: 왼쪽 라벨, 오른쪽 값, 1pt 선으로 구분. 하위 항목은 들여 쓰고 회색 작은 글자.
- 합계 줄: 왼쪽 굵은 라벨, 오른쪽 분홍 22pt 굵은 금액.
- 상품 카드(작게): 8pt 모서리 이미지 → 쇼핑몰 이름 12pt 굵게 → 상품명 13pt 한 줄 말줄임 → 분홍 할인율 + 진한 가격(16pt 굵게) → 회색 별점. 쿠폰가 상품은 분홍 작은 라벨과 회색 취소선 원가를 위에 더한다. 무료배송 같은 회색 작은 칩이 붙기도 한다.
- 이미지 위 배지: 보라 알약 배지(흰 글자)를 왼쪽 아래에 둔다.
- 원형 바로가기(홈): 지름 약 52pt 원 안에 로고·사진, 오른쪽 위 빨간 새 소식 점, 아래 12pt 이름. 가로 스크롤.
- 검색 순위: 2열 4줄씩, 번호 + 검색어 + 오른쪽 변동 표시(빨간 위 삼각형, 회색 –). 오른쪽 위 연령 선택 + 아래꺾쇠. 아래 쪽 표시 점 3개.
- 혜택 진행 막대 판(홈): 하단 탭 바 위에 붙은 판. 회색 막대 위를 분홍으로 채우고, 아래 "○원 더 담으면 ○% 할인" 꼴 문장, 오른쪽 끝에 목표 금액 표시.

### 상단 바·탭 바
- 상단 바: #1a1a1a 바탕, 높이 50pt, 가운데 흰 17pt 굵은 제목, 왼쪽 흰 닫기(X) 아이콘.
- 진행 막대: 주문 완료 화면 상단 바 바로 아래 4pt 높이 분홍 막대.
- 펼침 머리: 왼쪽 굵은 제목 + 옅은 개수, 오른쪽 분홍 요약 금액 + 위·아래 꺾쇠.
- 홈 상단 가로 탭: 16pt, 선택 탭은 밝은 굵은 글자 + 글자 위 작은 점, 나머지는 회색. 맨 앞 행사 탭은 빨간 글자(기획전 테마).
- 하단 탭 바(홈, 어두운 화면): 5칸(홈·스토어·카테고리·찜·마이페이지), 아이콘 + 11pt 이름. 선택된 홈은 밝은 사각 아이콘 상자. 위에 1pt 선. 결제 흐름에서는 숨겨진다. 밝은 화면의 탭 바는 확인 필요.

### 바텀시트·모달
- 주문·결제 흐름 전체가 닫기(X) 상단 바를 가진 전체 화면 모달로 열린다.
- 바텀시트: 캡처에 없음. 확인 필요.

### 토스트·스낵바
- 캡처에 없음. 확인 필요.

## 7. 아이콘·이미지·모션
- 아이콘: 가는 선 아이콘(닫기, 꺾쇠, 다운로드 화살표). 다운로드 화살표는 분홍.
- 정보 아이콘: 회색 원 안 물음표, 구획 제목 옆.
- 홈 상단·탭 바 아이콘도 같은 굵기의 선 아이콘이다. 선택된 탭 바 아이콘만 채운 모양.
- 사진: 상품 사진을 8pt 모서리로 잘라 쓴다. 바탕 색은 사진마다 다르다.
- 모션: 캡처로 알 수 없음. 확인 필요.

## 8. 글쓰기 톤(UX 라이팅)
- 완료 안내는 해요체 한 문장("~되었어요" 꼴).
- 구획 제목은 짧은 명사(주문 상품, 할인 적용, 결제방식). 추천 줄 제목만 문장형 설명을 쓴다.
- 버튼은 "금액 + 동작" 꼴로 무엇이 일어나는지 숫자로 보여 준다("○원 할인 적용", "○개 전체받기").
- 금액은 숫자 + "원", 포인트·마일리지는 단위 글자(P, M)를 붙인다.
- 안내 문단은 앞에 작은 점(·)을 두고 회색 작은 글자로 쓴다.

근거와 한계
- 지그재그는 공개 디자인 시스템 문서나 코드를 찾지 못했다. 모든 값은 앱 캡처 실측이다.
- 결제 흐름은 쿠폰 기한으로 보아 2023년 11월께 화면이다. 홈·검색은 할인 행사 이름과 문구로 보아 2025년 여름 화면이다. 두 시기 사이에 앱이 바뀌었을 수 있다.
- 홈은 행사 이름 워드마크와 '직잭' 표시, 하단 탭 바 앱 아이콘으로 지그재그 화면임을 확인했다. 검색 화면은 행사 이름이 들어간 배너·검색어로 확인했다.
- 같은 묶음의 검색 화면 2장은 하단 탭 구성(가운데 '플레이' 버튼, '하트' 탭)과 검색창 모양이 이 앱과 달라 다른 앱으로 보고 뺐다. 다른 1장은 다른 쇼핑 앱(EQL) 화면이라 뺐다.
- 캡처가 375pt 1배율이라 크기는 ±1pt, 작은 글자 색은 오차가 있다. 검색 화면은 430px를 393pt로 환산해 오차가 더 있다. 넓은 면 색(분홍 버튼, 상단 바, 회색 띠, 어두운 바탕)은 정확하다.
- 카테고리, 검색 결과 목록, 상품 상세, 밝은 화면의 홈·하단 탭 바는 확인하지 못했다. 어두운 홈이 다크 모드인지도 확인 필요.
- 화면 속 이름·주소·금액·주문 내역은 옮기지 않았다.

서비스 이름과 브랜드는 각 권리자의 것이다. 이 문서는 식별·학습용 참고 자료로 SylviaLab이 독자적으로 작성했다.
