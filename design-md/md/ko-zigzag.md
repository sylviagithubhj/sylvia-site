## 1. 개요와 원칙
- 서비스 성격: 카카오스타일이 운영하는 여성 패션 쇼핑 앱. 여러 쇼핑몰·브랜드 상품을 한 앱에서 모아 사고, 한 번에 결제한다. 화면 하단 법적 고지에서 운영사 이름을 확인했다.
- 디자인 인상 한 줄: 흰 바탕과 진한 회검정 글자 위에 분홍(#e976dd) 하나로 혜택과 행동을 칠한다. 상단 바만 검정에 가까운 어두운 띠다.
- 공식 시스템 이름: 공개된 이름 없음 (공개 문서·공개 코드를 찾지 못했다)
- 디자인 원칙(공식 원칙은 찾지 못했다):
  1. 강조색은 분홍 하나다. 혜택(쿠폰 금액, 할인율, 총액)과 마지막 행동(결제 버튼)을 같은 색으로 묶는다. (관찰에서 정리)
  2. 버튼과 칩은 완전히 둥글게, 카드와 입력창은 8pt로. 각진 요소는 작은 기한 배지뿐이다. (관찰에서 정리)
  3. 면은 그림자 대신 8pt 회색 띠와 1pt 연회색 선으로 나눈다. (관찰에서 정리)
  4. 글자는 순검정이 아니라 푸른 기가 도는 회검정(#242628)과 푸른 회색(#6a7174)을 쓴다. (관찰에서 정리)
  5. 버튼 문구에 금액·개수를 넣어 누르면 무엇이 일어나는지 숫자로 보여 준다. (관찰에서 정리)
- 톤: 밝고 가볍게, 혜택은 분홍으로 눈에 띄게.

### 특장점
- 혜택과 행동을 한 색으로 묶는다 — 분홍 #e976dd 하나가 결제 버튼, 쿠폰 금액, 할인율, 총 결제 금액, 선택된 라디오·체크, 진행 막대에 모두 쓰여, 분홍만 따라가면 "얼마 아끼고 어디를 누르는지"가 보인다.
- 결제 흐름을 어두운 상단 바 모달로 분리한다 — #1a1a1a 상단 바(50pt, 흰 17pt 제목, 왼쪽 X)가 주문·결제 화면 전체를 감싸 흰 본문 쇼핑 화면과 구별된다.
- 그림자 없이 띠와 선만으로 면을 나눈다 — 구획 사이 8pt #f5f6f8 띠, 줄 사이 1pt 선, 카드는 1pt #e8e9eb 테두리뿐이다.
- 버튼 문구가 숫자로 결과를 말한다 — "○원 할인 적용", "○개 전체받기"처럼 금액·개수를 버튼에 넣는다.
- 장바구니 금액을 하단에서 계속 보여 준다 — 홈 하단 탭 바 위 혜택 진행 막대 판이 "○원 더 담으면 ○% 할인"과 분홍 채움 막대로 목표까지 남은 금액을 보여 준다.

### 배울 점
- 할인과 주요 행동이 많은 쇼핑 화면을 만들 때 지그재그처럼 강조색을 하나만 정해 혜택 숫자와 마지막 버튼에만 칠한다.
- 결제처럼 집중이 필요한 흐름을 열 때 어두운 상단 바 + 닫기(X) 전체 화면 모달로 둘러 일반 화면과 구분한다.
- 버튼 문구를 쓸 때 "○원 할인 적용"처럼 금액이나 개수를 넣어 누른 뒤 결과를 미리 알린다.

### 이 문서를 읽는 AI 에이전트에게
- 색·크기는 YAML 토큰 이름으로만 쓴다. 관찰 팔레트(`gray-600`)보다 역할 이름(`text-secondary`)을 먼저 쓴다.
- 분홍 `primary`는 결제·쿠폰 버튼, 쿠폰 금액·할인율·총액, 선택 표시, 진행 막대에만 쓴다. 다른 강조가 필요하면 검정 버튼(`ink-button`)이나 회색 칩을 고른다.
- 면을 나눌 때 그림자를 쓰지 않는다. 8pt `section-divider` 띠나 1pt `border` 선을 쓴다.
- 모든 값은 앱 캡처 실측(±1pt)이다. 표에 `확인 필요`로 남은 상태(눌림·비활성·오류)는 만들어 넣지 말고 비워 둔다.
- 판단이 어려우면 둥근 쪽(버튼·칩 999px), 16pt 좌우 여백, 분홍을 덜 쓰는 쪽을 고른다.

## 2. 색상
값은 1배율 캡처 픽셀에서 읽었다. 넓은 면 색은 정확하고, 작은 글자 색은 글자 테두리 번짐 때문에 오차가 있다. 토큰 이름은 SylviaLab이 붙인 것이다.

### 색 체계
공식 팔레트는 공개되지 않았다. 캡처에서 반복되는 값을 **관찰 팔레트**로 모으고, 그 위에 **역할 이름**을 붙였다(관찰에서 정리).

| 층 | 예시 이름 | 쓰는 곳 |
|---|---|---|
| 관찰 팔레트 | `pink-500`, `gray-100`~`gray-900`, `ink-950` | YAML 정의에만. 밝을수록 숫자가 작다 |
| 역할 이름 | `primary`, `text-secondary`, `section-divider`, `border-strong` | 화면과 컴포넌트 |
| 상황 색 | 어두운 홈 `-dark`, 기획전 테마 | 해당 화면에서만 |

- 회색은 모두 푸른 기가 도는 한 계열이다. 바탕 쪽(50~300)은 면·선, 글자 쪽(400~900)은 안내·보조·본문 글자로 나뉜다.

### 역할별 색
- 분홍 `primary`: 결제·쿠폰 받기 버튼 면, 쿠폰 금액·할인율·총 결제 금액 글자, 선택된 라디오·체크 채움, 선택된 쿠폰 카드 테두리, 진행 막대. 눌림·비활성 짝은 확인 필요.
  - 연한 짝: 기한 배지 바탕 `primary-soft` + 글자 `primary-soft-text`.
- 검정 `ink-button`: 적용·계속 같은 확정 행동 버튼. 분홍 버튼과 모양이 같다.
- 어두운 띠 `header`: 결제 흐름 상단 바와 상태 표시줄. 글자는 `on-header`.
- 회색 면: 안내 상자 `surface-subtle`, 구획 띠·회색 칩 `section-divider`.
- 회색 선: 카드·입력창 `border`, 외곽선 버튼·빈 라디오 `border-strong`.
- 글자 다섯 단계: 본문 `text-primary` → 진한 회색 `text-strong-gray` → 보조 `text-secondary` → 안내 문단 `text-note` → 법적 고지 `text-muted`, 그리고 입력 안내 `text-placeholder`.
- 기능 색: 보라 배송 배지, 빨강 순위 상승·새 소식 점. 각자 한 곳에만 쓴다.
- 성공·주의·오류 상태 색: 캡처에 없음(확인 필요).

## 4. 레이아웃·간격
- 간격 단계(관찰, pt): 4, 8, 12, 16, 24
- 기준 화면: 375pt 폭 아이폰(상태 표시줄 44pt + 상단 바 50pt = 어두운 띠 94pt).
- 화면 좌우 여백: 16pt. 카드, 입력창, 버튼 모두 16pt 안쪽에서 시작해 343pt 폭이다.

|---|---|---|
| 기기 폭 | 375pt | 검색 화면은 393pt 기기 |

| 구간 | 값 |

### 화면 구조
- 홈 위쪽: 상태 표시줄 → 로고 줄(오른쪽 날씨·검색·장바구니 아이콘) → 가로 탭(선택 탭 위에 작은 점) → 큰 배너(좌우 16pt 여백, 둥근 카드) → 원형 바로가기 줄.
- 홈 하단: 탭 바 바로 위에 혜택 진행 막대 판(막대 높이 약 6pt)이 붙는다.
- 검색 시작 화면: 뒤로 + 알약 검색창(높이 약 32pt) + 이미지 검색 아이콘. 좌우 여백 16pt.

### 간격 적용 규칙
- 모든 카드·입력창·버튼은 좌우 16pt 안쪽에 343pt 폭으로 놓는다.
- 서로 다른 구획 사이는 8pt #f5f6f8 띠, 같은 구획 안 줄 사이는 1pt 선이다.
- 쿠폰 카드·상품 카드·칩 사이는 8pt, 카드 안쪽 여백은 16pt.
- 버튼 두 개를 나란히 둘 때는 사이 10pt로 반씩 나눈다.
- 하단 고정 버튼은 홈 인디케이터 위 16pt에 두고, 위에 1pt 선을 긋는다.

### Don't
- 좌우 여백을 16pt 밖의 값으로 바꾸지 않는다.
- 구획 사이를 빈 여백만으로 띄우지 않는다. 8pt 회색 띠를 넣는다.
- 같은 구획 안 줄 사이에 8pt 띠를 쓰지 않는다. 줄 사이는 1pt 선이다.
- 카드 사이를 8pt보다 넓게 벌리지 않는다.

## 5. 모서리·고도·모션
1pt = CSS 1px로 본다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| radius-xs | 2px | 기한 배지(D-5) |
| radius-md | 8px | 쿠폰 카드, 입력창, 선택 상자, 안내 상자, 상품 이미지 |
| radius-full | 999px | 주요 버튼, 외곽선 버튼, 회색 칩, 분홍 외곽선 칩, 보라 배송 배지, 라디오, 검색창, 추천 검색어 칩, 홈 필터 칩, 원형 바로가기 |

- 규칙: 누르는 것(버튼·칩·검색창)은 999px, 담는 것(카드·입력창·이미지)은 8px, 아주 작은 표시(기한 배지)만 2px. (관찰에서 정리)
- 테두리: border 1px #e8e9eb(카드, 입력창), border-strong 1px #d2d5d6(외곽선 버튼, 선택 안 된 라디오), border-selected 1px #e976dd(선택된 쿠폰 카드, 분홍 외곽선 칩).

### 고도
- 본 화면에서는 그림자를 찾지 못했다(shadow 확인 필요). 층은 면 색으로 나눈다: 흰 면 → #fafafb 안내 상자 → #f5f6f8 띠.
- 결제 흐름은 어두운 상단 바(#1a1a1a)로 "한 층 위" 화면임을 표시한다.

### 모션
- 길이·이징: 캡처로 알 수 없음. 확인 필요.

### 아이콘·사진
- 아이콘: 가는 선 아이콘(닫기, 꺾쇠, 다운로드 화살표). 다운로드 화살표는 분홍. 정보 아이콘은 회색 원 안 물음표로 구획 제목 옆에 둔다. 홈 상단·탭 바 아이콘도 같은 굵기의 선 아이콘이고, 선택된 탭 바 아이콘만 채운 모양이다.
- 사진: 상품 사진을 8pt 모서리로 잘라 쓴다. 바탕 색은 사진마다 다르다.

### Don't
- 카드·버튼에 그림자를 넣지 않는다.
- 주요 버튼·칩을 8px이나 각진 모서리로 만들지 않는다. 999px이다.
- 카드·입력창을 알약(999px)으로 만들지 않는다. 8px이다.
- 2px 모서리를 기한 배지 밖에 쓰지 않는다.

**규칙** (관찰에서 정리)
- 분홍 버튼은 한 화면에 하나다(본 화면에서는 늘 하나). 보조 행동에는 분홍 대신 회색 칩이나 외곽선 버튼을 쓴다.
- 버튼 두 개는 왼쪽 외곽선, 오른쪽 검정으로 짝짓는다.
- 하단 고정 버튼은 1pt 선 위, 홈 인디케이터 위 16pt에 둔다.
- 문구는 "금액 + 동작" 꼴("○원 할인 적용", "○개 전체받기").
- 로딩 중에는 `aria-busy="true"`로 알리고 중복 결제를 막는다(구현 권장).

### 6.3 선택 컨트롤 (라디오·체크)

- 체크: 분홍 원 안의 흰 체크(전체 동의), 하위 항목은 테두리 없는 분홍 체크 표시만.
- 상태: 선택됨 / 선택 안 됨을 봤다. 비활성은 확인 필요.
- 규칙: 라디오 22pt는 44pt보다 작으므로 줄 전체(약 49pt)를 누름 영역으로 잡는다(구현 권장).

### 6.4 칩·탭
- 추천 검색어 칩: #f4f7ff 바탕 알약, 높이 약 35pt, 12pt 진한 글자. 첫 칩만 파랑 글자(#2358c2).
- 홈 필터 칩(어두운 화면): 선택은 #d9dcde 바탕 + 어두운 글자, 나머지는 어두운 바탕 + 1pt 테두리. 아래쪽이 캡처에서 잘려 높이는 확인 필요.
- 홈 상단 가로 탭: 16pt, 선택 탭은 밝은 굵은 글자 + 글자 위 작은 점, 나머지는 회색. 맨 앞 행사 탭은 빨간 글자(기획전 테마).
- 상태: 선택 / 선택 안 됨만 봤다. 눌림·비활성은 확인 필요.
- 선택된 탭에는 `aria-selected="true"`(구현 권장).

### 6.5 카드·리스트
- 쿠폰 카드: 흰 바탕, 1pt 회색 테두리, 8pt 모서리, 안쪽 16pt. 위에서부터 분홍 큰 금액(20pt) → 굵은 쿠폰 이름(14pt) → 회색 조건 → 회색 기한. 오른쪽 위에 분홍 외곽선 칩.
- 선택된 쿠폰 카드: 테두리가 분홍으로 바뀌고 금액 앞에 분홍 원형 체크가 붙는다. 아래에 연분홍 기한 배지.
- 목록 줄: 왼쪽 라벨, 오른쪽 값, 1pt 선으로 구분. 하위 항목은 들여 쓰고 회색 작은 글자.
- 합계 줄: 왼쪽 굵은 라벨, 오른쪽 분홍 22pt 굵은 금액.
- 상품 카드(작게): 8pt 모서리 이미지 → 쇼핑몰 이름 12pt 굵게 → 상품명 13pt 한 줄 말줄임 → 분홍 할인율 + 진한 가격(16pt 굵게) → 회색 별점. 쿠폰가 상품은 분홍 작은 라벨과 회색 취소선 원가를 위에 더한다. 무료배송 같은 회색 작은 칩이 붙기도 한다.
- 원형 바로가기(홈): 지름 약 52pt 원 안에 로고·사진, 오른쪽 위 빨간 새 소식 점, 아래 12pt 이름. 가로 스크롤.
- 검색 순위: 2열 4줄씩, 번호 + 검색어 + 오른쪽 변동 표시(빨간 위 삼각형, 회색 –). 오른쪽 위 연령 선택 + 아래꺾쇠. 아래 쪽 표시 점 3개.
- 혜택 진행 막대 판(홈): 하단 탭 바 위에 붙은 판. 회색 막대 위를 분홍으로 채우고, 아래 "○원 더 담으면 ○% 할인" 꼴 문장, 오른쪽 끝에 목표 금액 표시.
- 상태: 쿠폰 카드는 기본 / 선택됨을 봤다. 나머지 상태는 확인 필요.
- 규칙: 카드에 그림자를 넣지 않는다. 구분은 1pt 테두리로 한다. 선택은 테두리 색(분홍)으로 표시한다.

## 9. 글쓰기 톤
- 말투: 완료 안내는 해요체 한 문장("~되었어요" 꼴). 구획 제목은 짧은 명사(주문 상품, 할인 적용, 결제방식). 추천 줄 제목만 문장형 설명을 쓴다.
- 버튼 문구 꼴: "금액 + 동작" 꼴로 무엇이 일어나는지 숫자로 보여 준다("○원 할인 적용", "○개 전체받기").
- 숫자·단위 표기: 금액은 숫자 + "원", 포인트·마일리지는 단위 글자(P, M)를 붙인다.
- 안내 문단은 앞에 작은 점(·)을 두고 회색 작은 글자로 쓴다.

## 10. Do & Don't
관찰 기반 문서의 규칙은 "이 서비스 화면에서 반복되는 규칙"을 SylviaLab이 정리한 것이다(공식 규칙 아님).

### Do
- 결제·쿠폰 받기 버튼은 폭 343pt, 높이 50pt, 999px 모서리, #e976dd 바탕에 흰 15pt 700 글자로 만든다.
- 쿠폰 금액, 할인율, 총 결제 금액은 #e976dd로 칠한다.
- 구획 사이는 8pt #f5f6f8 띠, 줄 사이는 1pt 선으로 나눈다.
- 카드·입력창은 8px 모서리에 1pt #e8e9eb 테두리를 둔다.
- 주문·결제 흐름은 #1a1a1a 상단 바(50pt, 흰 17pt 굵은 제목, 왼쪽 X)를 가진 전체 화면 모달로 연다.
- 버튼 문구에 금액이나 개수를 넣는다("○원 할인 적용").
- 화면 좌우 여백은 16pt로 맞춘다.

### Don't
- 분홍을 할인·혜택·주요 행동 밖의 장식에 쓰지 않는다.
- 글자에 순검정을 쓰지 않는다. 기본 글자는 #242628이다.
- 카드와 버튼에 그림자를 넣지 않는다.
- 주요 버튼을 각지게 만들지 않는다. 각진 요소는 2px 기한 배지뿐이다.
- 기획전 색(#ec3838, #c31e18)을 평소 화면에 섞지 않는다.
- 카카오페이 노랑(#f4e14a 부근)을 지그재그 브랜드색으로 쓰지 않는다.
