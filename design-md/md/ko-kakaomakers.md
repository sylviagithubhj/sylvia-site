> 근거: 관찰 기반 (앱 캡처: 2025년 여름쯤으로 추정되는 iOS 앱 화면 10장 — 홈 추천 2장, 랭킹 목록 2장, 카테고리 메뉴, 옵션 바텀시트, 주문서 3장, 결제 수단. 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

이 문서는 디자인 시스템의 다섯 층(원칙, 토큰, 컴포넌트, 사용 규칙, 구현·검증)을 한 파일로 줄인 요약이다. 맨 위 YAML은 도구와 AI가 그대로 읽는 값이고, 아래 글은 그 값을 언제·왜 쓰는지 설명한다.

## 1. 개요와 원칙
- 서비스 성격: 카카오가 운영하는 주문 생산형 커머스. 주문을 먼저 모은 뒤 만들어 보내는 방식이고, 사회 기여(임팩트)를 앞에 내세운다. 카카오톡 안과 단독 앱에서 쓴다.
- 디자인 인상 한 줄: 흰 바탕에 거의 검정(#1a1a1a) 글자, 행동은 산호빛 빨강(#ed554d) 하나. 결제 단계에서만 카카오 노랑이 나온다.
- 공식 시스템 이름: 공개된 이름 없음
- 공개 자료 상황: 카카오메이커스 전용 디자인 가이드, 디자인 토큰, UI 코드는 공개된 것을 찾지 못했다(확인 필요). 카카오 회사 브랜드와는 별개로, 이 문서는 카카오메이커스 앱 화면에서 잰 값만 적었다.
- 디자인 원칙(공식 원칙은 찾지 못했다):
  1. 주문 수가 핵심 정보다. 빨강(#ed554d)이 "주문하기" 버튼과 "○명 주문 중" 숫자를 함께 맡아 행동과 사회적 증거를 묶는다. (관찰에서 정리)
  2. 색은 흰색, #fafafa 한 단계 회색, #1a1a1a 검정으로 거의 끝낸다. 빨강은 하나뿐이다. (관찰에서 정리)
  3. 사진은 각지게, 버튼·입력창은 2~4pt로 거의 각지게, 칩만 완전히 둥글게 쓴다. (관찰에서 정리)
  4. 카카오페이 노랑은 결제 흐름 안에서만 쓴다. (관찰에서 정리)
  5. 그림자 없이 아주 옅은 회색 가는 선과 회색 띠로 나눈다. (관찰에서 정리)
- 톤: 차분한 흑백 위에 주문 수와 주문 버튼만 빨강으로 띄운다.

### 특장점
- 사회적 증거를 행동색으로 칠한다 — 랭킹 카드와 피드에서 "○명 주문 중", "○명이 주문했어요"가 주문하기 버튼과 같은 #ed554d 12pt 굵은 글자로 나오고, 할인율 표시는 보이지 않는다.
- 결제 색을 따로 떼어 둔다 — 노랑 두 가지(카카오페이 묶음 #ffeb00, 결제하기 버튼 #fed800)는 결제 수단·결제 버튼·켜진 체크박스에만 나오고 쇼핑 화면에는 없다.
- 흑백 위계가 촘촘하다 — 글자를 #1a1a1a → #4d4d4d(상품명) → #8a8a8a(판매가·라벨) → #b2b2b2(부제) → #c4c4c4(안내 문구) 다섯 단계로 나눈다.
- 각진 상품 사진과 알약 칩의 대비가 분명하다 — 사진·NEW 배지·결제 버튼은 0px, 버튼·입력창은 2px, 필터 칩은 999px 알약이다.
- 카테고리 메뉴가 2단 구조다 — 왼쪽 #fafafa 목록(폭 약 124pt)에서 선택 칸만 흰 바탕 + 3pt 빨강 막대, 오른쪽에 하위 항목을 나열한다.

### 배울 점
- 판매량이나 참여 수가 구매 이유가 되는 상품을 보여 줄 때 카카오메이커스처럼 "○명 주문 중" 숫자를 주문 버튼과 같은 색으로 칠한다.
- 외부 결제사 색을 써야 할 때 결제 단계에만 가두고, 쇼핑 화면은 흑백 + 행동색 하나로 둔다.
- 분류가 많은 메뉴를 만들 때 왼쪽 회색 목록 + 선택 칸 흰 바탕·색 막대 + 오른쪽 하위 목록 2단으로 나눈다.

### 이 문서를 읽는 AI 에이전트에게
- 색·크기는 YAML 토큰 이름으로만 쓴다. 관찰 팔레트(`gray-600`)보다 역할 이름(`text-secondary`)을 먼저 쓴다.
- 빨강 `primary`는 주문하기 버튼과 "○명 주문 중" 숫자, 하트, 선택 막대에만 쓴다. 할인율 강조에 쓰지 않는다.
- 노랑(`pay-yellow`, `checkout-yellow`)은 결제 단계 화면에서만 꺼낸다. 쇼핑 화면은 흑백 + 빨강 하나로 둔다.
- 모서리는 쓰임별로 고정이다: 사진 0, 버튼·입력 2~4, 칩 999px. 중간 값(8px 등)을 새로 만들지 않는다.
- 판단이 어려우면 더 각진 쪽, 회색 단계를 하나 더 흐리게 쓰는 쪽, 숫자(주문 수)를 앞에 두는 쪽을 고른다.

## 2. 색상
값은 1배율 캡처 픽셀에서 읽었다. 넓은 면 색은 정확하고, 작은 글자 색은 글자 테두리 번짐 때문에 몇 단계 오차가 있다. 토큰 이름은 SylviaLab이 붙인 것이다.

### 색 체계
공식 팔레트는 공개되지 않았다. 캡처에서 반복되는 값을 **관찰 팔레트**로 모으고 **역할 이름**을 붙였다(관찰에서 정리).

| 층 | 예시 이름 | 쓰는 곳 |
|---|---|---|
| 관찰 팔레트 | `red-500`, `ink-900`, `gray-50`~`gray-800`, `yellow-checkout` | YAML 정의에만. 회색은 숫자가 클수록 진하다 |
| 역할 이름 | `primary`, `text-secondary`, `surface-subtle`, `checkout-yellow` | 화면과 컴포넌트 |
| 결제 전용 | `pay-yellow`, `pay-chip`, `checkout-yellow` | 결제 흐름 안에서만 |

- 회색은 글자 다섯 단계(#1a1a1a → #4d4d4d → #8a8a8a → #b2b2b2 → #c4c4c4)와 면·선 단계(#fafafa, #f1f1f1, #f0f0f0, #ededed, #e7e7e7)로 나뉜다.

### 역할별 색
- 빨강 `primary`: 주문하기 버튼 면, "○명 주문 중"·"○명이 주문했어요" 숫자, 좋아요 하트, 카테고리 선택 막대, 새 소식 점, 필수 별표. 눌림·비활성 짝은 확인 필요.
- 검정 `ink`: 기본 글자와 함께 선택 표시(필터 칩 면, 탭 밑줄, 세그먼트 테두리, 하단 탭 아이콘)와 보조 버튼(쿠폰 선택·전체 사용), NEW 배지를 맡는다. 선택은 빨강이 아니라 검정이다.
- 면: 흰 바탕 위에 묶음은 `surface-subtle`(#fafafa) 한 단계만. 주문서 구획 사이만 `section-divider` 띠.
- 선: `border-hairline` 하나로 입력창·선택 상자·흰 버튼·칩 테두리를 모두 그린다.
- 결제: 카카오페이 묶음 `pay-yellow` + 혜택 알약 `pay-chip`, 결제 버튼·켜진 체크박스 `checkout-yellow`, 노랑 위 글자는 `on-yellow`(#1a1a1a).
- 보조 초록 `impact-green`: 임팩트 관련 칩·아이콘에서만 봤다.
- 성공·주의·오류 상태 색: 캡처에 없음(확인 필요).

### 고도
- 카드·버튼에 그림자는 보이지 않는다(shadow 확인 필요). 층은 면 색으로 나눈다: 흰 면 → #fafafa 묶음 → #ededed 띠.
- 맨 위로 버튼만 가는 테두리로 떠 보인다. 바텀시트는 검정 약 50% 막 위에 뜬다.

### 모션
- 길이·이징: 캡처로 알 수 없음. 확인 필요.

### 아이콘·사진
- 아이콘: 약 1.5pt 선 아이콘(검색, 장바구니, 뒤로, 홈). 하단 탭 선택 아이콘만 채운다. 필터 칩과 카테고리 대분류 앞에는 작은 컬러 그림 아이콘을 쓴다. 정보 아이콘은 선, 분류 아이콘은 그림으로 나눈다.
- 사진: 화면 대부분. 밝은 자연광 연출 사진이 많고, 사진 위에 글자를 바로 얹는 카드도 있다.

### Don't
- 상품 사진에 모서리를 주지 않는다. 홈 큰 카드 6pt만 예외다.
- 버튼·입력창을 알약(999px)으로 만들지 않는다.
- 카드·버튼에 그림자를 넣지 않는다. 떠 보이는 것은 맨 위로 버튼(가는 테두리)과 바텀시트(검정 약 50% 막)뿐이다.
- 결제하기 버튼에 모서리를 주지 않는다. 화면 폭 가득, 0px다.

| 회색 버튼 | gray-50 바탕 + 가는 테두리, 회색 글자 | 우편번호 검색 |
| 좋아요 버튼 | 약 70×35pt 흰 상자 + 가는 테두리, 하트 외곽선 + 숫자 | 피드 상품 아래 |
| 맨 위로 버튼 | 오른쪽 아래 떠 있는 흰 원(지름 약 45pt), 가는 테두리 + 위 화살표 | 긴 목록 |

- 상태: 기본만 봤다. 눌림 / 비활성 / 로딩은 확인 필요.

**규칙** (관찰에서 정리)
- 빨강 버튼은 주문하기에만 쓰고, 결제하기는 노랑 버튼으로 바꾼다. 쿠폰·포인트처럼 주문서 안 보조 행동에는 검정 버튼을 쓴다.
- 바텀시트 아래에는 흰(장바구니) 왼쪽, 빨강(주문하기) 오른쪽 두 버튼을 8pt 띄워 같은 크기로 둔다.
- 결제 버튼 바로 위에 회색 동의 안내 문장 한 줄을 둔다.
- 문구는 짧은 동사형(장바구니 담기, 주문하기, 결제하기).
- 맨 위로 버튼처럼 아이콘만 있는 버튼에는 `aria-label`을 단다(구현 권장).

### 6.2 입력창·선택 컨트롤
| 종류 | 높이 | 모서리 | 모양 |
|---|---|---|---|
| 입력창 | 약 36pt | 2px | 흰 바탕, 가는 회색 테두리, 안내 문구 #c4c4c4 12pt |
| 선택 상자 | 약 44pt | 2px | 회색 안내 문구 + 오른쪽 아래 꺾쇠 |
| 체크박스 | 약 17pt | 확인 필요 | 켜짐 #fed800 + 흰 체크, 꺼짐 #e7e7e7 |
| 수량 조절 | 약 28pt | 확인 필요 | − / 숫자 / + |

- 기본: 높이 약 36pt, 흰 바탕, 가는 회색 테두리, 모서리 2pt. 안내 문구는 gray-400 12pt.
- 라벨은 입력창 왼쪽 열에 두고, 필수 항목은 라벨 뒤 빨간 별표.
- 연락처는 세 칸으로 나누고 사이에 회색 "-".
- 숫자 입력(포인트): 왼쪽 원형 지우기 아이콘, 오른쪽 정렬 굵은 숫자 + 작은 회색 "원".
- 선택 상자: 높이 약 44pt, 회색 안내 문구 + 오른쪽 아래 꺾쇠.
- 체크박스: 약 17pt 네모. 켜지면 #fed800 바탕 + 흰 체크, 꺼지면 #e7e7e7.
- 상태: 빈 칸·값 있음·체크 켜짐/꺼짐을 봤다. 포커스·오류·비활성은 확인 필요.
- 규칙: 라벨은 왼쪽 열(14pt), 입력창은 82pt부터 오른쪽 여백까지. 필수 항목은 `aria-required="true"`도 단다(구현 권장).

### 6.3 칩·탭·세그먼트
- 필터 칩: 높이 약 34pt 알약. 선택은 ink 바탕 흰 글자, 나머지는 흰 바탕 + 가는 테두리 + 회색 글자. 칩 앞에 작은 컬러 아이콘이 붙는다.
- 홈 해시태그 칩: 높이 약 34pt 알약, 흰 바탕 + 가는 테두리, "#" 붙은 회색 12pt 글자. 일부 칩은 초록 테두리 + 원형 그림.
- 피드 해시태그: gray-200 바탕 작은 상자(높이 약 22pt), 10pt 회색 글자.
- 세그먼트(2칸): 높이 약 35pt, 화면 폭. 선택 칸은 흰 바탕 + 진한 글자, 나머지는 gray-50 바탕 + 회색 글자. 랭킹 화면은 선택 칸에 ink 테두리를 두르고, 주문서 화면은 가는 회색 테두리만 쓴다.
- 상단 탭: 가로 스크롤 글자 탭, 13pt. 선택 탭은 굵은 ink 글자 + 글자 폭만큼 2pt ink 밑줄. 새 소식은 탭 이름 오른쪽 위 작은 빨간 점.
- 상태: 선택 / 선택 안 됨만 봤다. 눌림·비활성은 확인 필요.
- 규칙: 선택은 검정(#1a1a1a) 면·밑줄·테두리와 굵기로 표시한다. 선택된 탭·칩에 `aria-selected`(구현 권장).

### 6.4 카드·리스트
- 홈 큰 카드: 사진이 카드 전체를 채우고, 아래쪽에 검정 20pt 제목 2줄과 12pt 설명 2줄을 사진 위에 바로 얹는다. 모서리 약 6pt.
- 피드 상품: 화면 폭 사진(모서리 없음) → 22pt 굵은 제목 → 13pt 회색 설명 3줄 → 해시태그 → 빨강 "○명 주문했어요" → 좋아요 버튼. 새 상품은 사진 왼쪽 위에 ink 바탕 흰 NEW 배지.
- 랭킹 상품 카드: 4:5 사진(모서리 없음), 왼쪽 위 흰 네모 순위 배지(약 20pt), 오른쪽 아래 반투명 흰 네모 안 하트 외곽선. 아래에 상품명 12pt 2줄 → 판매가 13pt 회색 → 빨강 "○명 주문 중" 12pt 굵게. 할인율 표시는 보이지 않는다.
- 목록 머리: 왼쪽 "○개의 제품"(숫자 굵게), 오른쪽 기준 시각 + 정보 아이콘(회색).
- 카테고리 메뉴: 왼쪽 gray-50 목록, 선택 칸은 흰 바탕 + 왼쪽 3pt accent-red 막대 + 굵은 글자. 오른쪽은 대분류 제목(작은 아이콘 + 굵은 글자 + `>`) 아래 하위 항목을 줄마다 나열하고, 대분류 사이를 가는 선으로 나눈다.
- 카테고리 상단 배너: 약 140×98pt 사진 + 굵은 제목 + 회색 부제, 가로 스크롤.
- 주문서 금액 표: 왼쪽 항목 이름(gray-800), 오른쪽 값(gray-500) 오른쪽 정렬. 마지막 "총 결제 금액"은 gray-50 띠(높이 약 48pt) 안에 굵게.
- 주문서 상품 묶음: 판매자 이름 줄 아래 진한 1pt 선, 썸네일(약 48pt, gray-100 바탕) + 굵은 상품명, 그 아래 gray-50 상자에 옵션·금액·수량.
- 쓰지 않는 때: 상품 사진에 모서리를 주지 않는다(홈 큰 카드 6pt만 예외). 카드에 그림자를 넣지 않는다.

### 6.5 상단 바·하단 탭 바
- 홈 상단 바: 왼쪽 kakaomakers 워드마크, 오른쪽 검색·장바구니 선 아이콘.
- 상세·주문서 상단 바: 왼쪽 뒤로·홈 아이콘, 가운데 제목, 오른쪽 검색(·장바구니). 아래 가는 회색 선.
- 하단 탭 바: 흰 바탕, 탭 5개(임팩트·카테고리·홈·좋아요·마이). 선 아이콘 약 20pt + 10pt 이름. 선택 탭은 채운 ink 아이콘 + 진한 이름. 좋아요 하트는 선택 여부와 관계없이 accent-red로 채워져 있다.
- 주문서 구획 머리: 15pt 굵은 제목 + 오른쪽 꺾쇠(접기·펼치기).

### 6.6 바텀시트·모달
- 옵션 선택 바텀시트: 위 두 모서리 12pt, 뒤는 검정 약 50% 막. 오른쪽 위 회색 X.
- 내용 순서: 회색 라벨 → 선택 상자 → 고른 옵션 묶음(gray-50, 상품명 밑줄 + 원형 지우기, 수량 조절 −/숫자/+ 약 28pt 높이, 오른쪽 금액) → 총 금액 줄 → 회색 안내 상자 → 흰·빨강 두 버튼.
- 상태: 옵션을 고른 상태만 봤다. 빈 상태·로딩은 확인 필요.
- 규칙: 시트 맨 아래는 항상 흰·빨강 두 버튼. 열리면 포커스를 시트 안으로 옮기고 X로 닫으면 되돌린다(구현 권장).

### 6.7 배지·토스트
- NEW 배지: ink 바탕 흰 11pt 굵은 글자, 모서리 0px, 사진 왼쪽 위.
- 랭킹 순위 배지: 흰 네모(약 20pt), 11pt 굵은 숫자, 모서리 0px.
- 새 소식 점: 빨강 작은 점, 탭 이름 오른쪽 위.
- 토스트·스낵바: 캡처에 없음. 확인 필요.

## 9. 글쓰기 톤
- 말투: 홈 구획 제목은 명사형 한 줄, 부제는 합니다체 한 문장으로 서비스 취지를 말한다. 상품 설명과 안내는 해요체가 많다. 입력 안내는 "~해 주세요", "○자 이내로 입력하세요" 꼴.
- 버튼 문구 꼴: 짧은 동사형(장바구니 담기, 주문하기, 쿠폰 선택, 전체 사용, 결제하기).
- 숫자·단위 표기: 쉼표 단위 구분, 금액 뒤 "원". 사회적 증거를 숫자로 앞에 둔다("○명 주문 중", "○명이 주문했어요", "○개의 제품").
- 상품명 앞에 대괄호 기획 이름을 붙인다([지역 기획명] 상품명).
- 해시태그(#)로 기획 묶음을 연결한다.

## 10. Do & Don't
관찰 기반 문서의 규칙은 "이 서비스 화면에서 반복되는 규칙"을 SylviaLab이 정리한 것이다(공식 규칙 아님).

### Do
- 상품 카드에는 판매가(13pt #8a8a8a) 아래 "○명 주문 중"을 12pt 굵은 #ed554d로 둔다.
- 주문하기 버튼은 #ed554d 바탕, 흰 15pt 굵은 글자, 높이 48pt, 모서리 2px로 만들고 왼쪽에 같은 크기 흰 장바구니 버튼을 8pt 띄워 둔다.
- 결제하기 버튼은 화면 폭 가득, 높이 약 42pt, #fed800 바탕, 모서리 0px로 둔다.
- 화면 좌우 여백은 14pt로 맞춘다.
- 선택된 필터 칩은 #1a1a1a 바탕 흰 글자 999px 알약으로 칠한다.
- 상품 사진은 모서리 없이 쓰고, 랭킹 카드는 4:5 비율로 자른다.
- 주문서 구획 사이는 약 6pt #ededed 띠로 나눈다.

### Don't
- 빨강 #ed554d를 장식·배경 면에 쓰지 않는다.
- 카카오페이 노랑(#ffeb00, #fed800)을 결제 흐름 밖에 쓰지 않는다.
- 버튼·입력창을 알약으로 만들지 않는다. 알약은 칩·혜택 알약·맨 위로 버튼·라디오뿐이다.
- 카드와 버튼에 그림자를 넣지 않는다.
- 랭킹 카드에 할인율을 크게 넣지 않는다. 본 화면에는 주문 수만 강조했다.
- 기본 글자를 순수 검정으로 칠하지 않는다. #1a1a1a를 쓴다.

## 13. 참고 자료
- 카카오메이커스 iOS 앱 화면 캡처 10장 (SylviaLab 벤치마킹 피그마 파일, 저장소에는 올리지 않음)
- 공개 URL: 이번 작업 환경에서 카카오메이커스 웹사이트와 앱스토어 페이지에 접속하지 못해 확인한 공개 URL이 없다(확인 필요).

근거와 한계
- 카카오메이커스 공개 디자인 시스템 문서나 코드는 찾지 못했다. 이 문서의 값은 모두 앱 캡처에서 잰 관찰값이다.
- 캡처 시기는 화면 속 상품 구성으로 보아 2025년 여름쯤으로 추정한다. 날짜는 캡처에 없다.
- 캡처가 375pt 1배율이라 크기는 ±1pt, 작은 글자 색과 가는 테두리 색은 오차가 있다. 넓은 면 색(흰색, #fafafa, #1a1a1a, #ed554d, 두 노랑)은 정확하다.
- 상품 상세 본문, 검색, 장바구니, 마이, 임팩트 탭, 주문 완료, 다크 모드 화면은 보지 못했다.
- 주문서 화면의 이름·주소·연락처 등 개인정보와 주문 금액은 옮기지 않았다.
- 결제 영역의 노랑은 카카오페이 결제 수단 표시이고, 카카오메이커스 자체 브랜드 색인지는 확인 필요다.
- 관찰 값은 서비스가 바뀌면 달라질 수 있다.

서비스 이름과 브랜드는 각 권리자의 것이다. 이 문서는 식별·학습용 참고 자료로 SylviaLab이 독자적으로 작성했다.

## 부록 B. 값의 출처 구분
- **공식 자료 그대로**: 없음. 카카오메이커스 전용 디자인 가이드·토큰·코드는 공개된 것을 찾지 못했다.
- **화면에서 잰 값(관찰)**: 모든 색 HEX, 글자 크기·굵기·행간(28·19·18pt), 좌우 여백 14pt, 간격(6·7·8·10·20pt), 버튼·입력창·칩·세그먼트·체크박스 높이, 모서리 0/2/4/6/12/999px, 랭킹 카드 171×214pt, 홈 큰 카드 202×270pt, 카테고리 목록 124pt. iOS 앱 캡처 10장(375pt 1배율), 실측일 2026-10-31. 바텀시트 막의 투명도(약 50%)는 바탕 색에서 거꾸로 추정한 값이다.
- **SylviaLab이 정리·권장한 것**: 토큰 이름 전체(관찰 팔레트 `gray-600` 등과 역할 이름), 디자인 원칙 5개, 각 장의 규칙과 Don't, 모서리 쓰임 규칙, `(구현 권장)`이 붙은 접근성 항목.
