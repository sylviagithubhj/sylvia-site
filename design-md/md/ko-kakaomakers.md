# 카카오메이커스 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 2025년 여름쯤으로 추정되는 iOS 앱 화면 10장 — 홈 추천 2장, 랭킹 목록 2장, 카테고리 메뉴, 옵션 바텀시트, 주문서 3장, 결제 수단. 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

## 1. 개요
- 서비스 성격: 카카오가 운영하는 주문 생산형 커머스. 주문을 먼저 모은 뒤 만들어 보내는 방식이고, 사회 기여(임팩트)를 앞에 내세운다. 카카오톡 안과 단독 앱에서 쓴다.
- 디자인 인상 한 줄: 흰 바탕에 거의 검정(#1a1a1a) 글자, 행동은 산호빛 빨강(#ed554d) 하나. 결제 단계에서만 카카오 노랑이 나온다.
- 공식 시스템 이름: 공개된 이름 없음
- 특징
  - 바탕은 흰색이고, 묶음 바탕은 아주 옅은 회색(#fafafa) 한 단계로 나눈다.
  - 기본 글자색은 순수 검정이 아니라 #1a1a1a다. 선택된 칩, 검정 버튼, NEW 배지도 같은 값이다.
  - 빨강(#ed554d)이 "주문하기" 버튼, "○명 주문 중" 숫자, 좋아요 하트, 카테고리 선택 막대, 새 소식 점을 함께 맡는다. 주문 수를 강조하는 것이 이 서비스의 핵심 장치다.
  - 상품 사진은 각지게, 홈의 큰 카드만 살짝 둥글게(약 6pt), 칩은 완전히 둥글게 쓴다. 버튼과 입력창은 거의 각진 2pt다.
  - 주문서 결제 영역은 카카오페이 노랑(#ffeb00) 면, 맨 아래 결제 버튼은 다른 노랑(#fed800)이다. 이 두 노랑은 결제 흐름에만 나온다.
  - 화면 좌우 여백이 14pt로 좁은 편이다.
- 공개 자료 상황
  - 카카오메이커스 전용 디자인 가이드, 디자인 토큰, UI 코드는 공개된 것을 찾지 못했다(확인 필요).
  - 카카오 회사 브랜드와는 별개로, 이 문서는 카카오메이커스 앱 화면에서 잰 값만 적었다.

## 4. 간격·레이아웃
- 기준 화면: 375pt 폭 아이폰.
- 화면 좌우 여백: 14pt. 칩, 카드, 목록, 주문서 입력창, 버튼이 모두 14pt 선에 맞는다.
- 간격 단계(관찰, pt): 4, 6, 8, 10, 14, 20
- 카드·칩 사이: 8pt(홈 큰 카드, 필터 칩, 주문서 입력창 줄, 바텀시트 두 버튼). 랭킹 그리드 두 열 사이는 약 7pt, 카테고리 상단 배너 사이는 약 6pt.
- 구획 제목과 부제 사이 약 10pt, 부제와 카드 사이 약 20pt.
- 주문서 구획 사이: 높이 약 6pt의 gray-200 띠로 나눈다.
- 랭킹 그리드: 2열, 카드 폭 약 171pt, 이미지 비율 약 4:5(171×214pt).
- 홈 큰 카드: 폭 약 202pt, 높이 약 270pt, 가로 스크롤로 다음 카드가 오른쪽에 보인다.
- 카테고리 화면: 왼쪽 목록 폭 약 124pt(한 칸 높이 약 43pt), 오른쪽에 하위 항목 목록.
- 주문서 입력: 라벨 열 14pt에서 시작, 입력창은 82pt에서 시작해 오른쪽 여백까지. 입력창 높이 약 36pt.
- 그리드: 확인 필요

## 6. 주요 컴포넌트
### 버튼
- 주문 버튼(빨강): 옵션 시트 아래 오른쪽, 약 170×48pt, accent-red 바탕, 흰 15pt 굵은 글자, 모서리 2pt.
- 보조 버튼(흰색): 같은 크기, 흰 바탕 + 가는 회색 테두리, ink 15pt 굵은 글자(장바구니 담기). 주문 버튼 왼쪽에 8pt 띄워 둔다.
- 검정 버튼: 약 99×42pt, ink 바탕, 흰 13pt 굵은 글자, 모서리 약 4pt(쿠폰 선택, 전체 사용).
- 결제 버튼: 화면 폭 가득, 높이 약 42pt, checkout-yellow 바탕, ink 13pt 굵은 글자, 모서리 없음. 바로 위에 회색 동의 안내 문장 한 줄.
- 회색 버튼: gray-50 바탕 + 가는 테두리, 회색 글자(우편번호 검색).
- 좋아요 버튼: 피드에서 약 70×35pt 흰 상자 + 가는 테두리, 하트 외곽선 + 숫자.
- 맨 위로 버튼: 오른쪽 아래 떠 있는 흰 원(지름 약 45pt), 가는 테두리 + 위 화살표.

### 칩·세그먼트
- 필터 칩: 높이 약 34pt 알약. 선택은 ink 바탕 흰 글자, 나머지는 흰 바탕 + 가는 테두리 + 회색 글자. 칩 앞에 작은 컬러 아이콘이 붙는다.
- 홈 해시태그 칩: 높이 약 34pt 알약, 흰 바탕 + 가는 테두리, "#" 붙은 회색 12pt 글자. 일부 칩은 초록 테두리 + 원형 그림.
- 피드 해시태그: gray-200 바탕 작은 상자(높이 약 22pt), 10pt 회색 글자.
- 세그먼트(2칸): 높이 약 35pt, 화면 폭. 선택 칸은 흰 바탕 + 진한 글자, 나머지는 gray-50 바탕 + 회색 글자. 랭킹 화면은 선택 칸에 ink 테두리를 두르고, 주문서 화면은 가는 회색 테두리만 쓴다.

### 입력창
- 높이 약 36pt, 흰 바탕, 가는 회색 테두리, 모서리 2pt. 안내 문구는 gray-400 12pt.
- 라벨은 입력창 왼쪽 열에 두고, 필수 항목은 라벨 뒤 빨간 별표.
- 연락처는 세 칸으로 나누고 사이에 회색 "-".
- 숫자 입력(포인트): 왼쪽 원형 지우기 아이콘, 오른쪽 정렬 굵은 숫자 + 작은 회색 "원".
- 선택 상자: 높이 약 44pt, 회색 안내 문구 + 오른쪽 아래 꺾쇠.
- 체크박스: 약 17pt 네모. 켜지면 checkout-yellow 바탕 + 흰 체크, 꺼지면 gray-300.

### 카드·리스트
- 홈 큰 카드: 사진이 카드 전체를 채우고, 아래쪽에 검정 20pt 제목 2줄과 12pt 설명 2줄을 사진 위에 바로 얹는다. 모서리 약 6pt.
- 피드 상품: 화면 폭 사진(모서리 없음) → 22pt 굵은 제목 → 13pt 회색 설명 3줄 → 해시태그 → 빨강 "○명 주문했어요" → 좋아요 버튼. 새 상품은 사진 왼쪽 위에 ink 바탕 흰 NEW 배지.
- 랭킹 상품 카드: 4:5 사진(모서리 없음), 왼쪽 위 흰 네모 순위 배지(약 20pt), 오른쪽 아래 반투명 흰 네모 안 하트 외곽선. 아래에 상품명 12pt 2줄 → 판매가 13pt 회색 → 빨강 "○명 주문 중" 12pt 굵게. 할인율 표시는 보이지 않는다.
- 목록 머리: 왼쪽 "○개의 제품"(숫자 굵게), 오른쪽 기준 시각 + 정보 아이콘(회색).
- 카테고리 메뉴: 왼쪽 gray-50 목록, 선택 칸은 흰 바탕 + 왼쪽 3pt accent-red 막대 + 굵은 글자. 오른쪽은 대분류 제목(작은 아이콘 + 굵은 글자 + `>`) 아래 하위 항목을 줄마다 나열하고, 대분류 사이를 가는 선으로 나눈다.
- 카테고리 상단 배너: 약 140×98pt 사진 + 굵은 제목 + 회색 부제, 가로 스크롤.
- 주문서 금액 표: 왼쪽 항목 이름(gray-800), 오른쪽 값(gray-500) 오른쪽 정렬. 마지막 "총 결제 금액"은 gray-50 띠(높이 약 48pt) 안에 굵게.
- 주문서 상품 묶음: 판매자 이름 줄 아래 진한 1pt 선, 썸네일(약 48pt, gray-100 바탕) + 굵은 상품명, 그 아래 gray-50 상자에 옵션·금액·수량.

### 상단 바·탭 바
- 홈 상단 바: 왼쪽 kakaomakers 워드마크, 오른쪽 검색·장바구니 선 아이콘.
- 상단 탭: 가로 스크롤 글자 탭, 13pt. 선택 탭은 굵은 ink 글자 + 글자 폭만큼 2pt ink 밑줄. 새 소식은 탭 이름 오른쪽 위 작은 빨간 점.
- 상세·주문서 상단 바: 왼쪽 뒤로·홈 아이콘, 가운데 제목, 오른쪽 검색(·장바구니). 아래 가는 회색 선.
- 하단 탭 바: 흰 바탕, 탭 5개(임팩트·카테고리·홈·좋아요·마이). 선 아이콘 약 20pt + 10pt 이름. 선택 탭은 채운 ink 아이콘 + 진한 이름. 좋아요 하트는 선택 여부와 관계없이 accent-red로 채워져 있다.
- 주문서 구획 머리: 15pt 굵은 제목 + 오른쪽 꺾쇠(접기·펼치기).

### 바텀시트·모달
- 옵션 선택 바텀시트: 위 두 모서리 12pt, 뒤는 검정 약 50% 막. 오른쪽 위 회색 X.
- 내용 순서: 회색 라벨 → 선택 상자 → 고른 옵션 묶음(gray-50, 상품명 밑줄 + 원형 지우기, 수량 조절 −/숫자/+ 약 28pt 높이, 오른쪽 금액) → 총 금액 줄 → 회색 안내 상자 → 흰·빨강 두 버튼.

### 토스트·스낵바
- 캡처에 없음. 확인 필요.

## 7. 아이콘·이미지·모션
- 아이콘: 약 1.5pt 선 아이콘(검색, 장바구니, 뒤로, 홈). 하단 탭 선택 아이콘만 채운다.
- 필터 칩과 카테고리 대분류 앞에는 작은 컬러 그림 아이콘을 쓴다. 정보 아이콘은 선, 분류 아이콘은 그림으로 나눈다.
- 사진: 화면 대부분. 밝은 자연광 연출 사진이 많고, 사진 위에 글자를 바로 얹는 카드도 있다.
- 모션: 캡처로 알 수 없음. 확인 필요.

## 8. 글쓰기 톤(UX 라이팅)
- 홈 구획 제목은 명사형 한 줄, 부제는 합니다체 한 문장으로 서비스 취지를 말한다.
- 상품 설명과 안내는 해요체가 많다. 입력 안내는 "~해 주세요", "○자 이내로 입력하세요" 꼴.
- 상품명 앞에 대괄호 기획 이름을 붙인다([지역 기획명] 상품명).
- 사회적 증거를 숫자로 앞에 둔다("○명 주문 중", "○명이 주문했어요", "○개의 제품").
- 버튼은 짧은 동사형(장바구니 담기, 주문하기, 쿠폰 선택, 전체 사용, 결제하기).
- 해시태그(#)로 기획 묶음을 연결한다.

## 10. 참고 자료
- 카카오메이커스 iOS 앱 화면 캡처 10장 (SylviaLab 벤치마킹 피그마 파일, 저장소에는 올리지 않음)
- 공개 URL: 이번 작업 환경에서 카카오메이커스 웹사이트와 앱스토어 페이지에 접속하지 못해 확인한 공개 URL이 없다(확인 필요).

근거와 한계
- 카카오메이커스 공개 디자인 시스템 문서나 코드는 찾지 못했다. 이 문서의 값은 모두 앱 캡처에서 잰 관찰값이다.
- 캡처 시기는 화면 속 상품 구성으로 보아 2025년 여름쯤으로 추정한다. 날짜는 캡처에 없다.
- 캡처가 375pt 1배율이라 크기는 ±1pt, 작은 글자 색과 가는 테두리 색은 오차가 있다. 넓은 면 색(흰색, #fafafa, #1a1a1a, #ed554d, 두 노랑)은 정확하다.
- 상품 상세 본문, 검색, 장바구니, 마이, 임팩트 탭, 주문 완료, 다크 모드 화면은 보지 못했다.
- 주문서 화면의 이름·주소·연락처 등 개인정보와 주문 금액은 옮기지 않았다.
- 결제 영역의 노랑은 카카오페이 결제 수단 표시이고, 카카오메이커스 자체 브랜드 색인지는 확인 필요다.
- 관찰 값은 서비스가 바뀌면 달라질 수 있다.
서비스 이름과 브랜드는 각 권리자의 것이다. 이 문서는 식별·학습용 참고 자료로 SylviaLab이 독자적으로 작성했다.
