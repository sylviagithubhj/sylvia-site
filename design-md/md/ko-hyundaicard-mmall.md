# 현대카드 M몰 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 2024년 11월 iOS 앱 홈(메인) 화면을 위에서 아래로 스크롤한 캡처 9장 + 시기 미상 iOS 앱 홈 첫 화면(흰 바탕 버전) 1장, 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

이 문서는 디자인 시스템의 다섯 층(원칙, 토큰, 컴포넌트, 사용 규칙, 구현·검증)을 한 파일로 줄인 요약이다. 맨 위 YAML은 도구와 AI가 그대로 읽는 값이고, 아래 글은 그 값을 언제·왜 쓰는지 설명한다. 둘이 어긋나면 YAML 값이 우선한다.

## 1. 개요와 원칙
- 서비스 성격: 현대카드가 운영하는 쇼핑몰. 현대카드 회원이 M포인트와 카드 결제로 가전, 리빙, 뷰티, 패션 상품을 산다. iOS·Android 앱.
- 디자인 인상 한 줄: 검정 바탕 위에 모서리가 둥근 흰 판을 차곡차곡 쌓는다. 색은 검정·흰색·회색이 거의 전부이고, 할인과 행동 유도만 주황(#e8542d)으로 찍는다.
- 공식 시스템 이름: 공개된 이름 없음
- 디자인 원칙(공식 원칙은 찾지 못했다):
  1. 구획은 선이 아니라 판으로 나눈다. 검정 바탕 위 흰 판 사이의 검정 틈이 구분선 역할을 한다. (관찰에서 정리)
  2. 색은 무채색으로 두고, 주황 하나는 할인과 행동 유도에만 쓴다. (관찰에서 정리)
  3. 상품 사진은 같은 회색 칸(#f7f7f7)에 담아 크기가 달라도 정돈돼 보이게 한다. (관찰에서 정리)
  4. 구획 제목은 "작은 머리말 + 큰 굵은 제목" 2단으로 위계를 만든다. (관찰에서 정리)
- 추가 캡처 1장(시기 미상)의 홈은 반대로 흰 바탕이다. 로고·아이콘이 검정, 선택 칩은 검정 알약, 하단 탭 바는 흰 바탕에 탭 4개(홈·브랜드·검색·로그인)다. 강조 주황도 더 밝은 #fc4514다. 두 모습 중 어느 쪽이 지금 모습인지는 확인 필요.
- 공개 자료 상황: 현대카드 M몰의 디자인 시스템 문서나 공개 디자인 코드는 찾지 못했다(확인 필요). 이번 작업 환경에서는 외부 웹 접속이 막혀 공식 사이트·스토어 페이지를 직접 확인하지 못했다.

- 톤: 장식 없이 차분하고 고급스럽게. 사진과 큰 제목이 화면을 이끈다.

### 특장점
- 검정 바탕 위에 판을 쌓아 구획을 나눈다 — 화면 바탕 #000000 위에 위 모서리 20pt 흰 판을 올리고, 판 사이 12~32pt 검정 틈이 구분선을 대신한다. 흰 바탕 위에 선을 긋는 일반 쇼핑 홈과 반대다.
- 색을 무채색으로 묶고 주황 하나만 쓴다 — #e8542d는 할인율·할인가·"Now on SALE"·할인 배지·원형 화살표 버튼에만 나오고, 칩·탭·버튼 글자는 검정·흰색·회색(#474747, #a3a3a3, #111111)이다.
- 사진 크기가 달라도 같은 칸에 담는다 — 모든 상품 사진을 #f7f7f7 칸(모서리 8pt)에 누끼로 넣어 2열 격자·가로 줄·순위 목록이 정돈돼 보인다.
- 찜·장바구니를 이미지에 걸친 원형 버튼으로 둔다 — 지름 약 46pt 흰 원 + 1pt 검정 테두리 버튼 두 개가 할인 카드·MD 추천 카드 이미지 아래 가장자리에 걸친다.
- 영문 디스플레이 글꼴로 구획에 얼굴을 준다 — "Best 50", "MD's pick" 같은 26~34pt 영문 제목은 로고 "M·MALL"과 같은 계열의 기하학적 굵은 산세리프다.

### 배울 점
- 긴 홈 화면을 구획으로 나눌 때 M몰처럼 어두운 바탕 위에 둥근 밝은 판(위 모서리 20pt)을 쌓아 선 없이 나눈다.
- 할인 정보를 돋보이게 할 때 M몰처럼 강조색 하나(#e8542d)를 할인율·할인가·배지에만 묶고 나머지는 무채색으로 둔다.
- 출처가 제각각인 상품 사진을 모을 때 M몰처럼 같은 회색 칸(#f7f7f7)에 담아 높이와 바탕을 맞춘다.

### 이 문서를 읽는 AI 에이전트에게
- 색·크기·간격은 YAML 토큰 이름으로만 쓴다. 캡처에서 잰 값이라 사이 값(예: 10pt, 18pt 여백)을 새로 만들지 않는다.
- 화면에서는 `gray-700` 같은 팔레트 이름보다 `surface-chip-selected` 같은 semantic 이름을 먼저 쓴다.
- `accent`(#e8542d)는 할인율·할인가·할인 배지·안내 배너 화살표 버튼에만 쓴다. 그 밖에 주황이 필요해 보여도 검정을 고른다.
- 검정 바탕 버전과 `light-*` 흰 바탕 버전 토큰을 한 화면에 섞지 않는다. 따로 지시가 없으면 캡처가 많은 검정 바탕 버전을 쓴다.
- 판단이 어려우면 선을 긋는 대신 판(20pt)과 틈으로 나누고, 색을 더하는 대신 글자 크기·굵기로 위계를 만든다.

## 2. 색상
값은 1배율 캡처 픽셀에서 읽었다. 넓은 면 색은 정확하고, 작은 글자 색은 글자 테두리 번짐 때문에 오차가 있다. 토큰 이름은 SylviaLab이 붙인 것이다.

### 색 체계
M몰은 공개된 팔레트가 없다. 그래서 캡처에서 반복되는 색을 **관찰 팔레트**로 모으고, 그 위에 **역할 이름(semantic)** 을 붙여 두 층으로 정리했다(관찰에서 정리).

| 층 | 예시 | 쓰는 곳 |
|---|---|---|
| 관찰 팔레트 | `black`, `gray-50`, `gray-700`, `orange-500` | 토큰 정의에만. 회색 번호는 밝기 순서를 뜻할 뿐 공식 단계가 아니다 |
| 역할 이름 | `background`, `surface-image`, `surface-chip-selected`, `accent` | 실제 화면과 컴포넌트 |
| 흰 바탕 버전 | `light-*` | 흰 바탕 캡처 1장의 값. 검정 바탕 버전과 섞지 않는다 |

- 캡처 시기(11월 말)가 겨울 기획전 시즌이라 배너 문구·사진은 시즌 내용이다. 다만 UI 요소(판, 칩, 버튼, 탭 바) 색은 시즌과 무관해 보인다.
- 상태 색의 "배경/선/글자" 조합 규칙은 캡처에 오류·완료 화면이 없어 확인 필요.

### 역할별 색
- 바탕 `background`(black #000000): 화면 전체 바탕이자 판 사이 틈. 판 밖에 놓인 머리말·제목·버튼도 이 위에 흰 글자로 둔다.
- 면 `surface`(white #ffffff): 구획 판, 할인 카드, MD 추천 카드, 기획전 카드. 위 모서리 20pt로 둥글린다.
- 이미지 칸 `surface-image`(gray-50 #f7f7f7): 상품 사진, 브랜드 원형 로고 바탕. 판의 흰색과 구분되는 가장 옅은 회색이다.
- 강조 `accent`(orange-500 #e8542d): 할인율·할인가·"Now on SALE"·할인 배지·안내 배너 원형 화살표. 눌림·hover 짝 색은 캡처에 없어 확인 필요.
- 칩 `surface-chip-selected`(gray-700 #474747) + `text-on-dark`: 선택 칩만. 선택 안 된 칩은 `text-chip-off`(#a3a3a3) 글자만 둔다.
- 탭 바 `surface-tabbar`(gray-900 #111111): 선택 탭은 흰색, 나머지는 아이콘 `icon-tab-off`(#949494)·이름 `text-tab-off`(#808080).
- 구분선 `divider-soft`(#f5f5f5)·`divider`(#ededed): 판 안 목록과 버튼 사이에만. 구획 사이에는 쓰지 않는다.

### 색 사용 규칙
- accent(#e8542d)는 할인율, 할인가, "Now on SALE" 라벨, 할인 배지, 원형 화살표 버튼에만 쓴다. 그 밖의 글자·아이콘은 검정·흰색·회색이다.
- 화면 바탕은 #000000, 구획 판과 카드는 #ffffff로 나눈다.
- 상품 이미지 칸은 사진 종류와 상관없이 #f7f7f7로 채운다.
- 상단 칩은 선택만 #474747로 채우고, 나머지는 바탕 없이 #a3a3a3 글자로 둔다.
- 하단 탭 바는 #111111이고, 선택 탭만 흰색으로 칠한다.
- 배너 칸 색(#dee1db, #66bb9c)은 배너 사진에 맞춘 색이라 일반 UI에 가져다 쓰지 않는다.
- 흰 바탕 버전 값(#fc4514 등)은 검정 바탕 버전 값과 섞지 않는다.

### 화면 모드
- 검정 바탕 버전(캡처 9장)과 흰 바탕 버전(캡처 1장)이 있다. 시스템 다크·라이트 설정을 따르는 모드 전환인지, 개편 전후 차이인지는 확인 필요.
- 그래서 흰 바탕 값은 `light-*` 이름으로만 두고 `-dark` 짝으로 묶지 않았다.

### Don't
- `accent`(#e8542d)를 구획 제목·아이콘·탭 선택 표시에 쓰지 않는다.
- 선택 안 된 칩에 바탕색이나 테두리를 넣지 않는다.
- 상품 이미지 칸을 흰색(#ffffff)으로 두지 않는다. 항상 `surface-image`(#f7f7f7).
- `curation-green`(#66bb9c)·`banner-caption`(#dee1db)을 버튼·글자 색으로 쓰지 않는다.
- #e8542d와 #fc4514를 한 화면에 함께 쓰지 않는다.

## 4. 레이아웃·간격
- 기준 화면: 375pt 폭 아이폰.
- 화면 좌우 여백: 24pt. 구획 머리말·제목·상품 카드가 같은 24pt 선에 맞는다. 흰 판 자체는 화면 폭을 꽉 채운다.

- 그리드·최대 폭: 확인 필요

### 간격 적용 규칙
- 글자와 카드의 왼쪽 끝은 24pt 선에 맞추고, 흰 판만 화면 끝까지 채운다.

- 상품 카드끼리는 약 2pt만 띄워 이미지 칸이 이어져 보이게 한다.
- 가로 스크롤 줄은 다음 카드가 오른쪽에 걸쳐 보이게 둔다.
- 구획 사이는 선 대신 12~32pt 검정 틈으로 나눈다.

### Don't
- 흰 판에 좌우 여백을 주어 화면 끝에서 띄우지 않는다. 판은 화면 폭을 꽉 채운다.
- 상품 카드 사이를 8pt 이상 벌리지 않는다(관찰값 약 2pt).
- 글자 시작선을 24pt 밖으로 어긋나게 두지 않는다(검정 바탕 버전).
- 가로 스크롤 줄의 마지막 보이는 카드를 화면 안에 딱 맞추지 않는다. 다음 카드가 걸쳐 보여야 한다.

| radius-full | 999px | 상단 카테고리 칩, 원형 브랜드·쇼케이스 로고, 원형 아이콘 버튼, 배너 페이지 표시 알약 |

테두리:
- border-strong: 1pt #000000. 흰 원형 아이콘 버튼(찜·장바구니) 테두리, 선택된 쇼케이스 원의 바깥 링.
- divider: 1pt #ededed. 카드 안 목록과 "모든 상품 보기" 버튼 사이 가로선.
- border-light: 1pt #e8e8e8. 흰 바탕 버전 넓은 외곽선 버튼, 하단 탭 바 위 선.
- 큰 판·카드는 20pt로 크게 둥글고, 그 안 이미지 칸은 8pt로 작게 둥글다. 칩과 아이콘 버튼은 완전히 둥글다.
- 픽셀 단위는 iOS pt와 같다고 보고 적었다(1pt = CSS 1px).

### 고도(층)
- 층은 그림자가 아니라 **면 색 대비**로 나눈다: 검정 바탕(#000000) → 흰 판(#ffffff) → 회색 이미지 칸(#f7f7f7) 순서로 한 단계씩 올라간다(관찰에서 정리).
- 그림자는 확인 필요. 캡처에서 보이지 않는다.
- 원형 아이콘 버튼은 그림자 대신 1pt 검정 테두리로 이미지 위에 떠 보이게 한다.
- 모달·바텀시트 뒤 어둡게 깔리는 막(dim)은 캡처에 없어 확인 필요.

### 모션
- 큰 배너는 자동 넘김(일시정지 버튼 있음)으로 보인다. 나머지는 캡처로 알 수 없음. 길이·이징은 확인 필요.

### Don't
- 판 안 이미지 칸 모서리를 판과 같은 20pt로 만들지 않는다(8pt).
- 카드·판에 그림자를 넣어 층을 만들지 않는다. 면 색 차이로 나눈다.
- 할인 배지를 알약(999px)으로 만들지 않는다(4pt).
- 큰 배너를 자동으로 넘기면서 일시정지 버튼을 빼지 않는다.

## 6. 컴포넌트
컴포넌트마다 크기, 종류, 상태, 규칙을 적는다. 보지 못한 상태는 `확인 필요`.

### 6.1 버튼
**종류**

| 변형 | 모양 | 쓰는 때 |
|---|---|---|
| 넓은 텍스트 버튼 | "모든 상품 보기 >", 16pt 굵은 글자 + `>`, 가운데 정렬 | 흰 판 맨 아래(가로선 위에 둠) 또는 검정 바탕 위 흰 글자 |
| 더보기 버튼 | 회전 화살표 아이콘 + "브랜드 더 보기" + 현재/전체 쪽수("1 / 2", 현재 쪽은 검정, 전체는 회색) | 브랜드 격자 다음 쪽 |
| 원형 아이콘 버튼 | 지름 약 46pt, 흰 바탕, 1pt 검정 테두리, 가운데 검정 선 아이콘(찜 하트, 장바구니) | 상품 이미지 아래 가장자리에 두 개 나란히 걸친다 |
| 원형 화살표 버튼 | 지름 약 32pt, accent 주황 바탕, 검정 오른쪽 화살표 | 검정 바탕 안내 배너 오른쪽 끝 |
| 넓은 외곽선 버튼(흰 바탕 버전) | 약 340×38pt, 흰 바탕, 1pt #e8e8e8 테두리, 모서리 4pt, 가운데 검정 13pt 굵은 글자 + `>` | 목록 바로 아래 |
| 반투명 원형 화살표 버튼(흰 바탕 버전) | 지름 약 36pt, 흰 반투명 바탕 + 검정 오른쪽 화살표 | 큰 배너 오른쪽 아래 |

**크기**

| 버튼 | 높이(지름) | 좌우 여백 | 모서리 | 글자 |
|---|---|---|---|---|
| 원형 아이콘 버튼 | 약 46pt | — | 999px | 아이콘만 |
| 원형 화살표 버튼 | 약 32pt | — | 999px | 아이콘만 |
| 넓은 텍스트 버튼 | 확인 필요 | 확인 필요 | 없음 | 16pt 700 |
| 넓은 외곽선 버튼(흰 바탕) | 약 38pt(폭 약 340pt) | 확인 필요 | 4pt | 13pt 700 |
| 반투명 원형 화살표(흰 바탕) | 약 36pt | — | 999px | 아이콘만 |

- 주요 채움 버튼(구매하기 등): 이번 캡처에 없음. 확인 필요.
- 상태: 기본만 봤다. 눌림 / 비활성 / 로딩은 확인 필요.
- 쓰지 않는 때: 주황 원형 화살표 버튼은 안내 배너 밖에서 쓰지 않는다. 흰 판 안 행동 유도는 넓은 텍스트 버튼으로 한다.

**규칙**
- 구획마다 끝에 넓은 텍스트 버튼 하나만 둔다. 문구는 "○○ 보기" + `>` 꼴(관찰에서 정리).
- 원형 아이콘 버튼은 찜·장바구니 두 개를 나란히, 이미지 아래 가장자리에 반쯤 걸쳐 둔다.
- 아이콘만 있는 원형 버튼에는 "찜하기", "장바구니 담기" 같은 `aria-label`을 단다(구현 권장).
- 32pt 원형 화살표 버튼은 안내 배너 전체를 누를 수 있게 해 터치 영역을 44pt 이상으로 넓힌다(구현 권장).

## 7. 패턴
- 홈 구성: 상단 바 → 카테고리 칩 → 큰 배너(자동 넘김) → 흰 판 구획(머리말 + 큰 제목 + 상품 줄 + "모든 상품 보기 >")을 검정 틈을 두고 반복한다.
- 목록 → 상세: 상품 카드·순위 목록에서 상세로 가는 흐름은 캡처하지 못했다. 확인 필요.
- 상품 묶음 보여주기: 2열 격자, 가로 스크롤 줄, 순위 목록, 3열 브랜드 격자를 구획마다 바꿔 쓴다.
- 쪽 넘김: 카드 안 "3 / 4", 배너 "1 / 18", 더보기 "1 / 2"처럼 현재/전체 숫자로 위치를 알린다.
- 구획 하나 만들기(관찰에서 정리):
  ```
  [이번 주]                ← eyebrow 14pt 500
  주말에 고르기 좋은        ← section-title 22pt 700, 2줄까지
  리빙 소품
  (상품 줄: 2열 격자 또는 가로 스크롤)
  ─────────────
  모든 상품 보기 >          ← button 16pt 700
  ```
  (예시 문구, SylviaLab 작성)
- 검색: 하단 탭에 검색이 있으나 화면은 확인 필요.
- 빈 상태·로딩·오류: 확인 필요.
- 폼·결제: 확인 필요.

## 8. 접근성
- 글자 대비(WCAG 2.x, 계산값):

| 글자 | 바탕 | 대비 | 본문 기준 4.5:1 |
|---|---|---|---|
| #000000 | #ffffff | 21.0:1 | 통과 |
| #767676 | #ffffff | 4.5:1 | 통과 |
| #a3a3a3 | #000000 | 8.3:1 | 통과 |
| #cacaca | #000000 | 12.8:1 | 통과 |
| #ffffff | #474747 | 9.3:1 | 통과 |
| #949494 | #111111 | 6.2:1 | 통과 |
| #808080 | #111111 | 4.8:1 | 통과 |
| #e8542d | #ffffff | 3.7:1 | 미달(큰 글자 3:1은 통과) |
| #ffffff | #e8542d | 3.7:1 | 미달(큰 글자 3:1은 통과) |
| #fc4514 | #ffffff | 3.5:1 | 미달(큰 글자 3:1은 통과) |

- 주황 할인가(13pt)와 할인 배지 글자(11pt)는 작은 글자라 4.5:1 기준에 못 미친다. 주황 원형 버튼 위 검정 화살표(#000000/#e8542d)는 5.7:1이다.
- 흰 바탕 버전 "전체 보기" 링크 #5c5c5c/#ffffff는 6.7:1, 선택 안 된 탭 아이콘 #858585/#ffffff는 3.7:1(아이콘 3:1 기준은 통과)이다.
- 큐레이션 배너 흰 글자 #ffffff/#66bb9c는 2.3:1로 큰 글자 기준(3:1)에도 못 미친다.
- 터치 영역: 원형 아이콘 버튼 지름 약 46pt는 44pt 기준을 넘는다. 원형 화살표 버튼 약 32pt, 칩 높이 약 34pt(흰 바탕 버전 32pt), 흰 바탕 버전 펼치기 버튼 약 22pt는 44pt보다 작다(실제 터치 영역은 확인 필요).
- 최소 글자 크기: 하단 탭 이름 10pt(흰 바탕 버전 9pt), 할인 배지 11pt.
- 포커스·스크린리더·글자 확대: 확인 필요.

### 점검 목록
- [ ] 할인가·할인 배지처럼 주황 작은 글자는 색만으로 할인을 알리지 않는다. "%"와 숫자가 함께 있어 뜻은 전달된다(관찰). 대비 보완은 (구현 권장).
- [ ] 아이콘만 있는 버튼(찜, 장바구니, 알림, 펼치기, 일시정지)에 `aria-label`(구현 권장).
- [ ] 자동 넘김 배너에 일시정지 버튼이 있다(관찰). 스크린리더로 조작되는지는 확인 필요.
- [ ] 상품 사진·브랜드 로고 대체 텍스트: 확인 필요.
- [ ] iOS 글자 크기 설정(Dynamic Type)에서 2줄 말줄임 제목이 잘리는지: 확인 필요.

## 9. 글쓰기 톤
- 말투: 구획 머리말은 영문 짧은 라벨(New, Super Brand, Now on SALE) 또는 한글 짧은 말(이번 주, 이달의 기획전). 구획 제목은 명사형 또는 마침표 없는 짧은 문구이고, 2줄로 끊어 쓰는 경우가 많다.
- 안내 배너: "○○부터 ○○까지" 머리말 + "'○○' 만나보기", "○○ 알아보기"처럼 행동을 담은 제목.
- 버튼 문구 꼴: "모든 상품 보기 >", "브랜드 더 보기"처럼 "○○ 보기" 꼴.
- 숫자·단위 표기: 할인은 숫자를 앞에 둔다("○% Off", "○○% ○○○,○○○원"). 가격은 쉼표 + "원".
- 서비스 이름은 화면에서 "M몰"로 줄여 부른다.

## 10. Do & Don't
관찰 기반 문서의 규칙은 "이 서비스 화면에서 반복되는 규칙"을 SylviaLab이 정리한 것이다(공식 규칙 아님).

### Do
- 화면 바탕을 #000000으로 두고, 구획은 위 모서리 20pt 흰 판으로 나눈다.
- 할인율·할인가·할인 배지는 #e8542d로 칠한다.
- 상품 사진은 #f7f7f7 칸(모서리 8pt)에 담는다.
- 구획 제목은 14pt 머리말 + 22pt 굵은 제목 2단으로 쓴다.
- 글자·카드는 좌우 24pt 선에 맞춘다.
- 찜·장바구니는 지름 46pt 흰 원형 버튼 + 1pt 검정 테두리로 둔다.
- 버튼 문구는 "모든 상품 보기 >"처럼 "○○ 보기" + `>`로 쓴다.

### Don't
- #e8542d를 할인·행동 유도 밖의 제목·아이콘에 쓰지 않는다.
- 구획 사이에 회색 선을 긋지 않는다. 검정 틈(12~32pt)으로 나눈다.
- 선택 안 된 칩에 바탕색을 넣지 않는다(#a3a3a3 글자만).
- 판 안 이미지 칸 모서리를 판과 같은 20pt로 만들지 않는다(8pt).
- 배너 칸 색(#dee1db, #66bb9c)을 일반 UI 색으로 쓰지 않는다.
- 검정 바탕 버전의 #e8542d와 흰 바탕 버전의 #fc4514를 한 화면에 섞지 않는다.
