# 캐치테이블 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: iOS 앱 검색 흐름 화면 11장 — 검색 시작, 입력 중, 자동완성, 검색결과 목록 4장, 지도, 정렬 바텀시트, 날짜·인원 선택, 새 버전 검색 시작 — 과 2025년 6월께 새 버전 홈 1장·지도 검색 1장, 모두 13장. 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

## 1. 개요
- 서비스 성격: 식당 예약 앱. 매장 검색, 날짜·시간·인원 예약, 픽업 예약, 웨이팅(줄서기)을 한 앱에서 한다.
- 디자인 인상 한 줄: 흰 바탕에 검정 글자, 행동은 모두 주황빨강(#eb4f27) 하나로. 목록 카드마다 예약 가능한 시간 버튼이 주황 덩어리로 줄지어 나온다.
- 공식 시스템 이름: 공개된 이름 없음(확인 필요)
- 특징
  - 강조색은 주황빨강 하나다. 시간 버튼, 확인 버튼, 선택된 날짜·인원, 검색어 일치 글자, 지도 핀, 해시태그 테두리까지 같은 색이다.
  - 검색결과 카드의 핵심은 "바로 고를 수 있는 시간"이다. 카드 아래에 시간 버튼 3개를 같은 폭으로 꽉 채운다. 예약이 안 되는 칸은 연회색 빈 버튼으로 둔다.
  - 선택 상태를 두 가지로 나눈다. 큰 결정(날짜, 인원, 확인)은 주황으로 채우고, 필터 칩·해시태그는 주황 테두리 + 옅은 주황 바탕으로 가볍게 표시한다.
  - 회색 단계가 많다. 본문 검정, 설명 진회색, 주소·업종·가격대 같은 메타 정보는 아주 옅은 회색(#bcbcbc 근처)으로 확 낮춘다.
  - 구획은 선 대신 10pt 높이 회색 띠(#ececec)로 크게 끊는다.
  - 모서리는 작다. 버튼·카드는 4~8pt, 칩·검색창·지도 위 떠 있는 요소만 완전히 둥글다.
  - 2025년 6월께 새 버전(홈, 지도 검색)은 강조색이 더 선명한 주황 #ff3d00이다. 회색도 푸른 기가 도는 회색(#f2f5f7, #7b919e, #e1e6eb)이 새로 보인다.
  - 새 버전 홈은 아이콘 타일 5열 격자(회색 둥근 사각 안 색 아이콘)가 중심이고, 하단 탭 바는 5칸(홈·검색·내 주변·마이다이닝·MY)이다.
  - 새 버전 지도 검색은 지도 위에 흰 검색창을 띄우고, 아래에서 올라오는 바텀시트에 매장 목록을 담는다.
- 공개 자료 상황: 캐치테이블(와드)의 공개 디자인 시스템 문서나 오픈소스 UI 코드는 이번 작업에서 찾지 않았다. 확인 필요.

## 4. 간격·레이아웃
- 기준 화면: 375pt 폭 아이폰.
- 화면 좌우 여백: 18~20pt. 검색창, 카드 이미지, 확인 버튼이 이 선에 맞는다.
- 간격 단계(관찰, pt): 4, 5, 8, 10, 12, 16, 20, 24
- 검색결과 화면 위쪽 구조(위에서 아래): 상단 바(뒤로 + 제목) → 3칸 탭(높이 약 35pt) → 날짜·시간·인원 줄(약 46pt) → 지도·필터 아이콘 상자 + 필터 칩 가로 스크롤(칩 높이 36pt) → 10pt 회색 띠 → 매장 수 + 정렬(약 46pt).
- 검색결과 카드: 왼쪽 이미지 약 74×99pt(세로형), 이미지와 글 사이 약 15pt. 글 영역 폭 약 243pt.
- 카드 안 세로 간격: 배지 → 이름 약 5pt, 이름 → 소개 약 10pt, 소개 → 별점 약 14pt, 별점 → 메타 약 14pt, 메타 → 시간 버튼 약 24pt.
- 시간 버튼 줄: 3칸, 칸 약 78×38pt, 사이 5pt.
- 카드 사이: 시간 버튼 아래에서 다음 카드 위까지 약 60pt를 비운다(구분선 없음).
- 자동완성 한 줄 높이: 지역 약 66pt, 매장 약 85pt(썸네일 47×63pt).
- 급상승 순위: 2열, 한 줄 간격 53pt, 줄마다 1pt 구분선.
- 정렬 바텀시트 옵션 간격: 46pt.
- 새 버전 홈: 상단 줄(로고 원 지름 30pt + 알약 검색창 높이 34pt + 저장·알림 아이콘) → 지역 선택 줄 → 큰 배너(약 336×220pt, 양옆 다음 배너가 보이는 가로 넘김) → 바로가기 5열 격자(타일 46pt, 열 간격 중심 사이 약 67pt, 줄 간격 약 79pt) → 8pt 회색 띠.
- 새 버전 하단 탭 바: 위 1pt #ebebeb 선, 5칸, 홈 인디케이터 포함 약 92pt.
- 새 버전 지도 검색: 떠 있는 검색창(좌우 18pt 여백, 높이 42pt) → 분류 칩(높이 약 28pt) → 지도 → 바텀시트(위 모서리 16pt, 손잡이 28×4pt).
- 바텀시트 안: 필터 칩 줄(높이 32pt) → 하위 탭 줄 + 1pt 선 → 매장 블록(태그 → 이름 → 별점 줄 → 가로 사진 3장(약 164×130pt, 사이 2pt) → 영업·혜택 줄 → 날짜 칸 줄 → 안내 상자).
- 날짜 칸: 약 60×39pt, 사이 약 6pt, 가로 스크롤.
- 그리드: 확인 필요

## 6. 주요 컴포넌트
### 버튼
- 시간 버튼: primary 바탕, 흰 13pt 글자, 약 78×38pt, 모서리 6pt. 카드마다 3개를 한 줄로. 예약 불가 칸은 gray-50 빈 칸.
- 하단 확인 버튼: 폭 꽉 참(약 338pt), 높이 48pt, primary 바탕, 흰 굵은 글자, 모서리 6pt.
- 닫기 버튼(바텀시트): 같은 크기, 흰 바탕 + 1pt gray-200 테두리 + 검정 굵은 글자.
- 지도 위 예약 조건 버튼: 약 195×36pt 알약, primary 바탕, 흰 글자(날짜·인원·시간 요약).
- 텍스트 링크: link 색 13pt, 앞에 "+".
- 저장 버튼: 지름 약 30pt 원, gray-250 바탕에 흰 북마크 아이콘. 카드 오른쪽 위. 새 버전 지도 목록에서는 원 없이 선 북마크 아이콘만 둔다.
- 새 버전 날짜 칸: 약 60×39pt, 모서리 6pt. 예약 가능은 흰 바탕 + 1pt #e1e6eb 테두리 + 검정 굵은 날짜 + 주황 "예약 가능". 마감은 #f2f5f7 바탕 + 흐린 회청색 글자. 시간 버튼 대신 날짜 단위로 고르게 한다.

### 칩
- 필터 칩: 높이 36pt 알약, 흰 바탕 + 1pt 회색 테두리 + 13pt 진회색 글자. 선택되면 primary 테두리 + primary-soft 바탕 + 주황 글자.
- 해시태그 칩: 높이 약 34pt 알약, 흰 바탕 + 1pt primary 테두리, 14pt 진회색 글자, "#"로 시작.
- 혜택 배지: 높이 약 20pt, badge-soft 바탕, 11pt 주황 글자, 매장 이름 위.
- 인원 선택: 지름 약 46pt 원, 회색 테두리 + "N명". 선택은 primary 채움 + 흰 글자. 가로 스크롤.
- 새 버전 필터 칩: 높이 32pt 알약, 흰 바탕 + 1pt #eeeeee 테두리 + 13pt 진회색 글자(정렬 칩은 아래꺾쇠). 선택은 #fdf0ec 바탕 + 주황 테두리·글자, 적용 개수는 오른쪽 위 주황 원 숫자 배지.
- 새 버전 지도 분류 칩: 높이 약 28pt 알약. 선택은 #222222 바탕 + 흰 글자, 나머지는 흰 바탕 + 회색 글자 + 옅은 개수.
- 새 버전 매장 주제 태그: 높이 약 21pt, 모서리 4pt, 노랑(#f9fac8) 또는 회색(#f5f5f5) 바탕 + 작은 아이콘 + 진회색 글자.

### 입력창
- 검색창: 상단 뒤로 화살표 오른쪽, 약 300×36pt 알약, gray-50 바탕, 왼쪽 돋보기, 회색 placeholder(13~14pt). 입력하면 오른쪽에 회색 원 지우기 버튼.
- 커서는 주황(primary 계열)이다.
- 새 버전(IMG_5240): 흰 바탕 + 1pt 진회색 테두리, 높이 약 42pt, 모서리 약 12pt, 돋보기 없이 placeholder만.
- 2025년 홈 검색창: #f1f1f1 알약, 높이 34pt, 왼쪽 회색 돋보기 + 회색 안내 글자.
- 2025년 지도 검색창: 지도 위에 떠 있는 흰 상자, 높이 42pt, 모서리 약 8pt, 옅은 그림자. 왼쪽 뒤로 화살표 + 검색어, 오른쪽에 세로선 뒤 파랑 달력 아이콘 + "날짜·인원".

### 카드·리스트
- 검색결과 카드: 왼쪽 세로 썸네일, 오른쪽 위에서부터 혜택 배지(선택) → 매장 이름 20pt 굵게 → 소개 2줄 말줄임 → 별 + 점수 굵게 + 리뷰 수 회색 → 업종·지역 / 영업·가격대 2줄 회색 → 시간 버튼 3개. 저장 원은 이름 오른쪽.
- 자동완성: 구획 이름(지역 / 레스토랑) 아래 줄 목록. 지역 줄은 주황 핀 + 이름(일치 부분 주황) + 주황 매장 수 + 아래 회색 주소. 매장 줄은 썸네일 + 이름 + 주소. 맨 아래 "없으면 제안하기" 안내와 링크.
- 급상승 순위: 2열 번호 목록(굵은 숫자 + 매장 이름 한 줄 말줄임), 줄마다 구분선.
- 둘러보기 카드: 약 148×148pt 정사각 사진, 모서리 8pt, 위에 흰 굵은 큰 제목, 아래 흰 작은 해시태그. 가로 스크롤.
- 새 버전 홈 바로가기: 46pt #f4f4f4 둥근 사각 타일(모서리 12pt) 안에 주황·회색 계열 그림 아이콘, 아래 12pt 이름. 5열 격자, 새 항목은 타일 오른쪽 위 주황 원 "N" 배지.
- 새 버전 홈 배너: 화면 폭보다 좁은 둥근 사진 카드(모서리 8pt), 양옆 배너가 살짝 보이고, 아래쪽 안에 흰 점 쪽 표시. 사진 위 흰 굵은 큰 제목 + 작은 설명.
- 새 버전 지도 목록 매장 블록: 태그 줄 → 매장 이름 18pt 굵게 + 결제 표시 → 별 + 굵은 점수 + 회색 리뷰 수·지역·업종 → 가로 사진 3장 → 영업 시간·가격대 줄(작은 아이콘) + 주황 혜택 줄 → 날짜 칸 줄 → 1pt 테두리 안내 상자(모서리 12pt). 맨 아래 작은 회색 "AD" 표시가 붙는 블록도 있다.

### 상단 바·탭 바
- 상단 바: 왼쪽 뒤로 화살표, 그 옆 왼쪽 정렬 제목 20pt 굵게(가운데 정렬 아님).
- 탭: 3칸 균등(예약 · 픽업 예약 · 웨이팅), 선택 탭은 검정 굵은 글자 + 아래 검정 밑줄, 나머지 회색. 탭 아래 1pt 연회색 선.
- 날짜·인원 줄: 달력 아이콘 + "오늘 (요일)" | 시간 | 인원, 세로선으로 나누고 오른쪽 끝에 주황 아래 화살표.
- 하단 탭 바(2025년 홈): 흰 바탕, 위 1pt #ebebeb 선, 5칸 아이콘 + 10pt 이름. 선택 탭은 #222222 채운 아이콘, 나머지는 회색 선 아이콘. 가운데 탭 위에 주황 알약 말풍선(흰 글자)을 띄워 기능을 알린다.
- 상단 바(2025년 홈): 왼쪽 주황 원 로고, 가운데 알약 검색창, 오른쪽 저장·알림 선 아이콘(알림에 주황 점). 아래 줄에 회색 핀 + 굵은 지역 이름 + 아래꺾쇠.
- 하위 탭(2025년 지도 목록): 밑줄 없이 글자만, 선택은 #222222 굵게, 나머지 회색. 줄 아래 1pt 선.

### 지도 화면
- 지도 위 떠 있는 3칸 알약 탭(높이 약 42pt), 선택 칸만 주황 글자.
- 핀: primary 물방울 핀. 선택된 매장 핀은 더 크다.
- 2025년 지도: 지역 묶음 핀은 흰 알약(높이 약 26pt) + 주황 테두리 + 진회색 지역 이름 + 주황 굵은 매장 수. 왼쪽 아래 흰 원형 현재 위치 버튼. 지도 위 맨 위에 떠 있는 검색창과 분류 칩 줄.
- "이 지역 검색하기": 흰 알약(약 36pt 높이), 그 오른쪽 원형 현재 위치 버튼.
- 아래에 가로로 넘기는 흰 매장 카드(목록 카드와 같은 구성, 시간 버튼 3개). 맨 아래 줄에 뒤로·목록·필터 아이콘 + 주황 예약 조건 버튼.

### 바텀시트·모달
- 2025년 지도 목록 바텀시트: 지도 아래에서 올라오는 흰 시트, 위쪽 모서리 16pt, 가운데 손잡이 막대(약 28×4pt, #eaeaea). 가림막 없이 지도 위에 겹친다.
- 정렬 바텀시트: 흰 바탕, 위쪽 모서리 16pt, 뒤는 약 50% 검정 가림막. 옵션은 가운데 정렬 16pt, 줄 간격 46pt, 선택 옵션 옆에 주황 체크. 맨 아래 닫기 버튼. 손잡이 막대는 없다.
- 날짜·인원 선택: 화면 전체를 덮는 흰 화면, 오른쪽 위 X. 달력(왼쪽 위 주황 "오늘", 가운데 연월과 좌우 화살표, 7열 날짜, 선택 날짜는 지름 35pt 주황 원) → 구분선 → 인원 원 가로 스크롤 → 맨 아래 확인 버튼.

## 7. 아이콘·이미지·모션

## 8. 글쓰기 톤(UX 라이팅)
- 화면·구획 제목은 명사형(검색결과, 관심 급상승 레스토랑).
- 둘러보기 질문은 해요체 의문문 한 줄("이런 ○○을 찾으시나요?" 꼴).
- 안내 문장은 해요체("~해주세요"). 그 아래 "+ ○○하기" 링크로 할 일을 준다.
- 홈 바로가기 이름은 2~6글자 명사구(○○맛집, ○○TOP). 검색창 안내는 해요체 권유 문장("~해보세요!" 꼴).
- 날짜 칸은 "날짜 (요일)" 아래 "예약 가능"·"예약 마감" 두 상태 말만 쓴다.
- 정렬 옵션은 "○○ 순"으로 끝을 맞춘다. 가격 순은 화살표(↑↓)로 방향을 붙인다.
- 혜택 배지·해시태그는 마침표 없는 짧은 명사구.
- 시간은 "오후 7:00", 날짜는 "오늘 (목)"처럼 요일을 괄호로.

- 캡처가 375pt 1배율이고 압축 잡음이 있어 크기는 ±1pt, 모서리는 ±2px, 작은 글자 색은 오차가 있다. 넓은 면 색(주황, 회색 바탕)은 정확한 편이다.
- 홈과 지도 검색 새 버전 화면은 배너 문구와 날짜 칸 요일로 보아 2025년 6월께 화면이다. 로고와 화면 구성으로 캐치테이블임을 확인했다. 2023년 화면과 강조색·회색이 달라, 두 시기 값을 "2025"·"새 버전" 이름으로 나눠 적었다.
- 매장 상세, 예약 확정·결제, 웨이팅, 마이페이지, 다크 모드는 보지 못했다. 홈과 하단 탭 바는 새 버전 1장만 봤다.
- 관찰 값은 서비스가 바뀌면 달라질 수 있다.

서비스 이름과 브랜드는 각 권리자의 것이다. 이 문서는 식별·학습용 참고 자료로 SylviaLab이 독자적으로 작성했다.
