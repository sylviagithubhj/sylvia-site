이 문서는 디자인 시스템의 다섯 층(원칙, 토큰, 컴포넌트, 사용 규칙, 구현·검증)을 한 파일로 줄인 요약이다. 맨 위 YAML은 도구와 AI가 그대로 읽는 값이고, 아래 글은 그 값을 언제·왜 쓰는지 설명한다. 둘이 어긋나면 YAML 값을 따른다.

## 1. 개요와 원칙
- 서비스 성격: 식당 예약 앱. 매장 검색, 날짜·시간·인원 예약, 픽업 예약, 웨이팅(줄서기)을 한 앱에서 한다.
- 디자인 인상 한 줄: 흰 바탕에 검정 글자, 행동은 모두 주황빨강(#eb4f27) 하나로. 목록 카드마다 예약 가능한 시간 버튼이 주황 덩어리로 줄지어 나온다.
- 공식 시스템 이름: 공개된 이름 없음(확인 필요)
- 공개 자료 상황: 캐치테이블(와드)의 공개 디자인 시스템 문서나 오픈소스 UI 코드는 이번 작업에서 찾지 않았다. 확인 필요.
- 디자인 원칙
  1. 강조색은 하나만 쓴다. 시간 버튼, 확인 버튼, 선택된 날짜·인원, 검색어 일치 글자, 지도 핀, 해시태그 테두리까지 같은 주황빨강이다. (관찰에서 정리)
  2. 목록에서 바로 예약하게 한다. 검색결과 카드의 핵심은 "바로 고를 수 있는 시간"이고, 카드 아래에 시간 버튼 3개를 같은 폭으로 꽉 채운다. (관찰에서 정리)
  3. 선택의 무게를 두 단계로 나눈다. 큰 결정(날짜, 인원, 확인)은 주황으로 채우고, 필터 칩·해시태그는 주황 테두리 + 옅은 주황 바탕으로 가볍게 표시한다. (관찰에서 정리)
  4. 정보 위계는 회색 단계로 만든다. 본문 검정, 설명 진회색, 주소·업종·가격대 같은 메타 정보는 아주 옅은 회색(#bcbcbc 근처)으로 확 낮춘다. (관찰에서 정리)
  5. 구획은 선 대신 10pt 높이 회색 띠(#ececec)로 크게 끊고, 카드 사이는 선 없이 여백으로 나눈다. (관찰에서 정리)
- 버전 차이: 2025년 6월께 새 버전(홈, 지도 검색)은 강조색이 더 선명한 주황 #ff3d00이다. 회색도 푸른 기가 도는 회색(#f2f5f7, #7b919e, #e1e6eb)이 새로 보인다. 새 버전 홈은 아이콘 타일 5열 격자(회색 둥근 사각 안 색 아이콘)가 중심이고, 하단 탭 바는 5칸(홈·검색·내 주변·마이다이닝·MY)이다. 새 버전 지도 검색은 지도 위에 흰 검색창을 띄우고, 아래에서 올라오는 바텀시트에 매장 목록을 담는다.
- 톤: 군더더기 없이 빠르게. 꾸밈보다 "지금 예약할 수 있는 시간"을 먼저 보여 준다.

### 특장점
- 목록 카드 자체가 예약 버튼이다 — 검색결과 카드마다 시간 버튼 3개(약 78×38pt, #eb4f27 채움)가 붙어 상세에 들어가지 않고 바로 시간을 고른다. 예약 불가 칸도 #f1f1f1 빈 칸으로 남겨 줄 모양을 지킨다.
- 강조색 하나가 화면 전체의 "고를 수 있는 것"을 표시한다 — 시간 버튼, 확인 버튼, 선택 날짜·인원 원, 지도 핀, 검색어 일치 글자, 정렬 체크가 모두 #eb4f27이다.
- 선택을 무게에 따라 두 가지로 나눈다 — 날짜·인원·확인은 주황 채움, 필터 칩·해시태그는 1pt 주황 테두리 + #f9eee8 바탕으로 가볍게 둔다.
- 회색 단계로 정보를 접는다 — 본문 #000000, 소개 #6e6e6e, 주소·업종·가격대 #bcbcbc로 세 층을 나눠 매장 이름과 시간 버튼만 눈에 띄게 한다.
- 새 버전은 시간 대신 날짜 칸으로 고른다 — 2025년 지도 목록 바텀시트에서 60×39pt 날짜 칸에 "예약 가능"(주황)·"예약 마감"(#f2f5f7 바탕) 두 상태만 보여 준다.

### 배울 점
- 목록에서 바로 행동하게 하고 싶을 때 캐치테이블처럼 카드 아래에 고를 수 있는 값(시간)을 같은 폭 버튼 3개로 깔고, 안 되는 칸은 빈 회색 칸으로 둔다.
- 선택 상태가 여러 종류일 때 큰 결정은 채움, 필터 같은 가벼운 선택은 테두리 + 옅은 바탕으로 나눠 한 색으로도 무게를 구분한다.
- 구획이 많은 검색 화면에서는 선 대신 10pt 회색 띠로 큰 구획을, 여백(약 60pt)으로 카드 사이를 나눈다.

### 이 문서를 읽는 AI 에이전트에게
- 색·크기·모서리는 YAML 토큰 이름으로만 쓴다. 캡처 오차(±2) 안의 비슷한 회색을 새로 만들지 않는다.
- 화면 코드에서는 팔레트 이름(`orange-500`, `gray-50`)보다 역할 이름(`primary`, `surface-search`, `text-muted`)을 먼저 쓴다.
- 주황은 "누르면 예약·선택이 되는 것"에만 쓴다. 장식, 제목, 배경 면에는 쓰지 않는다.
- 2023년 값(`primary` #eb4f27)과 2025년 값(`primary-2025` #ff3d00) 중 한 벌만 고른다. 정해지지 않았으면 2023년 값을 기본으로 둔다.
- 판단이 어려우면 채움보다 테두리, 선보다 여백, 새 컴포넌트보다 시간 버튼·필터 칩 같은 기존 부품을 고른다.

## 2. 색상
값은 1배율 캡처 픽셀에서 읽었다. 캡처에 압축 잡음이 있어 넓은 면도 ±2 정도 흔들린다. 가장 많이 나온 값을 적었다. 작은 글자 색은 글자 테두리 번짐 때문에 오차가 더 크다. 토큰 이름은 SylviaLab이 붙인 것이다.

### 색 체계
공식 단계 팔레트는 공개되지 않았다. 그래서 **관찰 팔레트 → 역할 이름** 두 층으로 정리했다.

| 층 | 예시 | 쓰는 곳 |
|---|---|---|
| 관찰 팔레트 | `orange-500`, `gray-50`, `slate-200` | 캡처에서 잰 값 그대로. YAML 정의에만 쓴다 |
| 역할 이름 | `primary`, `surface-search`, `text-muted`, `section-band` | 화면과 컴포넌트. 아래 표의 토큰이 이 층이다 |
| 버전 구분 | 이름 끝 `-2025` | 2025년 6월께 새 버전 화면에서만 본 값 |

### 역할별 색
- 주황 `primary`: 예약·선택 행동 전용. 채움(시간 버튼, 확인 버튼, 날짜·인원 원, 예약 조건 버튼)과 선(해시태그 테두리, 선택 필터 칩 테두리), 글자(검색어 일치, 선택 필터 칩 글자), 아이콘(지도 핀, 지역 핀, 정렬 체크, 날짜 펼침 화살표)에 같은 값을 쓴다.
  - 눌림(pressed)·hover 색: 확인 필요(캡처에 없음). 어둡게 만든 값을 지어내지 않는다.
- 옅은 주황 `primary-soft`·`badge-soft`: 주황 글자를 얹는 바탕 전용. 선택 필터 칩(주황 테두리 + 주황 글자)과 혜택 배지(주황 글자, 테두리 없음)에만 나온다.
- 회색 바탕 `surface-search`(#f1f1f1): 검색창 면과 예약 불가 시간 칸이 같은 값이다. "글자가 있으면 입력 칸, 글자가 없으면 막힌 칸"으로 구분된다.
- 회색 선 3종: 구획 띠 `section-band`(10pt 면), 목록 구분선 `divider`(1pt), 부품 테두리 `border`(1pt). 굵기와 쓰는 곳이 서로 겹치지 않는다.
- 글자 회색 5단: 검정 → #343434 → #6e6e6e → #979797 → #bcbcbc. 아래로 갈수록 정보 중요도가 낮다.
- 파랑·노랑: 파랑은 텍스트 링크와 새 버전 "날짜·인원"에만, 노랑은 별점 별에만.
- 상태 색 조합(배경/선/글자): 원본에 성공·경고·오류 조합이 없다. 확인 필요. 관찰된 조합은 "선택 = 주황 채움 + 흰 글자" 또는 "옅은 주황 바탕 + 주황 선 + 주황 글자", "막힘 = 회색 면 + 글자 없음" 두 가지뿐이다.

### 화면 모드
- 다크 모드 값은 캡처에 없다. 확인 필요.

### 색 사용 규칙
- primary(#eb4f27)는 예약 행동과 선택에만 쓴다: 시간 버튼, 확인 버튼, 선택된 날짜·인원, 검색어 일치 글자, 지도 핀, 정렬 체크, 해시태그 테두리.
- 한 화면 안에서 강조색은 한 가지다. 2023년 화면은 #eb4f27, 2025년 새 버전은 #ff3d00을 쓰고 둘을 섞지 않는다.
- 필터 칩 선택은 채우지 않는다. primary 테두리 + primary-soft(#f9eee8) 바탕 + 주황 글자로 가볍게 표시한다(새 버전은 #fdf0ec 바탕).
- 예약할 수 없는 시간은 gray-50(#f1f1f1) 빈 칸으로 둔다. 글자를 넣지 않는다.
- 주소·업종·가격대·리뷰 수 같은 메타 정보는 text-muted(#bcbcbc)로 낮춘다.
- 파랑은 텍스트 링크(#4a8bec)와 새 버전 지도 검색창의 "날짜·인원"(#186ade)에만 쓴다.
- 노랑 #f5c244는 별점 별에만 쓴다.

### Don't
- 주황(`primary`)을 화면 제목·구획 제목·배경 면에 쓰지 않는다.
- `primary`와 `primary-2025`를 한 화면에 함께 쓰지 않는다.
- 예약 불가 칸에 "마감" 같은 글자나 다른 색을 넣지 않는다(2023년 화면 기준. 글자 있는 마감 칸은 2025년 날짜 칸에만).
- 본문·매장 소개를 `text-muted`(#bcbcbc)로 쓰지 않는다. #bcbcbc는 메타 정보 전용이고 대비 1.9:1이다.
- 파랑을 버튼 바탕이나 선택 표시로 쓰지 않는다.

### 규칙
- 화면 제목과 매장 이름은 20pt 700으로 같은 크기다(새 버전 지도 목록 매장 이름은 18pt 700).
- 구획 제목은 17pt 700, 본문·입력 글자는 14pt 400이다.
- 선택은 굵기로 표시한다. 상단 탭·하위 탭은 선택만 700, 나머지 400.
- 매장 소개는 12pt, 2줄에서 말줄임한다. 메타 2줄은 11pt, 행간 16pt.
- 검색어 자동완성은 일치하는 글자만 주황으로 칠한다.
- 매장 수는 숫자 부분만 굵게 쓴다.
- 상단 바 제목은 왼쪽 정렬이다(가운데 정렬 아님).

### Don't
- 매장 이름을 17pt 구획 제목보다 작게 쓰지 않는다(2023년 20pt, 2025년 18pt).
- 매장 소개를 3줄 이상 펼치지 않는다. 2줄에서 말줄임한다.
- 선택 탭을 색으로만 바꾸지 않는다. 굵기 700과 밑줄(상단 탭)을 함께 쓴다.
- 검색어 자동완성에서 이름 전체를 주황으로 칠하지 않는다. 일치하는 글자만 칠한다.
- 새 화면에 9~10pt 글자를 늘리지 않는다. 관찰된 최소값이며 읽기 어렵다(8장 참고).

## 4. 레이아웃·간격
- 기준 화면: 375pt 폭 아이폰.

| 상단 바(뒤로 + 제목) | 확인 필요 |
| 3칸 탭 | 약 35pt |
| 날짜·시간·인원 줄 | 약 46pt |
| 지도·필터 아이콘 상자 + 필터 칩 가로 스크롤 | 칩 높이 36pt |
| 구획 띠 | 10pt #ececec |
| 매장 수 + 정렬 | 약 46pt |
| 카드 사이 | 약 60pt(구분선 없음) |

### 카드 안쪽
- 검색결과 카드: 왼쪽 이미지 약 74×99pt(세로형), 이미지와 글 사이 약 15pt. 글 영역 폭 약 243pt.

| 카드 안 구간 | 간격 |
|---|---|
| 배지 → 이름 | 약 5pt |
| 이름 → 소개 | 약 10pt |
| 소개 → 별점 | 약 14pt |
| 별점 → 메타 | 약 14pt |
| 메타 → 시간 버튼 | 약 24pt |
| 시간 버튼 사이 | 5pt(칸 약 78×38pt, 3칸) |

### 그 밖의 화면 치수
- 자동완성 한 줄 높이: 지역 약 66pt, 매장 약 85pt(썸네일 47×63pt).
- 급상승 순위: 2열, 한 줄 간격 53pt, 줄마다 1pt 구분선.
- 정렬 바텀시트 옵션 간격: 46pt.
- 새 버전 홈: 상단 줄(로고 원 지름 30pt + 알약 검색창 높이 34pt + 저장·알림 아이콘) → 지역 선택 줄 → 큰 배너(약 336×220pt, 양옆 다음 배너가 보이는 가로 넘김) → 바로가기 5열 격자(타일 46pt, 열 간격 중심 사이 약 67pt, 줄 간격 약 79pt) → 8pt 회색 띠.
- 새 버전 하단 탭 바: 위 1pt #ebebeb 선, 5칸, 홈 인디케이터 포함 약 92pt.
- 새 버전 지도 검색: 떠 있는 검색창(좌우 18pt 여백, 높이 42pt) → 분류 칩(높이 약 28pt) → 지도 → 바텀시트(위 모서리 16pt, 손잡이 28×4pt).
- 바텀시트 안: 필터 칩 줄(높이 32pt) → 하위 탭 줄 + 1pt 선 → 매장 블록(태그 → 이름 → 별점 줄 → 가로 사진 3장(약 164×130pt, 사이 2pt) → 영업·혜택 줄 → 날짜 칸 줄 → 안내 상자).
- 날짜 칸: 약 60×39pt, 사이 약 6pt, 가로 스크롤.

### 간격 적용 규칙
- 큰 구획 사이는 10pt 회색 띠(#ececec)로 나눈다. 새 버전 홈은 8pt #f5f5f5 띠다.
- 검색결과 카드 사이는 선 없이 약 60pt 여백으로 나눈다.
- 목록 줄 사이(급상승 순위 등)는 1pt #ebebeb 구분선을 쓴다.
- 시간 버튼·가로 사진처럼 같은 요소가 나란히 놓일 때는 사이를 좁게(5pt, 2pt) 둔다.
- 메타 정보와 시간 버튼 사이는 약 24pt로 카드 안에서 가장 크게 띄운다.

### Don't
- 검색결과 카드 사이에 구분선을 긋지 않는다.
- 큰 구획을 1pt 선으로 나누지 않는다. 10pt 띠를 쓴다.
- 시간 버튼 줄을 2칸이나 4칸으로 바꾸지 않는다. 3칸 같은 폭이다.
- 좌우 여백을 18~20pt 선 밖으로 벌리거나 좁히지 않는다(가로 넘김 배너·사진은 예외).

## 5. 모서리·고도·모션
픽셀은 iOS pt와 같다고 보고 적었다(1pt = CSS 1px). 1배율이라 ±2px 오차가 있다.

### 모서리
| 토큰 | 값 | 쓰임 |
|---|---|---|
| radius-xs | 2px | 매장 썸네일 이미지, 혜택 배지 |
| radius-tag-2025 | 4px | 새 버전 매장 주제 태그 |
| radius-sm | 6px | 시간 버튼, 하단 확인 버튼, 닫기 버튼, 새 버전 날짜 칸, 새 버전 매장 사진 |
| radius-md | 8px | 지도·필터 아이콘 상자, 둘러보기 사진 카드, 새 버전 추천 검색어 카드, 새 버전 홈 배너, 새 버전 지도 검색창 |
| radius-lg | 12px | 새 버전 검색창(흰 바탕 + 진회색 테두리), 새 버전 홈 바로가기 타일, 새 버전 안내 상자 |
| radius-sheet | 16px | 바텀시트 위쪽 두 모서리(새 버전 지도 목록 바텀시트도 같음) |
| radius-full | 999px | 검색창, 필터 칩, 해시태그 칩, 저장 원, 날짜 원, 인원 원, 지도 위 탭·버튼, 새 버전 홈 검색창·로고 원·"N" 배지, 지도 분류 칩, 지도 묶음 핀, 탭 바 위 말풍선 |

- 모서리 규칙: 누르는 버튼은 6pt로 각진 편, 고르는 칩·원은 완전히 둥글다.

### 테두리·구분선
- border: 1pt #e2e2e2 — 아이콘 상자, 닫기 버튼, 회색 칩
- border-accent: 1pt #eb4f27 — 해시태그 칩, 선택된 필터 칩
- divider: 1pt #ebebeb — 목록 구분선
- section-gap: 10pt #ececec — 구획 사이 띠(새 버전 홈은 8pt #f5f5f5)
- border-2025: 1pt #eeeeee — 새 버전 필터 칩
- border-date: 1pt #e1e6eb — 새 버전 예약 가능 날짜 칸

### 고도(층)
- 기본 목록 화면은 평면이다. 층은 흰 면과 회색 띠(#ececec)로 나눈다. 검색결과 카드에는 그림자가 없다.
- 그림자는 지도 위에 떠 있는 요소에만 쓴다: 떠 있는 탭, "이 지역 검색하기" 버튼, 현재 위치 버튼, 지도 위 매장 카드, 새 버전 지도 검색창, 새 버전 안내 상자(아래로 약 8pt 번짐). 그림자 값은 확인 필요.
- 바텀시트 뒤 가림막은 약 50% 검정(`dim`). 새 버전 지도 목록 바텀시트는 가림막 없이 지도 위에 겹친다.

### 모션
- 길이·이징: 캡처로 알 수 없음. 확인 필요.

### Don't
- 누르는 버튼(시간·확인·닫기)을 알약(999px)으로 만들지 않는다. 6pt다.
- 검색결과 목록 카드에 그림자를 넣지 않는다. 그림자는 지도 위 떠 있는 요소에만.
- 정렬 바텀시트에 손잡이 막대를 넣지 않는다(손잡이는 2025년 지도 목록 바텀시트에만).
- 그림자 수치를 정해진 값처럼 쓰지 않는다. 확인되지 않았다.

## 6. 컴포넌트
컴포넌트마다 크기, 종류, 상태, 규칙을 적는다. 보지 못한 상태는 `확인 필요`. 접근성 메모 중 서비스가 실제로 그렇게 한다는 근거가 없는 것은 `(구현 권장)`을 달았다.

| 눌림·hover | — | 확인 필요 |
| 로딩 | — | 확인 필요 |

**규칙**
- 주황 채움 버튼은 예약·확정 행동에만 쓴다. 필터 선택에 쓰지 않는다(필터는 테두리 칩).
- 바텀시트 닫기는 주황이 아니라 흰 테두리 버튼이다.
- 시간 버튼은 카드마다 3칸을 채운다. 예약 가능한 시간이 적으면 빈 회색 칸으로 3칸을 맞춘다.
- 하단 확인 버튼은 화면 맨 아래 하나만 둔다.
- 시간 버튼 문구는 "오후 7:00"처럼 오전·오후 + 12시간제로 쓴다.
- 접근성: 예약 불가 칸은 글자가 없으므로 스크린리더용 이름(예: "예약 불가")과 비활성 상태를 따로 준다 (구현 권장). 시간 버튼 높이 38pt는 44pt보다 낮으므로 위아래 누르는 영역을 넓힌다 (구현 권장).

### 6.2 입력창
**크기**

| 종류 | 높이 | 폭 | 모서리 | 바탕·선 |
|---|---|---|---|---|
| 검색창(2023) | 36pt | 약 300pt | 999px | gray-50 바탕, 선 없음 |
| 새 버전 검색창(IMG_5240) | 약 42pt | 확인 필요 | 약 12pt | 흰 바탕 + 1pt 진회색 테두리 |
| 2025년 홈 검색창 | 34pt | 확인 필요 | 999px | #f1f1f1 바탕 |
| 2025년 지도 검색창 | 42pt | 화면 폭 - 좌우 18pt | 약 8pt | 흰 상자 + 옅은 그림자 |

- 검색창(2023): 상단 뒤로 화살표 오른쪽, 왼쪽 돋보기, 회색 placeholder(13~14pt). 입력하면 오른쪽에 회색 원 지우기 버튼. 커서는 주황(primary 계열)이다.
- 새 버전 검색창: 돋보기 없이 placeholder만.
- 2025년 홈 검색창: 왼쪽 회색 돋보기 + 회색 안내 글자.
- 2025년 지도 검색창: 왼쪽 뒤로 화살표 + 검색어, 오른쪽에 세로선 뒤 파랑 달력 아이콘 + "날짜·인원".

**상태**: 기본·입력 중(지우기 버튼 나타남) 확인. 오류·비활성은 확인 필요.

**규칙**
- 검색창은 상단 바 안에 둔다(뒤로 화살표 오른쪽).
- 지우기 버튼은 입력이 있을 때만 보인다.
- 접근성: 지우기 버튼에 "검색어 지우기" 같은 `aria-label`을 단다 (구현 권장). placeholder만으로 입력창 이름을 대신하지 않는다 (구현 권장).

### 6.4 카드·리스트
**구성**

| 종류 | 구성(위 → 아래) | 크기 |
|---|---|---|
| 검색결과 카드 | 왼쪽 세로 썸네일, 오른쪽 혜택 배지(선택) → 매장 이름 20pt 굵게 → 소개 2줄 말줄임 → 별 + 점수 굵게 + 리뷰 수 회색 → 업종·지역 / 영업·가격대 2줄 회색 → 시간 버튼 3개. 저장 원은 이름 오른쪽 | 썸네일 약 74×99pt, 모서리 2pt |
| 자동완성 | 구획 이름(지역 / 레스토랑) 아래 줄 목록. 지역 줄은 주황 핀 + 이름(일치 부분 주황) + 주황 매장 수 + 아래 회색 주소. 매장 줄은 썸네일 + 이름 + 주소. 맨 아래 "없으면 제안하기" 안내와 링크 | 지역 줄 약 66pt, 매장 줄 약 85pt |
| 급상승 순위 | 2열 번호 목록(굵은 숫자 + 매장 이름 한 줄 말줄임), 줄마다 구분선 | 줄 간격 53pt |
| 둘러보기 카드 | 정사각 사진, 위에 흰 굵은 큰 제목, 아래 흰 작은 해시태그. 가로 스크롤 | 약 148×148pt, 모서리 8pt |
| 새 버전 홈 바로가기 | #f4f4f4 둥근 사각 타일 안 주황·회색 계열 그림 아이콘, 아래 12pt 이름. 5열 격자, 새 항목은 오른쪽 위 주황 원 "N" 배지 | 타일 46pt, 모서리 12pt |
| 새 버전 홈 배너 | 화면 폭보다 좁은 둥근 사진 카드, 양옆 배너가 살짝 보이고 아래쪽 안에 흰 점 쪽 표시. 사진 위 흰 굵은 큰 제목 + 작은 설명 | 약 336×220pt, 모서리 8pt |
| 새 버전 지도 목록 매장 블록 | 태그 줄 → 매장 이름 18pt 굵게 + 결제 표시 → 별 + 굵은 점수 + 회색 리뷰 수·지역·업종 → 가로 사진 3장 → 영업 시간·가격대 줄(작은 아이콘) + 주황 혜택 줄 → 날짜 칸 줄 → 1pt 테두리 안내 상자(모서리 12pt). 맨 아래 작은 회색 "AD" 표시가 붙는 블록도 있다 | 사진 약 164×130pt, 사이 2pt |

- 상태: 눌림·로딩(스켈레톤)은 확인 필요.

**규칙**
- 검색결과 카드는 테두리·그림자 없이 흰 면에 놓고, 카드 사이는 약 60pt 여백으로 나눈다.
- 혜택 배지는 매장 이름 위에만 둔다.
- 메타 정보는 2줄, #bcbcbc로 둔다.
- 접근성: 썸네일·사진에 매장 이름이 들어간 대체 텍스트를 준다 (구현 권장). 광고 블록의 "AD" 표시는 스크린리더에도 읽히게 한다 (구현 권장).

### 6.5 상단 바·하단 탭 바
- 상단 바: 왼쪽 뒤로 화살표, 그 옆 왼쪽 정렬 제목 20pt 굵게(가운데 정렬 아님).
- 날짜·인원 줄: 달력 아이콘 + "오늘 (요일)" | 시간 | 인원, 세로선으로 나누고 오른쪽 끝에 주황 아래 화살표. 높이 약 46pt.
- 상단 바(2025년 홈): 왼쪽 주황 원 로고, 가운데 알약 검색창, 오른쪽 저장·알림 선 아이콘(알림에 주황 점). 아래 줄에 회색 핀 + 굵은 지역 이름 + 아래꺾쇠.
- 하단 탭 바(2025년 홈): 흰 바탕, 위 1pt #ebebeb 선, 5칸 아이콘 + 10pt 이름. 선택 탭은 #222222 채운 아이콘, 나머지는 회색 선 아이콘. 가운데 탭 위에 주황 알약 말풍선(흰 글자)을 띄워 기능을 알린다. 홈 인디케이터 포함 약 92pt.
- 2023년 화면의 하단 탭 바는 캡처에 없다. 확인 필요.

**규칙**
- 하단 탭 선택은 아이콘을 채우는 것으로 표시한다(색은 #222222, 주황 아님).
- 접근성: 뒤로 화살표·저장·알림 아이콘 버튼에 `aria-label`을 단다 (구현 권장). 선택 탭에 `aria-current`를 준다 (구현 권장).

### 6.6 바텀시트·전체 화면 선택기
| 종류 | 모양 | 닫기 |
|---|---|---|
| 정렬 바텀시트 | 흰 바탕, 위쪽 모서리 16pt, 뒤는 약 50% 검정 가림막. 옵션은 가운데 정렬 16pt, 줄 간격 46pt, 선택 옵션 옆에 주황 체크. 손잡이 막대 없음 | 맨 아래 닫기 버튼 |
| 2025년 지도 목록 바텀시트 | 지도 아래에서 올라오는 흰 시트, 위쪽 모서리 16pt, 가운데 손잡이 막대(약 28×4pt, #eaeaea). 가림막 없이 지도 위에 겹친다 | 끌어내림(확인 필요) |
| 날짜·인원 선택 | 화면 전체를 덮는 흰 화면. 달력(왼쪽 위 주황 "오늘", 가운데 연월과 좌우 화살표, 7열 날짜, 선택 날짜는 지름 35pt 주황 원) → 구분선 → 인원 원 가로 스크롤 → 맨 아래 확인 버튼 | 오른쪽 위 X |

**규칙**
- 고르기만 하는 짧은 옵션(정렬)은 전체 화면이 아니라 바텀시트로 띄운다. 날짜·인원처럼 여러 값을 함께 고를 때만 전체 화면을 쓴다.
- 달력의 고를 수 없는 날짜는 #d6d6d6 글자로 낮춘다.
- 접근성: 바텀시트가 열리면 포커스를 시트 안으로 옮기고 닫히면 연 버튼으로 돌린다 (구현 권장). 시트에 `role="dialog"`를 준다 (구현 권장).

### 6.8 지도
- 지도 위 떠 있는 3칸 알약 탭(높이 약 42pt), 선택 칸만 주황 글자.
- 핀: primary 물방울 핀. 선택된 매장 핀은 더 크다.
- 2025년 지도: 지역 묶음 핀은 흰 알약(높이 약 26pt) + 주황 테두리 + 진회색 지역 이름 + 주황 굵은 매장 수. 왼쪽 아래 흰 원형 현재 위치 버튼. 지도 위 맨 위에 떠 있는 검색창과 분류 칩 줄.
- "이 지역 검색하기": 흰 알약(약 36pt 높이), 그 오른쪽 원형 현재 위치 버튼.
- 아래에 가로로 넘기는 흰 매장 카드(목록 카드와 같은 구성, 시간 버튼 3개). 맨 아래 줄에 뒤로·목록·필터 아이콘 + 주황 예약 조건 버튼.

**규칙**
- 지도 위 부품은 모두 흰 알약·원 + 옅은 그림자로 띄운다.
- 지도 카드에도 시간 버튼 3개를 그대로 둔다. 목록과 지도에서 같은 카드를 쓴다.

### 6.9 아이콘·이미지
- 아이콘: 약 1.5pt 굵기 선 아이콘(뒤로 화살표, 돋보기, 달력, 지도, 필터 슬라이더, 정렬). 대부분 검정·진회색, 지역 핀과 날짜 화살표만 주황.
- 사진: 매장 사진을 썸네일(세로형)과 정사각 카드로 쓴다. 둘러보기 카드는 사진 위에 어두운 막을 깔고 흰 글자를 얹는다.
- 새 버전 추천 검색어 카드에는 작은 색 아이콘(병, 막대그래프, 자동차)이 들어간다.
- 2025년 홈 바로가기 아이콘은 주황·회색·살구색 계열 그림 아이콘으로 톤을 맞춘다. 하단 탭 바 아이콘은 선 아이콘이고 선택하면 채운다.

## 7. 패턴
- 목록 → 상세: 검색결과 카드에서 시간 버튼을 바로 눌러 예약으로 들어간다. 매장 상세 화면은 보지 못했다(확인 필요).
- 검색: 검색 시작(추천 해시태그·급상승 순위·둘러보기) → 입력 중 자동완성(지역 / 레스토랑 구획, 일치 글자 주황) → 결과 목록(탭 → 날짜·인원 줄 → 필터 칩 → 매장 수 + 정렬 → 카드).
- 조건 고르기: 날짜·시간·인원은 목록 위 한 줄에 요약해 두고, 누르면 전체 화면 선택기(달력 + 인원 원 + 확인 버튼)를 연다.
- 정렬: 바텀시트 + 가운데 정렬 옵션 + 주황 체크 + 닫기 버튼.
- 지도 ↔ 목록: 지도 위에 떠 있는 탭·검색창, 아래 가로 넘김 카드(2023년) 또는 끌어올리는 바텀시트 목록(2025년).

### 빈 상태
- 확인된 것: 자동완성 맨 아래 "없으면 제안하기" 안내 + "+ 매장 제안하기" 텍스트 링크. 안내는 해요체 한 문장, 할 일은 "+ ○○하기" 링크로 준다.
- 검색결과 0건 화면 전체는 확인 필요.

```
찾는 식당이 없나요? 알려주시면 살펴볼게요.
+ 식당 알려주기
```
(예시 문구, SylviaLab 작성)

### 로딩
- 확인 필요(스켈레톤·스피너 캡처 없음).

### 오류
- 확인 필요(오류 화면 캡처 없음).

### 예약·결제 흐름
- 예약 확정·결제 화면은 보지 못했다. 확인 필요.
- 확인된 앞단: 시간 버튼(카드) 또는 날짜·인원 선택기의 확인 버튼에서 예약으로 넘어간다.

## 9. 글쓰기 톤
- 말투: 화면·구획 제목은 명사형(검색결과, 관심 급상승 레스토랑). 안내 문장은 해요체("~해주세요"). 그 아래 "+ ○○하기" 링크로 할 일을 준다.
- 둘러보기 질문은 해요체 의문문 한 줄("이런 ○○을 찾으시나요?" 꼴).
- 홈 바로가기 이름은 2~6글자 명사구(○○맛집, ○○TOP). 검색창 안내는 해요체 권유 문장("~해보세요!" 꼴).
- 버튼 문구 꼴: 정렬 옵션은 "○○ 순"으로 끝을 맞춘다. 가격 순은 화살표(↑↓)로 방향을 붙인다. 날짜 칸은 "날짜 (요일)" 아래 "예약 가능"·"예약 마감" 두 상태 말만 쓴다.
- 혜택 배지·해시태그는 마침표 없는 짧은 명사구.
- 숫자·단위 표기: 시간은 "오후 7:00", 날짜는 "오늘 (목)"처럼 요일을 괄호로. 리뷰 수는 괄호와 쉼표(1,247).

## 10. Do & Don't
관찰 기반 문서의 규칙은 "이 서비스 화면에서 반복되는 규칙"을 SylviaLab이 정리한 것이다(공식 규칙 아님).

### Do
- 검색결과 카드 아래에 시간 버튼 3개(약 78×38pt, 사이 5pt, 모서리 6pt, #eb4f27 채움)를 같은 폭으로 둔다.
- 예약할 수 없는 시간 칸은 #f1f1f1 빈 칸으로 남겨 3칸 줄을 유지한다.
- 필터 칩 선택은 1pt #eb4f27 테두리 + #f9eee8 바탕 + 주황 글자로 표시한다.
- 큰 구획 사이는 10pt #ececec 띠로 끊는다.
- 주소·업종·가격대는 11~12pt #bcbcbc로 낮춘다.
- 하단 확인 버튼은 폭 꽉 참, 높이 48pt, 모서리 6pt로 만든다.
- 바텀시트는 위 모서리 16pt, 정렬 옵션은 가운데 정렬 16pt에 선택 옆 주황 체크.
- 상단 바 제목은 왼쪽 정렬 20pt 700으로 둔다.

### Don't
- #eb4f27과 2025년 강조색 #ff3d00을 한 화면에 섞지 않는다.
- 필터 칩 선택을 주황으로 꽉 채우지 않는다(채움은 날짜·인원·확인에만).
- 검색결과 카드 사이에 구분선을 긋지 않는다(약 60pt 여백으로 나눈다).
