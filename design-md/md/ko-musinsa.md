# 무신사 디자인 시스템

> 근거: 관찰 기반 (웹: macOS Chrome 데스크톱 · 창 너비 1362px · computed style 직접 읽음, 실측일 2026-10-31) + (앱 캡처: 레이어 날짜 2024-10-21 iOS 앱 상품 옵션·장바구니·주문서·결제수단·약관 동의·주문 완료·주문 상세 화면 12장, 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31) + (앱 캡처 추가: 2025년 6월쯤 iOS 앱 홈 첫 화면 1장(375pt 폭 1배율)·검색 시작 화면 1장(430pt 폭 1배율), 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

웹 값은 연결된 Chrome에서 국내 사이트를 열고 읽었다(로그인하지 않음). 앱 값은 SylviaLab 벤치마킹 피그마 파일 속 iOS 캡처에서 쟀다. 구매 흐름 캡처와 웹은 2년쯤, 홈·검색 캡처와 웹은 1년 4개월쯤 차이가 난다. 그래서 웹과 앱 값이 다를 때 플랫폼 차이인지 시기 차이인지는 확인 필요다.

## 1. 개요
- 서비스 성격: 패션·뷰티 온라인 편집숍. 브랜드 상품 목록, 랭킹, 세일, 발매 정보가 중심이다. 웹(musinsa.com)과 iOS·Android 앱.
- 디자인 인상 한 줄: 흰 바탕에 검정·회색 글자. 웹은 거의 검정(#1a1b1f) 상단 바를 쓰고, 앱 구매 흐름은 파랑(#0078ff) 큰 버튼 하나로 결제까지 끌고 간다. 할인은 빨강, 할인 금액은 하늘색 숫자로 보여 준다.
- 공식 시스템 이름: 공개된 것 없음. 웹 CSS에서 공통 색 변수(:root)는 찾지 못했다.
- 특징
  - 웹 글꼴은 Pretendard 하나. 자간 기본값(normal).
  - 상품 사진은 모서리 없이(0px) 꽉 채운다. 웹 카드와 앱 장바구니 썸네일 모두 같다.
  - 모서리는 작다. 웹은 4px가 기본, 앱은 0~4px. 원형은 아이콘·체크·라디오·작은 알약 배지에만 쓴다.
  - 그림자를 거의 쓰지 않는다. 앱에서 보인 그림자는 아래에서 올라오는 시트와 하단 고정 버튼 영역 위쪽의 옅은 그림자뿐이다.
  - 앱 구매 흐름(옵션 → 장바구니 → 주문서)의 주요 버튼은 화면 폭 파랑 버튼(높이 48pt, 모서리 4pt)이다. 주문 완료 화면의 "다음" 버튼과 작은 "사용" 버튼은 검정이다.
  - 앱 화면은 10pt 회색 띠(#f1f1f1)로 구획을 나눈다.
  - 앱 홈 상단(로고 줄·검색창·메인 탭)은 웹과 같은 거의 검정(#1a1b1f) 바탕이다. 그 아래 본문 바탕은 연회색(#f5f5f5)이고, 흰 칩·카드를 그 위에 올린다.
  - 앱 하단 탭 바는 흰 바탕 5칸(카테고리·스냅·홈·좋아요·마이), 홈이 가운데다.
  - 앱 검색 화면은 순위 숫자 1~3위만 파랑으로, 순위 변동은 빨강 위 삼각형·파랑 아래 삼각형으로 보여 준다.

## 4. 간격·레이아웃
- 기본 단위: 4로 보인다. 공식 단위는 확인 필요.
- 간격 단계(관찰, pt): 3, 4, 5, 8, 10, 12, 14, 15, 16, 18, 20, 30, 40
- 웹에서 실측한 패딩 값: 2, 4, 5, 6, 7, 8, 12, 14, 16px
- 앱 화면 좌우 여백: 글자·입력창·구획 제목 14pt, 하단 파랑 버튼 12pt.
- 웹 화면 좌우 여백(데스크톱): 상단 바 좌우 16px. 메인 탭 바 좌우 8px + 탭마다 좌우 7px.
- 앱 기준 화면: 375×812pt 아이폰. 상태 표시줄 44pt, 상단 바 약 56pt. 검색 시작 화면 1장은 430pt 폭 기기 캡처다.
- 앱 홈 상단 구조(위→아래, 모두 #1a1b1f 바탕): 상태 표시줄 44pt → 로고·아이콘 줄 약 48pt → 검색창 줄(흰 상자 344×34pt, 좌우 15pt) → 메인 탭 줄 약 44pt. 상단 전체 약 176pt.
- 앱 홈 좌우 여백: 15pt. 배너는 왼쪽 15pt에서 시작해 오른쪽 화면 끝까지 걸친다(가로 넘김).

- 앱 결제 흐름은 금액이 먼저다. "[금액] 결제하기", "지금 구매하면 [금액] 할인", "[n]% SAVE". 할인 숫자에는 마이너스 기호를 붙인다.
- 안내 문장은 해요체·합니다체를 섞는다. 완료 문장은 "~되었습니다.", 권유 말풍선은 "~하세요!".
- 영문 짧은 표시를 섞는다(SAVE, EVENT).
- 검색 화면 순위에는 기준을 붙인다("날짜 시각, 성별 기준"). 검색창 안내 글자는 해요체 요청형, 홈 검색창에는 행사 문구를 넣는다.

### 근거와 한계
- 무신사는 디자인 시스템 문서를 공개하지 않았다. 웹 값은 세 화면의 computed style, 앱 값은 캡처 픽셀에서 반복된 값이다.
- 웹은 2026-10-31 데스크톱 Chrome 비로그인 상태 한 번의 실측이다. 앱 캡처는 레이어 날짜가 2024-10-21이고, 화면 속 정보로 보면 실제 캡처는 그보다 이를 수 있다. 웹과 앱 사이 차이(파랑 #0078ff 주요 버튼 등)가 지금도 그대로인지는 확인 필요다.
- 앱 캡처가 375pt 1배율이라 글자 크기는 ±1pt, 작은 글자 색과 1pt 테두리 색은 번짐 오차가 있다. 넓은 면 색(파랑 버튼, 회색 띠, 검정 버튼)은 정확하다.
- 앱 홈·검색 캡처는 화면 속 행사 기간과 순위 기준 시각으로 보아 2025년 6월쯤이다. 홈 첫 배너(주황 행사 그림)는 그때 행사 내용이라 UI 색에서 뺐다.
- 검색 시작 화면(1:25680)에는 로고가 없다. 순위 속 자사 브랜드 이름, 하락 표시 파랑(#0078ff)과 상승 표시 빨강(#ff0000)이 구매 흐름 캡처 값과 픽셀 단위로 같아 무신사 화면으로 판단했다. 이 화면은 430pt 폭 기기 캡처다.
- 앱은 구매 흐름, 홈 첫 화면, 검색 시작 화면만 봤다. 앱 목록, 검색 결과, 상품 상세, 토스트, 다크 모드, 모바일 웹은 보지 않았다.
- 캡처 속 이름, 주소, 주문 번호, 금액 같은 개인 정보는 옮기지 않았다.
- 토큰 이름은 SylviaLab이 쓰임에 맞춰 붙인 이름이다. 관찰한 값은 서비스가 바뀌면 달라질 수 있다.

서비스 이름과 브랜드는 각 권리자의 것이다. 이 문서는 식별·학습용 참고 자료로 SylviaLab이 독자적으로 작성했다.
