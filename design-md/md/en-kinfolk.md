# 킨포크(Kinfolk) 웹 디자인 시스템

> 근거: 관찰 기반 (모바일 웹 캡처: 킨포크 "Case Study Room" 콘텐츠 페이지를 휴대폰 브라우저로 본 화면 5장, 약 466px 폭 이미지에서 픽셀 측정. 원래 기기 폭은 확인 필요, 이미지 1px ≈ CSS 1px로 봄. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

## 1. 개요
- 서비스 성격: 라이프스타일 잡지 킨포크의 브랜드 웹사이트. 이번 캡처는 그 안의 "Case Study Room"(가구·사진 전시 공간을 소개하는 콘텐츠) 페이지다. 글은 영문이다.
- 디자인 인상 한 줄: 흰 바탕, 검정 글자, 큰 사진. 색은 거의 없고 세리프 제목과 산세리프 본문, 넉넉한 여백으로 잡지 지면처럼 읽힌다.
- 공식 시스템 이름: 공개된 이름 없음
- 특징
  - UI 색은 흰색과 검정 두 가지다. 강조색, 버튼 색은 캡처에서 보이지 않았다.
  - 첫 화면은 사진을 화면 끝까지 채우고, 그 위에 흰 글자 머리(Menu, 가운데 워드마크)를 얹는다.
  - 본문 사진은 화면 폭보다 좁은 세로 사진(약 4:5)을 왼쪽·가운데·오른쪽으로 번갈아 놓는다. 사진마다 아래에 작은 캡션을 단다.
  - 제목과 인용 문구는 세리프, 본문과 캡션은 산세리프로 나눈다.
  - 사진 모서리는 살짝 둥글다(약 8px).
- 공개 자료 상황: 공개 디자인 시스템 문서나 코드는 찾지 못했다. 확인 필요.

## 2. 색상
값은 캡처 이미지 픽셀에서 읽었다. UI(바탕·글자) 색만 적었고 사진 속 색은 넣지 않았다. 작은 글자 색은 글자 테두리 번짐 때문에 오차가 있다. 토큰 이름은 SylviaLab이 붙인 것이다.

### 바탕
| 토큰 | HEX | 쓰임 |
|---|---|---|
| bg | #ffffff | 본문 페이지 바탕 |

### 글자
| 토큰 | HEX | 쓰임 |
|---|---|---|
| text-primary | #000000 | 세리프 제목, 세리프 인용 문구, 본문, 사진 캡션 |
| text-on-photo | #ffffff | 첫 화면 사진 위 머리 글자(Menu, 워드마크) |

- 본문·캡션도 가장 진한 픽셀이 #000000~#0d0d0d로 읽혀 제목과 같은 검정으로 본다. 회색 보조 글자는 캡처에서 보이지 않았다.
- 링크 색, 버튼 색, 상태 색(오류·성공): 확인 필요

## 3. 타이포그래피
- 글꼴: 세리프 제목체(추정. 모양은 Lora 계열과 비슷하다. 실제 이름 확인 필요)
- 본문 글꼴: 산세리프(추정. Helvetica 계열 모양. 실제 이름 확인 필요)
- 워드마크: 자간을 넓게 띄운 세리프 영문 대문자, 아래 작은 세리프 약자를 한 줄 더 둔다.
- 크기는 영문 대문자 높이 ÷ 0.7로 계산한 추정값이다(±1). 행간은 줄 간격을 잰 값이다.

| 단계 | 크기(pt) | 굵기 | 행간 | 쓰임 |
|---|---|---|---|---|
| title-serif | 25 | 400 | 확인 필요 | 구획 제목(한 줄) |
| quote-serif | 23 | 400 | 약 26px(1.1) | 사진 사이 큰 세리프 문구(3줄) |
| body | 13 | 400 | 약 19px(1.5) | 본문 문단 |
| caption | 14 | 400 | 확인 필요 | 사진 아래 작품명·사진 출처 캡션 |
| nav | 13 | 400 | 확인 필요 | 첫 화면 왼쪽 위 "Menu" |

## 4. 간격·레이아웃
- 기준 화면: 휴대폰 폭(이미지 약 466px). 실제 기기 폭은 확인 필요.
- 간격 단계(관찰, pt): 8, 16, 20, 60, 80
- 본문 사진: 폭 약 361px, 세로 4:5. 화면 좌우 여백은 왼쪽 정렬일 때 약 16px, 오른쪽 정렬일 때 약 18px, 가운데 정렬은 양쪽 약 52px.
- 사진 → 캡션: 약 20px. 캡션 → 다음 사진: 약 80px로 크게 띄운다.
- 글 덩어리는 사진보다 안쪽에서 시작한다. 제목·본문은 왼쪽 약 75px, 큰 세리프 문구는 약 113px에서 시작한다.
- 제목 → 본문: 약 20px.
- 그리드: 확인 필요

## 5. 모서리·그림자·테두리
| 토큰 | 값 | 쓰임 |
|---|---|---|
| radius-photo | 8px | 본문 사진 |
| radius-none | 0px | 첫 화면 꽉 찬 사진 |

- 그림자, 테두리: 캡처에서 보이지 않았다.
- 이미지 1px을 CSS 1px로 보고 적었다.

## 6. 주요 컴포넌트
### 버튼
- 캡처에 없음. 확인 필요.

### 입력창
- 캡처에 없음. 확인 필요.

### 카드·리스트
- 사진 + 캡션 묶음: 둥근 모서리 세로 사진 아래 산세리프 한두 줄 캡션. 캡션은 사진 왼쪽 끝에 맞춘다.
- 큰 세리프 문구 덩어리: 사진 사이에 3줄 정도, 왼쪽 정렬로 안쪽에 들여 놓는다.
- 글 덩어리: 세리프 제목 한 줄 + 산세리프 본문 문단.

### 상단 바·탭 바
- 첫 화면 사진 위에 투명하게 얹는다. 왼쪽에 흰 "Menu" 글자(아이콘 없음), 가운데에 흰 워드마크.
- 스크롤 뒤 상단 바 모습, 메뉴를 연 화면: 확인 필요.
- 하단 탭 바: 없음.

### 바텀시트·모달

### 토스트·스낵바

## 7. 아이콘·이미지·모션
- 아이콘: 캡처에서 보이지 않았다. 메뉴도 글자로 쓴다.
- 사진: 화면 대부분을 차지한다. 밝은 자연광의 실내·가구 사진.
- 모션: 캡처로 알 수 없음. 확인 필요.

## 8. 글쓰기 톤(UX 라이팅)
- 영문으로 쓴다. 제목은 짧은 명사구, 본문은 서술형 문단.
- 사진 캡션은 "작품명, 사진 출처" 꼴로 짧게 붙인다.
- 한국어 문구는 캡처에 없음. 확인 필요.

근거와 한계
- 캡처 시기는 확인 필요. 화면 5장 모두 같은 콘텐츠 페이지(첫 화면과 아래로 스크롤한 부분)다.
- 이미지 폭이 약 466px이라 원래 기기 폭과 배율을 알 수 없다. 크기·간격은 이미지 1px을 CSS 1px로 본 추정이라 ±10% 정도 차이가 날 수 있다.
- 일부 캡처 왼쪽 끝의 옅은 회색 그림자는 화면 전환 중 겹친 것으로 보고 UI 색에서 뺐다.
- 홈, 목록, 메뉴, 쇼핑·구독 화면은 보지 못했다.
- 화면 속 워드마크와 글은 옮기지 않았다.
- 관찰 값은 서비스가 바뀌면 달라질 수 있다.

서비스 이름과 브랜드는 각 권리자의 것이다. 이 문서는 식별·학습용 참고 자료로 SylviaLab이 독자적으로 작성했다.
