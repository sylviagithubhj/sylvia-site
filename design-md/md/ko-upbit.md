# 업비트 디자인 시스템

> 근거: 관찰 기반 (앱 캡처, 실측일 2026-10-31, iOS 업비트 앱 다크 모드, 아이폰 393×852pt 화면 3배율 캡처 7장: 스플래시, 거래소(시세 목록), 코인정보 마켓 2장, 투자내역, 입출금, 더보기)
> 작성: SylviaLab · 최종 수정 2026-10-31

이 문서는 디자인 시스템의 다섯 층(원칙, 토큰, 컴포넌트, 사용 규칙, 구현·검증)을 한 파일로 줄인 요약이다. 맨 위 YAML은 도구와 AI가 그대로 읽는 값이고, 아래 글은 그 값을 언제·왜 쓰는지 설명한다. 이 문서의 색은 모두 다크 모드 값이다(라이트 모드는 찾지 못했다).

## 1. 개요와 원칙
- 서비스 성격: 두나무가 운영하는 디지털 자산 거래소. 웹(upbit.com)과 iOS·Android 앱. 실시간 시세, 차트, 주문, 입출금, 코인모으기(자동 적립 구매), 스테이킹을 제공한다.
- 디자인 인상 한 줄: 남색에 가까운 검정 바탕 위에 흰 글자, 오르면 빨강·내리면 파랑. 장식은 거의 없고 숫자와 색으로 시세를 읽게 한다.
- 공식 시스템 이름: 공개된 이름 없음
- 디자인 원칙(공식 원칙은 공개되지 않았다)
  1. 시세는 두 색으로 읽는다. 상승 빨강 #cc494a, 하락 파랑 #3673e4가 숫자·막대·차트 선·차트 아래 면까지 맡는다. (관찰에서 정리)
  2. 바탕은 순수 검정이 아니라 푸른 남색 #07101d이고, 카드·구획은 같은 남색 계열을 몇 단계 밝혀 나눈다. (관찰에서 정리)
  3. 정보는 각지게, 조작은 둥글게. 정보 카드는 4pt, 떠 있는 탭 바·토스트·아이콘 버튼은 완전히 둥글다. (관찰에서 정리)
  4. 정보는 선 아이콘, 혜택·이벤트는 광택 있는 3D 그림으로 나눈다. (관찰에서 정리)
  5. 색만으로 뜻을 나누지 않는다. 빨강 하나가 상승과 경고를 같이 맡으므로 글자와 아이콘으로 구분한다. (관찰에서 정리)
- 톤: 장식 없이 숫자 중심, 어둡고 차분하게.

### 이 문서를 읽는 AI 에이전트에게
- 이 문서의 색은 모두 다크 모드 값이다. 라이트 화면을 만들 근거는 없다. 바탕은 `bg` #07101d이고 순수 검정을 쓰지 않는다.
- 시세 값은 `rise` #cc494a / `fall` #3673e4 / `price-flat`(#d2d4d6) 셋 중 하나로만 칠한다. 다른 뜻에 이 두 색을 새로 쓰지 않는다.
- 층은 그림자가 아니라 남색 면 단계(`bg` → `surface-1` → `surface-2` → `tabbar`)로 나눈다.
- 정보 카드는 `rounded.sm`(4pt), 떠 있는 조작 요소는 `rounded.full`로 고른다.
- 판단이 어려우면 장식을 빼고 숫자와 등락 색만 남긴다.

### 특장점
- 등락 색이 화면 전체를 이끈다 — 시세 목록의 현재가 숫자 자체를 #cc494a/#3673e4로 칠하고, 오늘의 마켓 막대, 미니 차트 선과 그 아래 면(#201b29, #112039)까지 같은 두 색 계열로 맞춘다. 보합은 기본 글자색 #d2d4d6.
- 남색 단계로 층을 만든다 — 바탕 #07101d, 카드 #0e1625, 구획 띠 #0f192a, 태그·구분선 #1c2332, 탭 바 #253040처럼 같은 남색을 밝혀 그림자 없이 층을 나눈다.
- 하단 탭 바가 떠 있는 알약이다 — 약 350×60pt #253040 알약이 화면에서 떨어져 떠 있고, 선택 탭은 그 안의 약 84×52pt 더 어두운 알약(#0b192b)으로 표시한다. 탭 바는 반투명이다.
- 유의 정보를 한 글자 배지로 압축한다 — 코인 이름 옆 약 12×12pt 네모에 위(#cc494a)·경(#da7a33)·주(#e8973d)·밈(#6251d8) 한 글자를 넣는다.
- 시세 목록이 한 줄에 네 가지를 담는다 — 약 45pt 줄에 미니 캔들(폭 약 6pt), 한글명+거래쌍, 현재가, 등락률+차액, 거래대금을 놓는다.

### 배울 점
- 다크 모드에서 층을 나눌 때 업비트처럼 그림자 대신 같은 색조(남색)를 몇 단계 밝힌 면을 쓴다.
- 오름·내림처럼 두 값이 대비되는 데이터를 보여 줄 때 업비트처럼 숫자, 막대, 차트 선, 선 아래 면까지 한 쌍의 색으로 묶고, 중립 값은 기본 글자색으로 둔다.
- 경고 등급이 여럿일 때 업비트처럼 이름 옆에 한 글자 색 배지를 붙여 줄 높이를 늘리지 않고 표시한다.

## 2. 색상
모든 값은 다크 모드 캡처의 픽셀에서 직접 읽었다. 앱 안에서 라이트 모드 설정을 찾지 못해 다크 모드 값만 적었다. 토큰 이름은 SylviaLab이 붙인 것이다.

### 고도
- 고도(그림자·층): 그림자는 확인 필요. 다크 화면이라 캡처로는 보이지 않는다. 떠 있는 탭 바 경계는 바탕보다 밝은 면으로 드러난다. 상단 바는 내용 위로 스크롤될 때 흐림 처리(블러)가 들어가고, 하단 탭 바는 반투명이다.
- 정보 카드는 거의 각진 4pt, 떠 있는 조작 요소(탭 바, 토스트, 아이콘 버튼)는 완전히 둥글다. 두 성격을 모서리로 나눈다.
- 픽셀 단위는 iOS pt와 같다고 보고 적었다(1pt = CSS 1px).
### 모션
- 모션(길이·이징): 캡처로 알 수 없음. 확인 필요. 실시간 가격 변화 표시(깜빡임 등)도 확인 필요.

### Don't
- 정보 카드에 큰 모서리(12pt 이상)를 주지 않는다. 12pt는 안내 배너 하나뿐이다.
- 떠 있는 탭 바·토스트를 각지게 만들지 않는다.
- 층을 그림자로 표현하지 않는다. 밝은 남색 면으로 나눈다.
- 탭 바를 불투명 단색으로 막지 않는다. 반투명이다.

- 색은 PNG 원본 픽셀에서 읽어 정확도가 높다. 크기·간격은 캡처에서 잰 값을 pt로 바꾼 추정이라 ±1pt 오차가 있다.
- 다크 모드만 확인했다. 앱 안에서 라이트 모드 설정을 찾지 못했다(사용자 확인). 종목 상세(차트·호가)와 주문 화면은 아직 보지 못했다.
- 관찰 값은 서비스가 바뀌면 달라질 수 있다.
- 근거 줄은 캡처 7장, 참고 자료 줄은 5장으로 원본에 적혀 있다. 원본 그대로 옮겼고 어느 쪽이 맞는지는 확인 필요.
- 8장 대비값과 "(관찰에서 정리)" 규칙은 SylviaLab이 이 문서의 HEX와 관찰 사실로 계산·정리한 것이다.
- 서비스 이름과 브랜드는 두나무 주식회사의 것이다. 이 문서는 식별·학습용 참고 자료로 SylviaLab이 독자적으로 작성했다.

## 부록 B. 값의 출처 구분
- **공식 자료 그대로**: 없음. 업비트는 디자인 시스템·토큰을 공개하지 않았다(docs.upbit.com, github.com/upbit-official 확인). App Store 설명에서는 기능 목록과 말투만 참고했다.
- **화면에서 잰 값(관찰, 2026-10-31, 다크 모드 캡처)**: 모든 HEX(PNG 픽셀, 정확도 높음), 글자 크기(±1pt), 줄 높이·여백·모서리·컴포넌트 크기(±1pt), 세로 리듬 표.
- **SylviaLab이 정리·권장한 것**: 모든 토큰 이름, 면 색의 "관찰 단계" 표, YAML의 참조 연결, 1·6·10장 "(관찰에서 정리)" 규칙, 각 장 Don't, 8장 대비 계산과 "(구현 권장)" 항목, 7장 예시 문구.
- **확인하지 못한 것**: 라이트 모드, 종목 상세·주문·검색, 모든 눌림·비활성·로딩 상태, 그림자, 모션, 행간.
