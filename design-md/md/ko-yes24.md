# 예스24 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 6월 기획 구획이 보이는 시기(연도 확인 필요), iOS 앱 홈 화면과 홈 스크롤 2장, 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

이 문서는 디자인 시스템의 다섯 층(원칙, 토큰, 컴포넌트, 사용 규칙, 구현·검증)을 한 파일로 줄인 요약이다. 맨 위 YAML은 도구와 AI가 그대로 읽는 값이고, 아래 글은 그 값을 언제·왜 쓰는지 설명한다. 둘이 어긋나면 YAML 값이 우선한다. 캡처가 2장뿐이라 구조만 맞추고, 보지 못한 부분은 `확인 필요`로 남겼다.

## 1. 개요와 원칙
- 서비스 성격: 온라인 서점 앱. 국내·외국 도서, 신상품, 베스트셀러, 전자책 구독(크레마클럽) 등을 판다.
- 디자인 인상 한 줄: 흰 바탕에 진회색 글자, 선명한 파랑(#0080ff) 하나로 선택·별점·가운데 버튼을 표시한다. 책 표지가 화면 색을 대부분 채운다.
- 공식 시스템 이름: 확인 필요
- 디자인 원칙(공식 원칙은 확인하지 못했다):
  1. 강조색은 파랑 하나로, 선택·별점·가운데 버튼·새 소식 점에만 쓴다. (관찰에서 정리)
  2. 책 표지가 색을 맡고, UI는 흰색·#333333·회색으로 물러선다. (관찰에서 정리)
  3. 구획은 그림자 대신 8pt 회색 띠로 나눈다. (관찰에서 정리)
  4. 모서리는 각진 것(표지·띠)과 완전히 둥근 것(버튼) 두 가지만 쓴다. (관찰에서 정리)
- 톤: 장식을 줄이고 책 표지를 앞세운 담백한 화면.
- 공개 자료 상황: 이번 작업에서는 공개 문서·오픈소스를 확인하지 못했다(네트워크 제한). 확인 필요.

### 특장점
- 강조를 파랑 하나에 모은다 — #0080ff가 선택 탭 글자·3pt 밑줄, 별점 별, 하단 가운데 원형 버튼, 새 소식 점에 모두 같은 값으로 나온다. 별점도 노랑이 아니라 브랜드 파랑이다.
- 책 표지를 각지게 그대로 둔다 — 표지는 모서리 0px, 그림자 없이 약 106pt 폭으로 놓여 표지 자체가 색과 모양을 맡는다.
- 구획을 두 굵기 회색 선으로 나눈다 — 상단 탭 아래 3pt #eeeeee 선, 구획 사이 8pt #eeeeee 띠. 카드 그림자는 없다.
- 하단 탭 바 가운데 홈 버튼이 솟아 있다 — 지름 약 50pt 파란 원에 흰 "y" 로고가 탭 바 윗선보다 약 10pt 위로 올라오고, 나머지 탭 4개는 이름 없는 아이콘이다.
- 기본 글자를 순수 검정이 아닌 #333333으로 둔다 — 구획 제목, 탭, 별점 숫자, 책 제목이 모두 이 색이다.

### 배울 점
- 강조색을 정할 때 예스24처럼 선택 표시·평점·주요 버튼을 한 색(#0080ff)으로 묶어 화면에 색이 하나만 돌게 한다.
- 표지·포스터처럼 콘텐츠 이미지가 화려할 때 예스24처럼 모서리·그림자를 빼고 UI는 무채색으로 둔다.
- 긴 홈을 나눌 때 예스24처럼 카드 그림자 대신 8pt 회색 띠를 구획 사이에 둔다.

### 이 문서를 읽는 AI 에이전트에게
- 색·크기·간격은 YAML 토큰 이름으로만 쓴다. 화면에서는 `blue-500`보다 `primary`·`rating` 같은 semantic 이름을 먼저 쓴다.
- 강조색은 `primary`(#0080ff) 하나뿐이다. 별점·선택·새 소식 점이 모두 이 색이다. 빨강·노랑을 더하지 않는다.
- 글자는 `text-primary`(#333333)가 기본이다. 순수 검정을 쓰지 않는다.
- 모서리는 `rounded.none`(표지·띠) 아니면 `rounded.full`(원형 버튼) 둘 중 하나만 고른다.
- 근거가 2장뿐이라, 가격·버튼·입력창처럼 이 문서에 없는 화면은 값을 지어내지 말고 `확인 필요`로 둔다.

## 2. 색상
값은 1배율 캡처 픽셀에서 읽었다. 넓은 면 색은 정확하고, 작은 글자 색은 글자 테두리 번짐 때문에 오차가 있다. 토큰 이름은 SylviaLab이 붙인 것이다.

### 색 체계
공개 팔레트가 없어서 캡처의 반복 색을 **관찰 팔레트**로 모으고 **역할 이름**을 붙였다(관찰에서 정리).

| 층 | 예시 | 쓰는 곳 |
|---|---|---|
| 관찰 팔레트 | `blue-500`, `gray-100`, `gray-850` | 토큰 정의에만. 번호는 밝기 순서일 뿐 공식 단계가 아니다 |
| 역할 이름 | `primary`, `rating`, `divider`, `text-primary` | 실제 화면과 컴포넌트 |

### 브랜드·행동

| blue-light | #66beff | 상단 탭 중 "예스24" 탭 글자(특별 탭으로 보임, 쓰임 확인 필요) |

- 중간 광고 배너의 남색(#003366)은 광고 소재 색으로 보고 시스템 색에서 뺐다. 기획 구획의 그림 배경 색도 뺐다.
- 상태 색의 "배경/선/글자" 조합 규칙: 확인 필요.

### 역할별 색
- 강조 `primary`(#0080ff): 선택 탭 글자 + 3pt 밑줄, 하단 가운데 원형 버튼 채움(흰 로고), 새 소식 점. 눌림 짝은 확인 필요.
- 별점 `rating`(#0080ff): 별 모양만. 숫자는 `text-primary`, 참여 수는 `text-count`.
- 특별 탭 `primary-light`(#66beff): "예스24" 탭 글자 하나에서만 보였다. 다른 곳에 쓰지 않는다.
- 글자 `text-primary`(#333333) → 보조 `text-author`(#b2b2b2 근처)·`text-count`(#a6a6a6 근처).
- 선·띠 `divider`(#eeeeee): 굵기만 3pt(탭 아래)·8pt(구획 사이)로 바꿔 쓴다.
- 버튼 면 `surface-button`(#f6f6f6) + 화살표 `icon-muted`(#818488): 맨 위로 버튼.

### 화면 모드
- 다크 모드: 확인 필요.

### 색 사용 규칙
- #0080ff는 선택 탭 글자·밑줄, 별점 별, 하단 가운데 원형 버튼, 새 소식 점에만 쓴다.
- 기본 글자는 #333333이다. 순수 검정은 쓰지 않는다.
- 보조 글자는 작가 줄 #b2b2b2 근처, 참여 수 #a6a6a6 근처다.
- 선과 띠는 #eeeeee 하나로 쓴다.
- 광고·기획 그림·책 표지 속 색(#003366 등)은 시스템 색으로 쓰지 않는다.

### Don't
- 별점에 노랑·주황을 쓰지 않는다. 별은 `rating`(#0080ff).
- `primary-light`(#66beff)를 일반 글자·버튼에 쓰지 않는다.
- 선 색을 #eeeeee 밖의 회색으로 늘리지 않는다.
- 광고 남색(#003366)을 UI 색으로 쓰지 않는다.

## 3. 타이포그래피
- 글꼴: iOS 시스템 글꼴(추정. 한글은 Apple SD Gothic Neo, 숫자는 SF Pro와 같은 모양). 전용 글꼴은 확인 필요.
- 대체 글꼴: -apple-system, 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif
- 숫자 표기: 별점은 소수 첫째 자리(10.0, 9.8), 참여 수는 괄호.
- 크기는 1배율 캡처의 글자 높이로 계산한 추정값이다(±1pt). 행간은 확인 필요. 하단 탭은 이름 없이 아이콘만 있다.

### 위계와 사용처
| 단계 | 크기(pt) | 굵기 | 행간 | 쓰임 |
|---|---|---|---|---|
| section-title | 18 | 700 | 확인 필요 | 구획 제목(어린이 책 추천, 브랜드전, 크레마클럽 >) |
| ad-title | 17 | 700 | 확인 필요 | 광고 배너 제목(흰 글자) |

| rating | 16 | 700 | 확인 필요 | 별점 숫자 |
| book-title | 14 | 400 | 확인 필요 | 책 제목(2줄) |
| author | 12 | 400 | 확인 필요 | 글·그림 작가 줄(한 줄 말줄임) |
| count | 12 | 400 | 확인 필요 | 별점 참여 수 |

### 규칙
- 굵기는 700(제목·탭·별점 숫자)과 400(책 제목·작가·참여 수) 두 가지만 쓴다.
- 책 제목은 14pt 2줄, 작가 줄은 12pt 한 줄 말줄임이다.
- 별점 숫자는 16pt 굵게, 참여 수는 12pt 회색 괄호로 붙인다.
- 링크가 되는 구획 제목은 끝에 `>`를 붙인다.

### Don't
- 500·600 굵기를 쓰지 않는다(관찰된 굵기는 400·700).
- 책 제목을 굵게 쓰지 않는다. 굵기는 별점 숫자·제목·탭 몫이다.
- 작가 줄을 2줄로 펼치지 않는다(한 줄 말줄임).
- 12pt 미만 글자를 쓰지 않는다(관찰 최소 12pt).

## 4. 레이아웃·간격
- 기준 화면: 375pt 폭 아이폰.
- 화면 좌우 여백: 약 14pt. 구획 제목과 첫 책 표지가 같은 선에 맞는다.
- 간격 단계(관찰, pt): 3, 8, 13, 14
- 그리드·최대 폭: 확인 필요
- 상단 탭: 높이 약 50pt(상태 표시줄 아래), 탭 사이 글자 간격 약 13pt, 가로 스크롤. 오른쪽 끝에 펼치기(⌄) 원형 버튼, 왼쪽 끝은 흐리게 잘린다.
- 책 가로 줄: 표지 폭 약 106pt, 표지 사이 약 13pt, 오른쪽 다음 책이 잘려 보인다.
- 구획 사이: 8pt 회색 띠.
- 하단 탭 바: 홈 인디케이터 포함 약 83pt.

| 상단 탭 줄 높이 | 약 50pt, 아래 3pt #eeeeee 선 |
| 구획 → 구획 | 8pt #eeeeee 띠 |
| 광고 배너 높이 | 약 83pt |
| 구획 제목 → 책 줄, 표지 → 제목 | 확인 필요 |
| 하단 탭 바 | 약 83pt(홈 인디케이터 포함) |

### 카드 안쪽 여백
- 책 카드는 카드 면이 없다. 표지 아래에 글자가 바로 붙는다. 표지 ↔ 제목 간격은 확인 필요.

### 간격 적용 규칙
- 구획 제목과 첫 표지는 왼쪽 14pt 선에 맞춘다.
- 표지 사이와 탭 글자 사이는 약 13pt로 같게 둔다.
- 가로 줄은 다음 책이 오른쪽에 잘려 보이게 둔다.
- 구획 사이는 8pt 띠, 탭 줄 아래는 3pt 선이다.

### Don't
- 구획 사이를 빈 여백만으로 나누지 않는다. 8pt #eeeeee 띠를 둔다.
- 가로 줄 마지막 표지를 화면 안에 딱 맞추지 않는다(다음 책이 잘려 보여야 한다).
- 표지 사이와 탭 사이를 서로 다른 값으로 두지 않는다(둘 다 약 13pt).

## 5. 모서리·고도·모션
| 토큰 | 값 | 쓰임 |
|---|---|---|
| radius-none | 0px | 책 표지, 구획 띠, 광고 배너 |
| radius-full | 999px | 하단 가운데 원형 버튼, 맨 위로 버튼, 탭 펼치기 버튼 |

- 선: divider 3pt #eeeeee(상단 탭 아래 선), section-gap 8pt #eeeeee(구획 사이 띠).
- 픽셀 단위는 iOS pt와 같다고 보고 적었다(1pt = CSS 1px).
- 각진 표지·띠와 완전히 둥근 버튼 두 가지만 보인다. 중간 크기 모서리는 이번 캡처에서 찾지 못했다.

### 고도(층)
- 층은 그림자가 아니라 **위치**로 만든다: 하단 가운데 버튼이 탭 바 위로 약 10pt 솟는다.
- 그림자는 확인 필요. 카드 그림자는 보이지 않는다. 맨 위로 버튼 경계는 1배율이라 판단 어렵다.
- 탭 바 윗부분 뒤로 내용이 흐리게 비친다(반투명 처리로 보임, 확인 필요).

### 모션
- 캡처로 알 수 없음. 확인 필요.

### Don't
- 책 표지·배너에 모서리를 주지 않는다(0px).
- 4~12px 같은 중간 모서리를 새로 만들지 않는다.
- 카드·표지에 그림자를 넣지 않는다.

## 6. 컴포넌트
컴포넌트마다 크기, 종류, 상태, 규칙을 적는다. 보지 못한 상태는 `확인 필요`.

### 6.1 버튼
**종류**

| 변형 | 모양 | 쓰는 때 |
|---|---|---|
| 하단 가운데 버튼 | 지름 약 50pt 파란 원, 흰 "y" 로고. 탭 바 윗선보다 약 10pt 위로 솟는다 | 하단 탭 바 가운데 홈 |
| 맨 위로 버튼 | 오른쪽 아래, gray-50 원(지름 약 36pt) + 회색 위 화살표 | 긴 스크롤 화면 |
| 텍스트 링크 | 구획 제목 끝에 `>`를 붙여 제목 자체를 링크로 쓴다("크레마클럽 >") | 구획 전체 보기 |

**크기**

| 버튼 | 지름 | 모서리 | 색 |
|---|---|---|---|
| 하단 가운데 버튼 | 약 50pt | 999px | #0080ff + 흰 로고 |
| 맨 위로 버튼 | 약 36pt | 999px | #f6f6f6 + #818488 화살표 |
| 탭 펼치기 버튼 | 확인 필요 | 999px | 확인 필요 |

- 일반 주요 버튼(구매·장바구니): 캡처에 없음. 확인 필요.
- 상태: 눌림 / 비활성 / 로딩 모두 확인 필요.
- 쓰지 않는 때: 구획 이동에 별도 "더보기" 버튼을 두지 않고 제목에 `>`를 붙인다.

**규칙**
- 파란 채움 원은 하단 가운데 버튼 하나뿐이다(관찰에서 정리).
- 아이콘만 있는 버튼(홈, 맨 위로, 펼치기)에 "홈", "맨 위로" 같은 이름을 단다(구현 권장).
- 36pt 맨 위로 버튼은 터치 영역을 44pt 이상으로 넓힌다(구현 권장).

### 6.2 입력창
- 캡처에 없음. 확인 필요.

### 6.3 탭
- 상단 탭: 16pt 굵은 #333333 글자. 선택 탭은 파란 글자 + 아래 3pt 파란 밑줄(글자 폭보다 조금 넓게). 탭 줄 아래 3pt #eeeeee 선.
- 탭 이름이 2~4글자 명사이고, 가로 스크롤 + 오른쪽 끝 펼치기(⌄) 원형 버튼.

| 상태 | 글자 | 밑줄 |
|---|---|---|
| 선택 | #0080ff 16pt 700 | 3pt #0080ff |
| 선택 안 됨 | #333333 16pt 700 | 없음(줄 전체 3pt #eeeeee 선 위) |
| 눌림 | 확인 필요 | 확인 필요 |

**규칙**
- 선택은 색과 밑줄을 함께 바꾼다. 굵기는 같다.
- 탭 묶음에 `role="tablist"`, 선택 탭에 `aria-selected="true"`(구현 권장).

### 6.4 책 카드·구획
- 책 카드: 표지(약 106pt 폭, 각진 모서리) → 책 제목 14pt 2줄 → 작가 12pt 회색 한 줄 말줄임 → 파란 별 + 굵은 별점 + 회색 (참여 수).
- 기획 구획: 구획 제목 아래 큰 그림 배경을 깔고, 책 카드 줄을 그 위에 겹쳐 가로 스크롤.
- 광고 배너: 화면 폭 꽉 찬 띠(높이 약 83pt), 왼쪽 책 이미지 + 흰 굵은 제목 + 옅은 부제, 오른쪽 위 "AD", 오른쪽 아래 쪽수(1/2 꼴).
- 상태: 가격·할인 표시는 확인 필요.
- 쓰지 않는 때: 책 표지에 모서리나 그림자를 넣지 않는다.

**규칙**
- 책 카드 순서(표지 → 제목 → 작가 → 별점)를 바꾸지 않는다.
- 별점은 "별점 9.8, 53명 참여"처럼 숫자와 참여 수를 함께 읽히게 한다(구현 권장).
- 표지 `alt`에 책 제목(구현 권장).

### 6.5 상단 바·하단 탭 바
- 상단 바: 별도 로고·제목 없이 가로 스크롤 탭이 맨 위에 있다(이번 캡처 기준).
- 하단 탭 바: 흰 바탕, 아이콘 5개(메뉴·검색·가운데 홈 버튼·마이·알림), 이름 없음. 아이콘은 진회색 선 아이콘(높이 약 19pt), 일부 아이콘에 파란 점.
- 탭 바 윗부분 뒤로 내용이 흐리게 비친다(반투명 처리로 보임, 확인 필요).

**규칙**
- 이름 없는 아이콘 탭이므로 각 탭에 보이지 않는 이름(`aria-label`)을 반드시 단다(구현 권장).

### 6.6 배지·알림 점
- 새 소식 점: 메뉴 아이콘 위 파란 작은 점.
- 광고 배너 "AD" 표시: 오른쪽 위.
- 토스트·스낵바: 캡처에 없음. 확인 필요.

### 6.7 바텀시트·모달
- 캡처에 없음. 확인 필요.

### 6.8 아이콘·이미지
- 아이콘: 1.5pt 안팎 진회색 선 아이콘. 새 소식은 파란 작은 점으로 표시.
- 이미지: 책 표지가 주인공이다. 표지는 그림자·모서리 없이 그대로 놓는다.
- 기획 구획은 일러스트 배경을 크게 깐다(구획마다 다름).

## 7. 패턴
- 홈 구성: 상단 가로 스크롤 탭 → 구획(제목 + 책 가로 줄)을 8pt 회색 띠로 나눠 반복. 사이에 광고 배너가 끼어든다.
- 가로 스크롤 줄: 다음 책을 오른쪽에 잘리게 보여 스크롤을 알린다. 탭 줄은 왼쪽 끝을 흐리게 자른다.
- 구획 전체 보기: 구획 제목 끝 `>`로 들어간다.
- 긴 화면 되돌아가기: 오른쪽 아래 맨 위로 버튼.
- 목록 → 상세: 확인 필요.
- 검색: 하단 탭에 검색 아이콘이 있다. 화면은 확인 필요.
- 빈 상태·로딩·오류: 확인 필요.
- 폼·결제: 확인 필요.

- 포커스·스크린리더·글자 확대: 확인 필요. 하단 탭은 이름 없이 아이콘만 있어 화면 읽기 이름 확인이 필요하다.

## 9. 글쓰기 톤
- 말투: 구획 제목은 시기·대상·주제를 묶은 명사형("○○의 달 ○월 추천 ○○ 책", "○○ 브랜드전").
- 탭 이름: 2~4글자 명사(신상품, 베스트, 국내도서, 외국도서).
- 책 정보: "○○○ 글/○○○ 그림"처럼 역할을 이름 뒤에 붙인다.
- 광고 문구: 큰 제목 한 줄 + 작은 설명 한 줄.
- 버튼 문구 꼴: 별도 버튼 문구 대신 제목 끝 `>`("크레마클럽 >").
- 숫자·단위 표기: 별점 소수 첫째 자리(10.0, 9.8), 참여 수는 괄호("(53)").

## 10. Do & Don't
관찰 기반 문서의 규칙은 "이 서비스 화면에서 반복되는 규칙"을 SylviaLab이 정리한 것이다(공식 규칙 아님).

### Do
- 기본 글자는 #333333으로 쓴다.
- 선택 탭은 #0080ff 글자 + 3pt 파란 밑줄로 표시한다.
- 별점 별은 #0080ff, 숫자는 16pt 굵게, 참여 수는 12pt 회색 괄호로 쓴다.
- 구획 사이에 8pt #eeeeee 띠를 둔다.
- 책 표지는 약 106pt 폭, 사이 13pt로 가로 스크롤 줄에 놓는다.
- 좌우 여백은 약 14pt로 둔다.
- 링크 구획 제목은 끝에 `>`를 붙인다.

### Don't
- 순수 검정을 글자에 쓰지 않는다(#333333을 쓴다).
- 파랑 밖의 강조색(빨강·노랑 별점 등)을 넣지 않는다.
- 책 표지에 모서리나 그림자를 주지 않는다.
- 카드에 그림자를 넣어 구획을 나누지 않는다.
- 광고 배너 남색(#003366)을 UI 색으로 쓰지 않는다.
- 하단 탭 아이콘에 이름 글자를 붙이지 않는다(관찰 화면 기준).

- 서비스 이름과 브랜드는 각 권리자의 것이다. 이 문서는 식별·학습용 참고 자료로 SylviaLab이 독자적으로 작성했다.

- **공식 자료 그대로**: 없음. 공개 디자인 시스템 문서·코드를 확인하지 못했다.
- **화면에서 잰 값(관찰, iOS 홈 캡처 2장)**: 모든 HEX(#0080ff, #66beff, #333333, #3a3a3a, #818488, #a6a6a6, #b2b2b2, #f6f6f6, #eeeeee, 제외한 #003366), 글자 크기·굵기, 좌우 14pt·사이 13pt·선 3pt·띠 8pt, 표지 폭 106pt, 버튼 지름 50/36pt·솟음 10pt, 탭 줄 50pt, 배너·탭 바 83pt, 모서리 0/999.
- **SylviaLab이 정리·권장한 것**: 모든 토큰 이름, 관찰 팔레트 → 역할 이름 두 층, 원칙·규칙·Don't, 컴포넌트 표 묶음, `(구현 권장)`이 붙은 접근성 항목.
