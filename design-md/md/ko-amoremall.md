# 아모레몰 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 2025년 할인 행사 기간, iOS 앱 홈 화면 1장, 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

이 문서는 디자인 시스템의 다섯 층(원칙, 토큰, 컴포넌트, 사용 규칙, 구현·검증)을 한 파일로 줄인 요약이다. 맨 위 YAML은 도구와 AI가 그대로 읽는 값이고, 아래 글은 그 값을 언제·왜 쓰는지 설명한다. 둘이 어긋나면 YAML 값이 우선한다. 화면 1장에서 정리했으므로 구조만 맞추고, 보지 못한 부분은 `확인 필요`로 남겼다.

## 1. 개요와 원칙
- 서비스 성격: 아모레퍼시픽 브랜드 화장품을 파는 뷰티 쇼핑 앱.
- 디자인 인상 한 줄: 흰 바탕에 검정 글자, 회색 탭. 색은 사진과 배너가 맡고, UI는 검정·흰색·회색으로 절제한다. 붉은 색은 쿠폰·"hot" 같은 혜택 표시에만 쓴다.
- 공식 시스템 이름: 확인 필요
- 디자인 원칙(공식 원칙은 확인하지 못했다. 화면 1장에서 읽은 것이라 참고용이다):
  1. UI는 검정·흰색·회색으로 비우고, 색은 사진과 배너에 맡긴다. (관찰에서 정리)
  2. 붉은 계열은 혜택(쿠폰 문구, "hot" 배지, 강조 타일 테두리)에만 쓴다. (관찰에서 정리)
  3. 선택은 색이 아니라 검정 굵은 글자 + 2pt 밑줄로 표시한다. (관찰에서 정리)
  4. 바로가기는 사진을 담은 둥근 정사각 타일(모서리 약 16pt)로 보여 준다. (관찰에서 정리)
- 톤: 절제된 무채색 화면 위에 사진이 화려함을 맡는다.
- 캡처 시기 주의: 캡처는 할인 행사 기간 화면이다. 왼쪽 위 로고 자리에 행사 이름 워드마크가 들어가 있다. 평소 로고·색은 확인 필요.
- 공개 자료 상황: 공개 디자인 문서·오픈소스를 확인하지 못했다. 확인 필요.

### 특장점
- 혜택에만 붉은색을 쓴다 — #ff5a5a는 "hot" 배지 바탕과 강조 바로가기 타일 테두리(약 2pt)에, #ff6868 근처 값은 탭 위 9pt 쿠폰 문구에만 나온다. 버튼·선택 표시는 검정이다.
- 탭 위에 혜택 문구를 얹는다 — 혜택이 있는 상단 탭 위에 9pt 붉은 쿠폰 문구를 작게 올려, 탭 이름을 바꾸지 않고 혜택을 알린다.
- 바로가기를 사진 타일로 만든다 — 약 56×56pt 정사각 타일(모서리 약 16pt) 안에 상품 사진을 넣고 아래 12pt 이름을 단다. 강조 칸만 붉은 테두리 + "hot" 배지다.
- 하단 탭 바에 최근 본 상품을 둔다 — 맨 오른쪽 칸은 아이콘 대신 최근 본 상품 썸네일 + 작은 하트이고, 가운데는 지름 약 44pt 검정 원 홈 버튼이다.
- 떠 있는 남색 알약으로 안내한다 — 하단 탭 바 바로 위에 #3a416f 알약(높이 약 39pt, 폭 약 200pt, 흰 13pt 글자, 왼쪽 상품 썸네일 원)을 띄운다.

### 배울 점
- 혜택을 알리되 화면을 어지럽히지 않을 때 아모레몰처럼 붉은색(#ff5a5a)을 배지·테두리·작은 문구에만 묶고 UI는 무채색으로 둔다.
- 탭마다 진행 중인 혜택이 있을 때 아모레몰처럼 탭 이름 위에 아주 작은(9pt) 혜택 문구를 얹는다.
- 메뉴 바로가기를 늘어놓을 때 아모레몰처럼 사진을 담은 56pt 둥근 정사각 타일을 가로 스크롤로 둔다.

### 이 문서를 읽는 AI 에이전트에게
- 색·크기·간격은 YAML 토큰 이름으로만 쓴다. 화면에서는 `red-500`보다 `hot`, `black`보다 `primary` 같은 semantic 이름을 먼저 쓴다.
- 선택·행동은 `primary`(검정)로 표시한다. `hot`·`coupon-text`(붉은색)는 혜택 표시에만 쓴다.
- `floating`(#3a416f)은 하단 탭 바 위 안내 알약 하나에만 쓴다.
- 배너·사진 속 색을 UI 색으로 가져오지 않는다. 판단이 어려우면 무채색을 고른다.
- 근거가 화면 1장이라, 가격·버튼·입력창처럼 이 문서에 없는 부분은 값을 지어내지 말고 `확인 필요`로 둔다.

## 2. 색상
값은 1배율 캡처 픽셀에서 읽었다. 넓은 면 색은 정확하고, 작은 글자 색은 글자 테두리 번짐 때문에 오차가 있다. 토큰 이름은 SylviaLab이 붙인 것이다. 화면이 1장뿐이라 모든 값은 반복 확인이 안 됐다.

### 색 체계
공개 팔레트가 없어서 캡처의 색을 **관찰 팔레트**로 모으고 **역할 이름**을 붙였다(관찰에서 정리).

| 층 | 예시 | 쓰는 곳 |
|---|---|---|
| 관찰 팔레트 | `black`, `red-500`, `gray-300` | 토큰 정의에만. 번호는 밝기 순서일 뿐 공식 단계가 아니다 |
| 역할 이름 | `primary`, `hot`, `text-tab-off`, `floating` | 실제 화면과 컴포넌트 |

### 브랜드·행동
| 토큰 | HEX | 쓰임 |
|---|---|---|
| black | #000000 | 선택된 탭 글자·밑줄, 구획 제목, 하단 가운데 홈 버튼 원 |
| navy | #3a416f | 화면 아래 떠 있는 안내 알약 바탕(흰 글자) |

### 바탕·선
| 토큰 | HEX | 쓰임 |
|---|---|---|
| white | #ffffff | 기본 바탕, 하단 탭 바, 홈 버튼 안 아이콘 |
| gray-100 | #e7e7e7 | 흰 바로가기 타일 테두리 |

### 글자
| 토큰 | HEX | 쓰임 |
|---|---|---|
| text-body | #4d4d4d | 바로가기 이름(근처 값) |
| gray-600 | #666666 | 하단 탭 바 이름(근처 값) |
| gray-300 | #bbbbbb | 선택 안 된 상단 탭 글자(근처 값) |

### 상태
| 토큰 | HEX | 쓰임 |
|---|---|---|
| hot | #ff5a5a | "hot" 배지 바탕, 강조 바로가기 타일 테두리(약 2pt) |
| coupon-text | #ff6868 | 탭 위 작은 쿠폰 문구(근처 값) |
| 가격·할인·success·warning·error | 확인 필요 | 캡처에 가격과 상태 표시가 없음 |

- 할인 행사 기간 화면이다. 큰 배너의 보라·파랑 그라데이션과 상품 카드 배경은 행사 소재 색으로 보고 시스템 색에서 뺐다.
- 바로가기 타일 안 사진 바탕 색(파랑, 민트 등)도 콘텐츠 색으로 보고 뺐다.
- 상태 색의 "배경/선/글자" 조합 규칙: 확인 필요.

### 역할별 색
- 선택·행동 `primary`(#000000): 선택 탭 글자 + 2pt 밑줄, 구획 제목, 하단 가운데 홈 버튼 원(흰 아이콘). 눌림 짝은 확인 필요.
- 혜택 `hot`(#ff5a5a): "hot" 배지 바탕, 강조 바로가기 타일 2pt 테두리. 짝으로 탭 위 9pt 문구는 `coupon-text`(#ff6868 근처).
- 안내 `floating`(#3a416f) + `text-inverse`: 떠 있는 알약 하나.
- 글자 단계: `primary`(검정, 제목·선택 탭) → `text-body`(#4d4d4d, 바로가기 이름) → `text-tabbar`(#666666, 하단 탭 이름) → `text-tab-off`(#bbbbbb, 선택 안 된 탭).
- 선 `border`(#e7e7e7): 흰 바로가기 타일 1pt 테두리.

### 화면 모드
- 다크 모드: 확인 필요.

### 색 사용 규칙
- 검정(#000000)은 선택 탭 글자·밑줄, 구획 제목, 홈 버튼 원에 쓴다.
- 붉은 #ff5a5a·#ff6868은 혜택 표시(배지, 강조 타일 테두리, 탭 위 쿠폰 문구)에만 쓴다.
- 선택 안 된 탭 글자는 #bbbbbb 근처 옅은 회색이다.
- 남색 #3a416f는 떠 있는 안내 알약에만 쓴다.
- 배너 그라데이션과 타일 안 사진 바탕색은 시스템 색으로 쓰지 않는다.

### Don't
- `hot`(#ff5a5a)을 선택 표시·일반 버튼·구획 제목에 쓰지 않는다.
- 선택 탭을 붉은색으로 칠하지 않는다. 선택은 검정.
- `floating`(#3a416f)을 알약 밖의 버튼·배경에 쓰지 않는다.
- 배너 보라·파랑 그라데이션을 UI 색으로 가져오지 않는다.

## 3. 타이포그래피
- 글꼴: iOS 시스템 글꼴(추정. 한글은 Apple SD Gothic Neo와 같은 모양). 전용 글꼴은 확인 필요.
- 대체 글꼴: -apple-system, 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif
- 크기는 1배율 캡처의 글자 높이로 계산한 추정값이다(±1pt). 행간은 확인 필요.

### 위계와 사용처
| 단계 | 크기(pt) | 굵기 | 행간 | 쓰임 |
|---|---|---|---|---|
| section-title | 22 | 700 | 확인 필요 | 구획 제목 |

### 규칙
- 상단 탭은 16pt로 크기는 같고, 선택만 700, 나머지는 400이다.
- 구획 제목은 22pt 굵게 한 줄이다.
- 바로가기 이름은 12pt, 하단 탭 이름은 11pt 회색이다.
- 9pt는 탭 위 쿠폰 문구에만 쓴다.

### Don't
- 선택 안 된 탭을 굵게 쓰지 않는다(400, 옅은 회색).
- 9pt를 쿠폰 문구 밖에서 쓰지 않는다.
- 구획 제목을 두 줄로 늘리지 않는다(관찰은 한 줄).

## 4. 레이아웃·간격
- 기준 화면: 375pt 폭 아이폰(홈 인디케이터가 있는 기종).
- 화면 좌우 여백: 약 19~22pt. 로고, 탭, 구획 제목, 첫 상품 카드가 이 선 근처에 맞는다.
- 간격 단계(관찰, pt): 2, 6, 14, 16, 20
- 그리드·최대 폭: 확인 필요
- 상단: 상태 표시줄 → 로고 줄(오른쪽 검색·장바구니 아이콘) → 가로 탭(높이 약 35pt). 탭 바로 아래부터 큰 배너가 화면 폭을 꽉 채운다.
- 바로가기: 타일 약 56×56pt, 한 줄 5개 남짓 가로 스크롤.
- 상품 가로 줄: 카드 이미지 폭 약 108pt, 사이 약 6pt.
- 하단 탭 바: 탭 5개, 가운데 홈 원 지름 약 44pt.
- 떠 있는 안내 알약: 높이 약 39pt, 폭 약 200pt, 하단 탭 바 바로 위.

### 화면 세로 리듬
| 순서 | 높이·간격 |
|---|---|
| 로고 줄 | 확인 필요 |
| 상단 가로 탭 | 약 35pt |
| 큰 배너(화면 폭) | 확인 필요 |
| 바로가기 타일 줄 | 타일 56pt + 이름 12pt, 간격 확인 필요 |
| 구획 제목 → 상품 줄 | 확인 필요 |
| 떠 있는 알약 → 하단 탭 바 | 바로 위(간격 확인 필요) |

### 간격 적용 규칙
- 로고·탭·구획 제목·첫 카드는 왼쪽 약 19~22pt 선에 맞춘다.
- 큰 배너는 좌우 여백 없이 화면 폭을 채운다.
- 상품 카드 사이는 약 6pt로 좁게 둔다.

### Don't
- 큰 배너에 좌우 여백을 두지 않는다(화면 폭을 채운다).
- 상품 카드 사이를 넓게 벌리지 않는다(약 6pt).
- 떠 있는 알약을 탭 바에서 멀리 띄우지 않는다.

## 5. 모서리·고도·모션
1pt = CSS 1px로 본다. 1배율이라 ±2px 오차가 있다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| radius-sm | 6px | 상품 카드 이미지 위 모서리 |
| radius-lg | 16px | 바로가기 타일 |
| radius-full | 999px | 하단 가운데 홈 버튼, 떠 있는 안내 알약, "hot" 배지, 배너 쪽수 표시 |

- 테두리: border 1pt #e7e7e7(흰 바로가기 타일), border-hot 2pt #ff5a5a(강조 바로가기 타일).
- 하단 탭 바 위 경계는 아주 옅은 회색(#f5f5f5 근처)으로 보인다. 확인 필요.

### 고도(층)
- 그림자는 뚜렷하게 보이지 않는다. 확인 필요.
- 층은 위치로 만든다: 떠 있는 안내 알약이 하단 탭 바 위에 한 층 올라와 있다.

### 모션
- 캡처로 알 수 없음. 확인 필요.

### Don't
- 바로가기 타일을 원형(999px)으로 만들지 않는다(16pt 둥근 정사각).
- 강조하지 않는 타일에 2pt 붉은 테두리를 쓰지 않는다.
- 배너·카드에 뚜렷한 그림자를 넣지 않는다(관찰에서 보이지 않음).

## 6. 컴포넌트
컴포넌트마다 크기, 종류, 상태, 규칙을 적는다. 보지 못한 상태는 `확인 필요`.

### 6.1 버튼
**종류·크기**

| 변형 | 모양 | 크기 | 쓰는 때 |
|---|---|---|---|
| 하단 가운데 홈 버튼 | 검정 원 + 흰 선 집 아이콘 | 지름 약 44pt | 하단 탭 바 가운데 |
| 떠 있는 안내 알약 | 남색 바탕, 왼쪽 작은 상품 썸네일 원, 흰 13pt 글자, 오른쪽 아래 삼각형(펼치기) | 약 200×39pt, 999px | 하단 탭 바 바로 위 안내 |

- 일반 주요 버튼(구매·장바구니): 캡처에 없음. 확인 필요.
- 상태: 눌림 / 비활성 / 로딩 모두 확인 필요.
- 쓰지 않는 때: 확인 필요.

**규칙**
- 검정 채움 원은 홈 버튼 하나뿐이다(관찰에서 정리).
- 아이콘만 있는 홈 버튼에 "홈" 이름을 단다(구현 권장).
- 39pt 알약은 터치 영역을 44pt 이상으로 넓힌다(구현 권장).

### 6.2 입력창
- 캡처에 없음(검색은 오른쪽 위 아이콘으로 연다). 확인 필요.

### 6.3 탭
- 상단 가로 탭: 16pt. 선택 탭은 검정 굵은 글자 + 글자 폭만큼 2pt 검정 밑줄, 나머지는 옅은 회색. 혜택이 있는 탭 위에는 붉은 작은 문구를 얹는다. 가로 스크롤.

| 상태 | 글자 | 밑줄 | 위 문구 |
|---|---|---|---|
| 선택 | #000000 16pt 700 | 2pt 검정, 글자 폭 | 혜택 있으면 9pt #ff6868 |
| 선택 안 됨 | #bbbbbb 16pt 400 | 없음 | 혜택 있으면 9pt #ff6868 |
| 눌림 | 확인 필요 | 확인 필요 | — |

- 쓰지 않는 때: 선택 표시에 붉은색을 쓰지 않는다(붉은색은 탭 위 혜택 문구에만).

**규칙**
- 탭 이름은 바꾸지 않고 혜택은 위 문구로만 알린다.
- 탭 묶음에 `role="tablist"`, 선택 탭에 `aria-selected="true"`, 위 혜택 문구는 탭 이름과 함께 읽히게 한다(구현 권장).

### 6.4 바로가기 타일
| 종류 | 바탕 | 테두리 | 그 밖 |
|---|---|---|---|
| 첫 칸(메뉴) | 흰색 | 1pt #e7e7e7 | 메뉴 아이콘 |
| 일반 칸 | 상품 사진 | 확인 필요 | 아래 12pt 이름 |
| 강조 칸 | 상품 사진 | 2pt #ff5a5a | 오른쪽 위 "hot" 배지 |

- 크기 약 56×56pt, 모서리 16pt, 한 줄 5개 남짓 가로 스크롤.
- 쓰지 않는 때: 강조하지 않는 바로가기 타일에 붉은 테두리를 쓰지 않는다.

**규칙**
- 강조 칸은 붉은 테두리와 "hot" 배지를 함께 쓴다(색만으로 알리지 않는다).
- 타일 이름이 사진 대체 텍스트 역할을 하도록 함께 읽히게 한다(구현 권장).

### 6.5 상품 카드·배너
- 상품 카드(작게): 위 모서리가 둥근 이미지(6pt, 폭 약 108pt), 오른쪽 위에 작은 브랜드 배지(콘텐츠 그림으로 보임, 확인 필요). 아래 글은 캡처에서 가려져 확인 필요.
- 큰 배너: 화면 폭 꽉 참, 왼쪽 아래 흰 큰 제목 + 흰 작은 설명, 오른쪽 아래 어두운 알약 쪽수 표시(1/23 꼴).

**규칙**
- 자동 넘김 여부는 확인 필요. 자동으로 넘긴다면 멈춤 수단을 둔다(구현 권장).

### 6.6 상단 바·하단 탭 바
- 상단 바: 흰 바탕, 왼쪽 워드마크, 오른쪽 검색(목록+돋보기 모양)·장바구니 선 아이콘.
- 하단 탭 바: 흰 바탕, 5칸(왼쪽 2개, 가운데 검정 홈 원, 오른쪽 마이, 맨 오른쪽 최근 본 상품 썸네일). 아이콘은 선 아이콘, 이름은 회색 작은 글자.

**규칙**
- 최근 본 상품 칸에는 "최근 본 상품" 이름을 달아 썸네일만으로 뜻을 맡기지 않는다(구현 권장).

### 6.7 배지
- "hot" 배지: #ff5a5a 바탕, 완전히 둥근 알약, 강조 바로가기 타일 오른쪽 위. 글자색은 확인 필요.
- 토스트·스낵바: 캡처에 없음. 확인 필요.

### 6.8 바텀시트·모달
- 캡처에 없음. 확인 필요.

### 6.9 아이콘·이미지
- 아이콘: 진회색~검정 선 아이콘(약 1.5pt).
- 사진: 바로가기 타일 안에 상품 사진을 넣는다. 배너는 인물 사진을 화면 폭 가득 쓴다.
- 하단 탭 바 맨 오른쪽 칸은 아이콘 대신 최근 본 상품 썸네일 + 작은 하트를 쓴다.

## 7. 패턴
- 홈 구성: 로고 줄 → 상단 가로 탭 → 화면 폭 큰 배너(쪽수 1/23 꼴) → 바로가기 타일 가로 줄 → 구획 제목 + 상품 가로 줄.
- 혜택 알림: 탭 위 작은 붉은 문구, 바로가기 "hot" 배지·붉은 테두리로 알린다.
  ```
  3종 쿠폰팩          ← coupon-label 9pt, #ff6868
  베스트              ← tab 16pt
  ```

- 최근 본 상품 다시 보기: 하단 탭 바 맨 오른쪽 썸네일 칸.
- 떠 있는 안내: 하단 탭 바 위 남색 알약, 오른쪽 아래 삼각형으로 펼친다.

- 검색: 오른쪽 위 아이콘으로 연다. 화면은 확인 필요.

## 8. 접근성
- 글자 대비(WCAG 2.x, 계산값):

| 글자 | 바탕 | 대비 | 본문 기준 4.5:1 |
|---|---|---|---|
| #000000 | #ffffff | 21.0:1 | 통과 |
| #4d4d4d | #ffffff | 8.5:1 | 통과 |
| #666666 | #ffffff | 5.7:1 | 통과 |
| #bbbbbb | #ffffff | 1.9:1 | 미달 |
| #ffffff | #3a416f | 9.7:1 | 통과 |
| #ff6868 | #ffffff | 2.8:1 | 미달 |
| #ffffff | #ff5a5a | 3.1:1 | 미달(큰 글자 3:1은 통과) |

- 선택 안 된 탭 글자(#bbbbbb 근처)와 9pt 쿠폰 문구(#ff6868 근처)는 기준에 못 미친다. "hot" 배지가 흰 글자라면 #ffffff/#ff5a5a는 3.1:1이다(배지 글자색은 확인 필요).

## 10. Do & Don't
관찰 기반 문서의 규칙은 "이 서비스 화면에서 반복되는 규칙"을 SylviaLab이 정리한 것이다(공식 규칙 아님).

### Do
- 선택 탭은 검정 16pt 굵게 + 글자 폭 2pt 검정 밑줄로 표시한다.
- 혜택 표시는 #ff5a5a(배지·강조 테두리)로 한다.
- 바로가기는 56pt 정사각 타일, 모서리 16pt, 아래 12pt 이름으로 만든다.
- 흰 바로가기 타일에는 1pt #e7e7e7 테두리를 둔다.
- 구획 제목은 22pt 굵게 쓴다.
- 하단 탭 바 가운데에 44pt 검정 원 홈 버튼을 둔다.

### Don't
- 붉은색을 선택 표시나 일반 버튼에 쓰지 않는다.
- 선택 안 된 탭을 굵게 쓰지 않는다(400, 옅은 회색).
- 배너 그라데이션 색을 UI 색으로 가져오지 않는다.
- 남색 #3a416f를 떠 있는 안내 알약 밖에서 쓰지 않는다.
- 큰 배너에 좌우 여백을 두지 않는다(화면 폭을 채운다).
