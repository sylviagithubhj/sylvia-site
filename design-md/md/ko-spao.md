# SPAO 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 여름 데님 기획 배너가 보이는 시기(2025년 6월쯤 추정), iOS 앱 홈 화면 1장, 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

이 문서는 디자인 시스템의 다섯 층(원칙, 토큰, 컴포넌트, 사용 규칙, 구현·검증)을 한 파일로 줄인 요약이다. 맨 위 YAML은 도구와 AI가 그대로 읽는 값이고, 아래 글은 그 값을 언제·왜 쓰는지 설명한다. 홈 화면 1장만 본 문서라 모든 값과 규칙은 참고용이다.

## 1. 개요와 원칙
- 서비스 성격: SPA 의류 브랜드 스파오의 쇼핑 앱. 우먼·맨·키즈·협업 상품을 판다.
- 디자인 인상 한 줄: 흰 바탕에 거의 검정(#1a1a1a) 글자, 빨간 로고색(#c41e20)이 머리 쪽에서 브랜드를 표시한다. 화면 대부분을 큰 모델 사진이 채운다.
- 공식 시스템 이름: 확인 필요
- 디자인 원칙(공식 원칙은 확인하지 못했다)
  1. 사진이 화면을 채운다. 첫 배너는 화면 폭 꽉 차고 높이 약 510pt, 모서리 없음. (관찰에서 정리)
  2. 빨강은 브랜드 표시에만. 로고, 장바구니 숫자 배지, 상담 떠 있는 버튼에 빨간 계열을 쓴다. (관찰에서 정리)
  3. 선택은 검정으로 표시한다. 굵은 글자 + 2pt #1a1a1a 밑줄, 선택된 하단 탭 아이콘도 #1a1a1a. (관찰에서 정리)
  4. 내비게이션은 글자를 줄인다. 하단 탭 바는 이름 없이 아이콘 5개. (관찰에서 정리)
- 톤: 패션 화보처럼 사진이 먼저, UI는 흑백으로 물러난다.

### 이 문서를 읽는 AI 에이전트에게
- 캡처 1장에서 나온 문서다. YAML에 없는 화면(상품 목록·상세·결제)을 만들 때는 값을 지어내지 말고 `확인 필요`로 남긴다.
- 빨강은 `logo`(#c41e20)와 `cart-badge`(#ac0f15), 상담 떠 있는 버튼에만 쓴다. 선택 표시는 `selected`(#1a1a1a) 굵은 글자 + 2pt 밑줄이다.
- 파랑(`event-tab-blue`)은 기획전 탭 글자 하나뿐이다. 평소 색으로 쓰지 않는다.
- 판단이 어려우면 사진을 크게, UI는 흑백으로 물린다.

### 특장점
- 첫 배너가 화면의 절반을 넘는다 — 화면 폭 꽉 찬 모델 사진이 높이 약 510pt를 차지하고, 왼쪽 아래에 흰 영문 대문자 제목(26pt/700) + 한글 부제(14pt), 오른쪽 아래에 일시정지 + "3 / 8" 쪽 알약을 둔다.
- 빨강이 로고·배지·상담 버튼 세 곳에만 나온다 — 로고 #c41e20, 장바구니 숫자 배지 #ac0f15, 상담 떠 있는 버튼(#b30004~#cd0100 근처). 나머지 UI는 #1a1a1a·#333333·#a3a3a3 회색 단계다.
- 하단 탭 바에 이름이 없다 — 검색·배송·홈·찜·마이 아이콘 5개만 두고 홈을 가운데에 둔다. 선택 #1a1a1a, 나머지 #a3a3a3 근처.
- 기획전 탭만 다른 색으로 띄운다 — 상단 가로 탭 맨 앞 기획전 탭 글자만 파랑(#1671ea 근처)이고, 나머지 탭은 진한 회색이다.

### 배울 점
- 사진이 상품을 파는 패션 앱 홈을 만들 때 SPAO처럼 첫 배너를 화면 폭·절반 이상 높이로 모서리 없이 깔고, 글자는 사진 왼쪽 아래 흰색으로 얹는다.
- 브랜드색이 강한 빨강일 때 SPAO처럼 로고와 배지·상담 버튼에만 쓰고 선택 상태는 검정 굵은 글자 + 2pt 밑줄로 표시한다.
- 기간 한정 메뉴를 알릴 때 SPAO처럼 탭 줄 맨 앞에 두고 그 탭 글자만 다른 색으로 칠한다.

## 2. 색상
값은 1배율 캡처 픽셀에서 읽었다. 넓은 면 색은 정확하고, 작은 글자 색은 글자 테두리 번짐 때문에 오차가 있다. 토큰 이름은 SylviaLab이 붙인 것이다.

### 색 체계
단계 팔레트(primitive)는 없다. 캡처 한 장에서 읽은 색을 "관찰 색 → 역할 이름" 한 층으로 적었다.

| 흰색 | #ffffff | background, text-on-photo |
| 연회색 | #a3a3a3 | icon-off |
| 중간 회색 | #4d4d4d | icon-menu |
| 진한 회색 | #333333 | text-tab-off |

- 상담 떠 있는 버튼은 빨강(#b30004~#cd0100 근처)이다. 정확한 값은 확인 필요.

- 첫 배너의 데님·하늘색과 썸네일 줄의 빨강·파랑 타일은 사진·배너 소재 색이라 뺐다.

### 역할별 색
- **빨강 #c41e20**: 로고 글자. 장바구니 숫자 배지는 한 단계 어두운 #ac0f15 + 흰 숫자. 상담 떠 있는 버튼도 빨간 계열(정확한 값 확인 필요).
- **거의 검정 #1a1a1a**: 선택 탭 글자와 2pt 밑줄, 선택된 하단 탭 아이콘.
- **회색 세 단계**: 선택 안 된 상단 탭 #333333, 메뉴 아이콘 #4d4d4d, 선택 안 된 하단 탭 아이콘 #a3a3a3.
- **흰색**: 바탕, 배너 사진 위 글자.
- **가격·할인·상태 색**: 캡처에 없다. 확인 필요.

### 화면 모드
- 밝은 화면만 관찰했다. 다크 모드는 확인 필요.

### 색 사용 규칙
- 빨강 #c41e20은 로고에, #ac0f15는 장바구니 숫자 배지에 쓴다. 상담 떠 있는 버튼도 빨간 계열이다.
- 선택 상태(상단 탭 글자·밑줄, 하단 탭 아이콘)는 #1a1a1a, 선택 안 됨은 #333333(상단 탭)·#a3a3a3(하단 탭 아이콘).
- 파랑 #1671ea은 기획전 탭 글자에만 보였다. 평소 UI 색으로 쓰지 않는다.
- 배너·썸네일 사진 속 색은 시스템 색이 아니다.

### Don't
- 빨강을 로고·장바구니 배지·상담 버튼 밖(선택 표시, 제목)에 쓰지 않는다.
- 기획전 파랑을 평소 탭·버튼에 쓰지 않는다.
- 배너·썸네일 사진 속 색을 토큰으로 쓰지 않는다.

## 3. 타이포그래피
- 글꼴: iOS 시스템 글꼴(추정. 한글은 Apple SD Gothic Neo, 영문은 SF Pro와 같은 모양). 전용 글꼴은 확인 필요.
- 대체 글꼴: -apple-system, 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif
- 로고: 빨간 굵은 영문 대문자 워드마크(높이 약 19pt).
- 크기는 1배율 캡처의 글자 높이로 계산한 추정값이다(±1pt). 행간은 확인 필요.

### 위계와 사용처
| 단계 | 크기(pt) | 굵기 | 행간 | 쓰임 |
|---|---|---|---|---|
| hero-title | 26 | 700 | 확인 필요 | 첫 배너 영문 대문자 제목(흰 글자) |
| tab | 17 | 400 | 확인 필요 | 상단 가로 탭(선택 탭은 700) |
| hero-sub | 14 | 400 | 확인 필요 | 첫 배너 한글 부제(흰 글자) |

### 글자 사용 규칙
- 배너 제목은 영문 대문자 26pt/700, 부제는 한글 14pt/400. 둘 다 흰 글자로 사진 왼쪽 아래에 둔다.
- 상단 탭은 17pt, 선택 탭만 700으로 굵게.
- 상품명·가격 크기는 확인 필요(캡처에 없음).

### Don't
- 배너 제목을 한글로만 쓰지 않는다. 영문 대문자 제목 + 한글 부제 짝이다.
- 선택 안 된 탭을 굵게 쓰지 않는다. 굵기 차이(400 ↔ 700)로 선택을 나눈다.
- 상품명·가격 크기를 이 문서 값으로 정하지 않는다. 확인 필요다.

## 4. 레이아웃·간격
- 기준 화면: 375pt 폭 아이폰.
- 화면 좌우 여백: 약 15~16pt. 메뉴 아이콘, 첫 탭 글자, 배너 제목, 첫 썸네일이 같은 선에 맞는다.
- 간격 단계(관찰, pt): 2, 7, 16, 24
- 그리드·최대 폭: 확인 필요

| 첫 배너 | 화면 폭 꽉 참 | 모서리 0 |

### 간격 적용 규칙
- 상단 바: 왼쪽 메뉴(≡) + 빨간 로고, 오른쪽 검색·장바구니(숫자 배지). 높이 약 44pt(상태 표시줄 아래).
- 상단 탭: 높이 약 45pt, 가로 스크롤, 탭 글자 사이 약 24pt. 선택 탭 아래 2pt 밑줄(글자 폭과 같음).
- 첫 배너: 화면 폭 꽉 참, 높이 약 510pt.
- 썸네일 줄: 약 64pt 정사각 타일, 사이 약 7pt, 가로 스크롤.
- 하단 탭 바: 홈 인디케이터 포함 약 80pt.

### Don't
- 첫 배너에 좌우 여백 테를 두르지 않는다.
- 탭 글자 사이를 24pt보다 좁혀 한 화면에 다 넣지 않는다. 가로 스크롤이다.
- 좌우 여백을 16pt 선에서 어긋나게 두지 않는다.

## 5. 모서리·고도·모션

### 고도
- 고도(그림자·층): 카드 그림자는 보이지 않는다(확인 필요). 하단 탭 바는 뒤 내용이 흐리게 비친다(반투명 처리로 보임, 확인 필요).
- 픽셀 단위는 iOS pt와 같다고 보고 적었다(1pt = CSS 1px).
### 모션
- 모션(길이·이징): 첫 배너가 자동으로 넘어가는 것으로 보인다(일시정지 표시). 속도·효과는 확인 필요.

### Don't
- 첫 배너에 둥근 모서리를 주지 않는다.
- 썸네일 타일을 각지게(0px) 만들지 않는다. 8pt다.
- 카드에 그림자를 넣지 않는다(보이지 않았다).

**규칙** (관찰에서 정리)

- 상단 바: 흰 바탕, 메뉴(#4d4d4d 근처) + 빨간 로고 왼쪽 정렬, 검색·장바구니 아이콘 오른쪽 정렬. 높이 약 44pt.

### 6.6 바텀시트·모달

## 10. Do & Don't
관찰 기반 문서의 규칙은 "이 서비스 화면에서 반복되는 규칙"을 SylviaLab이 정리한 것이다(공식 규칙 아님). 홈 화면 1장에서 정리해 반복 확인은 하지 못했다.

### Do
- 첫 배너는 화면 폭 꽉 차게, 높이 약 510pt, 모서리 0px로 깐다.
- 배너 글자는 사진 왼쪽 아래에 흰 영문 대문자 26pt/700 + 한글 14pt 부제로 둔다.
- 선택 탭은 17pt/700 + 글자 폭 2pt #1a1a1a 밑줄로 표시한다.
- 화면 좌우 여백은 약 16pt로 메뉴·탭·배너 제목·썸네일을 맞춘다.
- 썸네일 타일은 약 64pt 정사각, 모서리 8pt, 사이 약 7pt.
- 하단 탭 바는 아이콘 5개, 홈 가운데, 선택 #1a1a1a.

### Don't
- 빨강을 로고·장바구니 배지·상담 버튼 밖에 쓰지 않는다.
- 선택 상태를 빨강으로 칠하지 않는다. 검정 굵은 글자 + 밑줄이다.
- 기획전 파랑(#1671ea)을 평소 탭·버튼 색으로 쓰지 않는다.
- 배너에 둥근 모서리를 주지 않는다.
- 카드에 그림자를 넣지 않는다(보이지 않았다).
