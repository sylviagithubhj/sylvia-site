# 올리브영 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 5~6월 무렵 iOS 앱 홈 탭 화면 9장(홈 위부터 아래까지 스크롤 8장 + 첫 진입 팝업 1장), 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

## 1. 개요
- 서비스 성격: CJ올리브영의 헬스·뷰티 스토어 앱. 화장품, 건강식품, 생활용품을 팔고 오프라인 매장 픽업·빠른 배송을 붙인다. 웹과 iOS·Android 앱.
- 디자인 인상 한 줄: 흰 바탕에 거의 검정(#131518) 글자, 브랜드 연두(#82dc28)는 로고와 몇몇 지점에만. 할인과 알림은 코럴 빨강(#ff5753) 하나로 처리한다.
- 공식 시스템 이름: 확인 필요 (공개 문서·공개 코드 확인 못 함)
- 특징
  - 브랜드 연두는 UI에 거의 안 쓴다. 로고, "헬스+" 전환 라벨, 떠 있는 원형 버튼 정도다.
  - 강조는 빨강 하나다. 할인율, 특가 배지, 알림 점, 장바구니 숫자 배지가 모두 같은 색이다.
  - 상품 정보는 작은 회색 배지(오늘드림·BEST·증정)로 덧붙인다. 배지 바탕은 모두 같은 연회색이고 글자 색만 바뀐다.
  - 칩·버튼은 완전히 둥근 알약, 카드·배너는 6pt 안팎의 작은 모서리, 순위 숫자 상자는 각진 검정 네모다.
  - 상단에는 글자 탭(홈·오특·랭킹·매거진 …)을 가로로 늘어놓고, 선택 탭만 검정 글자 + 짧은 검정 밑줄.

## 4. 간격·레이아웃
- 기준 화면: 375pt 폭 아이폰(홈 인디케이터 있는 기기).
- 화면 좌우 여백: 14pt. 배너, 구획 제목, 상품 그리드가 모두 x=14에서 시작해 오른쪽도 14pt 남긴다.
- 간격 단계(관찰, pt): 4, 7, 8, 10, 14, 16, 24, 40
- 상품 그리드(3열): 카드 폭 111pt, 사이 7pt.
- 가로 스크롤 상품 줄: 카드 폭 134pt, 사이 약 9pt. 셋째 카드가 오른쪽에 잘려 보인다.
- 2열 콘텐츠 카드(매거진): 폭 약 169pt, 사이 8pt.
- 가로로 긴 배너 카드: 폭 346pt, 높이 약 195pt, 카드 사이 14pt.
- 순위 목록: 왼쪽 100×100pt 썸네일 + 오른쪽 글 묶음(썸네일과 15pt 띄움). 항목 사이 14pt.
- 이미지 아래 상품명까지 약 10pt, 상품명·가격·배지·별점은 4~6pt 간격으로 쌓는다.
- 구획 사이: 40pt 안팎. 구획 제목과 내용 사이 약 16pt.
- 하단 탭 바: 5칸, 홈 인디케이터 포함 약 82pt, 위쪽 1pt 구분선(gray-100).
- 그리드 열 수 규칙: 확인 필요

## 6. 주요 컴포넌트
### 버튼
- 외곽선 알약 버튼: 흰 바탕, 1pt gray-200 테두리, 높이 약 40pt, 글자 13pt gray-700 + 오른쪽 `>`. 구획 맨 아래 가운데("○○ 더 보러가기").
- 텍스트 링크: 구획 제목 오른쪽 끝 "더보기 >", 12pt gray-500.
- 위로 가기 버튼: 지름 약 40pt 흰 원, 1pt 회색 테두리, 위쪽 화살표. 오른쪽 아래에 떠 있다.
- 떠 있는 "헬스+" 버튼: 지름 약 40pt brand-green 원, 흰 글자. 첫 화면 오른쪽 아래(나중 캡처에서는 위로 가기 버튼으로 바뀐다).
- 채운 주요 버튼(구매·장바구니 담기): 캡처에 없음. 확인 필요.

### 칩
- 카테고리 칩: 높이 32pt 알약, 사이 8pt, 가로 스크롤. 선택은 검정 바탕 흰 글자, 나머지는 흰 바탕 + 1pt gray-200 테두리 + gray-600 글자.
- 해시태그 칩: 높이 약 26pt 알약, 연한 테두리, `#` + 짧은 낱말.
- 상품 배지: 높이 16pt, 모서리 2pt, 바탕 gray-100. 글자 색으로 종류를 나눈다(오늘드림 분홍, BEST·증정 회색). 특가 "오특"만 sale-red 바탕 흰 글자.
- "AD" 표시: 구획 제목 오른쪽, 연회색 테두리 알약 + 회색 글자 + 작은 정보 아이콘.

### 입력창
- 캡처에 없음. 상단 바에는 돋보기 아이콘만 있다. 확인 필요.

### 카드·리스트
- 상품 카드(세로): 이미지(gray-50 빈 바탕, 4pt 모서리) → 상품명 13pt 2줄 → 정가 취소선 11pt → 할인율(빨강) + 판매가(검정) 14pt 굵게 → 배지 줄 → 별점(★ + 점수 + 리뷰 수) → 하트·장바구니 선 아이콘 줄.
- 순위 목록 항목: 100pt 정사각 썸네일 왼쪽 위에 20pt 검정 네모 + 흰 순위 숫자. 오른쪽에 상품명 2줄, 할인율 + 판매가 + 취소선 정가를 한 줄에, 아래 배지 줄. 맨 오른쪽 세로로 하트와 장바구니 아이콘.
- 순위 목록 아래 쪽 넘김: "< 1 | 20 >" 꼴, 현재 쪽 숫자만 진하게.
- 콘텐츠 카드(매거진): 세로로 긴 사진(약 169×203pt, 모서리 작음) → 제목 15pt 2줄 → 해시태그 칩 하나.
- 배너 카드: 346pt 폭 사진 배너, 왼쪽에 제목 2줄 17pt 굵게 + 해시태그 한 줄.

### 상단 바·탭 바
- 상단 바: 왼쪽 연두 원형 로고 + 굵은 서비스 이름 워드마크, 그 옆 "헬스+" 전환 라벨(선택 시 연두, 아닐 때 회색 #9c9ea6). 오른쪽 검색·알림·장바구니 선 아이콘(약 22pt, ink). 알림에는 빨간 점, 장바구니에는 빨간 원 숫자 배지.
- 상단 글자 탭: 15pt, 가로 스크롤. 선택 탭은 ink 글자 + 글자 폭만큼 2pt ink 밑줄. 새 소식이 있는 탭은 이름 오른쪽 위에 빨간 점.
- 퀵메뉴 줄: 아이콘 약 40pt + 11pt 이름, 6칸 한 줄.
- 하단 탭 바: 흰 바탕, 위 1pt 구분선. 카테고리·셔터·홈·히스토리·마이 5칸. 아이콘 약 18pt 검정, 이름 10pt. 선택 탭(홈)만 채운 아이콘.
- 큰 홈 배너 쪽수 표시: 오른쪽 아래 반투명 어두운 알약 "현재 | 전체 +".

### 바텀시트·모달
- 첫 진입 광고 팝업: 화면 아래에서 올라오는 시트, 위쪽 모서리 16pt. 뒤 화면은 약 50% 어둡게. 시트 안은 광고 그림 전체, 오른쪽 위에 일시정지 + 쪽 넘김 알약. 맨 아래 흰 띠에 왼쪽 "오늘 하루 보지 않기", 오른쪽 "닫기"(둘 다 회색 글자).

### 토스트·스낵바
- 캡처에 없음. 확인 필요.

### 페이지 표시
- 띠 배너 아래 점 3개(약 6pt). 선택 점만 검정, 나머지 연회색 #dadde0.

## 7. 아이콘·이미지·모션
- 아이콘: 1.5pt 안팎의 선 아이콘. 상단 바는 ink, 상품 카드의 하트·장바구니는 gray-400. 선택된 하단 탭만 채운 아이콘.
- 퀵메뉴 아이콘: 작은 3D 느낌의 컬러 그림(연두·분홍·금색)을 쓴다. 선 아이콘과 다른 계열이다.
- 사진: 상품 누끼 컷은 연회색 바탕, 기획 배너는 상품 + 단색·그라데이션 바탕 그림. 이미지 위에 "1+1" 같은 둥근 스티커를 얹는다.
- 모션: 캡처로 알 수 없음. 확인 필요.

## 8. 글쓰기 톤(UX 라이팅)
- 구획 제목은 해요체 한 문장이나 명사구(예: "지금 인기 있는 상품이에요", "카테고리 랭킹"). 개인화 구획은 "○○님을 위한 …" 꼴.
- 상품명은 앞에 대괄호로 기획 이름을 붙인다("[○월 올영픽]", "[단독기획]"). 구성은 괄호로 덧붙인다.
- 배지는 2~4글자 명사(오늘드림, BEST, 증정, 오특).
- 해시태그로 콘텐츠 주제를 짧게 단다("#○월 올영픽").
- 버튼은 "○○ 더 보러가기 >", 링크는 "더보기 >".
- 서비스 이름을 줄인 "올영"을 기획 이름에 자주 쓴다.
