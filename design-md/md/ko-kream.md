# KREAM 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 2025년 6월쯤(배너 날짜로 추정), iOS 앱 홈 화면 1장 + 같은 홈 위에 광고 바텀시트가 뜬 화면 1장, 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

이 문서는 디자인 시스템의 다섯 층(원칙, 토큰, 컴포넌트, 사용 규칙, 구현·검증)을 한 파일로 줄인 요약이다. 맨 위 YAML은 도구와 AI가 그대로 읽는 값이고, 아래 글은 그 값을 언제·왜 쓰는지 설명한다. 둘이 어긋나면 YAML 값을 따른다.

## 1. 개요와 원칙
- 서비스 성격: 한정판 신발·패션·명품 리셀 거래 앱. 발매 정보, 랭킹, 스타일(사용자 코디 글)도 보여 준다.
- 디자인 인상 한 줄: 흰 바탕에 거의 검정(#222222) 글자, 옅은 회색(#f4f4f4) 면만 쓰는 무채색 화면. 색은 배너 사진과 빨간 새 소식 점이 맡는다.
- 공식 시스템 이름: 확인 필요
- 공개 자료 상황: 이번 작업에서는 공개 문서·오픈소스를 확인하지 못했다. 확인 필요.
- 디자인 원칙
  1. UI는 무채색으로 둔다. UI 요소에 브랜드 강조색이 따로 보이지 않고, 색은 상품 사진과 배너가 맡는다. (관찰에서 정리)
  2. 선택은 색이 아니라 굵기와 밑줄로 표시한다. 검정 굵은 글자 + 2pt 검정 밑줄. (관찰에서 정리)
  3. 면은 테두리 없는 옅은 회색 하나(#f4f4f4)로 통일한다. 검색창과 카테고리 원이 같은 면이다. (관찰에서 정리)
  4. 알림은 점 하나로 짧게. 새 소식은 작은 빨간 점(#f15746 근처)을 탭 이름·아이콘 오른쪽 위에 붙인다. (관찰에서 정리)
- 톤: 패션 매장처럼 비우고 절제한다. 화면은 상품을 돋보이게 하는 배경이다.

### 특장점
- UI에 강조색이 없다 — 화면에 쓰인 UI 색은 #222222, #ffffff, 회색 단계(#f7f7f7~#7f7f7f)뿐이고, 색이 있는 UI 요소는 새 소식 점 #f15746 하나다. 홈 첫 배너의 파랑 #1f52ea도 기획전 한 장의 색이다.
- 선택 상태를 무채색으로 표시한다 — 상단 탭 선택은 15pt 700 #222222 + 글자 폭만큼 2pt #222222 밑줄, 하단 탭 선택은 #222222, 비선택은 #7f7f7f 근처.
- 카테고리를 회색 원 + 누끼 사진으로 보여 준다 — 지름 약 64pt #f4f4f4 원 안에 배경을 지운 상품 사진, 한 줄 5개 × 2줄, 마지막 원은 `>` 더보기.
- 하단 탭 이름을 영문 대문자로 쓴다 — HOME, STYLE, SHOP, SAVED, MY(11pt).
- 상단에 로고 대신 검색창을 둔다 — 맨 위가 폭 약 260pt × 높이 약 40pt 검색창(카메라 검색 아이콘 포함)이다(이번 캡처 기준).

### 배울 점
- 상품 사진이 화려한 서비스를 만들 때 KREAM처럼 UI 색을 #222222·#f4f4f4 무채색으로 묶고, 색은 사진과 배너에 맡긴다.
- 강조색 없이 선택 상태를 보여야 할 때 굵은 글자 + 2pt 같은 색 밑줄로 표시한다.
- 새 소식 표시는 숫자 배지 대신 작은 빨간 점 하나를 탭·아이콘 오른쪽 위에 붙여 무채색 화면을 깨지 않는다.

### 이 문서를 읽는 AI 에이전트에게
- 색은 역할 이름(`text-primary`, `surface-fill`, `badge-dot`)으로 쓴다. UI에 새 강조색을 더하지 않는다.
- 선택·활성 상태는 색 대신 굵기 700 + 2pt `text-primary` 밑줄로 표현한다.
- 빨강 `badge-dot`은 새 소식 점에만 쓴다. 가격 상승·오류 같은 다른 뜻으로 쓰지 않는다(그 색은 확인 필요).
- 이 문서는 홈 1곳에서 잰 값이다. 상품 상세·시세·구매·판매 화면은 지어내지 말고 `확인 필요`로 남긴다.
- 판단이 어려우면 색을 빼고, 테두리 대신 #f4f4f4 면을 고른다.

## 2. 색상
값은 1배율 캡처 픽셀에서 읽었다. 넓은 면 색은 정확하고, 작은 글자 색은 글자 테두리 번짐 때문에 오차가 있다. 토큰 이름은 SylviaLab이 붙인 것이다.

### 색 체계
공식 팔레트는 공개되지 않았다. **관찰 팔레트 → 역할 이름** 두 층으로 정리했다.

| 층 | 예시 | 쓰는 곳 |
|---|---|---|
| 관찰 팔레트 | `gray-950`, `gray-100`, `red-500` | 캡처에서 잰 값. YAML 정의에만 쓴다 |
| 역할 이름 | `text-primary`, `surface-fill`, `badge-dot` | 화면과 컴포넌트 |
| 콘텐츠 색 | 배너 바탕, 광고 바텀시트 속 색 | 기획전마다 바뀐다. 토큰으로 쓰지 않는다 |

- UI 색은 사실상 무채색 한 줄(#222222 → #7f7f7f → #c4c4c4 → #f0f0f0~#f7f7f7 → #ffffff)과 빨간 점 하나다.

### 브랜드·행동
| 토큰 | HEX | 쓰임 |
|---|---|---|
| text-primary | #222222 | 선택 탭 글자·밑줄, 선택된 하단 탭(HOME) 아이콘·이름(근처 값) |
| white | #ffffff | 기본 바탕, 하단 탭 바 |
| badge-dot | #f15746 | 상단 탭·알림·하단 탭 아이콘의 새 소식 점(근처 값) |

### 바탕·선
| 토큰 | HEX | 쓰임 |
|---|---|---|
| gray-50 | #f7f7f7 | 하단 탭 바 윗선(1pt) |
| gray-100 | #f4f4f4 | 검색창 바탕, 카테고리 원 바탕(근처 값) |
| gray-150 | #f0f0f0 | 카테고리 묶음 아래 1pt 구분선 |
| dim | #333333 | 바텀시트 뒤 덮개가 씌워진 흰 바탕 색. 검정 80% 덮개로 보인다 |

### 글자
| 토큰 | HEX | 쓰임 |
|---|---|---|
| gray-300 | #c4c4c4 | 검색창 안내 글자(근처 값) |
| gray-500 | #7f7f7f | 선택 안 된 하단 탭 아이콘·이름(근처 값) |
| gray-800 | #333333 | 상단 탭 중 일부 글자(근처 값, #222222와 같은 색일 수 있음) |

### 상태
| 토큰 | HEX | 쓰임 |
|---|---|---|
| new-dot | #f15746 | 새 소식 점(위 badge-dot과 같은 값) |

- 가격·상승·하락·success·error: 확인 필요(캡처에 가격과 거래 화면이 없음).

### 기획전 테마
| 토큰 | HEX | 쓰임 |
|---|---|---|
| banner-blue | #1f52ea | 홈 첫 배너 바탕(발매 협업 배너 한 장의 색. 시스템 색 아님) |

- 바텀시트 광고의 보라빛 바탕, 검정 쿠폰 칩(#111111), 파란 쪽 표시 점(#007aff)은 광고 소재 안에 있을 수 있어 시스템 색으로 확정하지 않았다. 확인 필요.

### 역할별 색
- 검정 `text-primary`(#222222): UI 글자 전부와 "선택" 표시 전부(상단 탭 굵은 글자·2pt 밑줄, 하단 탭 선택 아이콘·이름). 강조색 역할을 대신한다.
- 회색 `text-inactive`(#7f7f7f 근처): 선택 안 된 하단 탭. `text-placeholder`(#c4c4c4 근처): 검색창 안내 글자.
- 회색 면 `surface-fill`(#f4f4f4): 검색창과 카테고리 원. 둘 다 테두리 없이 면만 쓴다.
- 선 두 개: 카테고리 아래 1pt #f0f0f0, 하단 탭 바 윗선 1pt #f7f7f7.
- 빨강 `badge-dot`(#f15746 근처): 새 소식 점 하나. 글자나 면에는 쓰지 않는다.
- 상태 색 조합(배경/선/글자): 캡처에 상태 표시가 없다. 확인 필요.

### 화면 모드
- 다크 모드: 확인 필요.

### 색 사용 규칙
- UI 글자·선택 표시는 #222222 하나로 쓴다. 강조색으로 바꾸지 않는다.
- 빨강 #f15746은 새 소식 점에만 쓴다.
- 검색창·카테고리 원 같은 면은 #f4f4f4, 테두리 없이.
- 구분선은 1pt #f0f0f0(카테고리 아래), 하단 탭 바 윗선은 1pt #f7f7f7.
- 배너 바탕색(#1f52ea 등)은 기획전마다 바뀌는 색으로 보고 UI에 쓰지 않는다.

### Don't
- 탭·검색창·하단 탭 바에 유채색을 넣지 않는다.
- 빨간 점을 숫자 배지나 글자 색으로 키우지 않는다.
- 배너·광고 속 색(#1f52ea, #007aff 등)을 UI 토큰으로 옮기지 않는다.
- 회색 면 위에 테두리를 겹치지 않는다.

## 3. 타이포그래피
- 글꼴: iOS 시스템 글꼴(추정. 한글은 Apple SD Gothic Neo, 영문은 SF Pro와 같은 모양). 전용 글꼴은 확인 필요.
- 대체 글꼴: -apple-system, 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif
- 크기는 1배율 캡처의 글자 높이로 계산한 추정값이다(±1pt). 행간은 확인 필요.

### 위계와 사용처
| 단계 | 크기(pt) | 굵기 | 행간 | 쓰임 |
|---|---|---|---|---|
| tab | 15 | 400 | 확인 필요 | 상단 가로 탭(선택 탭은 700) |
| search | 15 | 400 | 확인 필요 | 검색창 안내 글자 |
| category | 12 | 400 | 확인 필요 | 카테고리 원 아래 이름(최대 2줄) |
| tabbar-label | 11 | 500 | 확인 필요 | 하단 탭 영문 대문자 이름(굵기 확인 필요) |

- 제목·본문·가격 단계는 캡처에 없다. 확인 필요(배너 큰 제목은 이미지 글자일 수 있어 재지 않았다).

### 규칙
- 상단 탭은 15pt, 선택 탭만 700.
- 카테고리 이름은 12pt, 길면 2줄.
- 하단 탭 이름은 11pt 영문 대문자.

### Don't
- 선택 탭을 색으로만 바꾸지 않는다. 700 + 2pt 밑줄이다.
- 하단 탭 이름을 한글이나 소문자로 섞지 않는다.
- 카테고리 이름을 3줄 이상으로 늘리지 않는다.

## 4. 레이아웃·간격
- 기준 화면: 375pt 폭 아이폰.
- 화면 좌우 여백: 약 16pt. 검색창, 첫 탭 글자, 첫 카테고리 원이 같은 선에 맞는다.
- 간격 단계(관찰, pt): 2, 6, 8, 16

### 그리드와 중단점
| 구분 | 값 |
|---|---|
| 기준 폭 | 375pt |
| 좌우 여백 | 약 16pt |
| 카테고리 격자 | 5열 × 2줄, 원 사이 약 6pt |
| 컬럼 그리드·최대 폭·중단점 | 확인 필요 |

### 화면 세로 리듬(홈)
| 구간 | 높이 |
|---|---|
| 상단 바(검색창) | 약 40pt(폭 약 260pt) + 오른쪽 알림·장바구니 아이콘 |
| 상단 탭 줄 | 약 30pt, 가로 스크롤 |
| 배너 | 약 340pt, 화면 폭 꽉 참, 아래 2pt 진행 막대 |
| 카테고리 원 2줄 | 원 지름 약 64pt + 이름 |
| 카테고리 아래 구분선 | 1pt #f0f0f0 |
| 하단 탭 바 | 홈 인디케이터 포함 약 80pt, 윗선 1pt |

- 구간 사이 정확한 간격은 확인 필요.

### 간격 적용 규칙
- 왼쪽 시작선은 16pt 하나로 맞춘다(검색창·탭·카테고리).
- 카테고리 원 사이는 약 6pt로 좁게 둔다.
- 배너는 좌우 여백 없이 화면 폭을 꽉 채운다.

### Don't
- 배너에 좌우 여백이나 모서리를 주지 않는다.
- 카테고리 원 사이를 넓게 벌려 한 줄 5개를 깨지 않는다.
- 검색창·탭·카테고리의 왼쪽 시작선을 서로 다르게 두지 않는다.

## 5. 모서리·고도·모션
픽셀 단위는 iOS pt와 같다고 보고 적었다(1pt = CSS 1px).

### 모서리
| 토큰 | 값 | 쓰임 |
|---|---|---|
| radius-none | 0px | 홈 배너 |
| radius-md | 12px | 검색창(관찰 10~12) |
| radius-sheet | 16px | 바텀시트 위 두 모서리 |
| radius-full | 999px | 카테고리 원, 새 소식 점 |

### 테두리
- divider 1pt #f0f0f0 — 카테고리 묶음 아래 구분선. 검색창·카테고리 원에는 테두리가 없다.

### 고도(층)
- 평면이다. 그림자는 보이지 않는다(확인 필요). 층은 흰 바탕과 #f4f4f4 면으로만 나뉜다.
- 바텀시트 뒤는 검정 80% 덮개.

### 모션
- 길이·이징: 캡처로 알 수 없음. 확인 필요.

### Don't
- 홈 배너를 둥글리지 않는다.
- 검색창을 알약(999px)으로 만들지 않는다. 약 12pt다.
- 그림자로 카드나 검색창을 띄우지 않는다(관찰 화면에 그림자 없음).

## 6. 컴포넌트
컴포넌트마다 크기, 종류, 상태, 규칙을 적는다. 보지 못한 상태는 `확인 필요`. 접근성 메모 중 서비스가 실제로 그렇게 한다는 근거가 없는 것은 `(구현 권장)`을 달았다.

### 6.1 버튼
| 종류 | 모양 | 쓰는 곳 |
|---|---|---|
| 아이콘 버튼 | 진회색 선 아이콘, 새 소식 때 빨간 점 | 상단 바 알림·장바구니 |
| 닫기 | 오른쪽 위 가는 X | 바텀시트 닫기 |

- 일반 주요 버튼(구매·판매): 캡처에 없음. 크기·색 확인 필요.
- 상태: 눌림·비활성·로딩 확인 필요.

**규칙**
- 아이콘 버튼에 새 소식이 있으면 오른쪽 위에 빨간 점만 붙인다(숫자 없음).
- 접근성: 아이콘 버튼과 닫기 X에 "알림", "장바구니", "닫기" 같은 이름을 단다 (구현 권장). 빨간 점이 있으면 "새 알림 있음"처럼 읽히게 한다 (구현 권장).

### 6.2 입력창(검색)
| 항목 | 값 |
|---|---|
| 크기 | 폭 약 260pt, 높이 약 40pt |
| 모서리 | 약 12pt |
| 바탕·선 | #f4f4f4, 테두리 없음 |
| 글자 | 15pt 회색 안내 글자(#c4c4c4 근처) |
| 아이콘 | 오른쪽 안에 카메라 검색 아이콘 |

- 상태: 기본만 확인. 포커스·입력 중은 확인 필요.

**규칙**
- 검색창은 화면 맨 위, 로고 자리에 둔다(이번 캡처 기준).
- 접근성: 안내 글자 대비가 1.6:1이라 입력창 이름을 따로 단다 (구현 권장). 카메라 검색 아이콘에 이름을 단다 (구현 권장).

### 6.3 탭
| 종류 | 글자 | 선택 표시 |
|---|---|---|
| 상단 가로 탭 | 15pt #222222, 줄 약 30pt, 가로 스크롤 | 700 + 글자 폭만큼 2pt #222222 밑줄 |

- 일부 탭 이름 오른쪽 위에 빨간 점.
- 상태: 기본·선택 확인.

**규칙**
- 선택 표시에 색 바탕(채운 칩)을 쓰지 않는다.
- 밑줄 폭은 글자 폭과 같다.
- 탭 이름은 2~4글자 명사.
- 접근성: 탭 줄 높이 약 30pt는 44pt보다 낮다. 누르는 영역을 넓힌다 (구현 권장). `role="tab"`과 선택 상태 (구현 권장).

### 6.4 카테고리 원
| 항목 | 값 |
|---|---|
| 원 | 지름 약 64pt, #f4f4f4, 테두리 없음 |
| 안 | 배경을 지운 상품 사진 또는 굵은 글자 |
| 이름 | 원 아래 12pt, 최대 2줄 |
| 배치 | 한 줄 5개 × 2줄, 사이 약 6pt |
| 마지막 원 | `>` 화살표(더보기) |

- 상품 카드·가격 리스트: 캡처에 없음. 확인 필요.

**규칙**
- 원 안에 배경 있는 사진을 넣지 않는다.
- 더보기는 마지막 원 자리에 둔다.
- 접근성: 원 안 사진은 장식이므로 이름 글자로 뜻을 전한다 (구현 권장).

### 6.5 상단 바·하단 탭 바
| 항목 | 값 |
|---|---|
| 상단 바 | 로고 없이 검색창이 맨 위(이번 캡처 기준) + 알림·장바구니 아이콘 |
| 하단 탭 바 | 흰 바탕, 1pt #f7f7f7 윗선, 아이콘 + 영문 대문자 이름 5개(HOME, STYLE, SHOP, SAVED, MY) |
| 하단 탭 선택 / 비선택 | #222222 / #7f7f7f 근처 |
| 높이 | 홈 인디케이터 포함 약 80pt |

**규칙**
- 하단 탭 선택은 검정, 비선택은 회색으로만 나눈다(유채색 없음).
- 접근성: 비선택 이름 11pt #7f7f7f(4.0:1)는 본문 기준 미달이다. 선택 탭에 `aria-current` 같은 상태 정보를 준다 (구현 권장).

### 6.6 바텀시트
| 항목 | 값 |
|---|---|
| 위 모서리 | 16pt |
| 위치 | 화면 아래에 붙음 |
| 뒤 덮개 | 검정 80% |
| 구성(광고) | 위에 작은 검정 칩 2개, 큰 굵은 제목, 작은 설명, 아래 쪽 표시 점 3개 |
| 닫기 | 오른쪽 위 가는 X |

**규칙**
- 광고·혜택 알림은 홈 위 바텀시트로 띄운다.
- 접근성: 열리면 포커스를 시트 안으로 옮기고, 닫으면 원래 자리로 돌린다 (구현 권장).

### 6.7 배지·진행 표시
| 종류 | 모양 |
|---|---|
| 새 소식 점 | #f15746 작은 원(모서리 999px), 탭 이름·아이콘 오른쪽 위 |
| 배너 진행 막대 | 배너 아래 2pt |
| 토스트·스낵바 | 캡처에 없음. 확인 필요 |

**규칙**
- 새 소식은 점 하나로만 표시한다. 개수를 쓰지 않는다.

### 6.8 아이콘·이미지
- 아이콘: 진회색 선 아이콘. 새 소식은 빨간 작은 점.
- 이미지: 상품 사진은 배경을 지운 누끼 사진을 회색 원 위에 올린다.
- 배너: 화면 폭 꽉 찬 사진(높이 약 340pt, 모서리 0) + 아래 2pt 진행 막대.

## 7. 패턴
- 홈 구성: 검색창 → 상단 가로 탭 → 꽉 찬 배너(진행 막대) → 카테고리 원 2줄 → 1pt 구분선.
- 검색: 맨 위 회색 검색창 + 카메라(이미지) 검색 아이콘. 검색 결과 화면은 확인 필요.
- 광고·혜택 알림: 홈 위에 바텀시트로 띄우고 뒤를 80% 덮개로 가린다.
- 목록 → 상세: 확인 필요(상품 목록·상세 화면을 보지 못함).

- 확인 필요(캡처에 없음).

## 8. 접근성
- 글자 대비(WCAG 2.x, 계산값):

| 글자 | 바탕 | 대비 | 본문 기준 4.5:1 |
|---|---|---|---|
| #222222 | #ffffff | 15.9:1 | 통과 |
| #333333 | #ffffff | 12.6:1 | 통과 |
| #7f7f7f | #ffffff | 4.0:1 | 미달(큰 글자 3:1은 통과) |
| #c4c4c4 | #f4f4f4 | 1.6:1 | 미달 |
| #222222 | #f4f4f4 | 14.5:1 | 통과 |
| #f15746 | #ffffff | 3.4:1 | 미달(큰 글자 3:1은 통과) |

- 대비 메모: 비선택 하단 탭 이름(11pt #7f7f7f)은 본문 기준에 못 미친다. 검색창 안내 글자(#c4c4c4 on #f4f4f4)는 1.6:1로 크게 모자란다. 새 소식 점(#f15746)은 글자가 아닌 표시라 그래픽 기준 3:1은 넘는다. 주요 버튼 색은 캡처에 없어 계산하지 못했다(확인 필요).
- 터치 영역: 카테고리 원 64pt는 44pt 기준을 넘는다. 검색창 높이 약 40pt는 조금 낮다. 상단 탭 줄 약 30pt는 모자란다.
- 최소 글자 크기: 11pt(하단 탭 영문 이름).

| 항목 | 상태 |

## 9. 글쓰기 톤
- 말투: 확인 필요(안내 문장이 캡처에 거의 없음).
- 상단 탭: 2~4글자 명사(추천, 랭킹, 이벤트).
- 카테고리 이름: 짧은 명사나 짧은 구(신상, 지금 인기, 더보기). 길면 2줄.

## 10. Do & Don't
관찰 기반 문서의 규칙은 "이 서비스 화면에서 반복되는 규칙"을 SylviaLab이 정리한 것이다(공식 규칙 아님).

### Do
- UI 글자와 선택 표시는 #222222로 쓴다.
- 선택 탭은 15pt 700 + 글자 폭만큼 2pt #222222 밑줄로 표시한다.
- 검색창과 카테고리 원은 #f4f4f4 면, 테두리 없이 만든다(검색창 모서리 12pt, 원 지름 64pt).
- 새 소식은 #f15746 작은 점을 탭·아이콘 오른쪽 위에 붙인다.
- 하단 탭 바는 흰 바탕 + 1pt #f7f7f7 윗선, 이름은 11pt 영문 대문자.
- 좌우 여백은 16pt, 배너는 화면 폭 꽉 차게(모서리 0).
- 바텀시트는 위 모서리 16pt, 뒤는 검정 80% 덮개.

### Don't
- UI 요소(탭·버튼·검색창)에 브랜드 강조색을 넣지 않는다.
- 빨강 #f15746을 새 소식 점 밖에 쓰지 않는다.
- 검색창·카테고리 원에 테두리를 긋지 않는다.
- 배너 바탕색(#1f52ea)을 UI 색으로 가져오지 않는다.
- 카테고리 원 안에 배경 있는 사진을 넣지 않는다(누끼 사진 또는 굵은 글자).

- 배너·광고 바텀시트 속 색은 시스템 색에서 빼거나 따로 적었다.
- 관찰 값은 서비스가 바뀌면 달라질 수 있다.
- 원칙(1장), 사용 규칙, 패턴(7장), Do & Don't(10장)는 위 관찰값에서 SylviaLab이 정리했고, 대비(8장)는 캡처 HEX로 계산했다.
- 서비스 이름과 브랜드는 각 권리자의 것이다. 이 문서는 식별·학습용 참고 자료로 SylviaLab이 독자적으로 작성했다.

## 부록 B. 값의 출처 구분
- **공식 자료 그대로**: 없음. KREAM 공개 디자인 시스템·코드를 확인하지 않았다.
- **화면에서 잰 값(관찰)**: 모든 HEX, 글자 크기·굵기, 검색창·탭 줄·카테고리 원·배너·하단 탭 바 크기, 좌우 여백 16pt, 모서리, 선 굵기, 덮개 농도(홈 캡처 2장). 크기 ±1pt, 작은 글자 색은 근처 값.
- **SylviaLab이 정리·권장한 것**: 토큰 이름 전부(팔레트·역할 두 층), 원칙·사용 규칙·Do·Don't, 패턴 정리, YAML `size`·`layout` 묶음 이름, `(구현 권장)` 접근성 메모, 대비 계산값.
