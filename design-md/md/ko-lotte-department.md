# 롯데백화점 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 롯데백화점 iOS 앱 메인(DISCOVER) 화면 12장. 한 장은 첫 화면 전체, 나머지 11장은 같은 긴 페이지를 내려가며 자른 것. 레이어 이름은 2025-01-19지만 화면 속 날짜는 2024년 1월. 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

이 문서는 디자인 시스템의 다섯 층(원칙, 토큰, 컴포넌트, 사용 규칙, 구현·검증)을 한 파일로 줄인 요약이다. 맨 위 YAML은 도구와 AI가 그대로 읽는 값이고, 아래 글은 그 값을 언제·왜 쓰는지 설명한다.

## 1. 개요와 원칙
- 서비스 성격: 롯데쇼핑이 운영하는 롯데백화점 전용 앱이다. 온라인몰 롯데ON이 아니다. 캡처에 매장 모드 스위치, 지점 안내 탭, 롯백클럽·롯데갤러리·문화센터·샤롯책방 구획이 있어 백화점 앱으로 확인했다. 매장 방문, 지점 소식, 혜택, 문화 콘텐츠를 모아 보여 준다.
- 디자인 인상 한 줄: 짙은 빨강 그러데이션 바탕 위에 모서리 16pt 카드를 세로로 쌓는다. 카드마다 보라·파랑·주황·검정 같은 단색을 통째로 칠하고, 안쪽 글자와 버튼은 흰 바탕·검정 글자로 단정하게 둔다.
- 공식 시스템 이름: 공개된 이름 없음
- 디자인 원칙 (공식 원칙은 찾지 못했다)
  1. 구획마다 고유 단색을 하나씩 준다(클럽 보라, 플레이스 파랑, 먹거리 주황, 문화센터 회갈색, 매거진 검정). (관찰에서 정리)
  2. 색은 바깥 구획 카드에만 쓰고, 안쪽 콘텐츠 카드·버튼·칩은 흰색·검정 무채색으로 둔다. (관찰에서 정리)
  3. 라임은 "지금 매장에 있는가"와 메인 탭처럼 앱의 핵심 조작에만 쓴다. (관찰에서 정리)
  4. 바깥은 크게(16pt), 안쪽은 작게(8pt), 누르는 칩은 완전히 둥글게 모서리를 겹쳐 쓴다. (관찰에서 정리)
  5. 구획 이름과 메뉴는 영문으로 잡지 표지처럼 꾸미고, 본문은 한국어로 쓴다. (관찰에서 정리)
- 톤: 잡지처럼 화려한 겉면에 안쪽 정보는 단정하게.
- 특징 메모
  - 메인 화면 전체 바탕이 흐린 빨강 그러데이션(#aa2720 근처)이다. 사진을 흐리게 깐 것처럼 위치마다 색이 조금씩 다르다. 평소 색인지 새해 시즌 테마인지 확인 필요.
  - 하단 탭 바와 오른쪽 떠 있는 버튼은 반투명(뒤가 비침)이다.
- 공개 자료 상황: 공개 디자인 시스템 문서나 코드는 찾지 못했다(이번 작업에서는 공개 URL을 따로 확인하지 않았다).

### 특장점
- 구획을 색으로 찾게 한다 — 메인 한 페이지를 클럽 #a12de9, 플레이스 #165bdc, 먹거리 #ff9111, 문화센터 #c3bdb9, 매거진 #000000 단색 카드로 나눠, 긴 세로 스크롤에서도 지금 어느 구획인지 색으로 안다.
- 오프라인 매장을 앱 조작으로 드러낸다 — 맨 위 오른쪽에 라임 #e7f574 매장 모드 스위치(약 51×22pt)를 두고, 같은 라임 계열(#e2f762)을 하단 가운데 DISCOVER 알약에만 쓴다.
- 하단 탭 가운데를 메인 버튼으로 만든다 — 5칸 탭 바 가운데에 약 82×38pt 검정 알약 "DISCOVER"(크림 #feffd1 → 라임 #e2f762 그러데이션 글자)를 둔다.
- 모서리를 겹쳐서 층을 보여 준다 — 바깥 구획 카드 16pt 안에 흰 콘텐츠 카드·버튼 8pt, 리뷰 썸네일 4pt를 넣고 그림자는 쓰지 않는다.
- 잡지 같은 구획 머리 — 구획 이름(Club, Place, Eat)을 큰 영문 세리프 글자로 쓰고, 매거진 사진은 세로 알약 모양으로 자른다.

### 배울 점
- 긴 메인 페이지를 나눌 때 롯데백화점처럼 구획마다 단색 카드 하나를 주고, 안쪽 콘텐츠는 흰 카드로 통일한다.
- 앱의 핵심 모드(매장 방문 같은)가 있을 때 전용 색 하나를 정해 그 스위치와 메인 탭에만 쓴다.
- 카드 안에 카드를 넣을 때 바깥 16pt·안쪽 8pt처럼 모서리를 한 단계 줄여 층을 구분한다.

### 이 문서를 읽는 AI 에이전트에게
- 색은 YAML 역할 이름(`section-club`, `text-meta`, `surface-card`)으로 쓴다. 구획 색은 바깥 구획 카드 바탕에만 쓴다.
- 라임(`store-mode`, `lime-text`)은 매장 모드 스위치와 DISCOVER 탭 두 곳뿐이다. 다른 강조가 필요하면 검정을 쓴다.
- 모서리는 바깥 16px → 안쪽 8px → 썸네일 4px, 누르는 칩은 999px. 이 순서를 뒤집지 않는다.
- 이 문서는 메인 화면 한 페이지(캡처 12장)에서 잰 값이다. 상세·검색·입력·오류 화면은 `확인 필요`이니 값을 지어내지 말고 흰 카드 + 검정 글자 + 8px 모서리 안에서 가장 단순하게 만든다.

- **검정 #000000**: 글자 말고도 "누르는 작은 것"(해시태그 칩, DISCOVER 알약, 선택된 점)에 쓴다.
- **라임 #e7f574 / #e2f762**: 매장 모드 스위치 바탕, DISCOVER 글자(크림 #feffd1 → 라임 그러데이션).
- **회색 선**: 버튼 테두리 #e0e0e0, 묶음 구분선 #f6f6f6, 꺼진 점 #cccccc.
- 눌림·선택·비활성 색: 확인 필요.

### 색 사용 규칙
- 구획 색 카드 위 제목·부제는 흰 글자, 안쪽 콘텐츠 카드는 흰 바탕이다. 문화센터(#c3bdb9)만 카드 위 글자가 검정이다.
- 구획 색은 바깥 구획 카드 바탕에만 쓴다. 버튼과 해시태그 칩은 무채색이다(흰 바탕 + 1pt #e0e0e0 테두리 버튼, 검정 알약 칩).
- 라임(#e7f574, #e2f762)은 매장 모드 스위치와 DISCOVER 탭에만 쓴다.
- 보조 글자(지점명, 기간, 작성자·날짜)는 #797979로 둔다.
- 구획 이름 로고 글자, 배너 사진, 매거진 사진 속 색은 디자인 시스템 색으로 쓰지 않는다.

### Don't
- 한 구획 카드에 구획 색을 두 가지 이상 섞지 않는다.
- 구획 색(#a12de9, #165bdc, #ff9111)을 버튼·칩·글자 색으로 쓰지 않는다.
- 라임을 매장 모드 스위치·DISCOVER 탭 밖에 쓰지 않는다.
- 문화센터 #c3bdb9 바탕에 흰 글자를 올리지 않는다.
- 먹거리 #ff9111 위 흰 글자를 15pt 미만으로 쓰지 않는다. 대비가 2.3:1이다.

## 5. 모서리·고도·모션
픽셀 단위는 iOS pt와 같다고 보고 적었다(1pt = CSS 1px).

| 토큰 | 값 | 쓰임 |
|---|---|---|
| radius-xs | 4px | 리뷰 썸네일 |
| radius-sm | 8px | 구획 안 흰 콘텐츠 카드, "전체 보기" 버튼 |
| radius-lg | 16px | 구획 카드, 첫 화면 큰 배너 |
| radius-full | 999px | 해시태그 칩, 분류 칩, DISCOVER 알약, 매장 모드 스위치, 떠 있는 둥근 버튼, 페이지 점 |

- 테두리·선: border 1pt #e0e0e0("전체 보기" 버튼), divider 1pt #f6f6f6(해시태그 묶음 사이 구분선).
### 고도
- 고도(그림자·층): 그림자는 확인 필요. 카드에 뚜렷한 그림자는 보이지 않는다. 떠 있는 버튼과 하단 탭 바는 반투명 면으로 구분된다.
- 층 나누기: 빨강 바탕 → 단색 구획 카드(16pt) → 흰 콘텐츠 카드(8pt). 그림자 대신 면 색과 모서리 크기로 층을 보인다. 떠 있는 것(탭 바, 떠 있는 메뉴)만 반투명 면이다.
- 모서리 규칙: 바깥 구획은 16pt로 크게 둥글고, 그 안 카드·버튼은 8pt로 작게 둥글다. 누르는 칩은 완전히 둥글다. 매거진 구획 사진은 세로로 긴 알약(타원) 모양으로 잘라 쓴다.

### 모션
- 모션(길이·이징): 캡처로 알 수 없음. 확인 필요.

### Don't
- 콘텐츠 카드나 버튼에 16pt 모서리를 쓰지 않는다.
- 구획 카드·콘텐츠 카드에 그림자를 넣지 않는다.
- 버튼(8pt)을 알약(999px)으로 바꾸지 않는다. 알약은 칩·DISCOVER·스위치·원형 버튼용이다.
- 반투명 면을 일반 카드에 쓰지 않는다. 탭 바·떠 있는 버튼 전용이다.

## 10. Do & Don't
관찰 기반 문서의 규칙은 "이 서비스 화면에서 반복되는 규칙"을 SylviaLab이 정리한 것이다(공식 규칙 아님).

### Do
- 구획 카드는 폭 약 328pt, 모서리 16pt, 카드 사이 약 18pt로 쌓는다.
- 구획마다 단색 하나를 쓴다(#a12de9, #165bdc, #ff9111, #c3bdb9, #000000, #ffffff).
- 구획 안 콘텐츠 카드와 버튼은 흰 바탕, 모서리 8pt로 둔다.

- 날짜는 "24.1.31(수)" 꼴로 쓴다.

### Don't

- 구획 색을 버튼이나 칩 바탕에 쓰지 않는다. 버튼·칩은 흰색·검정만.
- 카드에 그림자를 넣지 않는다.
- 밝은 구획 바탕(#c3bdb9)에 흰 글자를 올리지 않는다(문화센터는 검정 글자).

- 메타 글자를 #797979보다 옅게(#9a9a9a 등) 흰 바탕 본문에 쓰지 않는다.
