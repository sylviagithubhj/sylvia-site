# 이마트몰 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 2024년 12월 iOS 이마트몰 앱 홈의 "프리미엄" 탭 화면 6장(긴 한 페이지를 나눈 조각), 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

이 문서는 디자인 시스템의 다섯 층(원칙, 토큰, 컴포넌트, 사용 규칙, 구현·검증)을 한 파일로 줄인 요약이다. 맨 위 YAML은 도구와 AI가 그대로 읽는 값이고, 아래 글은 그 값을 언제·왜 쓰는지 설명한다. 둘이 어긋나면 YAML 값을 따른다.

## 1. 개요와 원칙
- 서비스 성격: 이마트의 온라인 장보기 앱. 신선식품·가공식품·생활용품을 팔고, 새벽배송과 쓱배송을 붙인다. 상품과 배송은 SSG.COM과 같은 기반을 쓴다(상품명 앞 "SSG푸드마켓", 배송 배지로 확인).
- 확인한 앱: 화면 왼쪽 위 워드마크가 "emart mall"이고 머리 띠가 노랑이다. SSG.COM 앱 안의 이마트몰 화면이 아니라 이마트몰 앱 화면으로 본다. 다만 앱 이름까지는 캡처로 확인하지 못했다.
- 디자인 인상 한 줄: 노랑(#ffd040) 머리 띠 아래 흰 바탕, 검정에 가까운 글자(#222222). 프리미엄 탭은 큰 사진과 영문 구획 제목으로 잡지처럼 보여준다.
- 공식 시스템 이름: 공개된 이름 없음(확인 필요)
- 공개 자료 상황: 디자인 시스템 문서·공개 코드는 이번에 찾지 않았다. 확인 필요.
- 디자인 원칙
  1. 브랜드 노랑은 머리 띠(로고 줄·검색창 바깥·상단 탭)에만 넓게 쓰고, 본문에는 거의 쓰지 않는다. (관찰에서 정리)
  2. 색으로 강조하는 것은 할인율 하나다. 할인율만 빨강(#ff5452), 가격은 검정 굵게, 정가는 회색 취소선. (관찰에서 정리)
  3. 어느 상품에서든 바로 담게 한다. 상품 사진마다 오른쪽 아래에 흰 장바구니 버튼이 붙는다. (관찰에서 정리)
  4. 프리미엄 탭은 잡지처럼 보여준다. 구획 제목은 영문(New Arrivals, Category, Cafe at HOME, Food Essay 등) + 한글 부제 한 줄, 연출 사진을 크게 쓴다. (관찰에서 정리)
  5. 배송 정보는 흐린 청회색(#a3b7cd)으로 따로 묶는다. 새벽배송 배지와 떠 있는 바로가기 버튼이 같은 계열이다. (관찰에서 정리)
- 톤: 장보기 앱이지만 프리미엄 탭은 차분하고 여유 있게. 큰 사진과 넓은 구획 간격(약 50pt).

### 특장점
- 노랑을 머리 띠 한 덩어리에 가둔다 — #ffd040은 로고 줄 약 40pt + 검색창 40pt + 상단 탭 약 37pt에만 깔리고, 그 아래 본문은 흰 바탕에 #222222 글자다. 머리 띠 아래 옅은 그림자로 경계를 준다.
- 노랑 위 검색창을 테두리로 띄운다 — 345×40pt 흰 칸에 진한 회색 1pt 테두리(#595959 근처), 모서리 8pt로 노랑 바탕 위에서 또렷하다.
- 장보기 화면을 잡지처럼 편집한다 — 영문 구획 제목 20pt 700 + 13pt 회색 한글 부제, 구획 사이 약 50pt, 정기구독 카드 약 215×202pt 큰 사진.
- 카테고리를 아이콘 대신 식품 그림으로 보여 준다 — 52pt 베이지(#eae5d5) 칸, 모서리 16pt 안에 실제 식품 누끼 그림을 넣는다.
- 배송 수단을 별도 색 계열로 표시한다 — 새벽배송 배지(#a3b7cd 알약 + 트럭 아이콘)와 왼쪽 아래 떠 있는 바로가기(#a3b6ce, 58pt)가 같은 청회색이다.

### 배울 점
- 브랜드 색이 강한 노랑일 때 이마트몰처럼 머리 띠에만 넓게 깔고 본문은 흰 바탕 + #222222로 비워, 상품 사진이 색을 다투지 않게 한다.
- 진한 색 바탕 위에 검색창을 둘 때 흰 칸 + 진한 1pt 테두리로 띄운다.
- 가로 스크롤 목록에는 다음 카드가 오른쪽에 걸쳐 보이게 하고, 아래 2pt 진행 막대(#e5e5e5 트랙 + #222222 막대)로 위치를 알린다.

### 이 문서를 읽는 AI 에이전트에게
- 색·크기는 YAML 토큰 이름으로만 쓴다. 화면 코드에서는 팔레트(`yellow-400`, `gray-950`)보다 역할(`brand-yellow`, `ink`, `discount`)을 먼저 쓴다.
- 노랑 `brand-yellow`는 머리 띠(로고 줄·검색창 바깥·상단 탭)에만 쓴다. 본문 버튼·카드에 쓰지 않는다.
- 색으로 강조하는 곳은 할인율(`discount`) 하나다. 가격은 `ink` 굵게.
- 이 값은 프리미엄 탭 한 페이지에서 잰 것이다. 상세·장바구니·결제처럼 보지 못한 화면을 그릴 때는 값을 지어내지 말고 `확인 필요`로 남기거나, 이 문서의 가장 가까운 부품(외곽선 버튼, 정보 칩)을 고른다.
- 판단이 어려우면 색을 더하기보다 흰 바탕·여백(구획 사이 50pt)을 고른다.

## 2. 색상
값은 1배율 PNG 캡처 픽셀에서 읽었다. 넓은 면 색은 정확하고, 작은 글자 색은 테두리 번짐 때문에 실제보다 밝게 읽힐 수 있다. 토큰 이름은 SylviaLab이 붙인 것이다.

### 색 체계
공식 팔레트는 공개되지 않았다. **관찰 팔레트 → 역할 이름** 두 층으로 정리했다.

| 층 | 예시 | 쓰는 곳 |
|---|---|---|
| 관찰 팔레트 | `yellow-400`, `gray-950`, `slate-blue-300` | 캡처에서 잰 값. YAML 정의에만 쓴다 |
| 역할 이름 | `brand-yellow`, `ink`, `discount`, `delivery`, `surface-chip` | 화면과 컴포넌트. 아래 표의 토큰 |
| 콘텐츠 색 | 브랜드관 구획 바탕 | 브랜드마다 바뀐다. 토큰으로 쓰지 않는다 |

- 색은 크게 세 무리다: 노랑(머리 띠), 검정·회색(본문 전부), 작은 의미색(할인 빨강, 신선 초록, 배송 청회색).

| brand-section-taupe | #706557 | 입점 브랜드 소개 구획 바탕(흰 제목·부제, 위에 상품 카드가 걸친다) |

- 이 색은 입점 브랜드마다 바뀌는 콘텐츠 색으로 보인다. 다른 브랜드 구획은 사진을 바탕으로 깔았다. 시스템 색으로 쓰지 않는다.
- 배너 속 밤색·사진 속 색은 상품 이미지라 재지 않았다.

### 역할별 색
- 노랑 `brand-yellow`: 머리 띠 세 줄(로고 줄 약 40pt, 검색창 40pt, 상단 탭 약 37pt)의 바탕 전용. 그 위 글자·아이콘은 모두 `ink`(#222222)다. 머리 띠 아래 옅은 그림자로 본문과 끊는다.
- 검정 `ink`: 제목·상품명·가격 글자와 "선택" 표시(상단 탭 2pt 밑줄, 캐러셀 진행 막대). 검정이 강조 표시 색 역할을 한다.
- 회색 글자 네 층: 카테고리 이름 #555555 → 부제 #777777 → 칩 글자·탭 이름 #888888 → 정가·별점 #999999 → 검색 안내 #c5c5c7.
- 빨강 `discount`: 할인율 숫자만. 판매가 앞에 붙는다.
- 초록 `fresh-green`: "신선보장" 칩 글자만. 바탕은 다른 칩과 같은 #f5f5f5.
- 청회색 `delivery`·`floating`: 배송 관련 표시(새벽배송 배지, 떠 있는 바로가기)만. 두 값은 1 차이라 같은 색으로 봐도 된다.
- 상태 색 조합(배경/선/글자): 성공·경고·오류 조합은 캡처에 없다. 확인 필요. 관찰된 조합은 "정보 칩 = #f5f5f5 바탕 + 회색 또는 초록 글자, 선 없음", "배송 배지 = 청회색 바탕 + 검정 글자" 두 가지다.

### 화면 모드
- 다크 모드: 캡처에 없음. 확인 필요.

### 색 사용 규칙
- brand-yellow(#ffd040)는 머리 띠(로고 줄·검색창 바깥·상단 탭)에만 쓴다. 본문 카드·버튼에는 쓰지 않는다.
- 빨강 #ff5452는 할인율에만 쓴다. 가격은 #222222 굵게, 정가는 #999999 취소선.
- 청회색(#a3b7cd, #a3b6ce)은 새벽배송 배지와 떠 있는 바로가기에만 쓴다.
- 초록 #40b07e는 "신선보장" 칩 글자에만 쓴다.
- 정보 칩 바탕은 #f5f5f5, 글자는 회색(#888888) 또는 초록.
- 브랜드관 구획 색(#706557 등)은 브랜드마다 바뀌는 콘텐츠 색이라 시스템 색으로 쓰지 않는다.

### Don't
- 노랑을 본문 버튼·카드·배지 바탕에 쓰지 않는다.
- 판매가를 빨강으로 쓰지 않는다. 빨강은 할인율 숫자만.
- 노랑 머리 띠 위 글자를 흰색으로 쓰지 않는다. `ink`다(워드마크만 흰색).
- 청회색을 배송과 관계없는 표시에 쓰지 않는다.
- 브랜드관 구획 색을 다른 구획의 바탕으로 재사용하지 않는다.

- 간격 단계(관찰, pt): 4, 8, 10, 12, 15, 20, 50

- 구획 사이를 20~30pt처럼 좁히지 않는다. 약 50pt다.

## 5. 모서리·고도·모션
1pt = CSS 1px로 본다.

### 모서리
| 토큰 | 값 | 쓰임 |
|---|---|---|
| radius-none | 0px | 상품 카드 이미지(가로 스크롤 카드) |
| radius-xs | 4px | 상품 정보 칩 |
| radius-sm | 6px | 장바구니 버튼(약 30pt 흰 정사각) |
| radius-md | 8px | 검색창, 큰 배너, 외곽선 버튼, 목록 썸네일, 정기구독 사진 |
| radius-lg | 16px | 카테고리 칸, 떠 있는 바로가기 버튼 |
| radius-section | 24px | 브랜드관 구획 왼쪽 위 모서리(추정) |
| radius-full | 999px | 새벽배송 배지, 맨 위로 버튼(지름 약 40pt) |

- 모서리 규칙: 사진은 각지거나 8pt, 누르는 칸(카테고리·떠 있는 버튼)은 16pt로 더 둥글다.

### 테두리
- border-search: 1pt #595959 — 검색창 테두리(추정)
- border-button: 1pt #dddddd — 외곽선 버튼

### 고도(층)
- 본문은 평면이다. 카드에 테두리·그림자가 없고 흰 바탕 위에 사진이 바로 놓인다.
- 그림자는 두 곳에만 보인다.
  - shadow-header: 머리 띠 아래 약 8pt에 걸쳐 흐려지는 옅은 그림자
  - shadow-float: 맨 위로 버튼의 옅은 그림자
- 그림자 값은 확인 필요.

### 모션
- 길이·이징: 캡처로 알 수 없음. 확인 필요.

### Don't
- 가로 스크롤 상품 카드 이미지를 둥글리지 않는다(0px).
- 상품 카드에 그림자나 테두리를 넣지 않는다.
- 외곽선 버튼·검색창을 알약(999px)으로 만들지 않는다. 8pt다.
- 그림자 수치를 정해진 값처럼 쓰지 않는다. 확인되지 않았다.

## 6. 컴포넌트
컴포넌트마다 크기, 종류, 상태, 규칙을 적는다. 보지 못한 상태는 `확인 필요`. 접근성 메모 중 서비스가 실제로 그렇게 한다는 근거가 없는 것은 `(구현 권장)`을 달았다.

### 6.1 버튼
**크기와 종류**

| 종류 | 크기 | 모서리 | 모양 | 쓰는 곳 |
|---|---|---|---|---|
| 외곽선 버튼 | 345×약 40pt(좌우 15pt) | 8pt | 흰 바탕 + 1pt 연회색 테두리, 가운데 14pt 검정 글자 + `>` | 구획 끝 "전체보기" |
| 장바구니 버튼 | 약 30pt 정사각 | 약 6pt | 흰 바탕, 검정 바구니 선 아이콘 | 모든 상품 사진 오른쪽 아래, 바로 담기 |
| 떠 있는 바로가기 | 약 58pt 둥근 사각 | 16pt | 청회색 바탕, 두 줄 굵은 짧은 글자 | 왼쪽 아래, 배송·특가 바로가기 |
| 맨 위로 | 약 40pt 원 | 999px | 거의 흰 바탕 + 옅은 그림자, 검정 위 화살표 | 오른쪽 아래, 긴 페이지 |

- 채운 주요 버튼(구매·담기): 이번 캡처에 없음. 확인 필요.

**상태**: 기본만 확인. 눌림·비활성·로딩은 확인 필요.

**규칙**
- 외곽선 버튼을 노랑으로 채우지 않는다(본문에 노랑을 쓰지 않음).
- 외곽선 버튼 문구는 "○○ 전체보기 >" 꼴이고, 구획마다 맨 끝에 하나만 둔다.
- 장바구니 버튼은 모든 상품 사진의 같은 자리(오른쪽 아래)에 둔다.
- 접근성: 장바구니 버튼(30pt)·맨 위로(40pt)는 44pt보다 작으므로 누르는 영역을 넓힌다 (구현 권장). 아이콘만 있는 버튼에 "장바구니 담기", "맨 위로" 같은 이름을 단다 (구현 권장).

### 6.2 입력창
| 항목 | 값 |
|---|---|
| 크기 | 345×40pt |
| 모서리 | 8pt |
| 바탕·선 | 흰 바탕, 진한 회색 1pt 테두리 |
| 안 | 왼쪽 돋보기 아이콘(약 20pt) + 연회색 14pt 안내 글자 |

**상태**: 기본만 확인. 포커스·입력 중·오류는 확인 필요.

**규칙**
- 검색창은 노랑 머리 띠 안, 로고 줄 바로 아래에 둔다.
- 접근성: 안내 글자(#c5c5c7)는 1.7:1이라 입력창 이름을 따로 단다 (구현 권장).

### 6.3 칩·탭
| 종류 | 크기 | 모양 | 상태 |
|---|---|---|---|
| 정보 칩 | 높이 약 20pt, 모서리 약 4pt, 12pt 500 | gray-100 바탕 + 회색 글자(프리미엄식품관) 또는 초록 글자(신선보장) | 누를 수 있는지 확인 필요 |
| 상단 탭 | 줄 높이 약 37pt, 15pt | 노랑 바탕 가로 스크롤(홈·프리미엄·신선직송·자주구매·세일중·베스트…), 검정 글자 | 선택: 700 + 글자 폭만큼 2pt 검정 밑줄 |

**규칙**
- 칩은 선 없이 옅은 바탕으로만 만든다.
- 상단 탭 밑줄은 탭 칸 폭이 아니라 글자 폭에 맞춘다.
- 접근성: 상단 탭에 `role="tab"`과 선택 상태를 준다 (구현 권장).

### 6.4 상품 카드·리스트
| 종류 | 구성 |
|---|---|
| 상품 카드(세로) | 150pt 정사각 사진(오른쪽 아래 장바구니 버튼) → 새벽배송 배지 → 상품명 2줄(브랜드명만 굵게) → 정가 취소선(있을 때) → 빨강 할인율 + 검정 판매가 → 회색 별점 → 정보 칩 줄 |
| 가로 목록형 상품 | 82pt 썸네일(모서리 8pt) 오른쪽에 상품명 14pt 2줄, 가격 16pt 굵게, 오른쪽 끝 장바구니 아이콘. 3줄씩 묶어 가로로 넘긴다 |
| 카테고리 칸 | 52pt 베이지 둥근 사각 안 상품 그림, 아래 12pt 이름 |
| 브랜드관 구획 | 왼쪽 위만 크게 둥근 색 띠(또는 사진) 위에 흰 제목·부제, 아래 상품 카드가 띠 경계에 걸쳐 놓인다 |
| 큰 배너 | 345pt 폭, 모서리 8pt, 사진 + 흰 굵은 문구 |
| 정기구독 카드 | 약 215×202pt 사진, 모서리 8pt, 가로 스크롤 |

- 상태: 품절·눌림·로딩은 확인 필요.

**규칙**
- 상품 카드 정보 순서는 배지 → 이름 → 가격 → 별점 → 칩으로 고정한다.
- 정가는 할인이 있을 때만 보인다.
- 카테고리 칸에는 선 아이콘이 아니라 식품 그림을 넣는다.
- 접근성: 상품 사진 대체 텍스트에 상품명을 쓴다 (구현 권장). 취소선 정가는 "정가 ○원"처럼 읽히게 한다 (구현 권장).

### 6.5 상단 바·하단 탭 바
- 로고 줄: 왼쪽 워드마크 + 원형 화살표, 가운데 배송지 문구 + 위치 아이콘, 오른쪽 메시지·장바구니 선 아이콘(약 24pt). 모두 노랑 위 검정.
- 하단 탭 바: gray-50 바탕, 선 아이콘 약 20pt(#262b2e) + 10pt 회색 이름. 홈·카테고리·장보기메모·배송조회·MY 다섯 칸 + 오른쪽 끝 최근 본 상품 작은 썸네일.
- 하단 탭의 선택 상태 표시: 캡처로 구분되지 않는다. 확인 필요.

**규칙**
- 로고 줄 아이콘은 머리 띠 안에서 모두 검정 선 아이콘으로 맞춘다.
- 접근성: 하단 탭 이름 10pt는 작다. 글자 확대 대응은 확인 필요.

- 카테고리 아이콘: 선 아이콘이 아니라 실제 식품 누끼 그림을 베이지 칸에 넣는다.

## 7. 패턴
- 목록 → 상세: 상품 카드에서 장바구니 버튼으로 상세 없이 바로 담는다. 상품 상세 화면은 보지 못했다(확인 필요).
- 가로 스크롤 묶음: 상품 카드·카테고리·가로 목록 모두 가로로 넘기고, 다음 카드가 오른쪽에 걸쳐 보인다. 카테고리는 아래 진행 막대로 위치를 보여 준다.
- 구획 끝 더보기: 구획마다 끝에 폭 꽉 찬 외곽선 "○○ 전체보기 >" 버튼을 둔다.
- 긴 페이지 이동: 왼쪽 아래 떠 있는 바로가기(배송·특가) + 오른쪽 아래 맨 위로 버튼.
- 편집형 구획: 영문 제목 + 한글 부제 한 줄 → 큰 사진 또는 가로 스크롤 → 전체보기 버튼. 프리미엄 탭의 구획이 이 순서를 반복한다.
- 검색: 머리 띠 안 검색창만 확인. 검색 결과 화면은 확인 필요.

### 빈 상태·로딩·오류
- 확인 필요(캡처에 없음).

### 장바구니·결제 흐름

## 9. 글쓰기 톤

- 탭 첫 화면 제목: 두 줄. 윗줄은 감성 문구, 아랫줄은 관 이름.
- 버튼 문구 꼴: "○○ 전체보기 >" 꼴로 끝에 `>`를 붙인다.
- 상품명: "[브랜드] 상품명 용량/단위" 꼴. 판매처 이름을 맨 앞에 굵게 붙인다.

## 10. Do & Don't
관찰 기반 문서의 규칙은 "이 서비스 화면에서 반복되는 규칙"을 SylviaLab이 정리한 것이다(공식 규칙 아님).

### Do
- 노랑 #ffd040은 머리 띠(로고 줄 + 검색창 + 상단 탭)에만 깔고 아래 옅은 그림자로 끊는다.
- 노랑 위 검색창은 흰 바탕 + 진한 회색 1pt 테두리, 345×40pt, 모서리 8pt로 만든다.
- 상단 탭 선택은 700 + 글자 폭만큼 2pt #222222 밑줄로 표시한다.
- 좌우 여백 15pt, 구획 사이 약 50pt.
- 상품 사진(150pt) 오른쪽 아래에 30pt 흰 장바구니 버튼을 붙인다.
- 구획 제목 20pt 700 아래에 13pt 회색 부제 한 줄을 둔다.

### Don't
- 본문 카드·버튼에 노랑을 쓰지 않는다.
- 할인율이 아닌 곳에 빨강 #ff5452를 쓰지 않는다(가격은 #222222).
- 청회색 #a3b7cd를 배송 배지·떠 있는 바로가기 밖에 쓰지 않는다.
- 카테고리 칸에 선 아이콘을 넣지 않는다(52pt 베이지 칸 + 식품 그림).
- 구획 사이를 선이나 회색 띠로 나누지 않는다(여백 약 50pt).
- 브랜드관 구획 색(#706557)을 시스템 색처럼 다른 곳에 쓰지 않는다.
