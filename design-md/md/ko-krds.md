# KRDS(대한민국 정부) 디자인 시스템

> 근거: 공개 문서 기반 (krds.go.kr 스타일 가이드 + KRDS-uiux/krds-uiux 오픈소스 토큰·CSS)
> 작성: SylviaLab · 최종 수정 2026-10-31

## 1. 개요
- 서비스 성격: 정부·공공기관 웹사이트와 앱이 같이 쓰는 표준 디자인 시스템. 운영 주체는 행정안전부 쪽 디지털 정부 사업이다.
- 디자인 인상 한 줄: 흰 바탕에 정부 파랑(#256ef4) 하나를 주색으로 쓰고, 큰 글자(본문 17px)와 넓은 행간(150%)으로 누구나 읽기 쉽게 만든 화면.
- 공식 시스템 이름: KRDS (Korea Design System, 대한민국 디지털 정부 디자인 시스템)
- 배포 형태: Figma 라이브러리, 디자인 토큰(JSON·CSS), HTML 컴포넌트 키트(npm `krds-uiux`).
- 특징
  - 색마다 5~95까지 11단계를 두고, 단계 숫자로 대비를 약속한다("매직 넘버"). 40=3:1, 50=4.5:1, 70=7:1, 90=15:1.
  - 다크 모드 대신 `선명한 화면 모드`(high-contrast)를 둔다. 검정 바탕에 본문 대비 15:1을 목표로 한다.
  - CSS 루트 글자 크기를 62.5%로 두고 rem을 쓴다. 따라서 토큰의 1rem = 10px이다.
  - 모든 크기는 PC와 모바일 두 벌로 나뉜다. 분기점은 767px(글자), 1023px(여백)이다.

### 색 쓰는 규칙(공식 문서 요약)
- 비율은 중립 60, 보조(secondary) 30, 주색(primary) 10을 권한다.
- 글자는 바탕과 매직 넘버 차이 40 이상, 본문은 50 이상을 지킨다. 선명한 화면 모드는 70 이상, 본문 90 이상.
- 색만으로 뜻을 전하지 않는다. 글자나 아이콘을 함께 둔다.
- 비활성 상태에 투명도를 쓰지 않는다. 정해진 회색 단계를 쓴다.
- 5단계와 95단계는 바탕과 섞여 보일 수 있어 조심한다.

## 3. 타이포그래피
- 글꼴: Pretendard GOV (Pretendard를 공공용으로 다듬은 글꼴. 깃허브 orioncactus/pretendard에서 배포)
- 대체 글꼴: 고딕 계열. 문서는 Noto Sans, 나눔고딕, 스포카 한 산스를 예로 든다. 고딕이 아닌 글꼴은 배너·디스플레이에만 쓴다.
- 굵기: 기본은 400과 700 두 가지. 500을 더해 세 가지까지가 이상적이고, 네 가지를 넘기지 않는다.
- 행간: 모든 단계 150% (`--krds-line-height-base: 1.5`). 행간은 px 대신 상대 단위로 쓴다.
- 자간: Display 전 단계와 Heading xlarge·large는 1px, 나머지는 0.
- 본문 최소 16px. Pretendard GOV는 같은 크기에서 작아 보여서 기본 본문을 17px로 잡는다.

## 4. 간격·레이아웃
- 기본 단위: 8pt 그리드. 토큰은 2px부터 시작하는 숫자 단계(number-0~21)를 쓴다.
- 숫자 단계(px): 0, 1, 2, 4, 6, 8, 10, 12, 16, 20, 24, 28, 32, 36, 40, 44, 48, 56, 64, 72, 80, 96
- 간격 단계(gap-1~12, px): 2, 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80
- 안쪽 여백 단계(padding-1~10, px): 2, 4, 8, 10, 12, 16, 20, 24, 32, 40
- 높이 단계(size-height-1~11, px): 8, 16, 20, 24, 32, 40, 48, 56, 64, 72, 80
- 화면 좌우 여백: 모바일 16px, 데스크톱 24px (`--krds-contents-padding-x`, 1023px 이하에서 16px)
- 콘텐츠 최대 폭: 1200px (여백 포함 감싸개 1248px). 모바일 기준 콘텐츠 폭은 348px.
- 그리드

|---|---|---|---|---|
| small | 360px 이상 | 4 | 16px | 16px |

### 카드·리스트
- 구조화 목록 카드: 모서리 12px, 테두리 1px #b1b8be, 안쪽 여백 24·32·40px 세 단계.
- 카드 사이 24px, 카드 안 요소 사이 16px. 카드 제목 19px(작은 카드 17px) 굵게, 본문 #464c53.
- 선택(활성) 시 2px 링크색 테두리.
- 표, 텍스트 목록, 아코디언, 디스클로저 컴포넌트가 따로 있다.

### 상단 바·탭 바
- 맨 위에 `공식 배너`(masthead)를 둔다. 바탕 #eef2f7, 글자 15px, 최소 높이 32px. 정부 공식 사이트임을 알리는 띠다.
- 헤더: 흰 바탕, 메뉴 글자 17px 굵게(모바일 15px), 메뉴 최소 높이 40px, hover 모서리 6px.
- 그 아래 브레드크럼, 사이드 메뉴, 콘텐츠 내 탐색이 이어진다.
- 탭: 버튼 높이 48px, 최소 폭 64px, 글자 17px. 꽉 찬 탭은 높이 56px, 글자 19px. 채움형 탭 모서리 6px.
- 앱 하단 탭 바 규격: 확인 필요.

### 바텀시트·모달
- 모달 폭: small 400px, medium 560px, large 760px. 최소 높이 264px.
- 모서리 12px, 안쪽 여백 40px(모바일 24px), 제목 24px(모바일 22px) 굵게.
- 바탕 흰색, 테두리 1px #b1b8be, 그림자 위 표 참고, 뒤 딤 검정 75%.
- 버튼 사이 8px, 버튼 최소 폭 78px.
- 바텀시트 전용 규격: 확인 필요.

### 토스트·스낵바
- HTML 키트에 토스트·스낵바 컴포넌트는 없다. 대신 `긴급 공지`(critical alerts) 배너가 있다: 최대 폭 846px, 모서리 10px, 안쪽 여백 16px.

### 배지·토글·툴팁
- 배지: 높이 24px(큰 것 32px), 좌우 여백 8px, 모서리 4px, 글자 15px. 점 배지 6px. 채움형과 연한 바탕형이 있다.
- 토글: medium 32×20px, large 40×24px. 켜짐 #256ef4, 꺼짐 #6d7882.
- 툴팁: 인라인형은 #1e2124 바탕에 흰 글자, 모서리 4px. 박스형은 흰 바탕, 모서리 12px.

## 7. 아이콘·이미지·모션
- 아이콘 크기: 16px(xsmall·small), 20px(medium), 24px(large·xlarge). 기본 색 #33363d. SVG 마스크로 색을 입힌다.
- 일러스트·사진: 차트와 배너에는 graphic 색 단계를 쓴다. 장식용 사진 규칙은 확인 필요.
- 모션: 기본 전환 0.4s ease-in-out, 페이드 0.4s linear, 펼침 0.4s ease. 모달은 투명도 0.2s로 나타난다.
- 화면 크기 조정 기능을 제공한다: 0.9, 1, 1.1, 1.3, 1.5배.

## 8. 글쓰기 톤(UX 라이팅)
- 말투: 공공 서비스답게 존댓말 평서문. 버튼은 짧은 명사·동사(확인, 취소, 삭제, 예, 아니요).
- 구조: 입력 아래 도움말 → 오류 시 같은 자리에 오류 메시지. 성공·안내 메시지도 같은 자리를 쓴다.
- 링크는 방문 여부를 색(#5917b8)으로 구분한다.
- 쉬운 공공언어 세부 지침의 KRDS 내 위치와 문장 규칙: 확인 필요.
