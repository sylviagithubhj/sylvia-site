# 29CM 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 2025년 2월 이구홈위크 기간 iOS 앱 홈 화면 10장 + 2025년 6월쯤 카테고리(가구·인테리어) 1장·장바구니 1장·검색 시작 1장, 375pt 폭 1배율 이미지에서 픽셀 측정(검색 1장은 430pt 폭 1배율). 실측일 2026-10-31) + 회사 기술 블로그 1편(디자인 시스템 Ruler 소개)
> 작성: SylviaLab · 최종 수정 2026-10-31

이 문서는 디자인 시스템의 다섯 층(원칙, 토큰, 컴포넌트, 사용 규칙, 구현·검증)을 한 파일로 줄인 요약이다. 맨 위 YAML은 도구와 AI가 그대로 읽는 값이고, 아래 글은 그 값을 언제·왜 쓰는지 설명한다.

## 1. 개요와 원칙
- 서비스 성격: 무신사 계열 온라인 편집숍. 패션, 리빙, 컬처 상품을 큐레이션과 콘텐츠로 묶어 판다. 웹(29cm.co.kr)과 iOS·Android 앱.
- 디자인 인상 한 줄: 검정·흰색·주황(#ff4800) 세 가지. 큰 사진과 짧은 제목을 잡지처럼 쌓고, 버튼과 칩은 각지거나 완전히 둥글게만 쓴다.
- 공식 시스템 이름: Ruler (사내 디자인 시스템. 공개 문서·공개 코드 없음)
- 디자인 원칙 (공식 원칙은 공개되지 않았다)
  1. 강조색은 주황 하나만 쓰고, 나머지는 검정과 회색으로 채운다. (관찰에서 정리)
  2. 사진과 타일은 각지게, 누르는 것은 4pt 또는 완전히 둥글게. 중간 크기 모서리는 쓰지 않는다. (관찰에서 정리)
  3. 선택된 상태는 검정으로 채워 보여 준다(칩, 날짜, 체크박스, 하단 탭 아이콘). (관찰에서 정리)
  4. 큰 사진과 짧은 제목이 화면 대부분을 차지하고, 장식은 거의 없다. (관찰에서 정리)
  5. 메뉴와 큰 분류는 영문 대문자, 기능 라벨은 한글 명사로 나눈다. (관찰에서 정리)
- 톤: 잡지처럼 담백하고 단정하게. 색보다 사진과 여백으로 말한다.
- 홈 캡처는 기획전(이구홈위크) 기간이라 상단 베이지 바탕(#ece5de)과 검정 탭 띠는 기획전 테마일 수 있다. 기획전이 아닌 카테고리·장바구니·검색 화면은 흰 바탕에 검정·회색만 쓴다.

### 특장점
- 강조색을 할인·시간 정보에만 묶는다 — 주황 #ff4800은 할인율·남은 시간·쿠폰 배너·켜진 토글·검색 강조 단어에만 나오고, 주요 버튼과 장바구니 구매 버튼은 검정 #000000이다.
- 모서리를 두 값으로만 나눈다 — 누르는 버튼·상자는 4px, 칩·검색창·토글·점은 999px, 사진·타일은 0px이고 8~16pt 모서리는 캡처 14장 어디에도 없다.
- 영문 대문자로 구역을 나눈다 — 하단 탭(HOME, CATEGORY, SEARCH, LIKE, MY)과 카테고리 타일 첫 줄(BEST, NEW, EXCLUSIVE)이 모두 영문 대문자라 편집숍 잡지 느낌을 낸다.
- 장바구니 금액을 식으로 풀어 보여 준다 — 금액 요약이 "쿠폰 적용가 + 배송비 = 합계" 꼴이고, 구매 버튼은 "취소선 원래 가격 + 할인가 + 동사" 한 줄이다.
- 테두리 대신 바탕 틈으로 나눈다 — 카테고리 타일(약 109×42pt)은 #e4e4e4 바탕 위에 5pt 틈을 두고 깔아 선을 긋지 않는다.

### 배울 점
- 할인을 강조할 때 29CM처럼 강조색을 할인율·남은 시간에만 쓰고 행동 버튼은 무채색으로 둔다. 할인 숫자가 더 눈에 띈다.
- 모서리 규칙을 정할 때 "사진은 0, 버튼은 4px, 칩은 999px"처럼 역할별로 두세 값만 둔다.
- 결제 금액을 보여 줄 때 "A + B = C" 식으로 계산 과정을 한 줄로 풀어 쓴다.

### 이 문서를 읽는 AI 에이전트에게
- 색은 YAML의 역할 이름(`text-primary`, `surface-muted`, `discount`)으로 쓴다. 관찰 팔레트 HEX를 새로 섞거나 비슷한 회색을 만들지 않는다.
- 주황 `accent`(#ff4800)는 할인율·남은 시간·쿠폰·켜진 토글·강조 단어에만 쓴다. 버튼 바탕이 필요하면 검정 `action-primary`다.
- 모서리는 0px·4px·999px 세 값 중에서만 고른다. 사진은 0, 누르는 상자는 4px, 칩·검색창은 999px.
- 선택 상태는 검정으로 채워 보여 준다.
- 이 문서는 캡처 13장에서 잰 값이다. `확인 필요` 자리(눌림·오류·빈 상태·바텀시트)는 지어내지 말고 비워 두거나 검정·회색 안에서 가장 단순한 모양을 고른다.

## 2. 색상
값은 1배율 캡처 픽셀에서 읽었다. 넓은 면 색은 정확하고, 작은 글자 색은 글자 테두리 번짐 때문에 ±몇 단계 오차가 있다. 토큰 이름은 SylviaLab이 붙인 것이다.

### 색 체계
공식 팔레트가 공개되지 않아, 캡처에서 반복된 색을 **관찰 팔레트**로 모으고 그 위에 **역할 이름**을 얹었다(YAML 참고).

| 층 | 예시 | 쓰는 곳 |
|---|---|---|
| 관찰 팔레트 | `black`, `accent`, `gray-100`, `gray-600` | 값 정의에만 |
| 역할 | `text-primary`, `surface-muted`, `action-primary`, `discount`, `selected` | 실제 화면과 컴포넌트 |

- 무채색이 거의 전부다. 회색은 바탕용(#f4f4f4·#e4e4e4)과 글자용(#494949·#777676·#b0b0b0)으로 나뉜다.
- 유채색 역할은 할인 계열(`discount`·`countdown`·`toggle-on` = 같은 #ff4800) 하나뿐이다.

### 역할별 색
- **검정 (`action-primary`·`selected` #000000)**: 주요 버튼, 장바구니 구매 버튼, 선택된 칩·날짜·체크박스, 선택된 하단 탭 아이콘. 눌림 색은 확인 필요.
- **주황 (`discount` #ff4800)**: 할인율, 남은 시간, 쿠폰 배너 바탕, 켜진 토글, 검색 화면 강조 단어. 연한 짝은 `accent-tint` #fff0eb(혜택 안내 띠 바탕) — 이때 글자도 주황.
- **회색 바탕 (`surface-muted` #f4f4f4)**: 선택 안 된 필터 칩, 검색창, 하단 탭 바, 쿠폰 상자, 원형 썸네일. 선택되면 검정으로 바뀐다.
- **선**: 선택 안 된 칩은 #acaaa9, 작은 외곽선 버튼은 #e8e8e8, 가게 이름 아래는 #eeeeee 1pt, 장바구니 전체선택 줄 아래만 검정 2pt.
- **선택 안 됨 → 선택**: 상단 칩은 회색 테두리·회색 글자 → 검정 테두리·진한 글자, 필터 칩은 #f4f4f4 바탕 → 검정 바탕 흰 글자.

### 색 사용 규칙
- 주황 #ff4800은 할인율, 남은 시간, 쿠폰 배너, 행동 유도 문구, 켜진 토글, 검색 화면 강조 단어에만 쓴다.
- 주요 버튼과 장바구니 구매 버튼은 검정 바탕 흰 글자다. 주황 버튼은 쓰지 않는다.
- 선택된 칩·날짜·체크박스는 검정으로 채우고, 선택 안 된 것은 #f4f4f4 바탕이나 #acaaa9 테두리로 둔다.
- 검색 화면 구획 제목에서는 바뀌는 단어만 주황으로 칠한다.
- 파랑 #4b6ffd는 장바구니 쿠폰 상자 할인 금액에만 보였다.
- 기획전 테마 색(#ece5de, #f2e6da, #fefaf4, #afcbff)은 기획전 화면에만 쓰고 기본 화면에는 쓰지 않는다.

### Don't
- 주황 #ff4800 바탕 버튼을 만들지 않는다. 주황 바탕은 쿠폰 배너 띠에만 나온다.
- 선택 상태를 주황이나 파랑으로 표시하지 않는다. 선택은 검정 채움이다.
- 파랑 #4b6ffd를 링크·버튼 일반색으로 넓히지 않는다. 쿠폰 상자 할인 금액에서만 보였다.
- 흰 바탕 본문에 #b0b0b0·#a8a8a8 같은 옅은 회색 글자를 쓰지 않는다. 안내 글자·비선택 아이콘 자리에만 있다.
- 기획전 베이지 #ece5de를 기본 화면 바탕으로 쓰지 않는다.

## 4. 레이아웃·간격
- 기준 화면: 375pt 폭 아이폰.
- 화면 좌우 여백: 20pt(홈, 장바구니). 카테고리 타일 묶음은 17~18pt, 430pt 기기 검색 화면은 22pt.
- 간격 단계(관찰, pt): 4, 5, 6, 8, 10, 12, 16, 20, 32, 40
- 그리드·최대 폭: 확인 필요
- 상품 그리드: 3열 + 오른쪽으로 다음 열이 살짝 보이는 가로 스크롤. 카드 폭 약 108pt, 사이 6pt. 이미지는 정사각형.
- 큰 상품 카드: 폭 240pt 가로 스크롤 한 장씩, 다음 카드가 오른쪽에 보인다.
- 원형 브랜드 아바타 줄: 지름 약 72pt, 선택은 검정 2pt 테두리 + 아래 작은 삼각형.
- 카테고리 타일 격자: 3열, 타일 약 109×42pt, 가로·세로 사이 5pt. #e4e4e4 회색 구획 위에 흰 타일을 깐다. 회색 구획 위아래 약 30pt.
- 카테고리 화면 상단: 상태 표시줄 44pt + 상단 바 약 58pt. 그 아래 큰 배너 높이 약 298pt.
- 장바구니 줄 구성: 전체선택 줄(높이 약 36pt) → 검정 2pt 선 → 가게 이름 줄(약 60pt) → 1pt #eeeeee 선 → 상품 줄. 금액 요약 줄 사이 약 38pt.
- 검색 화면: 원형 썸네일 지름 76pt, 사이 약 10pt, 가로 스크롤. 브랜드 순위는 2열 × 3줄, 한 줄 약 40pt, 구획 사이 약 50pt.
- 하단 탭 바: 5칸, 홈 인디케이터 포함 약 86pt.

### 간격 적용 규칙
- 구획 사이는 32~40pt 띄우고, 같은 구획 안 제목과 부제는 8pt.
- 가로 스크롤 목록은 다음 카드가 오른쪽에 살짝 보이게 둔다(작은 카드 사이 6pt, 큰 카드 240pt 폭).
- 카테고리 타일은 테두리 없이 회색 바탕 틈 5pt로 나눈다.

### Don't
- 화면 좌우 여백을 16pt 이하로 줄이지 않는다. 기본은 20pt다.
- 가로 스크롤 목록을 화면 폭에 딱 맞춰 끝내지 않는다. 다음 카드가 오른쪽에 살짝 보이게 둔다.
- 구획 사이를 32pt보다 좁게 붙이지 않는다.
- 타일 사이를 선으로 긋지 않는다. #e4e4e4 바탕 틈 5pt로 나눈다.

- 테두리·선
  - border: 1pt #acaaa9 — 선택 안 된 상단 칩
  - border-light: 1pt #e8e8e8 — 장바구니 "삭제" 버튼, 수량 조절 칸
  - border-strong: 1pt #000000 — 선택된 상단 칩
  - divider-strong: 2pt #000000 — 장바구니 전체선택 줄 아래
  - divider: 1pt #eeeeee — 장바구니 가게 이름 아래
### 고도
- 고도(그림자·층): 옅은 그림자는 오른쪽 아래 떠 있는 흰 원형 공유 버튼(지름 약 40pt)에만 있다. 나머지는 그림자 없이 평평하다.
- 층은 그림자 대신 바탕 색으로 나눈다: 흰 바탕 위 #f4f4f4 상자(쿠폰 상자, 검색창), #e4e4e4 바탕 위 흰 타일.
- 모서리 규칙: 사진과 타일은 각지게, 누르는 것은 4pt 또는 완전히 둥글게. 중간 크기 모서리(8~16pt)는 이번 캡처 14장 어디에도 없다.

### 모션
- 모션(길이·이징): 캡처로 알 수 없음. 확인 필요.
- 큰 배너는 점 대신 흰 2pt 진행 막대로 넘어가는 구간을 보여 준다(움직임 길이는 확인 필요).

### Don't
- 8~16px 모서리를 쓰지 않는다.
- 상품 사진·카테고리 타일·체크박스에 모서리를 주지 않는다.
- 카드·버튼·탭 바에 그림자를 넣지 않는다. 그림자는 떠 있는 원형 공유 버튼에만.
- 버튼(4px)과 칩(999px)의 모서리를 서로 바꿔 쓰지 않는다.

## 6. 컴포넌트
컴포넌트마다 변형, 상태, 쓰는 때, 쓰지 않는 때를 적는다. 보지 못한 상태는 `확인 필요`. Ruler 블로그에 나온 컴포넌트 이름(ProductCard, Dialog, Tabs, Badge, Button)은 11장에 적었다.

### 6.1 버튼
**크기**

| 종류 | 높이 | 폭 | 모서리 | 글자 |
|---|---|---|---|---|
| 구매(하단 고정) | 약 50pt | 335pt(화면 폭 − 40pt) | 4pt | 16pt 700 |
| 주요(검정) | 약 42pt | 240pt 또는 약 252pt | 4pt | 15pt 600 |
| 바로 구매하기 | 36pt | 약 88pt | 4pt | 13pt |
| 외곽선 | 약 36pt | 내용에 맞춤 | 확인 필요 | 확인 필요 |
| 작은 외곽선("삭제") | 약 27pt | 약 58pt | 확인 필요 | 13pt |
| 작은 검정 | 약 24pt | 내용에 맞춤 | 4pt | 11pt 500 |

**종류**

| 변형 | 모양 | 쓰는 때 |
|---|---|---|
| 주요(검정) | 검정 바탕, 흰 15pt 글자, 높이 약 42pt, 모서리 4pt. 카드 폭(240pt) 또는 가운데 고정 폭(약 252pt) | 카드 속 "상품 보기", 구획 대표 행동 |
| 구매(하단 고정) | 화면 폭(좌우 20pt 뺀 335pt) × 약 50pt, 검정, 모서리 4pt. "회색 취소선 원래 가격 + 흰 굵은 할인가 + 동사" 한 줄 | 장바구니 맨 아래 결제 |
| 바로 구매하기 | 검정 약 88×36pt, 흰 13pt 글자, 모서리 4pt | 장바구니 상품마다 가격 줄 오른쪽 |
| 작은 외곽선("삭제") | 약 58×27pt, 흰 바탕, 1pt #e8e8e8 테두리, 검정 13pt 글자 | 장바구니 상품 줄 보조 행동 |
| 작은 검정 | "상품 전체보기 >" 높이 약 24pt, 11pt 흰 글자 | 구획 제목 오른쪽 끝 |
| 외곽선 | 테두리 1pt 회색, 바탕은 구획 색 그대로, 높이 약 36pt("더 보러 가기 >") | 구획 아래 더 보기 |
| 텍스트 링크 | 회색 글자 + `>`("상품 전체보기 >"), 검정 굵은 글자 + `>`("쿠폰변경 >") | 가벼운 이동 |

- 상태: 기본만 봤다. 눌림 / 비활성 / 로딩은 확인 필요.
- 버튼 문구 끝에 `>`를 자주 붙인다.
- 쓰지 않는 때: 주황 바탕 버튼은 보이지 않았다. 주황은 쿠폰 배너 띠에만 바탕으로 쓴다.

**규칙** (관찰에서 정리)
- 결제 버튼은 화면 아래에 고정하고 "취소선 원래 가격 + 할인가 + 동사"를 한 줄에 쓴다.
- 한 상품 줄에 검정 버튼은 "바로 구매하기" 하나, 보조 행동은 흰 바탕 외곽선 버튼으로 둔다.
- 이동형 버튼 문구는 끝에 `>`를 붙인다.
- 터치: 구매 버튼(50pt)만 44pt를 넘는다. 작은 버튼(24~36pt)은 주변 여백까지 44pt 영역을 잡는다. (구현 권장)

### 6.2 입력창
- 검색창: 상단 바 안 회색(#f4f4f4) 알약, 높이 약 36pt. 왼쪽에 뒤로 화살표(←)가 따로 있고, 창 안 왼쪽에 회색 안내 글자 16pt, 오른쪽 끝에 검정 돋보기 선 아이콘(약 22pt). 안내 글자 자리에 기획 문구를 넣기도 한다.
- 상태: 글자 입력 중 상태·자동완성·오류는 확인 필요.
- 규칙: 검색창 안 돋보기는 오른쪽 끝, 뒤로 화살표는 창 밖 왼쪽. 아이콘 버튼에는 `aria-label`("검색", "뒤로")을 단다. (구현 권장)

### 6.3 칩·탭
| 변형 | 모양 | 쓰는 때 |
|---|---|---|
| 상단 카테고리 칩 | 높이 약 32pt 알약, 1pt 테두리. 선택은 검정 테두리 + 진한 글자, 나머지는 회색 테두리 + 회색 글자 | 서비스 구역(기획전·우먼·뷰티·홈·라이프…) 가로 스크롤 |
| 날짜·카테고리 필터 칩 | 높이 약 28pt 알약, 테두리 없음. 선택은 검정 바탕 흰 글자, 나머지는 gray-100 바탕 진회색 글자 | 목록 걸러 보기 |
| 외곽선 강조 칩 | 주황 1pt 테두리 + 주황 글자 + 아이콘 | "스케줄" 같은 강조 바로가기 |
| 기획전 탭 띠 | 검정 바탕 높이 약 50pt, 15pt 글자, 선택 탭은 흰 글자 + 2pt 흰 밑줄, 가로 스크롤 | 기획전 화면 안 탭 |
| 카테고리 타일 | 흰 바탕 약 109×42pt, 왼쪽 정렬 검정 글자(왼쪽 안 여백 약 9pt). 첫 줄은 영문 대문자 굵게, 다음 줄부터 한글 하위 분류 | 카테고리 화면 분류 격자 |

- 상태: 선택 / 미선택만 봤다. 눌림·비활성은 확인 필요.
- 기획전의 한 탭(라이브)은 화면 전체를 검정 바탕으로 뒤집어 쓴다.
- 규칙: 칩 줄은 가로 스크롤로 한 줄에 둔다. 선택된 칩·탭은 하나다. 선택 상태는 `aria-selected` 또는 `aria-pressed`로 알린다. (구현 권장)

### 6.4 선택 컨트롤
- 체크박스: 약 18pt 네모, 켜짐은 검정 채움 + 흰 체크. 모서리 없음.
- 토글: 약 38×21pt 알약, 켜짐은 #ff4800 바탕 + 오른쪽 흰 원 손잡이. 꺼짐 색은 확인 필요.
- 수량 조절: 약 86×28pt, 1pt 연회색 테두리로 나눈 3칸(− 숫자 +). − 는 회색, + 는 진회색. 최소 수량에서 비활성 모양은 확인 필요.

### 6.5 카드·리스트
- 상품 카드(작게): 정사각 이미지(오른쪽 위 흰 하트 외곽선), 브랜드 12pt 굵게, 상품명 13pt 한 줄 말줄임, 아래 줄에 주황 할인율 + 검정 가격(둘 다 15pt 굵게). 3열 가로 스크롤 목록에 쓴다.
- 상품 카드(크게): 회색 바탕 큰 이미지(240pt), 가운데 정렬 브랜드 16pt 굵게, 상품명 14pt 회색, 할인율 + 가격, 아래 검정 "상품 보기" 버튼과 남은 시간. 한정 판매 구획에 쓴다.
- 장바구니 상품 줄: 왼쪽 위 체크박스, 그 아래 상품명 16pt 굵게(2줄), 오른쪽 위 약 72×86pt 사진(모서리 0). 아래로 회색 취소선 원래 가격 + 할인율 + 가격(13pt), 옵션 줄, 수량 조절, 쿠폰 적용 가격(작은 회색 머리말 + 20pt 주황 할인율·검정 가격)과 오른쪽 "바로 구매하기".
- 장바구니 쿠폰 상자: #f4f4f4 바탕 약 335×68pt, 모서리 4pt. 왼쪽 회색 이름(상품 쿠폰·장바구니 쿠폰), 오른쪽 값. 할인 금액은 파랑(link-blue) + 다운로드 아이콘.
- 장바구니 금액 요약: 왼쪽 회색 이름 14pt, 오른쪽 검정 굵은 값 14pt. 계산식 줄은 "쿠폰 적용가 + 배송비 = 합계" 꼴, 끝에 원 안 i 아이콘.
- 장바구니 혜택 안내 띠: accent-tint 바탕 약 335×40pt, 모서리 4pt(거의 각짐). 왼쪽 주황 13pt 글자(앞부분 굵게), 오른쪽 주황 토글.
- 검색 순위 목록: 왼쪽 순위 숫자 + 브랜드 이름, 2열. 1~3위 숫자는 검정, 4~6위는 회색(#979797). 아래 점 5개로 다음 쪽(의류·홈·잡화 등)을 넘긴다.
- 원형 썸네일 줄(검색 화면 선물 추천): 지름 76pt #f4f4f4 원 안에 상품 사진, 아래 14pt 검정 이름. 오른쪽 위 줄에 "선물하기 >" 바로가기(갈색 원 아이콘 + 갈색 글자).
- 쿠폰 배너: 주황 바탕 가로 띠, 왼쪽 큰 흰 문구 + 남은 시간, 오른쪽 점선으로 나눈 다운로드 칸. 왼쪽 가장자리에 반원 홈을 파서 쿠폰 모양을 낸다.
- 이벤트 카드: 흰 상자 안에 색 카드(주황·파랑) + 아래 설명 문단.
- 키트 카드: 흰 카드 위 프로필 원 + 이름 + 주황 한 줄, 아래 큰 사진(위에 + 표시로 상품 위치), 맨 아래 검정 띠 버튼.
- 카운트다운 줄: 왼쪽 굵은 라벨, 오른쪽 주황 숫자 + 검정 단위.
- 카테고리 큰 배너: 화면 폭, 높이 약 298pt, 모서리 0. 왼쪽 약 155pt는 사진에 맞춘 단색 칸에 흰 큰 제목(2줄) + 흰 영문 대문자 머리말, 오른쪽은 사진. 아래쪽에 흰 2pt 진행 막대(현재 구간만 진하게).
- 상태: 하트 켜짐, 품절, 눌림은 확인 필요.
- 규칙 (관찰에서 정리): 상품 카드 정보 순서는 "이미지 → 브랜드(굵게) → 상품명 → 할인율 + 가격"으로 고정한다. 사진은 모서리 0, 하트는 이미지 오른쪽 위.

### 6.6 상단 바·하단 탭 바
- 홈 상단 바: 왼쪽 29CM 워드마크, 오른쪽 검색·알림·장바구니 선 아이콘(약 22pt).
- 하위 화면 상단 바(카테고리·장바구니·검색): 흰 바탕, 왼쪽 긴 뒤로 화살표(←, 약 21×16pt). 카테고리는 가운데 제목 + 아래 꺾쇠(다른 분류로 바꾸기), 오른쪽 돋보기·쇼핑백 선 아이콘. 장바구니는 화살표만 두고 제목이 없다.
- 하단 탭 바: gray-100 바탕, 선 아이콘 약 20pt + 10pt 영문 대문자 이름. 선택 탭(HOME)은 검정 채운 아이콘과 검정 이름. 카테고리·장바구니·검색 캡처에는 하단 탭 바가 보이지 않는다.

### 6.7 바텀시트·모달
- 캡처에 없음. Dialog(Ruler) 존재만 블로그로 확인. 모양·상태는 확인 필요.

### 6.8 토스트·배지
- 토스트·스낵바: 캡처에 없음. 확인 필요.
- 배지: Badge(Ruler)와 ProductCard의 extraBadge 존재만 블로그로 확인. 화면 속 모양은 확인 필요.

### 6.9 페이지 표시
- 가로 캐러셀 아래 점 6~7개(약 8pt), 선택 점만 검정.
- 검색 순위 점: 지름 약 5pt, 사이 약 8pt. 선택은 검정, 나머지 #e4e4e4.
- 큰 배너: 점 대신 아래쪽 흰 2pt 진행 막대.

### 6.10 아이콘·이미지
- 아이콘: 1.5pt 선 아이콘. 선택된 하단 탭만 채운 아이콘. 뒤로는 꺾쇠(<)가 아니라 긴 화살표(←)다.
- 사진: 화면 대부분. 상품 컷은 회색·흰 바탕 누끼, 기획전은 3D 오브제 그림(털 질감 글자, 작은 집 모형)을 크게 쓴다.
- 공유 버튼: 오른쪽 아래 흰 원형(그림자) 떠 있는 버튼.

## 7. 패턴
- 목록 → 상세: 홈과 카테고리에서 상품 카드 가로 스크롤(3열 작은 카드, 240pt 큰 카드)로 보여 준다. 상세 화면은 확인 필요.
- 카테고리 탐색: 큰 배너(진행 막대) → 회색 바탕 위 흰 타일 3열(첫 줄 BEST/NEW/EXCLUSIVE) → 구획별 상품 목록. 상단 바 제목 옆 꺾쇠로 다른 분류로 바꾼다.
- 검색: 검색 시작 화면에 회색 알약 검색창, 선물 추천 원형 썸네일 줄, 인기 브랜드 순위(2열 × 3줄, 점으로 분야 넘김)를 둔다. 검색 결과 화면은 확인 필요.
- 장바구니·결제: 혜택 안내 띠(토글) → 전체선택 줄 → 가게별 상품 줄(수량·쿠폰 적용가·바로 구매하기) → 쿠폰 상자 → 금액 요약("A + B = C") → 하단 고정 검정 구매 버튼(가격 + 동사). 주문서는 확인 필요.
- 한정 판매: 주황 남은 시간 + 쿠폰 배너 + 큰 상품 카드로 긴박감을 준다.
- 빈 상태·오류: 확인 필요.
- 바텀시트: 확인 필요.
- 로딩: 확인 필요.

### 장바구니 금액 표시 꼴
9장의 꼴("A + B = C", 가격 앞 + 동사 끝)을 따른 예시다. 실제 화면 문장이 아니다.

```
상품 금액 합계        00,000원
배송비                0원
쿠폰 적용가 + 배송비 = 00,000원
[ ~~00,000원~~ 00,000원 구매하기 ]
```
(예시 문구, SylviaLab 작성)

## 9. 글쓰기 톤
- 말투: 구획 제목은 명사형 짧은 문구, 부제는 해요체 한 줄. 장바구니 안내는 해요체 한 문장("~적용됐어요."). 큐레이션 카드는 마침표 없는 짧은 문구.
- 버튼 문구 꼴: "○○ 보기 >", "○○하고 ○○ 받기". 구매 버튼은 가격을 앞에 두고 동사로 끝낸다.
- 메뉴 이름은 영문 대문자 단어, 기능 라벨은 한글 명사(좋아요, 장바구니, 선택삭제).
- 검색 화면 구획 제목은 "지금 많이 찾는 + [강조 단어] + 브랜드" 꼴로 같은 틀에 단어만 바꾸고, 바뀌는 단어만 주황으로 칠한다.
- 숫자·단위 표기: 혜택은 숫자를 앞에 둔다("29% 앙코르입점회", "2,900,000 마일리지"). 계산은 "A + B = C" 식으로 풀어 보여 준다.
- "29"를 섞은 합성어로 기획 이름을 만든다(이구홈위크처럼 숫자 29를 소리로 쓴 이름).

## 10. Do & Don't
관찰 기반 문서의 규칙은 "이 서비스 화면에서 반복되는 규칙"을 SylviaLab이 정리한 것이다(공식 규칙 아님).

### Do
- 할인율은 #ff4800, 할인가는 #000000으로 같은 크기(15pt 700) 한 줄에 둔다.
- 주요 버튼은 검정 바탕 흰 글자, 모서리 4px로 만든다.
- 칩·검색창·토글·페이지 점은 999px 알약으로 만들고, 선택된 칩은 검정으로 채운다.
- 상품 이미지와 카테고리 타일은 모서리 0px로 둔다.
- 화면 좌우 여백은 20pt, 구획 사이는 32~40pt로 띄운다.
- 하단 탭 이름은 영문 대문자 10pt(HOME, CATEGORY, SEARCH, LIKE, MY)로 쓴다.
- 장바구니 금액은 "쿠폰 적용가 + 배송비 = 합계" 식으로 풀어 보여 준다.

### Don't
- #ff4800을 할인율·남은 시간·쿠폰·토글·강조 단어 밖의 넓은 면이나 주요 버튼 바탕에 쓰지 않는다.
- 8~16px 같은 중간 크기 모서리를 쓰지 않는다.
- 카드·버튼에 그림자를 넣지 않는다(그림자는 떠 있는 공유 버튼에만).
- 뒤로 가기를 꺾쇠(<)로 그리지 않는다. 긴 화살표(←)를 쓴다.
- 기획전 테마 색(#ece5de 등)을 기본 화면 바탕으로 쓰지 않는다.
- 카테고리 타일에 테두리를 긋지 않는다. #e4e4e4 바탕 틈 5pt로 나눈다.
- 선택 상태를 검정 채움 말고 다른 색으로 표시하지 않는다.
