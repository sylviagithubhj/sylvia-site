# 29CM 디자인 시스템

> 근거: 관찰 기반 (실측일 2026-10-31, WebFetch로 29cm.co.kr 홈 텍스트·메타 정보와 App Store 페이지 확인. 이 작업 환경은 브라우저·Playwright로 사이트를 열 수 없어 computed style은 재지 못함) + 회사 기술 블로그 1편(디자인 시스템 Ruler 소개)
> 작성: SylviaLab · 최종 수정 2026-10-31

## 1. 개요
- 서비스 성격: 무신사 계열 온라인 편집숍. 패션, 리빙, 컬처 상품을 큐레이션과 콘텐츠로 묶어 판다. 웹(29cm.co.kr)과 iOS·Android 앱.
- 디자인 인상 한 줄: 짧은 감성 문구가 붙은 큰 이미지 카드를 이어 놓은, 잡지에 가까운 쇼핑 화면. 색·크기 수치는 이번에 재지 못했다(아래 표 참고).
- 공식 시스템 이름: Ruler (사내 디자인 시스템. 공개 문서·공개 코드 없음)
- Ruler에 대해 회사 기술 블로그(2025-01-15, 프론트엔드 플랫폼팀)에서 확인한 사실
  - 고객용 화면 구현은 emotion(CSS-in-JS)에서 TailwindCSS + tailwind-variants로 옮겼다.
  - 관리자(백오피스) 화면은 Ant Design에 맞춤 테마(색·간격 토큰)를 씌운다.
  - Tailwind 테마 설정에 색 팔레트, 글자 크기 단계, 글꼴, 브레이크포인트, 모서리 값을 토큰으로 둔다. 실제 값은 글에 없다.
  - 컴포넌트 37개를 설계했고 약 30개가 서비스에 쓰인다. 글에 나온 이름: ProductCard, Dialog, Tabs, Badge, Button. 입력창과 내비게이션 바를 먼저 만들 핵심으로 꼽는다.
  - ProductCard에는 이미지 위 extraBadge, 하단 배지 묶음의 아이콘, 따로 누를 수 있는 브랜드명이 추가됐다.
  - Storybook과 Chromatic으로 컴포넌트를 검토한다.

## 6. 주요 컴포넌트
수치는 모두 확인 필요. 아래는 2026-10-31 홈 화면 텍스트 구조에서 확인한 구성이다.

### 버튼
- 이름이 확인된 컴포넌트: Button (Ruler). 크기·색·상태 값은 확인 필요.
- 홈에서 본 버튼 성격의 라벨: `앱으로 보기`, `더보기`, `로그인/회원가입`.

### 입력창
- 블로그에서 핵심 컴포넌트로 언급. 규격 확인 필요.

### 카드·리스트
- ProductCard(Ruler): 이미지, 이미지 위 추가 배지, 하단 배지 묶음(아이콘 포함), 별도로 누르는 브랜드명.
- 홈 큐레이션 카드: 이미지 + 짧은 한 줄 문구. 홈 한 화면에 이런 카드가 60개 넘게 이어진다.
- 브랜드 칩: 브랜드명을 영문 대문자 또는 한글로 나열(가로 목록).
- 큐레이션 묶음: 섹션 제목 한 줄 + 상품 타일 여러 개.

### 상단 바·탭 바
- 상단 띠 배너: 앱 설치 할인 안내 + `앱으로 보기`.
- 헤더 아이콘 메뉴: 마이페이지, 좋아요, 장바구니, 로그인/회원가입.
- 상단 서비스 메뉴: Special-Order, Showcase, PT, 29Magazine.
- 카테고리 탭(가로): BEST, WOMEN, MEN, INTERIOR, KITCHEN, ELECTRONICS, DIGITAL, BEAUTY, FOOD, LEISURE, KIDS, TICKET, CULTURE, EARTH, Event, Lookbook. 대부분 영문 대문자.
- 하단 탭 바(모바일 웹): 홈, 카테고리, 검색, 좋아요, 마이페이지 5개.
- Tabs(Ruler) 규격은 확인 필요.

근거와 한계
- 29CM은 공개 디자인 시스템 문서나 코드가 없다. 사내 시스템 Ruler의 구성은 회사 기술 블로그에서만 확인했다.
- 이 작업 환경은 셸에서 29cm.co.kr에 접속할 수 없고, WebFetch는 페이지를 글자로만 바꿔 가져와 CSS 링크와 스타일이 빠진다. 그래서 색, 글꼴, 크기, 간격, 모서리 수치를 하나도 확인하지 못했다. 목록·상세 페이지는 WebFetch가 거부돼 홈 한 화면만 봤다.
- 다음 단계: 브라우저(Playwright 등)로 홈, 목록, 상세 세 화면의 computed style을 재서 2~6절을 채운다.
- 관찰 값은 사이트가 바뀌면 달라질 수 있다.
- 서비스 이름과 브랜드는 각 권리자(무신사 계열 29CM)의 것이다. 이 문서는 식별·학습용 참고 자료로 SylviaLab이 독자적으로 작성했다.
