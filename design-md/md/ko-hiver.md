# 하이버 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 여름 시즌 구획이 보이는 시기(연도 확인 필요), iOS 앱 홈 화면 1장, 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

이 문서는 디자인 시스템의 다섯 층(원칙, 토큰, 컴포넌트, 사용 규칙, 구현·검증)을 한 파일로 줄인 요약이다. 맨 위 YAML은 도구와 AI가 그대로 읽는 값이고, 아래 글은 그 값을 언제·왜 쓰는지 설명한다.

## 1. 개요와 원칙
- 서비스 성격: 남성 패션 쇼핑 앱. 코디, 랭킹, 쿠폰, 쇼핑몰별 상품을 모아 판다.
- 디자인 인상 한 줄: 어두운 회검정(#1a1a1a) 머리 영역 아래에 흰 본문을 둔다. 강조는 탭마다 다른 색 글자와, 하단 탭 바의 황토색(#c9974d) 선택 표시로 한다.
- 공식 시스템 이름: 공개된 이름 없음 (공개 디자인 문서·오픈소스를 확인하지 못했다. 확인 필요)
- 디자인 원칙(공식 원칙은 찾지 못했다. 화면 1장에서 읽은 것이라 참고용이다):
  1. 머리와 본문을 색으로 나눈다. 로고·검색창·가로 탭은 #1a1a1a 띠 안에, 본문은 흰 바탕이다. (관찰에서 정리)
  2. 선택은 한 가지 방법으로 분명히 보인다. 상단은 흰 굵은 글자 + 4pt 흰 밑줄, 하단은 채운 아이콘 + 황토색. (관찰에서 정리)
  3. 특별한 탭만 따로 칠한다. 쿠폰 탭은 하늘색 글자, 랭킹 옆에는 분홍빨강 NEW 배지. (관찰에서 정리)
  4. 그림자 없이 흰 바탕과 회색(#ededed) 타일로 면을 나눈다. (관찰에서 정리)
- 톤: 어둡고 단단한 머리, 밝은 본문, 강조는 작게.

### 특장점
- 머리 영역 전체를 한 어두운 띠로 묶는다 — 상태 표시줄·로고·검색창·가로 탭이 높이 약 186pt의 #1a1a1a 띠 하나 안에 있다. 같은 모음의 지그재그도 #1a1a1a 상단 바를 쓰지만 결제 흐름의 50pt 바이고, 하이버는 홈 머리 전체를 감싼다.
- 하단 탭 선택색이 황토색이다 — 선택된 홈 탭만 채운 아이콘 + #c9974d 이름으로 바뀌고, 나머지는 #a0a4a8 선 아이콘이다.
- 탭마다 강조 방법을 다르게 둔다 — 쿠폰 탭은 #00c8ff 글자, 랭킹 옆은 #ff5166 NEW 배지로 일반 탭(#818488)과 구별한다.
- 선택 밑줄이 글자보다 넓다 — 가로 탭 선택 밑줄은 높이 4pt, 폭 약 30pt로 글자보다 넓게 깐다.
- 바로가기를 회색 타일로 정리한다 — 약 50pt #ededed 타일(모서리 12pt) + 12pt 이름을 2줄 가로 스크롤로 둔다.

### 배울 점
- 홈 위쪽에 로고·검색·탭이 몰려 있을 때 하이버처럼 하나의 어두운 띠로 묶어 본문과 확실히 나눈다.
- 이벤트·쿠폰 같은 특별 탭을 알려야 할 때 탭 전체를 바꾸지 않고 그 탭 글자색만 바꾸거나 작은 NEW 배지를 붙인다.
- 그림 아이콘이 제각각인 바로가기를 늘어놓을 때 같은 크기 회색 둥근 타일 안에 넣어 줄을 맞춘다.

### 이 문서를 읽는 AI 에이전트에게
- 이 문서는 홈 화면 1장에서 잰 값이다. 표에 없는 화면(상세·결제·목록)과 상태는 지어내지 말고 `확인 필요`로 둔다.
- 색·크기는 YAML 토큰 이름으로만 쓴다. 관찰 팔레트(`gray-500`)보다 역할 이름(`on-header-muted`)을 먼저 쓴다.
- 어두운 `header` 띠는 홈 머리(로고·검색창·가로 탭)에만 쓴다. 본문은 `surface` 흰 바탕이다.
- 황토색 `accent`는 하단 탭 선택 표시에만, `tab-highlight`·`new-badge`는 특별 탭 강조에만 쓴다.
- 판단이 어려우면 그림자 없이 흰 면과 회색 타일로 나누는 쪽을 고른다.

## 2. 색상
값은 1배율 캡처 픽셀에서 읽었다. 넓은 면 색은 정확하고, 작은 글자 색은 글자 테두리 번짐 때문에 오차가 있다. 토큰 이름은 SylviaLab이 붙인 것이다. 화면이 1장뿐이라 모든 값은 반복 확인이 안 됐다.

### 색 체계
공식 팔레트는 공개되지 않았다. 화면 1장에서 읽은 값을 **관찰 팔레트**로 모으고 **역할 이름**을 붙였다(관찰에서 정리).

| 층 | 예시 이름 | 쓰는 곳 |
|---|---|---|
| 관찰 팔레트 | `ink-900`, `gold-500`, `gray-50`~`gray-850` | YAML 정의에만 |
| 역할 이름 | `header`, `on-header-muted`, `accent`, `tile-bg` | 화면과 컴포넌트 |
| 특별 강조 | `tab-highlight`, `new-badge` | 특별 탭에서만 |

### 역할별 색
- 머리 띠 `header`(#1a1a1a): 상태 표시줄·로고·검색창·가로 탭 바탕. 위 글자는 선택 `on-header`(흰색), 나머지 `on-header-muted`(#818488).
- 황토 `accent`(#c9974d): 하단 탭 선택 아이콘·이름. 눌림·비활성 짝은 확인 필요.
- 면: 본문 `surface`, 검색창 `search-bg`, 바로가기 타일 `tile-bg`.
- 글자: 구획 제목 `text-primary`, 바로가기 이름 `text-body`, 검색 안내 `text-placeholder`, 광고 표시 `text-sponsored`.
- 특별 강조: 쿠폰 탭 글자 `tab-highlight`, NEW 배지 면 `new-badge`(흰 글자).
- 가격·할인·성공·주의·오류 색: 캡처에 없음(확인 필요).

### 색 사용 규칙
- #1a1a1a는 상단 머리 영역(상태 표시줄·로고·검색창·가로 탭) 바탕에만 쓰고, 본문은 흰색이다.
- 황토색 #c9974d는 하단 탭 바 선택 표시에만 보였다.
- 어두운 띠 위 선택 탭은 #ffffff, 선택 안 된 탭은 #818488.
- #00c8ff(쿠폰 탭 글자)와 #ff5166(NEW 배지)은 특별 탭 강조에만 쓴다.
- 배너·바로가기 그림 속 색(#07c47a 등)은 시스템 색으로 쓰지 않는다.

### 화면 모드
- 밝은 본문 + 어두운 머리 한 벌만 봤다. 다크 모드·고대비 모드는 확인 필요.

### Don't
- #1a1a1a 띠를 본문 구획 바탕으로 쓰지 않는다.
- 황토색 #c9974d를 버튼·가격·제목에 쓰지 않는다(본 화면 기준).
- 일반 탭 글자에 #00c8ff를 쓰지 않는다.
- 배너·바로가기 그림 속 색(#07c47a 등)을 시스템 색으로 가져오지 않는다.

## 3. 타이포그래피
- 글꼴: iOS 시스템 글꼴(추정. 한글은 Apple SD Gothic Neo와 같은 모양). 로고는 별도 워드마크다. 전용 글꼴은 확인 필요.
- 대체 글꼴: -apple-system, 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif
- 크기는 1배율 캡처의 글자 높이로 계산한 추정값이다(±1pt). 행간은 확인 필요.

### 위계와 사용처
앱 화면 한 벌이다(PC 웹은 확인 필요).

| 단계 | 크기(pt) | 굵기 | 행간 | 쓰임 |
|---|---|---|---|---|
| section-title | 18 | 700 | 확인 필요 | 구획 제목(추천 아이템 줄) |
| tab | 15 | 700 | 확인 필요 | 상단 가로 탭(선택 탭 굵게, 나머지는 굵기 확인 필요) |

### 규칙
- 구획 제목 18pt 700, 상단 가로 탭 15pt(선택 700), 검색창 안내 14pt 400.
- 바로가기 이름은 12pt 500, 광고 표시는 12pt 400 연회색.
- 10pt는 하단 탭 바 이름에만 쓴다.

### Don't
- 구획 제목을 18pt 700 밖의 크기로 바꾸지 않는다(본 화면 기준).
- 10pt를 하단 탭 이름 밖에 쓰지 않는다.
- 광고 표시(12pt #d0d3d7)를 제목만큼 진하게 쓰지 않는다.

| 구획 제목 → 내용 | 확인 필요 |

- 머리 띠 구성: 상태 표시줄 + 로고 줄 + 검색창 + 가로 탭. 가로 탭은 가로 스크롤.
- 바로가기는 한 줄 5개 남짓, 하단 탭 바는 탭 5개.

### 간격 적용 규칙
- 로고·검색창·구획 제목·첫 상품 이미지를 좌우 15pt 선에 맞춘다.
- 상품 가로 줄은 이미지 사이 약 9pt, 세 번째 카드가 오른쪽에 걸치게 둔다.
- 바로가기는 2줄, 타일 중심 사이 약 66pt로 가로 스크롤한다.

### Don't
- 좌우 여백을 15pt 선에서 벗어나게 두지 않는다. 로고·검색창·제목·첫 이미지가 같은 선이다.
- 상품 가로 줄에서 마지막 카드를 화면 안에 다 넣지 않는다. 세 번째 카드가 오른쪽에 걸친다.
- 바로가기 타일 크기를 아이콘마다 다르게 하지 않는다.

## 5. 모서리·고도·모션
1pt = CSS 1px로 본다. 1배율이라 ±2px 오차가 있다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| radius-sm | 6px | 검색창 |
| radius-md | 8px | 상품 이미지 |
| radius-lg | 12px | 바로가기 아이콘 타일 |
| radius-full | 999px | 배너 쪽수 표시 알약 |


### 고도
- 그림자는 보이지 않는다(shadow 확인 필요). 하단 탭 바 위 경계는 아주 옅은 회색 선(#f6f7f9 근처)으로 보인다. 확인 필요.
- 층은 색으로 나눈다: 어두운 머리 띠 → 흰 본문 → #ededed 타일.

### 모션
- 길이·이징: 캡처로 알 수 없음. 확인 필요.

### 아이콘·사진
- 아이콘: 하단 탭 바는 가는 선 아이콘, 선택하면 채운 아이콘. 상단은 흰 선 아이콘. 바로가기 아이콘은 사진·그림을 타일 안에 넣는다(구획마다 다름).
- 사진: 상품 사진을 8pt 모서리로 잘라 쓴다.

### Don't
- 카드·타일에 그림자를 넣지 않는다.
- 검색창을 알약(999px)으로 만들지 않는다. 6px다.
- 상품 사진을 각지게 쓰지 않는다. 8px다.


## 6. 컴포넌트
컴포넌트마다 크기·종류, 상태, 규칙을 적는다. 홈 1장만 봤으므로 보지 못한 컴포넌트와 상태는 `확인 필요`.

### 6.1 버튼
| 변형 | 모양 | 쓰는 때 |
|---|---|---|
| 하트(찜) 버튼 | 흰 선 하트 | 상품 이미지 오른쪽 아래 |
| 일반 주요 버튼 | 확인 필요 | 캡처에 없음 |

- 상태: 확인 필요(찜 켜짐 모양도 보지 못했다).
- 규칙: 하트 버튼은 아이콘만 있으므로 `aria-label`과 `aria-pressed`를 단다(구현 권장).

### 6.2 입력창
- 검색창: 어두운 상단 안의 #f2f3f5 둥근 사각(모서리 약 6pt, 폭 약 345pt, 높이 약 36pt), 왼쪽 회색 돋보기 + 회색 안내 글자.
- 상태: 기본만 봤다. 포커스·입력 중은 확인 필요.
- 규칙: 검색창은 어두운 머리 띠 안, 좌우 15pt 선에 맞춘다.

### 6.3 가로 탭
| 부분 | 값 |
|---|---|
| 줄 높이 | 약 54pt |
| 글자 | 15pt, 선택 700 흰색 / 나머지 #818488 |
| 선택 밑줄 | 높이 4pt, 폭 약 30pt, 흰색 |
| 특별 탭 | #00c8ff 글자 또는 #ff5166 NEW 배지 |

- 상단 가로 탭: 어두운 바탕 위 15pt 글자, 줄 높이 약 54pt. 선택 탭은 흰 굵은 글자 + 아래 4pt 흰 밑줄(약 30pt 폭). 나머지는 회색(#818488).
- 특별 탭: 글자 색을 따로 칠하거나(쿠폰 탭 #00c8ff) 분홍빨강 NEW 배지(#ff5166)를 붙인다.
- 상태: 선택 / 선택 안 됨만 봤다.
- 규칙: 일반 탭에는 특별 색을 쓰지 않는다. 선택된 탭에 `aria-selected="true"`(구현 권장).

### 6.4 카드·리스트
- 바로가기: 회색 둥근 타일(약 50pt, #ededed, 모서리 12pt) 안에 그림 아이콘 → 아래 12pt 이름. 2줄 가로 스크롤.
- 상품 카드(작게): 8pt 모서리 이미지(폭 약 110pt) + 오른쪽 아래 하트 → 아래 글(캡처 하단에 잘려 확인 필요).
- 구획 머리: 왼쪽 굵은 제목, 오른쪽 회색 작은 "Sponsored" + 정보 아이콘.
- 배너: 화면 폭 꽉 찬 띠, 오른쪽 아래 어두운 알약 쪽수 표시(1/16 꼴).
- 상태: 확인 필요.

### 6.5 상단 바·하단 탭 바
- 상단 바: 어두운 바탕, 왼쪽 흰 로고 워드마크, 오른쪽 흰 장바구니 아이콘.
- 하단 탭 바: 흰 바탕, 아이콘 + 이름 5개(홈·검색·카테고리·찜·마이), 홈 인디케이터 포함 약 80pt. 선택 탭은 채운 아이콘 + 황토색, 나머지는 #a0a4a8 선 아이콘.

### 6.6 바텀시트·모달
- 캡처에 없음. 확인 필요.

### 6.7 배지·토스트
- NEW 배지: #ff5166 바탕 + 흰 글자, 가로 탭 옆.
- 배너 쪽수 알약: 어두운 999px 알약, 배너 오른쪽 아래.
- 토스트·스낵바: 캡처에 없음. 확인 필요.

## 9. 글쓰기 톤

- 버튼 문구 꼴: 확인 필요(캡처에 글자 버튼이 없다).
- 숫자·단위 표기: 확인 필요(가격이 캡처에 없다).
- 가로 탭 이름: 2~3글자 명사(홈, 코디, 랭킹, 이벤트).
- 바로가기 이름: 짧은 명사 또는 명사구(○○쿠폰, ○○코디, 셔츠).

## 10. Do & Don't
관찰 기반 문서의 규칙은 "이 서비스 화면에서 반복되는 규칙"을 SylviaLab이 정리한 것이다(공식 규칙 아님).

### Do
- 로고·검색창·가로 탭은 #1a1a1a 띠 안에 두고, 본문은 흰 바탕으로 둔다.
- 검색창은 #f2f3f5 바탕, 모서리 6px, 높이 약 36pt로 만든다.
- 선택된 가로 탭은 흰 15pt 700 글자 + 4pt 흰 밑줄로 표시한다.
- 하단 탭 선택은 채운 아이콘 + #c9974d로 칠한다.
- 바로가기는 약 50pt #ededed 타일(모서리 12px) + 12pt 이름으로 만든다.
- 상품 이미지는 8px 모서리, 폭 약 110pt, 사이 약 9pt로 둔다.

### Don't
- 황토색 #c9974d를 하단 탭 선택 밖에 쓰지 않는다(본 화면 기준).
- 카드·타일에 그림자를 넣지 않는다.
- 일반 탭에 #00c8ff나 #ff5166을 쓰지 않는다. 특별 탭에만 쓴다.
- 배너 소재 색(#07c47a)을 시스템 색으로 쓰지 않는다.
- 어두운 띠를 본문 구획까지 넓히지 않는다.
