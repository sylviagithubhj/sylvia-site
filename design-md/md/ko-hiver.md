## 1. 개요
- 서비스 성격: 남성 패션 쇼핑 앱. 코디, 랭킹, 쿠폰, 쇼핑몰별 상품을 모아 판다.
- 디자인 인상 한 줄: 어두운 회검정(#1a1a1a) 머리 영역 아래에 흰 본문을 둔다. 강조는 탭마다 다른 색 글자와, 하단 탭 바의 황토색(#c9974d) 선택 표시로 한다.
- 공식 시스템 이름: 확인 필요
- 특징
  - 상단(로고, 검색창, 가로 탭)이 모두 어두운 띠 안에 있다. 본문은 흰 바탕이다.
  - 가로 탭은 선택 탭만 흰 굵은 글자 + 흰 밑줄, 나머지는 회색이다. 특정 탭은 글자 색을 따로 칠한다(쿠폰 탭은 하늘색, 랭킹 옆에는 분홍빨강 NEW 배지).
  - 하단 탭 바 선택 색은 황토색이다. 홈 아이콘을 채운 모양으로 바꾸고 이름도 같은 색으로 칠한다.
  - 바로가기 아이콘은 회색(#ededed) 둥근 사각 타일 안에 둔다.
  - 그림자 없이 흰 바탕과 회색 타일로 면을 나눈다.
- 공개 자료 상황: 공개 디자인 문서·오픈소스를 확인하지 못했다. 확인 필요.

## 4. 간격·레이아웃
- 기준 화면: 375pt 폭 아이폰(홈 인디케이터가 있는 기종).
- 화면 좌우 여백: 약 15pt. 로고, 검색창, 구획 제목, 첫 상품 이미지가 이 선에 맞는다.
- 간격 단계(관찰, pt): 4, 8, 9, 15, 16
- 어두운 상단 높이: 약 186pt(상태 표시줄 + 로고 줄 + 검색창 + 가로 탭).
- 검색창: 폭 약 345pt, 높이 약 36pt.
- 가로 탭 줄: 높이 약 54pt, 가로 스크롤. 선택 밑줄은 높이 4pt, 글자보다 넓게(약 30pt) 깐다.
- 바로가기: 한 줄 5개 남짓 가로 스크롤, 타일 폭 약 50pt, 타일 간격(중심 사이) 약 66pt, 2줄.
- 상품 가로 줄: 이미지 폭 약 110pt, 사이 약 9pt, 세 번째 카드가 오른쪽에 걸친다.
- 하단 탭 바: 홈 인디케이터 포함 약 80pt, 탭 5개.
- 그리드: 확인 필요

## 5. 모서리·그림자·테두리
1pt = CSS 1px로 본다. 1배율이라 ±2px 오차가 있다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| radius-sm | 6px | 검색창 |
| radius-md | 8px | 상품 이미지 |
| radius-lg | 12px | 바로가기 아이콘 타일 |
| radius-full | 999px | 배너 쪽수 표시 알약 |
| shadow | 확인 필요 | 그림자는 보이지 않는다 |

- 하단 탭 바 위 경계는 아주 옅은 회색 선(#f6f7f9 근처)으로 보인다. 확인 필요.

## 6. 주요 컴포넌트
### 버튼
- 하트(찜) 버튼: 상품 이미지 오른쪽 아래, 흰 선 하트.
- 일반 주요 버튼: 캡처에 없음. 확인 필요.

### 탭
- 상단 가로 탭: 어두운 바탕 위 15pt 글자. 선택 탭은 흰 굵은 글자 + 아래 4pt 흰 밑줄. 나머지는 회색. 특별 탭은 글자 색을 따로 칠하거나 분홍빨강 NEW 배지를 붙인다.

### 입력창
- 검색창: 어두운 상단 안의 #f2f3f5 둥근 사각(모서리 약 6pt), 왼쪽 회색 돋보기 + 회색 안내 글자.

### 카드·리스트
- 바로가기: 회색 둥근 타일(약 50pt) 안에 그림 아이콘 → 아래 12pt 이름. 2줄 가로 스크롤.
- 상품 카드(작게): 8pt 모서리 이미지 + 오른쪽 아래 하트 → 아래 글(캡처 하단에 잘려 확인 필요).
- 구획 머리: 왼쪽 굵은 제목, 오른쪽 회색 작은 "Sponsored" + 정보 아이콘.
- 배너: 화면 폭 꽉 찬 띠, 오른쪽 아래 어두운 알약 쪽수 표시(1/16 꼴).

### 상단 바·탭 바
- 상단 바: 어두운 바탕, 왼쪽 흰 로고 워드마크, 오른쪽 흰 장바구니 아이콘.
- 하단 탭 바: 흰 바탕, 아이콘 + 이름 5개(홈·검색·카테고리·찜·마이). 선택 탭은 채운 아이콘 + 황토색.

### 바텀시트·모달
- 캡처에 없음. 확인 필요.

### 토스트·스낵바
- 캡처에 없음. 확인 필요.

## 7. 아이콘·이미지·모션

- 바로가기 아이콘: 사진·그림을 타일 안에 넣는다(구획마다 다름).
- 사진: 상품 사진을 8pt 모서리로 잘라 쓴다.
- 모션: 캡처로 알 수 없음. 확인 필요.

## 8. 글쓰기 톤(UX 라이팅)
- 가로 탭 이름: 2~3글자 명사(홈, 코디, 랭킹, 이벤트).
- 바로가기 이름: 짧은 명사 또는 명사구(○○쿠폰, ○○코디, 셔츠).
- 구획 제목: 짧은 문장형 제목 한 줄.
- 검색창 안내: 혜택을 알리는 짧은 문장.

근거와 한계
