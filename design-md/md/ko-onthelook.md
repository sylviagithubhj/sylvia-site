# 온더룩 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 시기 확인 필요, iOS 앱 홈(추천 탭) 화면 1장, 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

## 1. 개요
- 서비스 성격: 패션 코디 사진 앱. 사람들의 착용 사진(스타일)을 보고, 사진 속 아이템을 확인·검색·저장한다.
- 디자인 인상 한 줄: 흰 바탕에 검정 글자, 밝은 파랑(#2496ff) 하나를 칩·안내 문구 강조에 쓴다. 색은 대부분 코디 사진이 채운다.
- 공식 시스템 이름: 확인 필요
- 특징
  - 강조색은 파랑 하나다. 스타일 칩 글자, 필터 아이콘, 구획 부제에 쓴다.
  - 칩은 옅은 하늘색 바탕(#edf7ff) + 파란 글자. 고르지 않은 칩은 흰 바탕 + 회색 테두리 + 회색 글자로 보인다.
  - 선택 탭은 검정 굵은 글자 + 2pt 검정 밑줄, 나머지 탭은 연회색(#bfbfbf) 글자다.
  - 구획은 8pt 회색 띠(#f4f4f4)로 나눈다.
  - 왼쪽 위 로고는 소문자 영문 워드마크다.
- 공개 자료 상황: 이번 작업에서는 공개 문서·오픈소스를 확인하지 못했다. 확인 필요.

## 4. 간격·레이아웃
- 기준 화면: 375pt 폭 아이폰.
- 화면 좌우 여백: 약 23pt(로고, 탭, 구획 제목, 첫 사진이 같은 선). 칩·카테고리 줄은 약 15~20pt에서 시작한다.
- 간격 단계(관찰, pt): 2, 4, 8, 12, 17, 23
- 상단 탭: 탭 글자 사이 약 17pt, 선택 탭 아래 2pt 밑줄(글자 폭과 같음).
- 착용 사진 카드: 폭 약 177pt, 높이 약 213pt, 카드 사이 약 12pt, 가로 스크롤. 아래에 아이템 작은 사진(약 54pt 정사각) 줄.
- 카테고리 타일: 약 58pt, 가로 스크롤, 아래 이름.
- 칩 줄: 높이 약 32pt, 칩 사이 약 4pt, 가로 스크롤.
- 구획 사이: 8pt #f4f4f4 띠.
- 사진 그리드: 2열(아래 피드, 일부만 보임). 간격 확인 필요.
- 하단 탭 바: 홈 인디케이터 포함 약 83pt, 윗선 1pt.

## 6. 주요 컴포넌트
### 버튼
- 구획 닫기: 구획 제목 오른쪽 끝 연회색 X.
- 일반 주요 버튼: 캡처에 없음. 확인 필요.

### 탭
- 상단 탭(추천·스타일랭킹·팔로잉 꼴): 16pt 굵은 글자. 선택 탭 #1f1f1f + 2pt 밑줄, 나머지 #bfbfbf. 탭 줄 아래 구분선은 없다.

### 칩
- 필터 칩: #edf7ff 바탕에 파란 조절 아이콘 + 고른 개수.
- 성별 칩: 흰 바탕 + #f0f0f0 근처 테두리 + 회색 글자(고르지 않음), 하늘색 바탕 + 파란 글자(고름)로 보인다.
- 스타일 칩: #edf7ff 바탕 + #2496ff 글자, 높이 약 32pt, 모서리 약 8pt.

### 입력창
- 캡처에 없음. 확인 필요.

### 카드·리스트
- 착용 사진 카드: 세로 사진(모서리 8pt), 오른쪽 위 여러 장 표시 아이콘. 아래에 그 코디의 아이템 작은 사진 줄, 일부 사진 왼쪽 위에 "비슷한" 검정 꼬리표.
- 카테고리 타일: #f4f4f4 둥근 사각 타일 안에 상품 누끼 사진 + 아래 이름.
- 사진 피드: 2열 사진, 오른쪽 위 여러 장 표시 아이콘.

### 상단 바·탭 바
- 상단 바: 왼쪽 소문자 로고, 오른쪽 알림 아이콘.
- 하단 탭 바: 흰 바탕, 아이콘 + 한글 이름 4개(홈·검색·북마크·MY). 아이콘은 검정 선 아이콘이고, 선택 홈 아이콘은 채운 모양.

### 바텀시트·모달
- 캡처에 없음. 확인 필요.

### 토스트·스낵바
- 캡처에 없음. 확인 필요.

## 7. 아이콘·이미지·모션
- 아이콘: 검정 선 아이콘, 선택 상태는 채운 아이콘.
- 이미지: 사람이 찍은 착용 사진이 주인공이다. 아이템은 배경을 지운 누끼 사진이나 작은 정사각 사진.
- 모션: 캡처로 알 수 없음. 확인 필요.

## 10. 참고 자료
- 온더룩 iOS 앱 화면 캡처 1장: 홈(추천 탭) 화면 (SylviaLab 벤치마킹 피그마 파일, 저장소에는 올리지 않음)
- 공개 URL: 이번 작업에서 확인한 URL이 없다. 확인 필요.

근거와 한계
- 화면 값은 모두 앱 캡처에서 잰 관찰값이다. 캡처 시기는 화면만으로 알 수 없어 확인 필요다.
- 홈 화면 1장뿐이라 최소 3개 화면 기준에 크게 못 미친다. 한 화면 안에서 여러 번 보인 값(파랑 #2496ff, 칩 바탕 #edf7ff, 회색 #f4f4f4)만 조금 믿을 만하고 나머지는 참고용이다.
- 캡처가 375pt 1배율이라 크기는 ±1pt, 작은 글자 색은 오차가 있다.
- 검색, 스타일 상세, 아이템 상세(가격·구매 연결), 북마크, 다크 모드는 확인하지 못했다.
- 착용 사진·아이템 사진 속 색은 시스템 색에서 뺐다.
- 관찰 값은 서비스가 바뀌면 달라질 수 있다.
- 서비스 이름과 브랜드는 각 권리자의 것이다. 이 문서는 식별·학습용 참고 자료로 SylviaLab이 독자적으로 작성했다.
