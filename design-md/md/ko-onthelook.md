## 1. 개요와 원칙
- 서비스 성격: 패션 코디 사진 앱. 사람들의 착용 사진(스타일)을 보고, 사진 속 아이템을 확인·검색·저장한다.
- 디자인 인상 한 줄: 흰 바탕에 검정 글자, 밝은 파랑(#2496ff) 하나를 칩·안내 문구 강조에 쓴다. 색은 대부분 코디 사진이 채운다.
- 공식 시스템 이름: 확인 필요
- 디자인 원칙(공식 원칙은 확인하지 못했다. 화면 1장에서 읽은 것이라 참고용이다):
  1. 강조색은 파랑 하나로, 칩 글자·필터 아이콘·구획 부제에만 쓴다. (관찰에서 정리)
  2. 색은 코디 사진이 맡고 UI는 흰색·검정·회색으로 단순하게 둔다. (관찰에서 정리)
  3. 구획은 그림자 없이 8pt 회색 띠로 나눈다. (관찰에서 정리)
  4. 착용 사진과 그 안의 아이템을 한 카드 묶음으로 보여 준다. (관찰에서 정리)
- 톤: 사진이 주인공이고, 문구는 권유형으로 부드럽다.
- 공개 자료 상황: 이번 작업에서는 공개 문서·오픈소스를 확인하지 못했다. 확인 필요.

### 특장점
- 착용 사진에 아이템 줄을 붙인다 — 약 177×213pt 착용 사진 카드 아래에 그 코디의 아이템 작은 사진(약 54pt 정사각) 줄을 두고, 일부에는 "비슷한" 검정 꼬리표를 단다. 코디를 보다 바로 상품으로 넘어간다.
- 칩을 하늘색 면 + 파란 글자로 만든다 — 스타일 칩은 #edf7ff 바탕 + #2496ff 글자, 높이 약 32pt, 모서리 약 8pt의 둥근 사각형이다. 알약 모양이 아니다.
- 칩의 고름·안 고름을 면 유무로 나눈다 — 고른 칩은 하늘색 바탕 + 파란 글자, 고르지 않은 칩은 흰 바탕 + #f0f0f0 근처 테두리 + #9b9b9b 근처 글자다.
- 구획 부제로 추천 이유를 말한다 — 16pt 굵은 권유형 제목 아래 14pt 파란 해요체 부제가 추천 이유를 짧게 설명한다.
- 구획을 회색 띠와 닫기로 관리한다 — 구획 사이 8pt #f4f4f4 띠, 구획 제목 오른쪽 끝 연회색 X로 구획을 닫을 수 있다.
- 착용 사진 위에 아이템 말풍선을 띄운다 — 게시물 상세 사진 위, 아이템 자리마다 흰 반투명 말풍선(브랜드 굵게 + 가격 회색 + 착용 사이즈 파랑)을 꼬리로 가리킨다. 사진 아래에는 "착용제품" 목록이 같은 정보를 다시 보여 준다. (관찰에서 정리, 소개 이미지 추정)

### 배울 점
- 사진 속 상품을 연결할 때 온더룩처럼 큰 사진 카드 바로 아래 작은 정사각 아이템 사진 줄을 붙인다.
- 필터·태그 칩을 둘 때 온더룩처럼 고른 칩은 옅은 브랜드색 면(#edf7ff) + 브랜드색 글자, 고르지 않은 칩은 흰 바탕 + 옅은 테두리로 나눈다.
- 추천 구획을 둘 때 온더룩처럼 제목 아래 강조색 부제로 추천 이유를 한 줄 적는다.
- 사진 속 상품을 알릴 때 온더룩처럼 상품 위치에 브랜드·가격·사이즈 세 줄짜리 작은 말풍선을 두고, 같은 정보를 사진 아래 목록으로 한 번 더 준다. 착용 사이즈만 색을 달리해 눈에 띄게 한다. (관찰에서 정리, 추정)

### 이 문서를 읽는 AI 에이전트에게
- 색·크기·간격은 YAML 토큰 이름으로만 쓴다. 화면에서는 `blue-500`보다 `primary`, `gray-100`보다 `section-gap` 같은 semantic 이름을 먼저 쓴다.
- `primary`(#2496ff)는 칩 글자, 필터 아이콘·숫자, 구획 부제에만 쓴다. 넓은 면은 `primary-light`(#edf7ff)까지만.
- 칩·카드 모서리는 `rounded.md`(8pt)다. 스타일·성별 칩에 알약(999px)을 쓰지 않는다. 소개 이미지의 브랜드 칩만 알약이다(추정).
- 색을 채운 주요 버튼(`button-primary`)은 아직 보지 못했다. 소개 이미지의 "View More"는 #f4f4f4 면 + 검정 글자 보조 버튼(`button-secondary`)이다. 주요 버튼 색을 지어내지 않는다.
- 선택 탭은 색(`text-primary` / `text-tab-off`)과 2pt 밑줄로 나눈다. 굵기는 같다.
- 근거가 캡처 1장 + 소개 이미지 3장(추정)뿐이다. 주요 버튼·할인 색처럼 이 문서에 없는 부분은 값을 지어내지 말고 `확인 필요`로 둔다.

## 2. 색상
값은 1배율 캡처 픽셀에서 읽었다. 넓은 면 색은 정확하고, 작은 글자 색은 글자 테두리 번짐 때문에 오차가 있다. 토큰 이름은 SylviaLab이 붙인 것이다.

### 색 체계
공개 팔레트가 없어서 캡처의 색을 **관찰 팔레트**로 모으고 **역할 이름**을 붙였다(관찰에서 정리).

| 층 | 예시 | 쓰는 곳 |
|---|---|---|
| 관찰 팔레트 | `blue-500`, `blue-50`, `gray-100`, `gray-950` | 토큰 정의에만. 번호는 밝기 순서일 뿐 공식 단계가 아니다 |
| 역할 이름 | `primary`, `primary-light`, `section-gap`, `text-tab-off` | 실제 화면과 컴포넌트 |

### 브랜드·행동
| 토큰 | HEX | 쓰임 |
|---|---|---|
| blue | #2496ff | 스타일 칩 글자, 필터 칩 아이콘·숫자, 구획 부제(근처 값) |
| blue-light | #edf7ff | 스타일 칩·필터 칩 바탕 |
| black | #000000 | 하단 탭 아이콘, 구획 제목(#030303 근처) |

| 검색 필터 칩 | 흰 면 + 옅은 회색(#f4f4f4 근처) 1px 테두리 + #8f8f8f 근처 글자, 작은 모서리. 속성 칩은 오른쪽 아래 화살표 | 검색 결과 위(성별 M/W, 체형, 색 등) |
| 옛 홈 칩 | 흰 면 + 옅은 테두리 + 회색 글자, 맨 앞에 회색 면 필터 아이콘 칩 | 한글 옛 홈(MEN/WOMEN, 스타일) |

- 고른 브랜드 칩의 흰 글자/#000000은 21:1이다. 검색 필터 칩 글자 #8f8f8f/#ffffff는 3.2:1로 본문 기준에 못 미친다.
- 검색 필터 줄 끝에 되돌리기(초기화) 아이콘이 있다.

**규칙**
- 고름은 면(하늘색) + 글자색(파랑) 두 가지를 함께 바꾼다.
- 필터 칩은 고른 개수를 숫자로 보인다.
- 칩에 `aria-pressed`(또는 체크 상태)를 달아 고름을 알린다(구현 권장).
- 32pt 칩은 터치 영역을 44pt 이상으로 넓힌다(구현 권장).

### 6.4 탭
- 상단 탭(추천·스타일랭킹·팔로잉 꼴): 16pt 굵은 글자. 선택 탭 #1f1f1f + 2pt 밑줄, 나머지 #bfbfbf. 탭 줄 아래 구분선은 없다.

| 상태 | 글자 | 밑줄 |
|---|---|---|
| 선택 | #1f1f1f 16pt 700 | 2pt, 글자 폭 |
| 선택 안 됨 | #bfbfbf 16pt 700 | 없음 |

**규칙**
- 탭 줄 아래에 진한 구분선을 긋지 않는다(영문 소개 이미지에는 아주 옅은 선이 보임, 확인 필요).
- 선택 탭에 `aria-selected="true"`(구현 권장).

**소개 이미지에서 본 탭(추정)**
- 영문 홈(For You / Following): 처음 캡처와 같은 꼴. 선택 탭 검정 굵은 글자 + 글자 폭 검정 밑줄(약 2~3pt), 나머지 연회색. 탭 줄 아래에 아주 옅은 1px 선이 보인다(확인 필요).
- 검색 결과(Style / Item / Brand): 탭이 화면을 3등분한다. 선택 탭 #232323 근처 굵은 글자 + 칸 전체 폭 검정 밑줄, 나머지 #c6c6c6 근처.
- 북마크(스타일·상품·좋아요 + 개수): 선택 탭만 검정 굵게, 나머지 연회색. 밑줄은 보이지 않는다.

### 6.5 착용 사진 카드·아이템 줄
- 착용 사진 카드: 세로 사진(모서리 8pt), 오른쪽 위 여러 장 표시 아이콘. 아래에 그 코디의 아이템 작은 사진 줄, 일부 사진 왼쪽 위에 "비슷한" 검정 꼬리표.
- 크기: 카드 약 177×213pt, 카드 사이 약 12pt / 아이템 사진 약 54pt 정사각, 모서리 8pt.
- 상태: 저장(북마크) 표시는 확인 필요.

- 게시물 상세(소개 이미지, 추정): 위에 프로필 사진(원형) + 아이디 굵게 + 인증 표시(#e22f57 근처) + 키(cm), 오른쪽 "+ Follow". 그 아래 화면 폭 사진(모서리 0, 오른쪽 아래 장 수 점). 사진 위 아이템 자리마다 흰 반투명 말풍선(브랜드 굵게 / 가격 회색 / 착용 사이즈 파랑, 작은 모서리, 꼬리 있음). 사진 아래 선 아이콘 줄(좋아요·댓글·공유 왼쪽, 북마크 오른쪽) → 날짜(연회색) → 본문(왼쪽 세로선 + 아이디 굵게 + 해시태그 파랑) → "착용제품" 목록(작은 사진 + 브랜드 굵게 · 사이즈 파랑 + 상품명 + 가격 + 오른쪽 북마크).

**규칙**
- 카드와 아이템 줄은 한 묶음이다. 아이템 줄만 따로 쓰지 않는다(관찰에서 정리).
- 사진에 착용 아이템을 설명하는 대체 텍스트를 단다(구현 권장).

### 6.6 카테고리 타일·사진 피드
- 카테고리 타일: #f4f4f4 둥근 사각 타일(약 58pt, 모서리 8pt) 안에 상품 누끼 사진 + 아래 12pt 이름.
- 사진 피드: 2열 사진, 오른쪽 위 여러 장 표시 아이콘. 모서리는 0px로 보인다(확인 필요).
- 카테고리 목록(소개 이미지, 추정): 맨 위 #f4f4f4 정사각 타일(약 55pt, 모서리 약 8pt) + 아래 영문 이름 줄. 고른 타일은 검정 테두리(약 2pt) + 이름 굵게. 그 아래 2열 사진 그리드.

### 6.7 상단 바·하단 탭 바
- 상단 바: 왼쪽 소문자 로고, 오른쪽 알림 아이콘.
- 하단 탭 바: 흰 바탕, 아이콘 + 한글 이름 4개(홈·검색·북마크·MY). 아이콘은 검정 선 아이콘이고, 선택 홈 아이콘은 채운 모양. 윗선 1pt #f5f5f5.

- 소개 이미지(추정): 하단 탭 4개 구성은 같고, 영문판 이름은 대문자 영문(HOME·DISCOVER·BOOKMARK·MY)이다. 검색 탭 자리가 DISCOVER로 바뀌어 있다. 상단 바 오른쪽에는 검색·알림(옛 화면은 쇼핑백·검색·알림) 아이콘.

**규칙**
- 선택 탭은 아이콘을 채운 모양으로 바꾼다(색은 같은 검정).
- 선택 탭에 `aria-current="page"`(구현 권장).

### 6.8 꼬리표·배지
- "비슷한" 꼬리표: #232323 근처 바탕(반투명일 수 있음), 흰 10pt 글자, 모서리 약 4pt(확인 필요). 아이템 작은 사진 왼쪽 위.
- 사진 위 가격표(검색 결과, 추정): 검정 #000000 각진 상자 + 흰 굵은 글자 두 줄(브랜드 / 가격). 사진 속 아이템 옆에 놓인다.
- 토스트·스낵바: 캡처에 없음. 확인 필요.

### 6.9 바텀시트·모달
- 캡처에 없음. 확인 필요.

### 6.10 아이콘·이미지
- 아이콘: 검정 선 아이콘, 선택 상태는 채운 아이콘.
- 이미지: 사람이 찍은 착용 사진이 주인공이다. 아이템은 배경을 지운 누끼 사진이나 작은 정사각 사진.

## 7. 패턴
- 홈(추천 탭) 구성: 로고 줄 → 상단 탭 → 칩 줄(필터·성별·스타일) → 구획(권유형 제목 + 파란 부제 + 착용 사진 카드 가로 줄) → 8pt 띠 → 카테고리 타일 줄 → 2열 사진 피드.
- 코디 → 아이템: 착용 사진 카드 아래 아이템 작은 사진 줄, "비슷한" 꼬리표로 비슷한 상품을 알린다.
- 필터: 필터 칩에 고른 개수를 숫자로 보인다.
- 추천 구획 머리(9장 말투 규칙으로 SylviaLab이 쓴 예):
  ```
  오늘은 니트로 코디해 보세요            ← 16pt 700, 검정, 권유형
  최근 고른 스타일과 비슷해서 골랐어요    ← 14pt 400, #2496ff, 해요체        [X]
  ```
  (예시 문구, SylviaLab 작성)
- 목록 → 상세(소개 이미지, 추정): 2열 사진 그리드 → 게시물 상세(사진 + 아이템 말풍선 → 본문 → 착용제품 목록). 상품 구매 화면은 확인 필요.
- 검색(소개 이미지, 추정): 검색창 → Style/Item/Brand 3등분 탭 → 필터 칩 줄(가로 스크롤 + 초기화) → 오른쪽 정렬 줄(정렬 아이콘 + 기준 글자 | 보기 바꾸기 아이콘) → 2열 사진 그리드(사진 위 검정 가격표).
- 빈 상태·로딩·오류: 확인 필요.
- 폼·결제: 확인 필요.

## 10. Do & Don't
관찰 기반 문서의 규칙은 "이 서비스 화면에서 반복되는 규칙"을 SylviaLab이 정리한 것이다(공식 규칙 아님).

### Do
- 고른 칩은 #edf7ff 바탕 + #2496ff 글자, 높이 32pt, 모서리 8pt로 만든다.
- 고르지 않은 칩은 흰 바탕 + #f0f0f0 근처 테두리 + 회색 글자로 둔다.
- 선택 탭은 #1f1f1f + 글자 폭 2pt 밑줄, 나머지 탭은 #bfbfbf로 쓴다.
- 구획 사이에 8pt #f4f4f4 띠를 둔다.
- 보조 버튼은 #f4f4f4 면 + 검정 글자, 전체 폭, 높이 약 45pt, 모서리 약 6pt로 둔다(소개 이미지 추정).
- 사진 속 아이템은 말풍선(브랜드·가격·사이즈)과 사진 아래 착용제품 목록 두 곳에서 보여 준다(소개 이미지 추정).
- 착용 사진 카드(약 177×213pt, 모서리 8pt) 아래에 54pt 아이템 사진 줄을 붙인다.
- 구획 제목은 권유형, 부제는 14pt 파란 해요체로 쓴다.

### Don't
- 스타일·성별 칩을 알약 모양(999px)으로 만들지 않는다(브랜드 칩은 예외, 추정).
- 색을 채운 주요 버튼 값을 지어내지 않는다. 아직 보지 못했다.
- #2496ff를 칩·필터·구획 부제 밖의 큰 면에 쓰지 않는다.
- 상단 탭 줄 아래에 진한 구분선을 긋지 않는다(영문 소개 이미지에는 아주 옅은 선이 보여 확인 필요).
- 카드에 그림자를 넣지 않는다.
- 사진 속 색을 UI 색으로 가져오지 않는다.

- https://apps.apple.com/kr/app/id1476231289 (확인 2026-11-01) — 온더룩 App Store 앱 페이지. 수집 메모: "App Store + 공개 앱 소개 이미지", "온더룩은 현재 App Store API에서 앱 스크린샷을 제공하지 않아 공개 앱 소개 이미지 3장을 넣었습니다." 이미지 3장(영문 홈·목록·상세, 한글 옛 홈·북마크·상세, 영문 검색)은 소개용 편집 이미지라 값은 모두 추정. 각 소개 이미지의 원래 게시 URL은 메모에 없어 확인 필요.

근거와 한계
- 화면 값은 모두 앱 캡처에서 잰 관찰값이다. 캡처 시기는 화면만으로 알 수 없어 확인 필요다.
- 홈 화면 1장뿐이라 최소 3개 화면 기준에 크게 못 미친다. 한 화면 안에서 여러 번 보인 값(파랑 #2496ff, 칩 바탕 #edf7ff, 회색 #f4f4f4)만 조금 믿을 만하고 나머지는 참고용이다.
- 캡처가 375pt 1배율이라 크기는 ±1pt, 작은 글자 색은 오차가 있다.
- 처음 캡처에서는 검색, 스타일 상세, 아이템 상세(가격·구매 연결), 북마크, 다크 모드를 확인하지 못했다. 2026-11-01에 공개 앱 소개 이미지 3장으로 검색·게시물 상세·북마크·카테고리 목록의 모양을 봤다. 다만 소개용 편집 이미지이고 영문판·옛 한글판이 섞여 있으며 JPEG 압축이 있어 값은 모두 추정이다. 색을 채운 주요 버튼, 아이템 상세(구매 연결), 다크 모드는 여전히 확인 필요다.
- 착용 사진·아이템 사진 속 색은 시스템 색에서 뺐다.
- 관찰 값은 서비스가 바뀌면 달라질 수 있다.
- 서비스 이름과 브랜드는 각 권리자의 것이다. 이 문서는 식별·학습용 참고 자료로 SylviaLab이 독자적으로 작성했다.

## 부록 B. 값의 출처 구분
- **공식 자료 그대로**: 없음. 공개 디자인 시스템 문서·코드를 확인하지 못했다.
- **화면에서 잰 값(관찰, iOS 홈 캡처 1장)**: 모든 HEX(#2496ff, #edf7ff, #000000, #ffffff, #1f1f1f, #f5f5f5, #f4f4f4, #f0f0f0, #d3d3d3, #bfbfbf, #9b9b9b, #6d6d6d, #232323 및 근처 값 #030303·#101010), 글자 크기·굵기, 좌우 23pt·칩 사이 4pt·카드 사이 12pt·탭 사이 17pt, 칩 32pt·카드 177×213pt·아이템 54pt·타일 58pt·탭 바 83pt, 밑줄 2pt·선 1pt·띠 8pt, 모서리 0/4/8.
- **공개 앱 소개 이미지에서 읽은 값(추정, 2026-11-01)**: #f4f4f4(버튼·검색창·타일 면), #000000(브랜드 칩·가격표·버튼 글자), #c6c6c6, #8f8f8f, #ef446e, #e22f57, #2e5d87, #35538f, "View More" 높이 약 45pt·모서리 약 6pt, 검색창 높이 약 39pt, 브랜드 칩 알약 약 32pt, 카테고리 타일 약 55pt, 사진 그리드 틈 1~2pt, 화면 구성(검색·게시물 상세·북마크·카테고리 목록).
- **SylviaLab이 정리·권장한 것**: 모든 토큰 이름, 관찰 팔레트 → 역할 이름 두 층, 줄 구성 표, 원칙·규칙·Don't, 추천 구획 예시 문구, `(구현 권장)`이 붙은 접근성 항목.
