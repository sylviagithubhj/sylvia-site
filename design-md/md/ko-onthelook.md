# 온더룩 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 시기 확인 필요, iOS 앱 홈(추천 탭) 화면 1장, 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

이 문서는 디자인 시스템의 다섯 층(원칙, 토큰, 컴포넌트, 사용 규칙, 구현·검증)을 한 파일로 줄인 요약이다. 맨 위 YAML은 도구와 AI가 그대로 읽는 값이고, 아래 글은 그 값을 언제·왜 쓰는지 설명한다. 둘이 어긋나면 YAML 값이 우선한다. 화면 1장에서 정리했으므로 구조만 맞추고, 보지 못한 부분은 `확인 필요`로 남겼다.

## 1. 개요와 원칙
- 서비스 성격: 패션 코디 사진 앱. 사람들의 착용 사진(스타일)을 보고, 사진 속 아이템을 확인·검색·저장한다.
- 디자인 인상 한 줄: 흰 바탕에 검정 글자, 밝은 파랑(#2496ff) 하나를 칩·안내 문구 강조에 쓴다. 색은 대부분 코디 사진이 채운다.
- 공식 시스템 이름: 확인 필요
- 디자인 원칙(공식 원칙은 확인하지 못했다. 화면 1장에서 읽은 것이라 참고용이다):
  1. 강조색은 파랑 하나로, 칩 글자·필터 아이콘·구획 부제에만 쓴다. (관찰에서 정리)
  2. 색은 코디 사진이 맡고 UI는 흰색·검정·회색으로 단순하게 둔다. (관찰에서 정리)
  3. 구획은 그림자 없이 8pt 회색 띠로 나눈다. (관찰에서 정리)
  4. 착용 사진과 그 안의 아이템을 한 카드 묶음으로 보여 준다. (관찰에서 정리)
- 톤: 사진이 주인공이고, 문구는 권유형으로 부드럽다.
- 공개 자료 상황: 이번 작업에서는 공개 문서·오픈소스를 확인하지 못했다. 확인 필요.

### 특장점
- 착용 사진에 아이템 줄을 붙인다 — 약 177×213pt 착용 사진 카드 아래에 그 코디의 아이템 작은 사진(약 54pt 정사각) 줄을 두고, 일부에는 "비슷한" 검정 꼬리표를 단다. 코디를 보다 바로 상품으로 넘어간다.
- 칩을 하늘색 면 + 파란 글자로 만든다 — 스타일 칩은 #edf7ff 바탕 + #2496ff 글자, 높이 약 32pt, 모서리 약 8pt의 둥근 사각형이다. 알약 모양이 아니다.
- 칩의 고름·안 고름을 면 유무로 나눈다 — 고른 칩은 하늘색 바탕 + 파란 글자, 고르지 않은 칩은 흰 바탕 + #f0f0f0 근처 테두리 + #9b9b9b 근처 글자다.
- 구획 부제로 추천 이유를 말한다 — 16pt 굵은 권유형 제목 아래 14pt 파란 해요체 부제가 추천 이유를 짧게 설명한다.
- 구획을 회색 띠와 닫기로 관리한다 — 구획 사이 8pt #f4f4f4 띠, 구획 제목 오른쪽 끝 연회색 X로 구획을 닫을 수 있다.

### 배울 점
- 사진 속 상품을 연결할 때 온더룩처럼 큰 사진 카드 바로 아래 작은 정사각 아이템 사진 줄을 붙인다.
- 필터·태그 칩을 둘 때 온더룩처럼 고른 칩은 옅은 브랜드색 면(#edf7ff) + 브랜드색 글자, 고르지 않은 칩은 흰 바탕 + 옅은 테두리로 나눈다.
- 추천 구획을 둘 때 온더룩처럼 제목 아래 강조색 부제로 추천 이유를 한 줄 적는다.

### 이 문서를 읽는 AI 에이전트에게
- 색·크기·간격은 YAML 토큰 이름으로만 쓴다. 화면에서는 `blue-500`보다 `primary`, `gray-100`보다 `section-gap` 같은 semantic 이름을 먼저 쓴다.
- `primary`(#2496ff)는 칩 글자, 필터 아이콘·숫자, 구획 부제에만 쓴다. 넓은 면은 `primary-light`(#edf7ff)까지만.
- 칩·카드 모서리는 `rounded.md`(8pt)다. 알약(999px)을 쓰지 않는다.
- 선택 탭은 색(`text-primary` / `text-tab-off`)과 2pt 밑줄로 나눈다. 굵기는 같다.
- 근거가 화면 1장이라, 가격·버튼·입력창처럼 이 문서에 없는 부분은 값을 지어내지 말고 `확인 필요`로 둔다.

## 2. 색상
값은 1배율 캡처 픽셀에서 읽었다. 넓은 면 색은 정확하고, 작은 글자 색은 글자 테두리 번짐 때문에 오차가 있다. 토큰 이름은 SylviaLab이 붙인 것이다.

### 색 체계
공개 팔레트가 없어서 캡처의 색을 **관찰 팔레트**로 모으고 **역할 이름**을 붙였다(관찰에서 정리).

| 층 | 예시 | 쓰는 곳 |
|---|---|---|
| 관찰 팔레트 | `blue-500`, `blue-50`, `gray-100`, `gray-950` | 토큰 정의에만. 번호는 밝기 순서일 뿐 공식 단계가 아니다 |
| 역할 이름 | `primary`, `primary-light`, `section-gap`, `text-tab-off` | 실제 화면과 컴포넌트 |

- 상태 색의 "배경/선/글자" 조합 규칙: 확인 필요.

### 역할별 색
- 강조 `primary`(#2496ff): 고른 칩 글자, 필터 칩 아이콘·고른 개수, 구획 부제(14pt). 눌림 짝은 확인 필요.
- 강조 면 `primary-light`(#edf7ff): 고른 칩·필터 칩 바탕. `primary` 글자와 늘 짝으로 쓴다.
- 고르지 않은 칩: 바탕 `surface` + 테두리 `chip-border`(#f0f0f0 근처) + 글자 `text-chip-off`(#9b9b9b 근처).
- 탭: 선택 `text-primary`(#1f1f1f) + 같은 색 2pt 밑줄, 나머지 `text-tab-off`(#bfbfbf).
- 면·선: `section-gap`(#f4f4f4, 구획 띠·카테고리 타일), `divider`(#f5f5f5, 하단 탭 바 윗선 1pt).
- 꼬리표 `tag-dark`(#232323 근처) + 흰 글자: "비슷한" 표시에만.

### 화면 모드
- 다크 모드: 확인 필요.

### 색 사용 규칙
- #2496ff는 칩 글자, 필터 아이콘·숫자, 구획 부제에만 쓴다.
- #edf7ff는 고른 칩·필터 칩 바탕에만 쓴다.
- 선택 탭은 #1f1f1f, 선택 안 된 탭은 #bfbfbf다.
- 구획 띠와 카테고리 타일 바탕은 #f4f4f4다.
- 사진 속 색은 UI 색으로 쓰지 않는다.

### Don't
- `primary`(#2496ff)를 큰 면(배너·버튼 전체 채움)에 쓰지 않는다.
- 고르지 않은 칩에 하늘색 바탕을 넣지 않는다.
- 선택 탭 밑줄을 파랑으로 칠하지 않는다(선택 탭은 #1f1f1f).
- 사진 속 색을 UI 색으로 가져오지 않는다.

## 3. 타이포그래피
- 글꼴: iOS 시스템 글꼴(추정. 한글은 Apple SD Gothic Neo와 같은 모양). 전용 글꼴은 확인 필요.
- 로고: 굵은 소문자 영문 워드마크(높이 약 15pt).
- 대체 글꼴: -apple-system, 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif
- 크기는 1배율 캡처의 글자 높이로 계산한 추정값이다(±1pt). 행간은 확인 필요.

### 위계와 사용처
| 단계 | 크기(pt) | 굵기 | 행간 | 쓰임 |
|---|---|---|---|---|
| tab | 16 | 700 | 확인 필요 | 상단 탭(선택·비선택 모두 굵게 보임) |
| section-title | 16 | 700 | 확인 필요 | 구획 제목 |
| section-sub | 14 | 400 | 확인 필요 | 구획 부제(파란 글자) |
| chip | 14 | 500 | 확인 필요 | 스타일·성별 칩 글자(굵기 확인 필요) |
| category | 12 | 400 | 확인 필요 | 카테고리 타일 아래 이름 |
| tabbar-label | 10 | 400 | 확인 필요 | 하단 탭 이름 |
| tag | 10 | 400 | 확인 필요 | "비슷한" 꼬리표 |

### 규칙
- 탭과 구획 제목은 16pt 굵게로 같은 크기다. 탭은 선택 여부를 굵기가 아니라 색(#1f1f1f / #bfbfbf)과 밑줄로 나눈다.
- 구획 부제는 14pt 파란 글자로 제목 바로 아래 둔다.
- 10pt는 하단 탭 이름과 "비슷한" 꼬리표에만 쓴다.
- 위계는 크기 차이가 작다(16 → 14 → 12 → 10pt). 대신 색(검정 제목 / 파란 부제)으로 제목과 설명을 나눈다(관찰에서 정리).

### Don't
- 구획 부제를 굵게 쓰지 않는다(400).
- 10pt를 하단 탭 이름·꼬리표 밖에서 쓰지 않는다.
- 탭 선택을 굵기 차이로만 표시하지 않는다(색 + 밑줄).

- 화면 좌우 여백: 약 23pt(로고, 탭, 구획 제목, 첫 사진이 같은 선). 칩·카테고리 줄은 약 15~20pt에서 시작한다.

- 그리드·최대 폭: 사진 그리드는 2열(아래 피드, 일부만 보임). 간격 확인 필요.
- 상단 탭: 탭 글자 사이 약 17pt, 선택 탭 아래 2pt 밑줄(글자 폭과 같음).

- 칩 줄: 높이 약 32pt, 칩 사이 약 4pt, 가로 스크롤.

## 5. 모서리·고도·모션
| 토큰 | 값 | 쓰임 |
|---|---|---|
| radius-sm | 4px | "비슷한" 꼬리표(확인 필요) |
| radius-md | 8px | 착용 사진 카드, 아이템 작은 사진, 칩, 카테고리 타일(관찰 6~8) |
| radius-none | 0px | 아래 2열 사진 피드로 보임(일부만 보여 확인 필요) |

- 선: divider 1pt #f5f5f5(하단 탭 바 윗선), section-gap 8pt #f4f4f4(구획 사이 띠).
- 픽셀 단위는 iOS pt와 같다고 보고 적었다(1pt = CSS 1px).
- 칩은 알약이 아니라 약 8pt 모서리의 둥근 사각형이다.

### 고도(층)
- 그림자는 보이지 않는다. 확인 필요.
- 층은 면 색으로 나눈다: 흰 바탕 위 #f4f4f4 띠·타일, #edf7ff 칩.

### 모션
- 캡처로 알 수 없음. 확인 필요.

### Don't
- 칩을 알약 모양(999px)으로 만들지 않는다.
- 카드·칩에 그림자를 넣지 않는다.
- 사진 카드와 칩 모서리를 서로 다르게 두지 않는다(둘 다 약 8pt).

## 6. 컴포넌트
컴포넌트마다 크기, 종류, 상태, 규칙을 적는다. 보지 못한 상태는 `확인 필요`.

### 6.1 버튼
| 변형 | 모양 | 쓰는 때 |
|---|---|---|
| 구획 닫기 | 구획 제목 오른쪽 끝 연회색 X(#d3d3d3 근처) | 추천 구획을 닫을 때 |

- 일반 주요 버튼: 캡처에 없음. 확인 필요.
- 크기: 닫기 아이콘 크기·터치 영역은 확인 필요.
- 상태: 눌림 / 비활성 / 로딩 모두 확인 필요.

**규칙**
- 닫기 X는 구획 제목과 같은 줄 오른쪽 끝에만 둔다(관찰에서 정리).
- X에 "이 추천 닫기" 같은 이름을 달고 터치 영역을 44pt 이상으로 둔다(구현 권장).

### 6.2 입력창
- 캡처에 없음. 확인 필요.

### 6.3 칩
**종류**

| 종류 | 모양 | 쓰는 곳 |
|---|---|---|
| 필터 칩 | #edf7ff 바탕 + 파란 조절 아이콘 + 고른 개수 | 칩 줄 맨 앞 |
| 성별 칩 | 고름: 하늘색 바탕 + 파란 글자 / 안 고름: 흰 바탕 + #f0f0f0 근처 테두리 + 회색 글자 | 칩 줄 |
| 스타일 칩 | #edf7ff 바탕 + #2496ff 글자 | 칩 줄 |

**크기**: 높이 약 32pt, 모서리 약 8pt, 글자 14pt, 칩 사이 약 4pt. 좌우 여백은 확인 필요.

- 상태: 고름 / 고르지 않음. 눌림·비활성은 확인 필요.
- 쓰지 않는 때: 칩을 알약(완전히 둥근 모양)으로 만들지 않는다.

**규칙**
- 고름은 면(하늘색) + 글자색(파랑) 두 가지를 함께 바꾼다.
- 필터 칩은 고른 개수를 숫자로 보인다.
- 칩에 `aria-pressed`(또는 체크 상태)를 달아 고름을 알린다(구현 권장).
- 32pt 칩은 터치 영역을 44pt 이상으로 넓힌다(구현 권장).

### 6.4 탭
- 상단 탭(추천·스타일랭킹·팔로잉 꼴): 16pt 굵은 글자. 선택 탭 #1f1f1f + 2pt 밑줄, 나머지 #bfbfbf. 탭 줄 아래 구분선은 없다.

| 상태 | 글자 | 밑줄 |
|---|---|---|
| 선택 | #1f1f1f 16pt 700 | 2pt, 글자 폭 |
| 선택 안 됨 | #bfbfbf 16pt 700 | 없음 |

**규칙**
- 탭 줄 아래에 구분선을 긋지 않는다.
- 선택 탭에 `aria-selected="true"`(구현 권장).

### 6.5 착용 사진 카드·아이템 줄
- 착용 사진 카드: 세로 사진(모서리 8pt), 오른쪽 위 여러 장 표시 아이콘. 아래에 그 코디의 아이템 작은 사진 줄, 일부 사진 왼쪽 위에 "비슷한" 검정 꼬리표.
- 크기: 카드 약 177×213pt, 카드 사이 약 12pt / 아이템 사진 약 54pt 정사각, 모서리 8pt.
- 상태: 저장(북마크) 표시는 확인 필요.

**규칙**
- 카드와 아이템 줄은 한 묶음이다. 아이템 줄만 따로 쓰지 않는다(관찰에서 정리).
- 사진에 착용 아이템을 설명하는 대체 텍스트를 단다(구현 권장).

### 6.6 카테고리 타일·사진 피드
- 카테고리 타일: #f4f4f4 둥근 사각 타일(약 58pt, 모서리 8pt) 안에 상품 누끼 사진 + 아래 12pt 이름.
- 사진 피드: 2열 사진, 오른쪽 위 여러 장 표시 아이콘. 모서리는 0px로 보인다(확인 필요).

### 6.7 상단 바·하단 탭 바
- 상단 바: 왼쪽 소문자 로고, 오른쪽 알림 아이콘.
- 하단 탭 바: 흰 바탕, 아이콘 + 한글 이름 4개(홈·검색·북마크·MY). 아이콘은 검정 선 아이콘이고, 선택 홈 아이콘은 채운 모양. 윗선 1pt #f5f5f5.

**규칙**
- 선택 탭은 아이콘을 채운 모양으로 바꾼다(색은 같은 검정).
- 선택 탭에 `aria-current="page"`(구현 권장).

### 6.8 꼬리표·배지
- "비슷한" 꼬리표: #232323 근처 바탕(반투명일 수 있음), 흰 10pt 글자, 모서리 약 4pt(확인 필요). 아이템 작은 사진 왼쪽 위.
- 토스트·스낵바: 캡처에 없음. 확인 필요.

### 6.9 바텀시트·모달
- 캡처에 없음. 확인 필요.

### 6.10 아이콘·이미지
- 아이콘: 검정 선 아이콘, 선택 상태는 채운 아이콘.
- 이미지: 사람이 찍은 착용 사진이 주인공이다. 아이템은 배경을 지운 누끼 사진이나 작은 정사각 사진.

## 7. 패턴

## 8. 접근성
- 글자 대비(WCAG 2.x, 계산값):

| 글자 | 바탕 | 대비 | 본문 기준 4.5:1 |
|---|---|---|---|
| #000000 | #ffffff | 21.0:1 | 통과 |
| #1f1f1f | #ffffff | 16.5:1 | 통과 |
| #6d6d6d | #ffffff | 5.2:1 | 통과 |
| #6d6d6d | #f4f4f4 | 4.7:1 | 통과 |
| #9b9b9b | #ffffff | 2.8:1 | 미달 |
| #bfbfbf | #ffffff | 1.8:1 | 미달 |
| #2496ff | #ffffff | 3.1:1 | 미달(큰 글자 3:1은 통과) |
| #2496ff | #edf7ff | 2.8:1 | 미달 |
| #ffffff | #232323 | 15.7:1 | 통과 |

- 칩 글자(14pt, #2496ff/#edf7ff)와 구획 부제(14pt 파랑)는 기준에 못 미친다. 카테고리 이름이 타일 바탕 위라면 #6d6d6d/#f4f4f4는 4.7:1이다.

- 홈 화면 1장뿐이라 최소 3개 화면 기준에 크게 못 미친다. 한 화면 안에서 여러 번 보인 값(파랑 #2496ff, 칩 바탕 #edf7ff, 회색 #f4f4f4)만 조금 믿을 만하고 나머지는 참고용이다.
- 캡처가 375pt 1배율이라 크기는 ±1pt, 작은 글자 색은 오차가 있다.
- 검색, 스타일 상세, 아이템 상세(가격·구매 연결), 북마크, 다크 모드는 확인하지 못했다.
- 착용 사진·아이템 사진 속 색은 시스템 색에서 뺐다.
- 관찰 값은 서비스가 바뀌면 달라질 수 있다.
- 서비스 이름과 브랜드는 각 권리자의 것이다. 이 문서는 식별·학습용 참고 자료로 SylviaLab이 독자적으로 작성했다.

## 부록 B. 값의 출처 구분
- **공식 자료 그대로**: 없음. 공개 디자인 시스템 문서·코드를 확인하지 못했다.
- **화면에서 잰 값(관찰, iOS 홈 캡처 1장)**: 모든 HEX(#2496ff, #edf7ff, #000000, #ffffff, #1f1f1f, #f5f5f5, #f4f4f4, #f0f0f0, #d3d3d3, #bfbfbf, #9b9b9b, #6d6d6d, #232323 및 근처 값 #030303·#101010), 글자 크기·굵기, 좌우 23pt·칩 사이 4pt·카드 사이 12pt·탭 사이 17pt, 칩 32pt·카드 177×213pt·아이템 54pt·타일 58pt·탭 바 83pt, 밑줄 2pt·선 1pt·띠 8pt, 모서리 0/4/8.
- **SylviaLab이 정리·권장한 것**: 모든 토큰 이름, 관찰 팔레트 → 역할 이름 두 층, 줄 구성 표, 원칙·규칙·Don't, 추천 구획 예시 문구, `(구현 권장)`이 붙은 접근성 항목.
