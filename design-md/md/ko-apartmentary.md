# 아파트멘터리 웹 디자인 시스템

> 근거: 관찰 기반 (모바일 웹 캡처: 아파트멘터리 웹사이트를 휴대폰 브라우저로 본 홈 화면 5장(첫 화면, 서비스 소개, 시공 사례 2장, 후기), 약 453px 폭 이미지에서 픽셀 측정. 원래 기기 폭은 확인 필요, 이미지 1px ≈ CSS 1px로 봄. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

## 1. 개요
- 서비스 성격: 아파트 인테리어 리모델링 회사의 웹사이트. 서비스 소개, 평형·유형별 시공 사례, 고객 후기, 쇼룸 소식을 보여준다.
- 디자인 인상 한 줄: 흰 바탕에 진한 회색 글자, 거의 검정인 알약 버튼 하나. 시공 사진을 크게 깔고 색은 사진에 맡긴다.
- 공식 시스템 이름: 공개된 이름 없음
- 특징
  - UI 색은 흰색, 검정, 회색뿐이다. 따로 정한 강조색은 캡처에서 보이지 않았다.
  - 주요 버튼은 노란 기운이 도는 거의 검정(#13130b) 알약에 흰 굵은 글자와 `>`다.
  - 사진은 모서리 없이 각지게 쓴다.
  - 구획 제목은 두 줄로 끊은 굵은 한글 제목이다.
  - 가로로 넘기는 사례 묶음 아래에 가는 회색 선 + 검정 진행 막대를 둔다.
  - 맨 위에 검정 띠 공지가 있고, 그 아래 머리는 첫 사진 위에 투명하게 얹는다.
- 공개 자료 상황: 공개 디자인 시스템 문서나 코드는 찾지 못했다. 확인 필요.

## 2. 색상
값은 캡처 이미지 픽셀에서 읽었다. UI 요소(바탕·글자·버튼·선) 색만 적었고 시공 사진 속 색은 넣지 않았다. 작은 글자 색은 번짐 때문에 오차가 있다. 토큰 이름은 SylviaLab이 붙인 것이다.

## 4. 간격·레이아웃
- 기준 화면: 휴대폰 폭(이미지 약 453px). 실제 기기 폭은 확인 필요.
- 화면 좌우 여백: 왼쪽 약 15px, 오른쪽 약 20px(사진 오른쪽 끝 기준). 왼쪽 값은 캡처 가장자리 그림자 때문에 오차가 있다.
- 간격 단계(관찰, pt): 8, 12, 16, 20, 24, 40
- 시공 사례 묶음 세로 순서: 두 줄 제목 → 22px → 사진(폭 꽉 참, 약 3:2) → 20px → 사례 이름 → 12px → 한 줄 설명 → 16px → 가격 → 약 40px → 진행 표시 → 22px → 알약 버튼.
- 서비스 소개 묶음: 사진을 좁게(폭 약 210px, 왼쪽 약 40px 들여) 놓고, 아래 제목·문단·버튼을 같은 선에 맞춘다.
- 후기 목록: 번호(01, 02) 열 + 문장 열, 문장 시작은 왼쪽 약 58px. 후기 사이 약 78px.
- 그리드: 확인 필요

## 5. 모서리·그림자·테두리
| 토큰 | 값 | 쓰임 |
|---|---|---|
| radius-none | 0px | 시공 사진, 첫 화면 사진, 공지 띠 |
| radius-full | 999px | 주요 알약 버튼, 사진 위 슬라이드 번호 알약 |
| line | 1px #e2e2e2 | 슬라이드 진행 표시 바탕 선 |

- 사진은 각지게, 누르는 것은 완전히 둥글게. 중간 모서리 값은 캡처에서 보이지 않았다.
- 그림자: 보이지 않았다.
- 이미지 1px을 CSS 1px로 보고 적었다.

## 6. 주요 컴포넌트
### 버튼
- 주요 알약 버튼: button-dark 바탕, 높이 약 38px, 폭은 글자에 맞춤(약 116~143px), 완전히 둥근 모서리. 흰 굵은 글자 + 오른쪽 `>`. 왼쪽 정렬로 콘텐츠 선에 맞춘다.
- 다른 버튼 모양(외곽선, 비활성): 확인 필요.

### 입력창
- 캡처에 없음. 확인 필요.

### 카드·리스트
- 시공 사례: 두 줄 제목 + 꽉 찬 사진 + 이름(굵게) + 한 줄 설명(회색) + 평당 가격(굵게). 가로로 넘기는 묶음으로 보인다.
- 슬라이드 진행 표시: 폭 전체 1px 회색 선 위에 2~3px 두께 검정 막대. 막대 길이로 현재 위치를 보여준다.
- 후기: 왼쪽 두 자리 번호, 오른쪽 굵은 후기 문장(두 줄까지), 아래 회색 작성자 줄. 작성자는 가린 이름을 쓴다.

### 상단 바·탭 바
- 맨 위 공지 띠: 검정 바탕 높이 약 29px, 가운데 흰 작은 글자, 오른쪽 흰 X 닫기.
- 머리: 첫 사진 위에 투명하게 얹는다. 왼쪽 검정 "A" 심볼, 오른쪽 검정 햄버거 메뉴 아이콘.
- 첫 화면 사진 왼쪽 아래 반투명 알약에 "현재 / 전체 >" 슬라이드 번호.
- 하단 탭 바: 없음.

### 바텀시트·모달

### 토스트·스낵바

## 7. 아이콘·이미지·모션
- 아이콘: 가는 선 아이콘(햄버거, X, `>`). 수가 적다.
- 사진: 화면 대부분. 밝은 톤 시공 완료 사진. 소개 사진 위에 흰 워드마크를 얹기도 한다.
- 모션: 캡처로 알 수 없음. 확인 필요.

## 8. 글쓰기 톤(UX 라이팅)
- 구획 제목: 꾸미는 말 + 명사로 끝나는 두 줄("○○한 / ○○ 아파트" 꼴).
- 소개 문단: 합니다체, 두 줄 정도.
- 사례 설명: 마침표 없는 한 줄, "~을 소개합니다" 꼴.
- 가격: "평당 ○○~○○만 원대"처럼 범위로 적는다.
- 버튼: "○○ 더 보기 >", "서비스 알아보기 >" 꼴.
- 후기: 해요체 고객 문장 + 가린 이름.

- 공개 URL: 이번 작업 환경에서 사이트 접속이 막혀 직접 확인하지 못했다. 확인 필요.

근거와 한계
- 캡처 시기는 확인 필요. 5장 모두 홈 한 페이지를 위에서 아래로 나눠 찍은 화면이다.
- 이미지 폭이 약 453px이라 원래 기기 폭과 배율을 알 수 없다. 크기·간격은 이미지 1px을 CSS 1px로 본 추정이라 ±10% 정도 차이가 날 수 있다.
- 일부 캡처 왼쪽 끝의 옅은 회색 그림자는 화면 전환 중 겹친 것으로 보고 UI 색에서 뺐다.
- 사례 상세, 상담 신청(입력창), 메뉴를 연 화면, PC 화면은 보지 못했다.
- 후기 작성자 이름, 단지 이름 같은 화면 속 정보와 문장은 옮기지 않았다.
- 관찰 값은 서비스가 바뀌면 달라질 수 있다.

서비스 이름과 브랜드는 각 권리자의 것이다. 이 문서는 식별·학습용 참고 자료로 SylviaLab이 독자적으로 작성했다.
