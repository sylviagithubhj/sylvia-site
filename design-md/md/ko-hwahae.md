# 화해 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 촬영 시기 확인 필요, iOS 앱 홈 화면과 홈 스크롤 5장, 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

이 문서는 디자인 시스템의 다섯 층(원칙, 토큰, 컴포넌트, 사용 규칙, 구현·검증)을 한 파일로 줄인 요약이다. 맨 위 YAML은 도구와 AI가 그대로 읽는 값이고, 아래 글은 그 값을 언제·왜 쓰는지 설명한다.

## 1. 개요와 원칙
- 서비스 성격: 화장품 성분·리뷰를 보고 바로 살 수 있는 뷰티 앱. 랭킹, 성분 검색, 리뷰, 쇼핑(화해 단독 상품·화해배송)을 한 앱에서 제공한다.
- 디자인 인상 한 줄: 흰 바탕에 청록(#00a5aa) 포인트와 산호색(#ff8c82) 알약 배지. 상품 카드는 얇은 회색 테두리 상자에 담고, 리뷰 별점과 할인율을 숫자로 크게 보여 준다.
- 공식 시스템 이름: 확인 필요
- 디자인 원칙(공식 원칙은 확인하지 못했다)
  1. 청록은 브랜드 포인트에만 쓴다. 떠 있는 선물 버튼, 구획 제목 속 강조 단어, 투표 카드의 "vs". (관찰에서 정리)
  2. 산호색 알약은 작은 표시 전용이다. 인기검색어 라벨, 메뉴 배지(0원응모·NEW), 단독 상품 칩. (관찰에서 정리)
  3. 상품은 테두리, 콘텐츠는 그림자. 상품 이미지는 1pt 회색 테두리 상자, 투표·리뷰 카드는 옅은 그림자 카드. (관찰에서 정리)
  4. 리뷰 신뢰를 숫자로 보여 준다. 노란 별 + 별점 숫자 + 괄호 리뷰 수를 상품마다 붙인다. (관찰에서 정리)
  5. 정보는 선 아이콘, 혜택·이벤트는 광택 있는 3D 그림. (관찰에서 정리)
- 톤: 밝고 가볍게, 리뷰 숫자는 또렷하게.

### 이 문서를 읽는 AI 에이전트에게
- 색은 YAML 이름으로만 쓰고, 화면 코드에서는 `text-title`, `marker`, `accent-keyword` 같은 semantic을 먼저 고른다.
- 청록(`teal` #00a5aa)은 떠 있는 선물 버튼·제목 속 개인화 키워드·투표 "vs"에만, 산호(`marker` #ff8c82)는 작은 알약 표시에만, 빨강(`discount`)은 할인율에만 쓴다. 세 색을 서로 바꿔 쓰지 않는다.
- 상품은 `product-image-box`(1pt 테두리, 그림자 없음), 커뮤니티 콘텐츠는 `card-content`(그림자, 16pt)로 고른다.
- 상품 카드에는 별점 묶음(`rating`)을 빼지 않는다.
- 판단이 어려우면 색을 줄이고 리뷰 숫자를 또렷하게 남기는 쪽을 고른다.

### 특장점
- 개인화 키워드를 색으로 강조한다 — 구획 제목 속 피부 타입 같은 키워드만 청록 #00a5aa로 칠하고 나머지 제목은 #000000이다.
- 리뷰가 상품 카드의 중심이다 — 모든 상품 카드에 노란 별 #ffbe14 + 별점 숫자(#7a7a7a, 소수 둘째 자리) + 괄호 리뷰 수(#aeaeae)를 둔다. 리뷰 카드는 사진 위에 별 5개와 흰 제목·본문 2줄을 얹는다.
- 참여형 투표 카드가 있다 — 흰 그림자 카드 안에 굵은 질문(17pt) + 약 136×51pt #eefbfb 선택 버튼 2개 + 가운데 청록 "vs" + 포인트 "P" 아이콘(#06d1c9)과 참여 수를 담는다.
- 테두리와 그림자로 콘텐츠 종류를 가른다 — 상품 이미지 상자는 1pt #eeeeee 테두리·모서리 8pt, 투표·리뷰 카드는 옅은 그림자·모서리 16pt.
- 혜택 태그를 두 가지 색으로만 쓴다 — 단독·무료배송·한정특가는 #f0f0fb 바탕 + #6a6f9f 글자, "최저가"만 #fef0ee 바탕 + #f98879 글자.

### 배울 점
- 상품 목록과 커뮤니티 콘텐츠가 한 피드에 섞일 때 화해처럼 상품은 테두리 상자, 콘텐츠는 그림자 카드로 나눠 종류를 바로 알게 한다.
- 개인화 추천을 보여 줄 때 화해처럼 구획 제목 속 사용자 키워드(피부 타입)만 브랜드색으로 칠한다.
- 작은 표시(라벨·배지·칩)가 많을 때 화해처럼 한 색(산호 #ff8c82) 알약으로 묶어 브랜드색과 할인색이 섞이지 않게 한다.

## 2. 색상
값은 1배율 캡처 픽셀에서 읽었다. 넓은 면 색은 정확하고, 작은 글자 색은 글자 테두리 번짐 때문에 오차가 있다. 토큰 이름은 SylviaLab이 붙인 것이다.

### 색 체계
공개 토큰이 없다. 캡처 회색을 밝기 순 "관찰 단계"(gray-50~900)로 두고 역할 이름(semantic)을 얹었다. 브랜드·강조·태그 색은 단계 없이 한 값씩이다.

| 층 | 예시 | 쓰는 곳 |
|---|---|---|
| 관찰 단계(회색) | gray-50 #f7f7f7 … gray-900 #111111 | 토큰 정의 |
| 역할(semantic) | surface-weak, border-product, text-rating, marker, accent-keyword | 실제 화면 |
| 태그 짝 | tag-bg + tag-text, tag-hot-bg + tag-hot-text | 혜택 태그 두 종류 |
| 배너·광고 색 | #6599ff, #ccf5fc | 토큰 아님 |

### 역할별 색
- **청록 #00a5aa**: 떠 있는 선물 버튼 바탕, 구획 제목 속 개인화 키워드, 투표 "vs"·시간. 연한 짝 #eefbfb는 투표 선택 버튼 바탕, 포인트 아이콘은 #06d1c9. 눌림·선택 뒤 모양은 확인 필요.
- **산호 #ff8c82**: 인기검색어 라벨과 순위 숫자, 메뉴 배지(0원응모·NEW), 단독 상품 칩. 흰 11pt 굵은 글자를 얹는다.
- **빨강(#ff5555 / #f86755)**: 할인율 글자, "마이" 새 소식 점.
- **노랑 #ffbe14**: 리뷰 별만.
- **혜택 태그 조합**: 바탕 #f0f0fb + 글자 #6a6f9f(단독·무료배송·한정특가), "최저가"만 바탕 #fef0ee + 글자 #f98879.
- **어두운 태그 #282c2d**: "화해배송" 알약 하나.
- **글자 단계**: 제목·가격 #000000 → 질문·가격 #111111 → 상품명 #343434·#444444 → 닉네임 #666666 → 별점 #7a7a7a → 보조 #818181 → 리뷰 수 #aeaeae → 안내 #bcbcbc.
- **상태 색(성공·주의·오류)**: 캡처에 없다. 확인 필요.

### 색 사용 규칙
- 청록 #00a5aa는 떠 있는 선물 버튼, 제목 속 강조 단어, 투표 "vs"·시간에만 쓴다.

## 7. 패턴

## 10. Do & Don't
관찰 기반 문서의 규칙은 "이 서비스 화면에서 반복되는 규칙"을 SylviaLab이 정리한 것이다(공식 규칙 아님).

### Do
- 화면 좌우 여백은 약 18pt로 검색창·배너·카드·제목을 맞춘다.
- 상품 이미지는 124pt 정사각 상자, 1pt #eeeeee 테두리, 모서리 8pt에 흰 바탕 누끼로 넣는다.
- 투표·리뷰 카드는 흰 바탕 + 옅은 그림자, 모서리 16pt로 만든다.
- 상품마다 #ffbe14 별 + 별점 숫자(#7a7a7a) + 괄호 리뷰 수(#aeaeae)를 붙인다.
- 할인율(13pt/700 빨강)을 가격(16pt/700) 앞에 두고 가격 뒤 "원"은 작은 회색으로.
- 작은 표시는 산호 #ff8c82 알약 + 흰 11pt 굵은 글자로 만든다.
- 혜택 태그는 높이 약 17pt, 모서리 4pt, #f0f0fb 바탕 + #6a6f9f 글자로 붙인다.

### Don't
- 청록 #00a5aa를 할인·배지에 쓰지 않는다. 산호는 작은 표시, 빨강은 할인이다.
- 상품 이미지 상자에 그림자를 넣지 않는다. 그림자는 투표·리뷰 같은 콘텐츠 카드에만.
- "최저가" 외의 혜택 태그를 분홍으로 칠하지 않는다.
- 배너·광고 색(#6599ff, #ccf5fc)을 UI 토큰으로 쓰지 않는다.
- 정보 아이콘에 3D 그림을 쓰지 않는다. 3D는 아이콘 메뉴·떠 있는 버튼 전용이다.
- 리뷰 수 색(#aeaeae)을 본문 글자에 쓰지 않는다(대비 2.2:1).
