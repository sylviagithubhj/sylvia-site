# 화해 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 촬영 시기 확인 필요, iOS 앱 홈 화면과 홈 스크롤 5장, 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

## 1. 개요
- 서비스 성격: 화장품 성분·리뷰를 보고 바로 살 수 있는 뷰티 앱. 랭킹, 성분 검색, 리뷰, 쇼핑(화해 단독 상품·화해배송)을 한 앱에서 제공한다.
- 디자인 인상 한 줄: 흰 바탕에 청록(#00a5aa) 포인트와 산호색(#ff8c82) 알약 배지. 상품 카드는 얇은 회색 테두리 상자에 담고, 리뷰 별점과 할인율을 숫자로 크게 보여 준다.
- 공식 시스템 이름: 확인 필요
- 특징
  - 브랜드 강조색은 청록이다. 떠 있는 선물 버튼, 구획 제목 속 강조 단어(피부 타입 같은 키워드), 투표 카드의 "vs"에 쓴다.
  - 산호색 알약은 "작은 표시" 전용이다. 인기검색어 라벨, 아이콘 메뉴 위 배지(0원응모·NEW), 단독 상품 칩에 같은 색을 쓴다.
  - 할인율 빨강은 두 가지가 보인다. 가로 스크롤 카드는 #ff5555, 세로 목록 카드는 #f86755. 같은 토큰인지 확인 필요.
  - 리뷰 별은 노랑(#ffbe14), 별점 숫자는 회색, 리뷰 수는 괄호 안 더 옅은 회색이다.
  - 상품 이미지는 흰 바탕 누끼 사진을 1pt 회색 테두리 둥근 상자에 담는다.
  - 홈은 구획 제목 + 가로 스크롤 카드 줄을 반복해 쌓는다.
- 공개 자료 상황: 이번 작업에서는 공개 문서·오픈소스를 확인하지 못했다(네트워크 제한). 확인 필요.

## 4. 간격·레이아웃
- 기준 화면: 375pt 폭 아이폰.
- 화면 좌우 여백: 약 18pt. 검색창, 배너, 카드, 구획 제목이 같은 선에 맞는다.
- 간격 단계(관찰, pt): 4, 8, 10, 14, 16, 18, 30
- 아이콘 메뉴: 52×52pt 타일, 타일 사이 약 10pt, 가로 스크롤. 아래 12pt 이름.
- 가로 상품 카드: 이미지 상자 124×124pt, 카드 사이 약 14pt, 오른쪽에 다음 카드가 잘려 보인다.
- 세로 상품 목록: 2열 격자(카드 폭 약 162pt, 사이 약 16pt), 이어서 왼쪽 이미지 + 오른쪽 정보의 가로형 목록.
- 구획 사이: 카드끼리 약 30pt, 상품 줄 끝과 다음 구획 제목 사이 약 55pt.
- 하단 탭 바: 5칸, 홈 인디케이터 포함 약 79pt.
- 그리드: 확인 필요

## 6. 주요 컴포넌트
### 버튼
- 떠 있는 선물 버튼: 오른쪽 아래, 약 48×48pt, teal 바탕, 모서리 약 12pt, 안에 3D 선물 그림.
- 맨 위로 버튼: 선물 버튼 위, 흰 원(지름 약 36pt) + 그림자 + 검정 위 화살표.
- 투표 선택 버튼: 약 136×51pt 두 개, teal-light 바탕, 모서리 12pt, 가운데 14pt 글자. 사이에 청록 "vs".
- 텍스트 링크: 구획 제목 오른쪽 끝 `>` 화살표만 둔다.
- 일반 주요 버튼(구매 등): 캡처에 없음. 확인 필요.

### 검색창
- 홈 맨 위, 폭 약 297pt·높이 약 37pt 알약, gray-50 바탕, 회색 안내 글자, 오른쪽 돋보기. 옆에 장바구니 선 아이콘.
- 아래 줄: 산호색 "인기검색어" 알약 + 순위 숫자(산호색) + 검색어(굵은 검정) + 회색 상태 문구, 끝에 `>`.

### 배지·태그
- 산호색 알약: 높이 약 16~19pt, 흰 11pt 굵은 글자. 메뉴 아이콘 위에 걸치거나 상품명 위에 붙는다.
- "화해배송" 태그: 이미지 상자 왼쪽 위, dark-tag 바탕 알약, 흰 글자 + 작은 화살표.
- 혜택 태그: 높이 약 17pt, 모서리 4pt, 연보라 바탕(tag-bg) + 보라 회색 글자. "최저가"만 연분홍 바탕 + 산호 글자.

### 카드·리스트
- 투표 카드: 폭 약 337pt, 흰 바탕 + 그림자, 안쪽 여백 약 18pt. 닉네임 줄(굵은 회색 + 보통 회색, 오른쪽 청록 시간) → 굵은 질문 → 선택 버튼 2개 → 포인트 아이콘 + 참여 수.
- 가로 상품 카드: 테두리 상자 이미지 → 회색 브랜드명 + 검정 상품명(2줄 말줄임) → 노란 별 + 별점 + (리뷰 수) → 빨간 할인율 + 굵은 가격 + 회색 "원".
- 랭킹 카드: 가로 상품 카드 위에 금·은·동 메달 숫자 표시.
- 세로 목록 카드: 왼쪽 정사각 이미지(약 132pt), 오른쪽 상품명 15pt 2줄 → 회색 한 줄 설명 → 취소선 정가 → 할인율 + 굵은 검정 가격 → 혜택 태그 줄.
- 리뷰 카드: 폭 약 242pt, 위에 프로필 원 + 닉네임 머리(약 50pt), 아래 사진 위에 별 5개 + 흰 굵은 제목 + 흰 본문 2줄.
- 광고 배너: 폭 337pt·높이 약 85pt, 모서리 8pt, 오른쪽 아래 회색 "AD" 알약.
- 홈 큰 배너: 폭 약 339pt, 모서리 16pt, 좌우 다음 배너가 살짝 보이는 캐러셀. 오른쪽 위 반투명 흰 알약에 쪽수(5/15 꼴).

### 입력창

## 7. 아이콘·이미지·모션
- 아이콘: 1.5pt 안팎 선 아이콘(검색, 장바구니, 하단 탭).
- 아이콘 메뉴와 떠 있는 버튼은 광택 있는 3D 그림을 쓴다. 정보는 선 아이콘, 혜택·이벤트는 입체 그림.
- 상품 사진: 흰 바탕 누끼, 테두리 상자 안에 여백을 두고 넣는다.
- 모션: 캡처로 알 수 없음. 확인 필요.

## 8. 글쓰기 톤(UX 라이팅)
- 구획 제목: "○○가 추천하는 ○○", "지금 ○○?"처럼 짧은 명사형이나 질문형. 개인화 키워드(피부 타입)를 색으로 강조한다.
- 참여 유도: "○○하고 포인트 받기" 꼴로 행동과 보상을 한 줄에 붙인다.
- 안내 문장: 해요체("받았어요").
- 혜택 태그: 2~4글자 명사(무료배송, 최저가, 한정특가).
- 숫자: 별점은 소수 둘째 자리, 리뷰 수는 괄호, 할인율은 가격 앞.

- 화해 iOS 앱 화면 캡처 5장: 홈 첫 화면 1장 + 홈 스크롤 4장 (SylviaLab 벤치마킹 피그마 파일, 저장소에는 올리지 않음)
- 공개 URL: 이번 작업 환경에서 외부 접속이 막혀 확인한 URL이 없다. 확인 필요.

근거와 한계
- 화면 값은 모두 앱 캡처에서 잰 관찰값이다. 캡처 날짜는 화면에 없어 촬영 시기는 확인 필요.
- 캡처가 375pt 1배율이라 크기는 ±1pt, 작은 글자 색은 오차가 있다. 넓은 면 색(바탕, 버튼, 배지)은 정확하다.
- 홈 화면만 봤다. 검색 결과, 상품 상세, 성분 화면, 리뷰 쓰기, 장바구니, 다크 모드는 확인하지 못했다.
- 배너·광고·상품 사진 속 색은 시스템 색에서 뺐다.
- 관찰 값은 서비스가 바뀌면 달라질 수 있다.
- 서비스 이름과 브랜드는 각 권리자의 것이다. 이 문서는 식별·학습용 참고 자료로 SylviaLab이 독자적으로 작성했다.
