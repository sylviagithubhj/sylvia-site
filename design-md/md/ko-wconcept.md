# W컨셉 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 여름 기획 문구가 보이는 시기(2025년 6월쯤 추정), iOS 앱 홈 화면 1장, 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

이 문서는 디자인 시스템의 다섯 층(원칙, 토큰, 컴포넌트, 사용 규칙, 구현·검증)을 한 파일로 줄인 요약이다. 맨 위 YAML은 도구와 AI가 그대로 읽는 값이고, 아래 글은 그 값을 언제·왜 쓰는지 설명한다. 홈 화면 1장에서 잰 값이라 참고용이다.

## 1. 개요와 원칙
- 서비스 성격: 여성 패션 중심 온라인 편집숍 앱. 디자이너 브랜드 의류·잡화를 큐레이션해 판다.
- 디자인 인상 한 줄: 흰 바탕에 순수 검정(#000000) 글자와 아이콘. 선택은 검정 원으로 채우고, 하단 가운데 분홍 그라데이션 "플레이" 버튼 하나만 색이 강하다.
- 공식 시스템 이름: 확인 필요
- 디자인 원칙(공식 원칙은 확인하지 못함):
  1. 흑백으로 짠다. 글자·아이콘·로고·선택 표시가 모두 순수 검정 #000000이다. (관찰에서 정리)
  2. 색은 한 곳에만. 강한 색은 하단 가운데 플레이 버튼(#fc393d → #f01776)과 새 소식 점(#fa5500)뿐이다. (관찰에서 정리)
  3. 선택은 면으로 채운다. 선택 탭은 밑줄이 아니라 검정 원 안 흰 글자다. (관찰에서 정리)
  4. 둥글게 감싼다. 배너 카드 24pt, 칩·탭 원·배지·버튼은 모두 999px 원형이다. (관찰에서 정리)
- 톤: 흑백 잡지처럼 차분하게, 색은 플레이 버튼 하나에만.

### 특장점
- 선택 탭을 검정 원으로 채운다 — 상단 가로 탭의 선택 상태가 지름 약 32pt 검정 원 + 흰 15pt 글자다. 같은 모음의 무신사 앱 홈이 선택 탭을 흰 굵은 글자 + 2pt 밑줄로 표시하는 것과 다르다.
- 색을 한 버튼에 몰아준다 — 화면 전체가 #000000·#ffffff·회색인데, 하단 탭 바 가운데 플레이 버튼(지름 약 38pt)만 분홍 그라데이션(#fc393d → #f01776)이라 눈이 그쪽으로 간다.
- 배너를 카드 묶음처럼 겹친다 — 첫 배너는 모서리 약 24pt, 폭 약 326pt·높이 약 432pt 사진 카드이고, 뒤에 기울어진 회색 카드가 한 장 더 비친다.
- 추천 칩에 사진을 단다 — 흰 알약(높이 약 40pt) + 1pt #e8e8e8 테두리 + 왼쪽 작은 원형 상품 사진 + 14pt 글자를 2줄로 쌓아 가로 스크롤한다.

### 배울 점
- 흑백 위주 화면에서 선택 상태를 보일 때 W컨셉처럼 밑줄 대신 검정 원(지름 약 32pt) 안 흰 글자로 채운다.
- 한 기능을 밀고 싶을 때 W컨셉처럼 나머지를 흑백으로 두고 그 버튼 하나에만 그라데이션 색을 쓴다.
- 주제 칩을 만들 때 W컨셉처럼 글자 왼쪽에 작은 원형 사진을 붙여 무엇을 보여 줄지 미리 알린다.

### 관찰한 특징
- 기본 글자·아이콘·로고가 순수 검정이다.
- 선택된 상단 탭은 밑줄이 아니라 검정 원(지름 약 32pt) 안에 흰 글자로 표시한다.
- 새 소식은 주황 작은 점(#fa5500 근처)을 탭 이름 오른쪽 위에 붙인다.
- 홈 첫 배너는 모서리가 크게 둥근 카드(약 24pt)이고, 뒤에 기울어진 회색 카드가 겹쳐 카드 묶음처럼 보인다.
- 추천 주제 칩은 흰 알약 + 옅은 회색 테두리 + 왼쪽 작은 원형 사진이다.
- 공개 자료 상황: 이번 작업에서는 공개 문서·오픈소스를 확인하지 못했다. 확인 필요.

### 이 문서를 읽는 AI 에이전트에게
- 홈 화면 캡처 1장에서 잰 값이다. 가격·버튼·상세 화면 값은 없으니 지어내지 말고 비워 둔다.
- 색은 YAML 역할 이름(`text`, `selected`, `play-pink`, `chip-border`)으로 쓴다. 기본 글자·아이콘·선택 표시는 모두 `black` #000000이다.
- 강한 색은 두 곳뿐이다: 플레이 버튼 그라데이션(#fc393d → #f01776)과 새 소식 점(#fa5500). 다른 곳에 색을 더하지 않는다.
- 선택은 밑줄이 아니라 검정 원(지름 약 32pt) 채움으로 보인다. 모서리는 배너 24pt, 나머지 999px.
- 판단이 어려우면 흑백, 둥근 모양, 좌우 20pt 정렬을 고른다.

## 2. 색상
값은 1배율 캡처 픽셀에서 읽었다. 넓은 면 색은 정확하고, 작은 글자 색은 글자 테두리 번짐 때문에 오차가 있다. 토큰 이름은 SylviaLab이 붙인 것이다.

### 색 체계
공개된 색 체계가 없어 **관찰 팔레트 → 역할 이름** 두 층으로 정리했다(관찰에서 정리).

| 층 | 예시 | 쓰는 곳 |
|---|---|---|
| 관찰 팔레트 | `black`, `gray-50`, `pink-f01776` | 캡처에서 잰 값. YAML 정의에만 |
| 역할 이름 | `selected`, `tabbar-bg`, `play-pink`, `dot-orange` | 화면과 컴포넌트 |

- 팔레트는 검정·흰색과 무채색 회색 5개(#191919, #555555, #ababab, #cccccc, #e8e8e8, #f9f9f9), 그리고 강조 3개(#fc393d, #f01776, #fa5500)가 전부다.

### 브랜드·행동
| 토큰 | HEX | 쓰임 |
|---|---|---|
| black | #000000 | 로고, 상단 탭 글자, 선택 탭 원, 장바구니 숫자 배지, 선택된 하단 탭 아이콘 |
| play-pink | #f01776 | 하단 가운데 "플레이" 원 버튼(그라데이션 아래쪽 색) |
| play-red | #fc393d | 같은 버튼 그라데이션 위쪽 색(근처 값) |

### 바탕·선
| 토큰 | HEX | 쓰임 |
|---|---|---|
| white | #ffffff | 기본 바탕, 칩 바탕, 선택 탭 원 안 글자 |
| gray-50 | #f9f9f9 | 하단 탭 바 바탕 |
| gray-200 | #e8e8e8 | 칩 테두리(1pt, #ececec 근처까지 번짐) |

### 글자
| 토큰 | HEX | 쓰임 |
|---|---|---|
| text | #191919 | 칩 글자(근처 값, 검정일 수 있음) |
| gray-700 | #555555 | 선택된 하단 탭 이름(근처 값, 검정일 수 있음) |
| gray-450 | #ababab | 선택 안 된 하단 탭 이름(근처 값) |
| gray-400 | #cccccc | 선택 안 된 하단 탭 아이콘 |

### 상태
| 토큰 | HEX | 쓰임 |
|---|---|---|
| dot-orange / new-dot | #fa5500 | 상단 탭 새 소식 점(근처 값) |
| 가격·할인·success·error | 확인 필요 | 캡처에 가격과 상태 표시가 없음 |

### 역할별 색
- **검정(`selected`·`text` #000000)**: 글자, 아이콘, 로고, 선택 탭 원, 장바구니 배지. 선택 탭 원 위 글자는 흰색.
- **분홍 그라데이션(`play-red` → `play-pink`)**: 하단 가운데 플레이 버튼만. 위에 흰 아이콘·글자(대비 3.6~4.1:1).
- **주황(`dot-orange` #fa5500)**: 탭 이름 오른쪽 위 새 소식 점만.
- **하단 탭 바**: 바탕 #f9f9f9, 선택 아이콘 검정·이름 #555555 근처, 나머지 아이콘 #cccccc·이름 #ababab 근처.
- **칩**: 흰 바탕 + 1pt #e8e8e8 테두리 + #191919 근처 글자.
- 눌림·비활성 색: 확인 필요.

### 다크 모드
| 토큰 | HEX | 쓰임 |
|---|---|---|
| 전체 | 확인 필요 | 다크 모드 화면을 보지 않음 |

### 색 사용 규칙
- 글자·아이콘·로고·선택 표시는 순수 검정 #000000을 쓴다.
- 분홍 그라데이션(#fc393d → #f01776)은 하단 가운데 플레이 버튼에만 쓴다. 정확한 시작·끝 값과 방향은 1배율이라 확인 필요.
- 주황 #fa5500은 새 소식 점에만 쓴다.
- 하단 탭 바는 #f9f9f9 바탕, 선택 아이콘 검정, 나머지 #cccccc.
- 칩 테두리는 1pt #e8e8e8.
- 첫 배너 카드 속 사진·글자 색과 뒤 회색 카드 색, 칩 속 작은 사진 색은 시스템 색에서 뺐다.

### Don't
- 분홍 그라데이션을 플레이 버튼 밖(배너, 칩, 탭)에 쓰지 않는다.
- 주황 #fa5500을 점보다 큰 면이나 글자에 쓰지 않는다.
- 기본 글자를 회색으로 낮추지 않는다. 기본은 #000000.
- 선택 안 된 탭 이름 #ababab을 #f9f9f9 위 일반 글자로 쓰지 않는다(2.2:1).
- 사진 속 색을 UI 색으로 뽑아 쓰지 않는다.

## 3. 타이포그래피
- 글꼴: iOS 시스템 글꼴(추정. 한글은 Apple SD Gothic Neo와 같은 모양). 전용 글꼴은 확인 필요.
- 로고: 굵은 영문 대문자 워드마크(높이 약 14pt), 검정.
- 대체 글꼴: -apple-system, 'Apple SD Gothic Neo', 'Noto Sans KR', sans-serif

### 위계와 사용처
크기는 1배율 캡처의 글자 높이로 계산한 추정값이다(±1pt). 행간은 확인 필요. 홈 화면에 있는 세 단계만 적는다.

| 단계 | 크기(pt) | 굵기 | 행간 | 쓰임 |
|---|---|---|---|---|
| tab | 15 | 500 | 확인 필요 | 상단 가로 탭(선택 탭은 검정 원 안 흰 글자, 굵기 확인 필요) |
| chip | 14 | 500 | 확인 필요 | 추천 주제 칩 글자(굵기 확인 필요) |
| tabbar-label | 10 | 400 | 확인 필요 | 하단 탭 이름 |

### 규칙
- 상단 탭은 15pt, 칩은 14pt, 하단 탭 이름은 10pt로 쓴다.
- 탭·칩 글자는 검정(칩은 #191919 근처). 선택 탭 글자만 흰색이다.
- 제목·본문·가격 단계는 캡처에 없어 확인 필요.

### Don't
- 탭·칩 글자를 15pt·14pt보다 키워 위계를 섞지 않는다(관찰한 단계 안에서).
- 선택 탭 글자를 검정으로 두지 않는다. 검정 원 위 흰 글자.
- 10pt 하단 탭 이름보다 작은 글자를 쓰지 않는다.

| 구획 사이 세로 간격 | 확인 필요 |

### 화면 구조(위→아래)
- 상단 바: 왼쪽 로고, 오른쪽 검색·장바구니(검정 숫자 배지). 높이 약 44pt(상태 표시줄 아래).
- 상단 탭: 가로 스크롤, 탭 사이 약 10pt. 선택 탭 원 지름 약 32pt.
- 첫 배너 카드: 폭 약 326pt, 높이 약 432pt, 왼쪽 약 25pt에서 시작. 뒤에 기울어진 카드가 왼쪽·오른쪽으로 비친다.
- 칩: 높이 약 40pt, 2줄, 가로 칩 사이 약 6pt, 줄 사이 약 10pt, 가로 스크롤.
- 하단 탭 바: 홈 인디케이터 포함 약 81pt, 바탕 #f9f9f9.

### 간격 적용 규칙
- 로고·첫 탭·첫 칩을 좌우 약 20pt 같은 선에 맞춘다.
- 탭 사이와 칩 줄 사이는 약 10pt, 가로 칩 사이는 약 6pt.
- 가로 스크롤 목록(탭, 칩)은 화면 오른쪽 끝으로 넘친다.

### Don't
- 로고·첫 탭·첫 칩의 왼쪽 선을 어긋나게 두지 않는다(좌우 약 20pt).
- 가로 스크롤 목록을 화면 안에 딱 맞춰 자르지 않는다. 오른쪽으로 넘쳐 보이게 둔다.
- 관찰한 간격(6·10·20·25pt) 밖의 값을 새로 만들지 않는다.

## 5. 모서리·고도·모션
| 토큰 | 값 | 쓰임 |
|---|---|---|
| radius-lg | 24px | 홈 첫 배너 카드(관찰 20~24) |
| radius-full | 999px | 추천 주제 칩, 선택 탭 원, 장바구니 배지, 플레이 버튼, 칩 속 사진, 배너 위 메뉴 버튼 |

- 픽셀 단위는 iOS pt와 같다고 보고 적었다(1pt = CSS 1px).
- 테두리: 1pt #e8e8e8(칩 테두리).

### 고도
- 확인 필요. 배너 카드 뒤 카드 겹침은 보이나 그림자 여부는 1배율이라 판단 어렵다.
- 층은 흰 바탕 위 사진 카드, 하단 탭 바만 #f9f9f9 면으로 나뉜다.

### 모션
- 확인 필요. 배너가 카드 묶음처럼 넘어가는 것으로 보이나 캡처로 알 수 없다.

### Don't
- 칩·탭 원·배지·버튼을 각지게 만들지 않는다(999px).
- 배너 카드 모서리를 999px 알약으로 만들지 않는다. 카드는 약 24pt.
- 관찰하지 못한 그림자를 만들어 넣지 않는다.

## 6. 컴포넌트
컴포넌트마다 변형, 상태, 쓰는 때, 쓰지 않는 때를 적는다. 보지 못한 상태는 `확인 필요`.

### 6.1 버튼
**크기**

| 크기 | 높이 | 좌우 여백 | 모서리 | 글자 |
|---|---|---|---|---|
| 플레이 원 | 약 38pt | — | 999px | 확인 필요 |
| 배너 메뉴 원 | 약 35pt | — | 999px | — |
| 일반 버튼 | 확인 필요 | 확인 필요 | 확인 필요 | 확인 필요 |

**종류**

| 변형 | 모양 | 쓰는 때 |
|---|---|---|
| 플레이 버튼 | 하단 탭 바 가운데, 지름 약 38pt 분홍 그라데이션 원 + 흰 재생 아이콘 + 흰 "플레이" 글자 | 플레이 화면으로 가기 |
| 배너 위 메뉴 버튼 | 배너 오른쪽 아래 어두운 반투명 원(지름 약 35pt) + 흰 점 4개 아이콘 | 배너 묶음 메뉴 |
| 일반 주요 버튼(구매·장바구니) | 캡처에 없음. 확인 필요 | 확인 필요 |

- 상태: 눌림·비활성·로딩 확인 필요.
- 쓰지 않는 때: 분홍 그라데이션을 플레이 버튼 밖에 쓰지 않는다(관찰한 화면에서는 한 곳뿐).
- 접근성: 원형 버튼(35~38pt)은 44pt보다 작으니 누를 영역을 넓힌다(구현 권장). 아이콘만 있는 메뉴 원에는 `accessibilityLabel`(구현 권장).

### 6.2 입력창
- 캡처에 없음. 상단 바에는 검색 아이콘만 있다. 확인 필요.

### 6.3 칩·탭
- 상단 탭: 15pt 검정 글자. 선택 탭은 검정 원(지름 약 32pt) + 흰 글자. 일부 탭 오른쪽 위에 주황 점(#fa5500).
- 추천 주제 칩: 흰 알약, 1pt #e8e8e8 테두리, 왼쪽에 작은 원형 사진 + 14pt 글자. 높이 약 40pt, 2줄로 쌓아 가로 스크롤.
- 상태: 선택·비선택(탭)만 봤다. 칩 선택 상태는 확인 필요.
- 쓰지 않는 때: 선택 탭에 밑줄을 쓰지 않는다(관찰한 화면에서는 원으로만 표시).
- 규칙: 칩은 2줄로 쌓아 가로 스크롤하고, 칩 사이 약 6pt·줄 사이 약 10pt. (관찰에서 정리)
- 접근성: 선택 탭에 선택 상태(`accessibilityTraits = .selected`)를 알리고, 새 소식 점은 "새 소식" 같은 대체 텍스트로도 알린다(구현 권장).

### 6.4 카드·리스트
- 첫 배너 카드: 큰 모서리(약 24pt) 사진 카드, 아래쪽에 겹친 제목·부제 글자, 오른쪽 아래 메뉴 원. 뒤에 기울어진 카드가 한 장 더 보인다.
- 상품 카드·가격: 캡처에 없음. 확인 필요.

### 6.5 상단 바·하단 탭 바
- 상단 바: 흰 바탕, 로고 왼쪽, 아이콘(검색·장바구니) 오른쪽. 장바구니 숫자 배지는 검정 원.
- 하단 탭 바: #f9f9f9 바탕, 아이콘 + 한글 이름 5개(홈·카테고리·플레이·하트·마이). 선택 아이콘 검정, 나머지 #cccccc. 이름은 선택 #555555 근처, 나머지 #ababab 근처. 가운데 플레이만 분홍 원.

### 6.6 바텀시트·모달
- 캡처에 없음. 확인 필요.

### 6.7 토스트·배지
- 토스트·스낵바: 캡처에 없음. 확인 필요.
- 배지: 장바구니 숫자 배지는 검정 원(999px). 새 소식은 주황 점 #fa5500.

### 6.8 아이콘·이미지
- 아이콘: 검정 아이콘. 하단 탭은 채운 모양 아이콘(선택 검정, 나머지 연회색).
- 이미지: 모델 착용 사진을 큰 둥근 카드에 담는다. 칩에는 작은 원형 상품 사진.
- 오른쪽 아래에 작은 상품 사진 떠 있는 창이 보인다(쓰임 확인 필요).

## 7. 패턴
- 홈 첫 화면: 상단 바(로고·검색·장바구니) → 가로 스크롤 탭(선택은 검정 원) → 카드 묶음 배너(24pt) → 사진 달린 추천 칩 2줄 → 하단 탭 바(가운데 플레이 버튼).
- 새 소식 알림: 탭 이름 오른쪽 위 주황 점.
- 목록 → 상세: 확인 필요(상품 목록·상세 화면을 보지 않았다).
- 검색: 확인 필요(상단 바 검색 아이콘만 확인).
- 빈 상태·오류: 확인 필요(캡처에 없다).
- 폼·결제: 확인 필요.
- 예시 문구: 해당 화면 정보가 없어 쓰지 않는다. 확인 필요.

## 10. Do & Don't
관찰 기반 문서의 규칙은 "이 서비스 화면에서 반복되는 규칙"을 SylviaLab이 정리한 것이다(공식 규칙 아님).

### Do
- 글자·아이콘·로고는 순수 검정 #000000으로 쓴다.
- 선택 탭은 지름 약 32pt 검정 원 + 흰 15pt 글자로 표시한다.
- 새 소식은 탭 이름 오른쪽 위 주황 점 #fa5500으로 알린다.
- 추천 칩은 흰 알약, 1pt #e8e8e8 테두리, 높이 약 40pt, 왼쪽 원형 사진으로 만든다.
- 첫 배너는 모서리 약 24pt 사진 카드로 두고 뒤에 기울어진 카드를 겹친다.
- 로고·첫 탭·첫 칩을 좌우 약 20pt 선에 맞춘다.

### Don't
- 선택 탭에 밑줄을 쓰지 않는다.
- 분홍 그라데이션(#fc393d → #f01776)을 플레이 버튼 밖에 쓰지 않는다.
- 회색 글자(#555555 등)로 기본 글자를 대신하지 않는다. 기본은 #000000이다.
- 칩·버튼·배지를 각지게 만들지 않는다(모두 999px).
- 선택 안 된 하단 탭 이름 #ababab을 #f9f9f9 바탕 본문 글자로 쓰지 않는다(대비 2.2:1).
