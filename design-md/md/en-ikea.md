# 이케아(IKEA) 앱 디자인 시스템

> 근거: 관찰 기반 (앱 캡처: 2024년 11월 25일 iOS 이케아 앱 홈 화면 3장(같은 화면을 위·가운데·아래로 나눠 찍은 것), 375pt 폭 1배율 이미지에서 픽셀 측정. 실측일 2026-10-31)
> 작성: SylviaLab · 최종 수정 2026-10-31

## 1. 개요
- 서비스 성격: 가구·홈퍼니싱 브랜드 이케아의 쇼핑 앱. 홈에서 신제품 소식, 공간별 아이디어, 내 공간을 꾸며 보는 기능(IKEA Kreativ)을 보여 주고, 하단 탭으로 검색·매장·위시리스트·장바구니로 간다.
- 디자인 인상 한 줄: 흰 바탕에 거의 검정(#111111) 글자, 큰 사진. 브랜드 파랑(#0058a3)은 카드 하나에만 넓게 쓰고, 버튼은 검정 알약이다.
- 공식 시스템 이름: 확인 필요 (이번 작업은 캡처만 근거로 썼다)
- 특징
  - 글자와 주요 버튼은 순수 검정이 아니라 #111111이다. 순수 검정(#000000)은 맨 위 큰 인사 제목에서만 읽혔다.
  - 브랜드 파랑 #0058a3은 기능 소개 카드 바탕 한 곳에만 넓게 나온다. 버튼·링크 색으로는 보이지 않았다.
  - 누르는 것(주요 버튼, 사진 위 칩, 원형 화살표 버튼)은 모두 완전히 둥글다. 카드는 8pt 안팎으로 살짝만 둥글다.
  - 사진 카드는 그림자로 띄우고, 공간 아이디어 사진은 모서리 없이 가로로 이어 붙인다.
  - 브랜드 노랑은 이번 캡처에서 UI 요소로 보이지 않았다. 확인 필요.

## 2. 색상
값은 1배율 PNG 픽셀에서 읽었다. 넓은 면 색은 정확하고, 작은 글자 색은 글자 테두리 번짐 때문에 오차가 있다. 토큰 이름은 SylviaLab이 붙인 것이다. 사진 속 색(가구, 벽, 옆 카드의 빨강 사진)은 넣지 않았다.

## 4. 간격·레이아웃
- 기준 화면: 375pt 폭 아이폰.
- 화면 좌우 여백: 24pt(큰 제목, 주요 버튼, 파랑 카드, 아래 카드). 소식 구획 제목과 소식 카드만 20pt에서 시작한다.
- 간격 단계(관찰, pt): 8, 12, 16, 20, 24, 40
- 소식 카드: 폭 320pt, 높이 약 306pt(사진 180pt + 흰 글 영역). 다음 카드와 12pt 띄우고, 오른쪽에 다음 카드가 살짝 보이는 가로 스크롤.
- 공간 아이디어 사진: 240×320pt(3:4) 세로 사진, 사이 8pt, 화면 왼쪽 끝부터 붙어 가로 스크롤.
- 파랑 카드: 폭 327pt, 사진 약 185pt + 파랑 영역 약 220pt. 안쪽 여백 약 20pt.
- 구획 사이: 40pt 이상 크게 띄운다(사진 끝 → 버튼 24pt, 버튼 → 다음 카드 약 64pt).
- 하단 탭 바: 5칸 아이콘, 홈 인디케이터 포함 높이 약 84pt.
- 그리드: 확인 필요

## 5. 모서리·그림자·테두리
픽셀 단위는 iOS pt와 같다고 보고 적었다(1pt = CSS 1px).

| 토큰 | 값 | 쓰임 |
|---|---|---|
| radius-none | 0px | 공간 아이디어 사진, 소식 카드 사진의 아래쪽 |
| radius-sm | 4px | 소식 카드(위 모서리 약 4pt, 아래 모서리는 거의 각짐) |
| radius-md | 8px | 파랑 기능 소개 카드, 아래 사진 카드 |
| radius-full | 999px | 주요 버튼, 사진 위 칩, 원형 화살표 버튼, 알림 배지 |
| shadow-card | 옅은 회색 그림자 | 소식 카드. 아래로 약 15pt, 옆으로 약 8pt 번진다(#e6e6e6 → 흰색) |
| divider | 1pt #f4f4f4 | 하단 탭 바 위쪽 |

- 누르는 것은 완전히 둥글게, 정보 카드는 4~8pt, 사진은 각지게 나눈다.
- 그림자 정확한 값(흐림, 투명도)은 확인 필요.

## 6. 주요 컴포넌트
### 버튼
- 주요 버튼: ink(#111111) 바탕 알약, 폭 327pt(좌우 24pt 여백 꽉 채움), 높이 56pt, 흰 14pt 굵은 글자 가운데 정렬.
- 원형 화살표 버튼: 지름 약 42pt 흰 원, 가운데 검정 오른쪽 화살표. 파랑 카드 왼쪽 아래.
- 보조 버튼, 외곽선 버튼, 비활성 상태: 캡처에 없음. 확인 필요.

### 칩
- 사진 위 칩: ink 바탕 알약, 높이 약 38pt, 흰 12pt 굵은 글자. 공간 사진 아래쪽 가운데 근처에 얹는다.

### 입력창
- 캡처에 없음. 확인 필요.

### 카드·리스트
- 소식 카드: 흰 카드 + 옅은 그림자. 위쪽은 꽉 찬 사진(180pt), 아래 흰 영역에 굵은 제목 14pt와 회색 한 줄 설명 12pt. 글 영역 왼쪽 여백 약 33pt.
- 기능 소개 카드: 위쪽은 동영상(오른쪽 아래 일시정지 표시), 아래쪽은 brand-blue 바탕. 작은 굵은 기능 이름 → 큰 흰 3줄 문구(18pt) → 흰 원형 화살표 버튼 순서로 쌓는다.
- 공간 아이디어 줄: 구획 머리말(14pt) + 큰 제목(22pt), 아래 3:4 사진 가로 스크롤, 그 아래 꽉 찬 검정 버튼.

### 상단 바·탭 바
- 상단 바: 제목 없이 왼쪽 사람 아이콘(약 16pt), 오른쪽 알림 종 아이콘. 알림 종 오른쪽 위에 지름 약 18pt notification 배지와 흰 숫자.
- 하단 탭 바: 흰 바탕, 위쪽 1pt gray-100 선. 아이콘만 5개(반짝임·검색 목록·매장·하트·장바구니), 아이콘 약 16~20pt. 선택 탭은 ink, 나머지는 gray-700. 탭 이름 글자는 없다.

### 바텀시트·모달
- 캡처에 없음. 확인 필요.

### 토스트·스낵바
- 캡처에 없음. 확인 필요.

## 7. 아이콘·이미지·모션
- 아이콘: 약 1.5pt 굵기 선 아이콘, 끝이 둥글다. 선택된 하단 탭(반짝임 모양)만 색이 진하다.
- 사진: 화면 대부분을 차지한다. 실내 공간·제품 연출 사진을 크게, 여백 없이 쓴다.
- 홈 맨 위 큰 제목 아래에 굵은 아래 화살표 그림(약 30×47pt)이 있다. 아래로 내려 보라는 표시로 보인다.
- 모션: 기능 소개 카드는 동영상이 재생되고 일시정지 표시가 있다. 그 밖의 전환·움직임은 확인 필요.

## 8. 글쓰기 톤(UX 라이팅)
- 안내 문장은 해요체·권유형으로 끝낸다("~해보세요", "~하세요" 꼴).
- 구획 제목은 짧은 명사구, 그 위 머리말은 권유형 한 줄로 제목을 풀어 준다.
- 버튼은 "모든 ○○ 둘러보기"처럼 동사로 끝나는 짧은 행동 문구.
- 칩은 공간 이름 한 단어(거실 같은 명사).
- 기능 이름·브랜드 이름은 영문 그대로 둔다(IKEA, Kreativ).

## 10. 참고 자료
- 이케아 iOS 앱 화면 캡처 3장 (2024년 11월 25일 홈 화면, SylviaLab 벤치마킹 피그마 파일, 저장소에는 올리지 않음). 피그마에는 같은 3장이 두 번씩 들어 있어 6개 중 서로 다른 3장만 썼다.

근거와 한계
- 공식 디자인 문서나 코드는 이번에 확인하지 않았다. 이 문서의 값은 모두 앱 캡처에서 잰 관찰값이다.
- 캡처는 2024년 11월 앱 홈 화면 한 곳뿐이다. 검색, 상품 목록, 상품 상세, 장바구니, 매장, 다크 모드 화면은 보지 못했다.
- 375pt 1배율 캡처라 크기는 ±1pt, 작은 글자 색은 오차가 있다. 넓은 면 색(흰색, #111111, #0058a3)은 정확하다.
- 브랜드 노랑, 상태 색(성공·경고·오류), 글꼴 정확한 이름은 확인 필요.
- 관찰 값은 서비스가 바뀌면 달라질 수 있다.

서비스 이름과 브랜드는 각 권리자의 것이다. 이 문서는 식별·학습용 참고 자료로 SylviaLab이 독자적으로 작성했다.
